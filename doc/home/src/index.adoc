= Open Chiplet Atlas Harness (OCAH)

The Open Chiplet Atlas Harness (OCAH) is an OCA-compliant, open-source chiplet
framework: a reusable implementation vehicle for the Open Chiplet Atlas
(OCA) standard. It packages the common, non-differentiating infrastructure
every chiplet needs -- security, boot, system management, debug, test, and
die-to-die integration -- so adopters can focus their effort on their own
value-differentiating application logic.

image::oca-banner.png[OCA banner,width=600]

[NOTE]
OCAH is the *Harness* pillar of the wider
https://www.openchipletatlas.org[Open Chiplet Atlas (OCA)] ecosystem,
alongside the OCA Architecture specification and the OCA Compliance program.

OCAH also reuses third-party open-source IP rather than reimplementing it.
Tenstorrent generally maintains a fork of each such dependency to support
coordinated development, keeps it synchronized with the upstream project, and
contributes suitable changes back upstream where possible. The exact
revisions and subsets imported into this repository are defined in
`Bender.yml`; the
xref:ocah-starting:ROOT:workflows.adoc#vendor-packages[Getting Started Guide]
explains how Bender materializes and updates them.

The SMC's Rocket CPU cluster is a further exception: it is generated
SystemVerilog output of the
https://chipyard.readthedocs.io/en/stable/Generators/Rocket.html[Chipyard
Rocket-chip] Chisel generator rather than a checked-out upstream source
tree, so there is no upstream repository to fork or pin. It lives flat in
the repository under
`hw/sys/smc/rtl/smc_cpu/chipyard_generated_files/`.
