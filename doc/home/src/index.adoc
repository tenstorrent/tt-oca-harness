= Open Chiplet Atlas Harness (OCAH)

The Open Chiplet Atlas Harness (OCAH) is an OCA-compliant, open-source chiplet
framework: a reusable implementation vehicle for the Open Chiplet Atlas
(OCA) standard. It packages the common, non-differentiating infrastructure
every chiplet needs -- security, boot, system management, debug, test, and
die-to-die integration -- so adopters can focus their effort on their own
value-differentiating application logic.

image::oca-banner.png[OCA banner,width=600]

[NOTE] 
OCAH is the *Harness* pillar of the wider
https://www.openchipletatlas.org[Open Chiplet Atlas (OCA)] ecosystem,
alongside the OCA Architecture specification and the OCA Compliance program.

== Ecosystem repositories

OCAH integrates both Tenstorrent-owned projects and third-party open-source
projects. For third-party dependencies, Tenstorrent generally maintains a fork
to support coordinated development, keeps it synchronized with the upstream
project, and contributes suitable changes back upstream where possible. The
exact revisions and subsets imported into this repository are defined in
`Bender.yml`; the
xref:ocah-contributing:ROOT:workflows.adoc#vendor-packages[Contributing Guide]
explains how Bender materializes and updates them.

|Advanced eXtensible Interface components

|Intelligent direct memory access engine

|UNBENT

|AXI bus-error-unit wrapper for chiplet integrators; not instantiated in

|AXI Stream
|https://github.com/tenstorrent/tt-axi_stream[tenstorrent/tt-axi_stream]
|Compiled into iDMA's generated backend bundle; OCAH's AXI-only DMA
configuration does not instantiate it

|OBI
|https://github.com/tenstorrent/tt-obi[tenstorrent/tt-obi]
|Supplies the types iDMA's OBI backend headers reference; OCAH does not

|https://github.com/tenstorrent/tt-register_interface[tenstorrent/tt-register_interface]
|AXI-to-register bridge (`axi_to_reg_v2`) used by the iDMA control interface

|Adams Bridge
|https://github.com/chipsalliance/adams-bridge[chipsalliance/adams-bridge]
|Post-quantum cryptography engine

|Caliptra RTL
|https://github.com/chipsalliance/caliptra-rtl[chipsalliance/caliptra-rtl]
|Key-vault client helpers for Adams Bridge

|VeeR EL2
|https://github.com/tenstorrent/tt-Cores-VeeR-EL2[tenstorrent/tt-Cores-VeeR-EL2]
|SEP processor core

|PicoRV32
|https://github.com/tenstorrent/tt-picorv32[tenstorrent/tt-picorv32]
|Key Manager processor core

|AoU RTL

|I3C Core
