= Issue alignment

Ingest copies form picks onto empty
https://github.com/orgs/tenstorrent/projects/291[Project 291]
fields on every issue open or edit. It assigns a PR to its opener.
It does not assign issues.

The curator (`.github/ISSUE_CURATION.md`) can later fill leftover fields
and assign an unassigned issue from a named person, the parent assignee,
or the usual or majority owner of the title prefix. It is in the tree,
*disabled*.
