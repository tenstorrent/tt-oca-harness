= Issue alignment

Ingest copies form picks onto empty
https://github.com/orgs/tenstorrent/projects/291[Project 291]
fields on every issue open or edit. It needs Workstream, Subsystem, and
Component to run; it also copies Priority and Target release when present.
It prefixes the title from those picks (`[WORKSTREAM/SUBSYSTEM]` or
`[WORKSTREAM/SUBSYSTEM-COMPONENT]`). It assigns a PR to its opener. It
does not assign issues, and it does not police PR Summary or Test plan.

The curator (`.github/ISSUE_CURATION.md`) later fills leftover fields,
assigns an unassigned issue from a named person, the parent assignee,
or the usual or majority owner of the title prefix, and copy-edits
issue and PR titles and bodies for capitalization, imperative mood,
and grammatical English without adding or removing content. Issue
titles keep the ingest taxonomy prefix. PR titles use a path-like
scope (`hw/smc:`, `dv:`, `github:`), or `treewide:` when the change
spans several trees, not `[WORKSTREAM/SUBSYSTEM]` and
not `feat(scope):`. It comments
on a PR that has been approved for 3 days and is still open, and it
reminds an issue assignee 3 days before a milestone or issue due date.
It runs at 05:00 and 16:00 PDT, and on dispatch of
`ocah-project-curator.lock.yml`. Each run covers items opened at or
after the last successful run; the first successful run covers every
open issue and PR. Approved-but-unmerged PRs and issues with a due
date in the next 3 days are always included.

A Monday run of `ocah-weekly-issue-activity.lock.yml` posts a General
discussion with opened-versus-closed and time-to-close charts built
from the Issues API. Those charts are not GitHub Insights and are
not Project 291 Insights. A daily run of
`ocah-discussion-task-miner.lock.yml` opens Task issues for concrete
action items in Ideas discussions from the last 7 days. Those issues
skip the issue form; the curator fills leftover fields.
