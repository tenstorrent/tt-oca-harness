|OCAH-HWSR-GENERAL-000 |GENERAL |OCAH shall always generate level sensitive, active-high, wired interrupts upon detection of an error
|OCAH-HWSR-GENERAL-001 |GENERAL |OCAH shall be capable of performing HW-driven error injection to test against latent faults in diagnostic mechanisms
