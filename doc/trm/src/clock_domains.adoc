= Clock Domains
:description: OCAH clock domains, the always-on reference clock, and the reference counter.

[[ocah-clock-domains]]

OCAH distinguishes low-level management timing from functional application
clocks. The SMC receives an always-on reference clock (`clk_ref_i`) that is
available from power-on, before any PLL is locked. Using this reference clock,
the SMC controls the PLLs during early bring-up and generates the primary
system clock (`clk_smu_i`) that is then distributed to the SMC itself, the
SEP, and the DTP.

The SMN lives in its own clock domain with respect to the SMU --- as highlighted
by the clock domain crossing in the top level diagram --- and with respect
to the application logic.

The following table summarises the clock domains present in OCAH.

[[ocah-clock-domain-table]]
.OCAH Clock Domains
[cols="<25%,<25%,<50%",options="header"]
|===
|Clock |Subsystem |Description

|`clk_smu_i`
|SMU (SMC, SEP, DTP)
|Primary system clock, generated by the PLL under SMC control. Distributed
internally to the SMC, SEP, and DTP subsystems. Drives the CPU cluster,
fabric interconnect, peripheral controllers, and DTP cross-trigger / AXI
bridges.

|`clk_smn_i`
|SMN
|System Management Network clock. Independent of `clk_smu_i`; clock-domain
crossings (CDCs) are used at the SMU-SMN boundary to isolate the management
fabric timing from the SMU subsystem clock.

|`clk_ref_i`
|SMC
|Always-on reference clock, available before PLL lock. Used by the SMC for
early bring-up, PLL control, reset synchronisation, and peripherals requiring
a stable, lower-frequency source.

|`clk_periph_i`
|SMC
|Peripheral clock domain. Drives SMC peripheral subsystems. The reset unit
generates a dedicated synchronised reset (`rst_primary_periph_clk`) in this
domain.

|`clk_telemetry_i`
|SMC
|ATB telemetry clock domain. Separate clock for Advanced Trace Bus data
collection, with its own reset (`rst_telemetry_ni`).

|`clk_sep_wdt_i`
|SEP
|Low-frequency watchdog timer clock. Must be independent of the system clock
so the WDT can detect system clock failures.

|`jtag_tck`
|DTP / SEP
|JTAG Test Clock. Drives PTAP, STAP state machines, and all JTAG-domain scan
logic inside the DTP/SMC/SEP.

|`entropy_rosc_sample_clk_i`
|SEP
|Ring-oscillator sample clock for the entropy source (TRNG). Must be
asynchronous to `clk_i` and typically runs between 100 and 400 MHz.
|===

[[ocah-reference-counter]]
== Reference Counter

Both the SMC and the SEP expose a free-running 64-bit reference counter in their
CPU control register block (the `REFERENCE_COUNTER` CSR), clocked by the
always-on reference clock (`clk_ref_i`). It advances continuously from reset,
independent of the system clock (`clk_smu_i`) frequency or PLL state. Its value
is synchronised into the CPU clock domain for software reads, and software may
write the CSR to reload the counter, after which it resumes counting from the
loaded value. Both subsystems share the same implementation
(`prim_refclk_count_w_cdc`) and behave identically.
