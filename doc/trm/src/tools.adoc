Tools
-----

[WARNING]
====
This section is currently under development. *Content has been taken
verbatim from existing documentation.* More content will be added as the
project matures.
====

This section outlines the development tools used in the OCAH project,
categorized by purpose and licensing model.

FOSS identifies Free Open Source Software tools. If the tool doesn't
have such a tag, then by default it is a commercial tool.

We will also develop a set of custom tools for OCAH for tasks such as
AXI/APB crossbar generation, SystemRDL processing and so on. These will
be documented here.

=== General Development Tools

==== Required Tools

* *Git*: Source code repository (FOSS)
* *Python 3.9+*: For build scripts and SystemRDL tools (FOSS)
* *Bender*: Manage IP dependencies and build automation (FOSS)
* *Make*: Build HW and SW (FOSS)
* *PeakRDL*: SystemRDL processing and RTL generation (FOSS)

==== Optional Tools

* *Bazel*: Alternative build system (FOSS)

=== Documentation Tools

* *Asciidoctor*: AsciiDoc documentation processing and PDF generation (FOSS)
* *Antora*: Multi-repository documentation site generator for AsciiDoc (FOSS)
* *DrawIO*: Create diagrams and generate SVG figures (FOSS)
* *Wavedrom/Wavedrompy*: Timing diagrams (FOSS)

=== Hardware Development Tools

==== Open Source Tools (FOSS)

* *Verilator*: HDL simulator
* *Verible*: Linting and style checker
* *Svlint*: SystemVerilog linter
* *Surfer*: Waveform viewer
* *Yosys*: Logic synthesis tool

==== Commercial Tools

* *VCS*: Simulator (requires license)
* *Verdi*: Waveform viewer (requires license)
* *AscentLint*: Advanced linting (requires license)
* *Design Compiler*: Logic synthesis (requires license)
* *PrimeTime*: Static timing analysis (requires license)
* *Vivado*: FPGA synthesis and implementation (requires license)

=== Software Development Tools

* *GCC*: C/C++ compiler suite (FOSS)
* *Clang*: Alternative C/C++ compiler (FOSS)
* *Rust*: Rust compiler suite (FOSS)
* *Valgrind*: Memory debugging and profiling (FOSS)
* *Renode*: System emulation (FOSS)

=== Software Runtime

* *TockOS*: Real-time OS for SEP (FOSS)
* *Zephyr OS*: RTOS for SMC (FOSS)
