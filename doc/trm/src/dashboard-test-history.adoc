= Test History

Per-test outcomes for one block across the published regression runs, aggregated
from the run archives on the `dv-dashboard-data` branch. One row per test, one
column per run; hovering a cell gives how many seeds passed out of how many
ran, so a partial result is a flaky run rather than a clean pass or failure.
