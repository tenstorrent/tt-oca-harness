== Interface and Security Standards

[cols="2,3",options="header"]
|===
|Document |Referenced for

|Universal Chiplet Interconnect Express (UCIe) specification
|AoU FDI interface, flit cancellation and stall handling.
The cited revision is not specified in this manual.

|IEEE 1149.1-2013
|DTP JTAG TAPs, instruction registers and IC_RESET test data register.

|IEEE 1838-2019
|DTP hierarchical multi-chiplet test access and STAP 3D control register.

|IEEE 1687-2014
|DTP iJTAG instrumentation and segment insertion bits (SIBs).

|I2C-bus specification, revisions 6 and 7.0
|I2C controller. The feature overview cites revision 7.0; the architecture
chapter cites revision 6 for electrical and timing requirements.

|System Management Bus (SMBus) specification, revision 3.2
|I2C controller SMBus operation.

|Power Management Bus (PMBus) specification, revision 1.4
|I2C controller PMBus operation.

|AVSBus specification, version 1.3.1
|AVSBus controller voltage-scaling frames and responses.

|MIPI I3C Basic specification, versions 1.0 and 1.1.1
|I3C core controller interface.

|MIPI I3C HCI (Host Controller Interface) specification, version 1.2
|I3C core controller register map.

|TCRI recovery specification, version 1.0
|I3C core controller recovery interface.

|https://csrc.nist.gov/pubs/sp/800/90/a/r1/final[NIST SP 800-90A, revision 1]
|DRBG and SEP random-number generation.

|https://csrc.nist.gov/publications/detail/sp/800-90b/final[NIST SP 800-90B]
|Entropy Source and SEP TRNG entropy assessment and health tests.

|FIPS 140-2
|Entropy Source discussion of planned certification readiness.

|FIPS 203
|Adams Bridge ML-KEM-1024 operations.

|FIPS 204
|Adams Bridge ML-DSA-87 operations and SEP lifecycle signing policy.
|===
