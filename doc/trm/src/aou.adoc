= AXI-over-UCIe Bridge (AoU)

[[axi-over-ucie-bridge]]
The AXI-over-UCIe bridge transports AXI transactions between chiplets through
the UCIe interface. These pages reproduce the AOU_CORE Microarchitecture
Specification, originally authored by BOS Semiconductors, and follow the
https://www.openchipletatlas.org/specifications/aou/latest[AXI over UCIe protocol specification].
