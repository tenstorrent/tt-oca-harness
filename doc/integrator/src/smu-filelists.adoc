[[rtl-filelist-collateral]]
= RTL Filelists

OCAH ships generated, repository-relative filelists under
`integration/filelists/`. Run tools that consume them from the repository
root.

These filelists are listed in the following table, which gives the filelist
needed to synthesize or simulate each system.

[cols="1,1,1,1",options="header"]
|===
| System | Synthesis | Simulation (Verilator) | Simulation (VCS)
| SMU | smu.synth.f | smu.verilator.sim.f | smu.vcs.sim.f
| SMC | smc.synth.f | smc.verilator.sim.f | smc.vcs.sim.f
| DTP | dtp.synth.f | dtp.verilator.sim.f | dtp.vcs.sim.f
| AoU | aou.synth.f | - | -
|===

The filelists for synthesis come from Bender's `synth` target and carry the
target's `+define+` lines. Preserve those lines when passing the filelist to a
synthesis tool; see
ifdef::backend-html5[]
xref:defines.adoc#synthesis-filelist-defines[Synthesis filelist defines].
endif::backend-html5[]
ifdef::backend-pdf[]
<<synthesis-filelist-defines,Synthesis filelist defines>>.
endif::backend-pdf[]

The filelists for simulation are different for Verilator and VCS. Each is the
complete filelist generated by that subsystem's DV configuration for the named
simulator, including the subsystem's testbench top, supplemental models, and
tool-selected stubs. AoU's DV environment is maintained in its vendor folder, so
it is not provided at the OCAH level.

Like the synthesis filelists, the simulation filelists carry the target's
`+define+` lines. Preserve these lines when passing the filelist to a simulator.

Regenerate all filelists with `python3 scripts/update_integration_filelists.py`.
Add the `--check` argument to verify that committed outputs are current.
