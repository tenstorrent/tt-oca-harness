= RTL Filelists

OCAH ships generated, repository-relative filelists under
`integration/filelists/`. Run tools that consume them from the repository
root.

Use `<system>.synth.f` for the SMU, SMC, DTP, or AoU synthesis view. These
filelists come from Bender's `synth` target and carry its `+define+` lines.
Preserve those lines when passing the filelist to a synthesis tool; see
ifdef::backend-html5[]
xref:defines.adoc#synthesis-filelist-defines[Synthesis filelist defines].
endif::backend-html5[]
ifdef::backend-pdf[]
<<synthesis-filelist-defines,Synthesis filelist defines>>.
endif::backend-pdf[]

For SMU, SMC, and DTP simulation, select
`<system>.verilator.sim.f` or `<system>.vcs.sim.f`. Each is the complete
filelist generated by that subsystem's native DV configuration for the named
simulator, including its testbench top, supplemental models, and tool-selected
stubs. AoU's DV environment is maintained in its vendor folder, so it is not
provided at the OCAH level.

Regenerate all filelists with
`python3 scripts/update_integration_filelists.py`. Use `--check` to verify
that committed outputs are current.
