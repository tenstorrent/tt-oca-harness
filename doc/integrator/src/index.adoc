Use this guide to connect OCAH to your chiplet: assign address apertures,
connect clocks, resets and external interfaces, prepare boot firmware, and
adapt the technology cells and timing constraints.

The HTML edition has a page for each task and reference appendix. The PDF
collects the same material into one book. SMN integration and the detailed
SEP/Key Manager ROM integration contracts are still under development.
