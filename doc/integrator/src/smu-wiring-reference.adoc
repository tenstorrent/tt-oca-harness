== DTP Port Mapping

The following tables define the complete DTP port list as connected within the
SMU. Ports marked "SMU external port" are exposed on the SMU boundary for
integrator connection. Ports marked with a subsystem name (e.g. SMC, SEP) are
wired internally within the SMU.

=== Cross Trigger Matrix Interface

[cols="<30%,<10%,<20%,<40%",options="header"]
|===
|Port |Direction |Width |SMU Connection

|`xtrig_ctm_src_req_o` |output |[XTRIG_NUM_INT_CT-1:0] |[1:0]: SMU internal (SMC), [9:2]: SMU external `xtrig_ctm_src_req_o[7:0]`
|`xtrig_ctm_src_ack_i` |input |[XTRIG_NUM_INT_CT-1:0] |[1:0]: Tie-off (SMC), [9:2]: SMU external `xtrig_ctm_src_ack_i[7:0]`
|`xtrig_ctm_dst_req_i` |input |[XTRIG_NUM_INT_CT-1:0] |[1:0]: SMC `xtrigger_ss_o[1:0]`, [9:2]: SMU external `xtrig_ctm_dst_req_i[7:0]`
|`xtrig_ctm_dst_ack_o` |output |[XTRIG_NUM_INT_CT-1:0] |[1:0]: Unused (SMC connection), [9:2]: SMU external `xtrig_ctm_dst_ack_o[7:0]`
|===

Internal cross trigger ports [1:0] are reserved for SMC (both bits of
`xtrigger_ss_o`). The SMU exposes ports [9:2] as external ports [7:0], so the
SMU `XTRIG_NUM_INT_CT` parameter is two less than DTP's (8 vs 10). The SMC uses
pulse-synchronization mode, so ack signals for ports [1:0] are unused:
`xtrig_ctm_src_ack_i[1:0]` should be tied to `2'b00` and
`xtrig_ctm_dst_ack_o[1:0]` are left unconnected. The usage of ack signals
depends on the `XTRIG_INT_CT_MODE` parameter: when a mode bit is 0 (pulse
synchronization), the corresponding ack is unused; when 1 (req/ack handshaking),
the ack must be connected to the cross trigger endpoint.

|Port |Direction |Width |SMU Connection

|`xtrig_clk_stop_req_i` |input |[XTRIG_NUM_CLK_STOP_REQ-1:0] |[0]: SMC `tdr_dbg_ctrl_clocks_stopped_by_cla_o`, [8:1]: SMU external `xtrig_clk_stop_req_i[7:0]`
