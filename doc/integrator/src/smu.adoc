[[smu-top-level-integration]]
= SMU Top-Level Integration

The System Management Unit (SMU) comprises three peer subsystems: the System
Management Controller (SMC), the Debug & Test Ports (DTP), and the Security
Processor (SEP). The subsections below describe each subsystem's interfaces
independently, followed by the <<smu-composition,SMU Composition>> section that
explains how they are wired together inside the SMU and how to select between the
`smu.sv` logic-level core and the `smu_wrapper.sv` reference integration.
