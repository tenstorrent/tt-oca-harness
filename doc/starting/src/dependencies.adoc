This section outlines the system requirements and dependencies for the
OCAH project. To install the required packages, refer to xref:setup.adoc[Environment Setup].

== System Requirements

* *Linux Distribution*: The guide included in xref:setup.adoc[Environment Setup] is written
for Ubuntu 26.04 LTS, but most modern distributions should be compatible, though package
installation instructions may vary. Development on MacOS _should_ also be possible, though
you will need to handle package installation yourself.
* *Python*: Version 3.11 - 3.13 (3.14+ is not supported at this time)
* *CPU*: Multi-core processor (8+ cores recommended for simulation and synthesis)
* *Memory*: Minimum 16GB RAM recommended for full builds, 32GB recommended for large designs
* *Storage*: Minimum 50GB available disk space, SSD recommended for build performance

== Software Dependencies

The project uses the following documentation tools, a Python virtual environment for SystemRDL
and a docker container for synthesis tools:

* *Asciidoctor*: AsciiDoc documentation processing and PDF generation - Requires `asciidoctor-pdf` Version 2.3.24+
* *Antora*: Multi-repository documentation site generator for AsciiDoc - Version 3.1.10+
* *Python packages*: Managed by the repo-level `pyproject.toml` and `uv.lock`;
run `make uv-sync` or `uv sync` from the repository root.
** *PeakRDL*: SystemRDL processing and RTL generation
* *Podman/Docker Containers*: Used for some workflows.
** If using Podman, also required is *Fuse-OverlayFS*
* *RISC-V Toolchain*: `riscv64-unknown-elf-*` with support for both 32 bit and 64 bit architectures - used
to compile firmware and bootcode - containerised alternative available
** `riscv-unknown-elf-gcc` - Version 15.3.0+ recommended
** `binutils-riscv-unknown-elf` - Version 2.44+ recommended
** `picolibc-riscv64-unknown-elf` - Version 1.8.12+ recommended
* *Verilator*: Used for simulation workflows - Version 5.050+
* *Verible*: Version v0.0-4148-g1ea007ec or newer
* *GnuMake*: Version 4.4.1
* *Bender*: Version 0.32.0 - Used to manage Vendor RTL and code
* *Slang*: Version 9.1+
* *Yosys*: Version 0.60+ - Currently only used via a container, included for completeness
* *GCC*: Version 15.3.0+ recommended
* *CCache*: Version 4.12.3+
* *CMake*: Version 4.2.3+
* The Virtual Platform for testing the SEP Firmware has the following additional dependencies, but installs and manages them itself unless configured otherwise:
** *SystemC*: Version 3.0.2, built with C++20
** *Boost*: Version 1.84.0
** *OPENSSL*: Version 3.3.2
** *SystemC CCI*: Version 1.0.2, built with the above SystemC and C++20
** *Whisper*: RISC-V Simulator - Pinned Version Managed Automatically
