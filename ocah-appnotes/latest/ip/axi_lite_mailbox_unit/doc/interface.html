Interface

The Mailbox Unit exposes a single struct-based AXI4-Lite slave port. All mailbox apertures are decoded from this one port by an internal demux.

AXI4-Lite Interface
input  axi_req_t  mailbox_axi_req_i,
output axi_resp_t mailbox_axi_resp_o

The request and response struct types are supplied by the integrator through the axi_req_t/axi_resp_t parameters, together with the per-channel types aw_chan_t, w_chan_t, b_chan_t, ar_chan_t and r_chan_t.

Table 1. Interface Characteristics
Parameter Value

Address Width

ADDR_WIDTH parameter

Data Width

DATA_WIDTH parameter

Strobe Width

DATA_WIDTH/8

Total Address Space

2 × MAILBOX_SIZE × NUM_MAILBOXES

Protocol

Standard AXI4-Lite with separate read/write channels
Interrupt Outputs
output logic [NUM_MAILBOXES-1:0] inbound_interrupt_o,
output logic [NUM_MAILBOXES-1:0] outbound_interrupt_o
Table 2. Interrupt Characteristics
Parameter Value

Type

Level-triggered (the unit ties the underlying IrqEdgeTrig to 0)

Polarity

Active high

Sources

Write threshold, read threshold, and a single shared error bit (read from empty or write to full)
Control Signals
input logic clk_i,       // System clock
input logic rst_ni,      // Active-low asynchronous reset
input logic test_en_i    // Test enable for DFT
Table 3. Control Signal Descriptions
Signal Description

clk_i

Primary system clock for all mailbox logic and AXI interface

rst_ni

Asynchronous reset (active low), resets all mailbox state

test_en_i

Test enable for design-for-test (DFT) functionality
Timing Characteristics
Parameter Value

Latency

One clock cycle; the R and B responses pass through spill registers

Throughput

One 64-bit transfer per clock cycle

Outstanding Transactions

MAX_TRANS per demux port (default: 32)
Error Handling
Error Condition Behavior

Read from empty FIFO (READ_DATA)

Sets read_error in ERROR_FLAGS and the error bit in IRQS; returns 0xFEEDDEAD with SLVERR

Write to full FIFO (WRITE_DATA)

Sets write_error in ERROR_FLAGS and the error bit in IRQS; discards the data and responds SLVERR

Read from write-only WRITE_DATA

Returns 0xFEEDC0DE with OKAY; no FIFO access and no error flag

Write to a read-only register (READ_DATA, STATUS, ERROR_FLAGS, IRQP)

Write is ignored, responds SLVERR

Access to an unmapped offset inside an aperture (0x50 and above)

Read returns 0 with SLVERR; write is ignored with SLVERR

Read of ERROR_FLAGS

Both flags clear on read; an error raised in the same cycle as the clearing read is retained

Interrupt Generation

Triggered if enabled via IRQEN register
Integration Requirements
Requirement Description

Address Space

MAILBOX_SIZE (2KB) per aperture, 4KB per mailbox pair; Total = 4KB × NUM_MAILBOXES

Software

Poll STATUS or use interrupts for data availability; configure WIRQT/RIRQT thresholds; check ERROR register

Hardware

Connect interrupts to system controller; proper reset sequencing; single clock domain (no CDC required)
