# iDMA Wrapper

SMC wrapper around the PULP iDMA engine.

## Documentation

Authoritative description and register maps: SMC DMA chapter `hw/sys/smc/doc/dma.adoc` (published in the TRM).

## Location

- RTL: `hw/ip/idma_wrapper/rtl/`
- Registers: SMC `dma_ctrl` under `hw/sys/smc/regs/`.

## Verification

Covered by SMC DV.
