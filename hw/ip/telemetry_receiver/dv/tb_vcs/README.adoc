= OCA Telemetry Receiver Unit Tests (VCS)
:sectnums:

This document describes how to run the unit tests for the OCA Telemetry Receiver Component using
VCS.

First, make sure you have set up the environment as described in the main `README.adoc` file of the
`tt-oca-hw` repository:

```bash
pushd ../../../..
source bin/setup_env.sh
popd
```

Second, make sure you have built the Telemetry Receiver Component and testbench as described in the
main `README.adoc` file of the Telemetry Receiver Component:

```bash
pushd ..
python3 generate_all.py -i axi4-lite
popd
```

Next, run

```
make clean # If needed
make filelist
make [STRESS=1]
```

The `STRESS=1` option will run the tests with stress mode enabled, which includes additional checks
and longer test durations. If you just want to run the sanity tests, simply omit the `STRESS`
variable.
