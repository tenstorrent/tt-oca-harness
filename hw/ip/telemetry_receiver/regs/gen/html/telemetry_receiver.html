Telemetry Receiver Address Map

Configuration, status, and data-buffer registers for a single telemetry receiver channel.

Register List:

AddressNameAccessDescription
0x0CTRLRWControl Register
0x4STATUSRStatus Register
0x8INTR_STATUSRInterrupt Status Register
0xCINTR_ENABLERWInterrupt Enable Register
0x10INTR_TESTRWInterrupt Test Register
0x14TELEMETRY_DATARTelemetry Data Register. One read returns `DATA`, `ATID` and `VALID` of the oldest beat
in the buffer and removes that beat. A read while the buffer is empty returns
`0x0000_0000` and removes nothing.

31:24Reserved--Reserved
23:12BUFFER_THRESHOLDRW0x0Telemetry Buffer Threshold. The Telemetry Buffer Threshold Interrupt is
asserted when the number of beats in the buffer is greater than this value.
Only values below the buffer depth can assert the interrupt.
11:9Reserved--Reserved
8TELEMETRY_TX_FLUSHRW0x0Telemetry Transmitter Flush. Writing `1` flushes all FIFOs in the telemetry
transmitter. The flushing is done via the ATB AF interface. This bit clears
itself when the transmitter acknowledges the flush. Writing `0` while a
flush is pending withdraws the request, so other fields of this register
must be updated with a read-modify-write while the bit is set. The
transmitter can finish a flush only while the buffer has space, so firmware
must read `TELEMETRY_DATA` while this bit is set.
