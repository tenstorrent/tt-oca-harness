[#regmap-{regmap-instance}-telemetry_receiver_wrap]
== Telemetry Receiver Wrapper Address Map

Wrapper address map instantiating the telemetry receiver channels.

[NOTE]
======
*Register Arrays:*

* *telemetry_receiver[3].CTRL*: 3 registers, base 0x0, stride 0x100
* *telemetry_receiver[3].STATUS*: 3 registers, base 0x4, stride 0x100
* *telemetry_receiver[3].INTR_STATUS*: 3 registers, base 0x8, stride 0x100
* *telemetry_receiver[3].INTR_ENABLE*: 3 registers, base 0xC, stride 0x100
* *telemetry_receiver[3].INTR_TEST*: 3 registers, base 0x10, stride 0x100
* *telemetry_receiver[3].TELEMETRY_PROBE_ID*: 3 registers, base 0x14, stride 0x100
* *telemetry_receiver[3].TELEMETRY_COUNTER_VLDS*: 3 registers, base 0x18, stride 0x100
* *telemetry_receiver[3].TELEMETRY_COUNTER[32]*: 96 registers, base 0x80 (telemetry_receiver x3 stride 0x100, TELEMETRY_COUNTER x32 stride 0x4)
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 - 0x200 | <<reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-CTRL,telemetry_receiver[3].CTRL>> | RW a| Control Register
| 0x4 - 0x204 | <<reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-STATUS,telemetry_receiver[3].STATUS>> | R a| Status Register
| 0x8 - 0x208 | <<reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-INTR_STATUS,telemetry_receiver[3].INTR_STATUS>> | RW a| Interrupt Status Register
| 0xC - 0x20C | <<reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-INTR_ENABLE,telemetry_receiver[3].INTR_ENABLE>> | RW a| Interrupt Enable Register
| 0x10 - 0x210 | <<reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-INTR_TEST,telemetry_receiver[3].INTR_TEST>> | RW a| Interrupt Test Register
| 0x14 - 0x214 | <<reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-TELEMETRY_PROBE_ID,telemetry_receiver[3].TELEMETRY_PROBE_ID>> | R a| Telemetry Probe ID Register
| 0x18 - 0x218 | <<reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-TELEMETRY_COUNTER_VLDS,telemetry_receiver[3].TELEMETRY_COUNTER_VLDS>> | R a| Telemetry Counter Valid Bits Register
| 0x80 - 0x2FC | <<reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-TELEMETRY_COUNTER-,telemetry_receiver[3].TELEMETRY_COUNTER[32]>> | R a| Telemetry Counter Register

[#reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-CTRL]
=== telemetry_receiver[3].CTRL

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:24 | `Reserved` | - | - a| Reserved
| 23:12 | `BUFFER_THRESHOLD` | RW | 0x0 a| Telemetry Message Buffer Threshold. The Telemetry Buffer Threshold Interrupt is
asserted when the number of entries in the buffer is greater than this value.
Only the low log2(queue depth)+1 bits are compared, so values alias modulo
twice the queue depth, and only values below the queue depth can assert the
interrupt.
| 11:9 | `Reserved` | - | - a| Reserved
| 8 | `TELEMETRY_TX_FLUSH` | RW | 0x0 a| Telemetry Transmitter Flush. Writing `1` flushes all FIFOs in the telemetry
transmitter. The flushing is done via the ATB AF interface. This bit clears
itself after the flush completes.
| 7:5 | `Reserved` | - | - a| Reserved
| 4 | `TELEMETRY_RX_FLUSH` | W 1P | 0x0 a| Telemetry Receiver Flush. Writing `1` discards queued messages and resets the assembly write
pointer. Stored payload bytes are not cleared. In particular, a later short
message can retain trailing counter values and validity from an earlier
message. This operation does not erase storage.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `BUFFER_POP` | W 1P | 0x0 a| Telemetry Message Buffer Pop. Effective only if `STATUS.BUFFER_EMPTY = 0`.
Writing `1` pops the buffer and thus updates the data in the
`TELEMETRY_PROBE_ID`, `TELEMETRY_COUNTER_VLDS`, and `TELEMETRY_COUNTER[32]`
registers.
|===

[#reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-INTR_STATUS]
=== telemetry_receiver[3].INTR_STATUS

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `BUFFER_THRESHOLD` | R | 0x0 a| Telemetry Message Buffer Threshold Interrupt. Asserted when the number of
telemetry messages in the Telemetry Message Buffer is greater than
`CTRL.BUFFER_THRESHOLD`.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `MISSING_LAST` | RW1C | 0x0 a| Last Packet Missing Interrupt. Asserted when the Telemetry Receiver has not
received a Last Packet flag when the maximum number of packets a message can
consist of has been received.
|===

[#reg-{regmap-instance}-telemetry_receiver_wrap-telemetry_receiver-TELEMETRY_COUNTER_VLDS]
=== telemetry_receiver[3].TELEMETRY_COUNTER_VLDS

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `COUNTER_VLDS` | R | 0x0 a| Counter Valid Bits. Indicates which of the counter values in the telemetry
message at the bottom of the Telemetry Message Buffer are valid. Bit `i` is for
the `i`-th counter.
|===
