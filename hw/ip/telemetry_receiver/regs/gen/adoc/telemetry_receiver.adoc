[NOTE]
======
*Register Arrays:* This register map contains the following register arrays:

* *TELEMETRY_COUNTER[32]*: 32 registers
  ** Base Address: 0x80
  ** Address Increment: 0x4 per register

======

[cols="1,4,1,6", options="header"]
.Register Map
|===
| Address | Name | Access | Description
| 0x0 | CTRL | RW a| Control Register
| 0x4 | STATUS | R a| Status Register
| 0x8 | INTR_STATUS | RW a| Interrupt Status Register
| 0xC | INTR_ENABLE | RW a| Interrupt Enable Register
| 0x10 | INTR_TEST | RW a| Interrupt Test Register
| 0x14 | TELEMETRY_PROBE_ID | R a| Telemetry Probe ID Register
| 0x18 | TELEMETRY_COUNTER_VLDS | R a| Telemetry Counter Valid Bits Register
| 0x80 - 0xFC | TELEMETRY_COUNTER[32] | R a| Telemetry Counter Register
|===

[cols="1,3,1,1,6", options="header"]
.CTRL Register
|===
| Bits | Field | Access | Reset | Description
| 31:24 | `Reserved` | - | - a| Reserved
| 23:12 | `BUFFER_THRESHOLD` | RW | 0x0 a| Telemetry Message Buffer Threshold. The Telemetry Buffer Threshold Interrupt is
asserted when the number of entries in the buffer is greater than this value.
| 11:9 | `Reserved` | - | - a| Reserved
| 8 | `TELEMETRY_TX_FLUSH` | RW | 0x0 a| Telemetry Transmitter Flush. Writing `1` flushes all FIFOs in the telemetry
transmitter. The flushing is done via the ATB AF interface. This bit clears
itself after the flush completes.
| 7:5 | `Reserved` | - | - a| Reserved
| 4 | `TELEMETRY_RX_FLUSH` | W | 0x0 a| Telemetry Receiver Flush. Writing `1` flushes the Telemetry Receiver Buffer and
all other storage elements in the Telemetry Receiver.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `BUFFER_POP` | W | 0x0 a| Telemetry Message Buffer Pop. Effective only if `STATUS.BUFFER_EMPTY = 0`.
Writing `1` pops the buffer and thus updates the data in the
`TELEMETRY_PROBE_ID`, `TELEMETRY_COUNTER_VLDS`, and `TELEMETRY_COUNTER[32]`
registers.
|===

[cols="1,3,1,1,6", options="header"]
.STATUS Register
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `BUFFER_FULL` | R | 0x0 a| Telemetry Message Buffer Full.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `BUFFER_EMPTY` | R | 0x1 a| Telemetry Message Buffer Empty.
|===

[cols="1,3,1,1,6", options="header"]
.INTR_STATUS Register
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `BUFFER_THRESHOLD` | R | 0x0 a| Telemetry Message Buffer Threshold Interrupt. Asserted when the number of
telemetry messages in the Telemetry Message Buffer is greater than
`CTRL.BUFFER_THRESHOLD`.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `MISSING_LAST` | RW | 0x0 a| Last Packet Missing Interrupt. Asserted when the Telemetry Receiver has not
received a Last Packet flag when the maximum number of packets a message can
consist of has been received.
|===

[cols="1,3,1,1,6", options="header"]
.INTR_ENABLE Register
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `BUFFER_THRESHOLD` | RW | 0x0 a| Telemetry Message Buffer Threshold Interrupt Enable.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `MISSING_LAST` | RW | 0x0 a| Last Packet Missing Interrupt Enable.
|===

[cols="1,3,1,1,6", options="header"]
.INTR_TEST Register
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `BUFFER_THRESHOLD` | RW | 0x0 a| Telemetry Message Buffer Threshold Interrupt Test. Writing `1` forces the
interrupt and writing `0` releases it.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `MISSING_LAST` | W | 0x0 a| Last Packet Missing Interrupt Test. Writing `1` forces the interrupt.
|===

[cols="1,3,1,1,6", options="header"]
.TELEMETRY_PROBE_ID Register
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4:0 | `PROBE_ID` | R | 0x0 a| Probe ID. Contains the Probe ID field of the telemetry message at the bottom of
the Telemetry Message Buffer.
|===

[cols="1,3,1,1,6", options="header"]
.TELEMETRY_COUNTER_VLDS Register
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `COUNTER_VLDS` | R | 0x0 a| Counter Valid Bits. Indicates which of the counter values in the telemetry
message at the bottom of the Telemetry Message Buffer are valid. Bit `i` is for
the `i`-th counter.
|===

[cols="1,3,1,1,6", options="header"]
.TELEMETRY_COUNTER[32] Register
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `COUNTER` | R | 0x0 a| Counter Value. Contains one of the 32 counter values in the telemetry message
at the bottom of the Telemetry Message Buffer.
|===
