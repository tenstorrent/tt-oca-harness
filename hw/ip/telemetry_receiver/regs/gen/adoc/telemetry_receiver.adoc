[#regmap-{regmap-instance}-telemetry_receiver]
== Telemetry Receiver Address Map

Configuration, status, and data-buffer registers for a single telemetry receiver channel.

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-telemetry_receiver-CTRL,CTRL>> | RW a| Control Register
| 0x4 | <<reg-{regmap-instance}-telemetry_receiver-STATUS,STATUS>> | R a| Status Register
| 0x8 | <<reg-{regmap-instance}-telemetry_receiver-INTR_STATUS,INTR_STATUS>> | R a| Interrupt Status Register
| 0xC | <<reg-{regmap-instance}-telemetry_receiver-INTR_ENABLE,INTR_ENABLE>> | RW a| Interrupt Enable Register
| 0x10 | <<reg-{regmap-instance}-telemetry_receiver-INTR_TEST,INTR_TEST>> | RW a| Interrupt Test Register
| 0x14 | <<reg-{regmap-instance}-telemetry_receiver-TELEMETRY_DATA,TELEMETRY_DATA>> | R a| Telemetry Data Register. One read returns `DATA`, `ATID` and `VALID` of the oldest beat
in the buffer and removes that beat. A read while the buffer is empty returns
`0x0000_0000` and removes nothing.
|===

[#reg-{regmap-instance}-telemetry_receiver-CTRL]
=== CTRL

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:24 | `Reserved` | - | - a| Reserved
| 23:12 | `BUFFER_THRESHOLD` | RW | 0x0 a| Telemetry Buffer Threshold. The Telemetry Buffer Threshold Interrupt is
asserted when the number of beats in the buffer is greater than this value.
Only values below the buffer depth can assert the interrupt.
| 11:9 | `Reserved` | - | - a| Reserved
| 8 | `TELEMETRY_TX_FLUSH` | RW | 0x0 a| Telemetry Transmitter Flush. Writing `1` flushes all FIFOs in the telemetry
transmitter. The flushing is done via the ATB AF interface. This bit clears
itself when the transmitter acknowledges the flush. Writing `0` while a
flush is pending withdraws the request, so other fields of this register
must be updated with a read-modify-write while the bit is set. The
transmitter can finish a flush only while the buffer has space, so firmware
must read `TELEMETRY_DATA` while this bit is set.
| 7:5 | `Reserved` | - | - a| Reserved
| 4 | `TELEMETRY_RX_FLUSH` | W 1P | 0x0 a| Telemetry Receiver Flush. Writing `1` discards all beats queued in the buffer.
| 3:0 | `Reserved` | - | - a| Reserved
|===

[#reg-{regmap-instance}-telemetry_receiver-STATUS]
=== STATUS

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `BUFFER_FULL` | R | 0x0 a| Telemetry Buffer Full. Set when the buffer holds the maximum number of beats.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `BUFFER_EMPTY` | R | 0x1 a| Telemetry Buffer Empty. Set when the buffer holds no beats.
|===

[#reg-{regmap-instance}-telemetry_receiver-INTR_STATUS]
=== INTR_STATUS

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `BUFFER_THRESHOLD` | R | 0x0 a| Telemetry Buffer Threshold Interrupt. Asserted when the number of beats in the
buffer is greater than
`CTRL.BUFFER_THRESHOLD`.
| 3:0 | `Reserved` | - | - a| Reserved
|===

[#reg-{regmap-instance}-telemetry_receiver-TELEMETRY_DATA]
=== TELEMETRY_DATA

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31 | `VALID` | R RMOD | 0x0 a| Beat Valid. Set when the buffer holds a beat, so `DATA` and `ATID` are valid.
| 30:15 | `Reserved` | - | - a| Reserved
| 14:8 | `ATID` | R RMOD | 0x0 a| ATB ID. Contains `atid` of the oldest beat in the buffer.
| 7:0 | `DATA` | R RMOD | 0x0 a| ATB Data. Contains `atdata` of the oldest beat in the buffer.
|===
