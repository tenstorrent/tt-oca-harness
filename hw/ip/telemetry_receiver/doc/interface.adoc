[[telemetry-receiver-interface]]
== Interface

The Telemetry Receiver component provides AXI4-Lite register access and
Advanced Trace Bus (ATB) telemetry data reception interfaces.

=== Configuration Parameters

ifdef::backend-html5[]
The parameters and ports of `telemetry_receiver` are listed in xref:ocah-docs:ROOT:rtl-modules-reference/ip/telemetry_receiver/telemetry_receiver.adoc[telemetry_receiver].
endif::backend-html5[]
ifndef::backend-html5[]
The parameters and ports of `telemetry_receiver` are listed in the HTML edition of this manual, under RTL Modules Reference.
endif::backend-html5[]

The telemetry buffer dimensions are described as `NUM_BUFFERS` (default
2, a dual-buffer architecture), `BUFFER_DEPTH` (default 16 entries per
buffer), `ATB_DATA_WIDTH` (default 8 bits), `PACKET_WIDTH` (default 64
bits), `ADDR_WIDTH` (default 32-bit register address) and `DATA_WIDTH`
(default 32-bit data bus).

=== Signal Interfaces

=== Global Interface

The global interface provides fundamental clock and reset signals
required for basic operation.

=== Clock and Reset Specifications

* *Clock Frequency*: The component can operate at frequencies up to 200
MHz
* *Clock Jitter*: Maximum 100ps peak-to-peak jitter tolerance
* *Reset Duration*: Minimum 10 clock cycles for complete reset
* *Reset Recovery*: Component ready for operation 2 clock cycles after
reset deassertion

=== ATB Telemetry Interface

The ATB (Advanced Trace Bus) interface receives telemetry data using standard
ATB protocol.

=== ATB Protocol Specifications

* *Data Width*: 8 bits per beat
* *ID Width*: 7 bits (128 unique trace sources)
* *Flow Control*: Valid/ready handshaking for reliable data transfer
* *Flush Support*: Bidirectional flush signaling for stream management
* *Back-pressure*: Component can assert `atready_o` low to apply
back-pressure
* *Latency*: Zero-cycle latency when ready, immediate acceptance when
`atready_o` is high

=== Interrupt Interface

The interrupt interface provides a single interrupt output for event
notification.

=== Interrupt Specifications

* *Polarity*: Active high (asserted when high)
* *Duration*: Level-sensitive, remains asserted until cleared
* *Sources*: Buffer threshold and error condition interrupts
* *Clearing*: `MISSING_LAST` is write-one-to-clear. The read-only
`BUFFER_THRESHOLD` source remains asserted while occupancy exceeds the configured
threshold or its test bit is set; it cannot be cleared by writing status.
* *Latency*: Interrupt assertion within 2 clock cycles of triggering
condition
