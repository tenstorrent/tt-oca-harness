[[telemetry-receiver]]
= Telemetry Receiver

== Overview

ifdef::backend-html5[]
// Preserve incoming links to the consolidated sections.
++++
<span id="description-and-features"></span>
++++
endif::backend-html5[]

The receiver captures an 8-bit ATB stream as raw beats. Each accepted beat
stores its 7-bit ATB ID and 8 data bits in a FIFO, 32 entries deep by default.
Software reads and pops beats through `TELEMETRY_DATA` on a 32-bit AXI4-Lite
register interface. The depth is an elaboration parameter, not a software
setting. A threshold interrupt reports when the FIFO needs service.

The receiver applies backpressure when the FIFO is full: `atready_o` stays low
and no beat is dropped. The
ifdef::backend-html5[]
xref:ocah-programmer-guide::index.adoc#smc-telemetry-receiver[Telemetry Receiver section]
endif::backend-html5[]
ifdef::backend-pdf[]
https://docs.tenstorrent.com/tt-oca-harness/ocah-programmer-guide/latest/index.html#smc-telemetry-receiver[Telemetry Receiver section]
endif::backend-pdf[]
of the Programmer's Guide gives the drain, flush and interrupt procedures. The
receiver stores `atid_i` with each beat and keeps no per-source state.
