== Memory Map

The Telemetry Receiver provides a comprehensive register interface for
configuration, status monitoring, and telemetry data access. All
registers are accessed through a 32-bit AXI4-Lite interface with 4-byte
address alignment.

=== Address Space Overview

The component uses a 128-byte address space (7-bit address width) with
the following organization:

* *Control and Status*: 0x00 - 0x1F (Configuration, status, probe ID, and counter validity registers)
* *Counter Array*: 0x80 - 0xFF (32 × 32-bit counter value registers)

=== Reset Behavior

Upon system reset (rst_ni assertion):

* All registers reset to their default values as specified
* Message buffer is cleared and marked empty (STATUS.BUFFER_EMPTY = 1)
* All interrupts are cleared and disabled
* Telemetry data registers reset to zero
* Component enters idle state ready for telemetry reception

The reset operation is asynchronous for assertion and synchronous for
deassertion, ensuring clean startup behavior and proper synchronization
with the system clock domain.
