== Memory Map and Register Reference

=== Memory Map

ifdef::backend-html5[]
// Preserve incoming links to the consolidated sections.
++++
<span id="address-space-overview"></span>
++++
endif::backend-html5[]

Each core occupies 256 bytes with 32-bit registers at four-byte offsets.
Control, status, interrupt and message-header registers occupy `0x00`–`0x18`;
32 counter registers occupy `0x80`–`0xFC`. The wrapper map places each receiver
in its integration-defined aperture. Reset values and field access types are
specified below; reset and flush storage behavior is described in Architecture.
