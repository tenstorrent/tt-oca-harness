[[telemetry-receiver-programming]]
== Programming

=== Buffer Management

Reading Telemetry Data:

....
1. Check STATUS.BUFFER_EMPTY to ensure data is available
2. Read TELEMETRY_PROBE_ID to get the probe identifier
3. Read TELEMETRY_COUNTER_VLDS to determine valid counters
4. Read required TELEMETRY_COUNTER[0..31] registers
5. Write CTRL.BUFFER_POP = 1 to advance to next message
6. Repeat as needed while STATUS.BUFFER_EMPTY = 0
....

Buffer Threshold Configuration:

....
1. Calculate desired threshold value (0-4095 messages)
2. Write CTRL.BUFFER_THRESHOLD = threshold_value
3. Write INTR_ENABLE.BUFFER_THRESHOLD = 1 to enable interrupt
4. Monitor INTR_STATUS.BUFFER_THRESHOLD for threshold events
....

=== Flush Operations

Receiver Flush (clears internal buffers):

....
1. Write CTRL.TELEMETRY_RX_FLUSH = 1
2. Wait for operation to complete (automatic)
3. Check STATUS.BUFFER_EMPTY = 1 to confirm flush
....

Transmitter Flush (upstream telemetry source):

....
1. Write CTRL.TELEMETRY_TX_FLUSH = 1
2. Monitor bit until it automatically clears (flush complete)
3. Resume normal operation
....

=== Interrupt Handling

Buffer Threshold Interrupt:

....
1. Read INTR_STATUS.BUFFER_THRESHOLD to confirm source
2. Process available telemetry messages using buffer read sequence
3. Interrupt automatically clears when buffer level drops below threshold
....

Missing Last Packet Interrupt:

....
1. Read INTR_STATUS.MISSING_LAST to confirm source
2. Handle error condition (log, reset, etc.)
3. Write INTR_STATUS.MISSING_LAST = 1 to clear interrupt
....
