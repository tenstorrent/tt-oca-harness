[[telemetry-receiver-architecture]]
== Architecture

The receiver stores each accepted ATB beat in a FIFO that software drains
through `TELEMETRY_DATA`. It does not decode beats or track the ATB source.

=== Beat FIFO

ifdef::backend-html5[]
++++
<span id="functional-blocks"></span>
<span id="atb-interface-block"></span>
<span id="assembly-buffer"></span>
<span id="message-decoder"></span>
<span id="data-flow"></span>
++++
endif::backend-html5[]

An accepted beat (`atvalid_i && atready_o`) is stored as `{atid_i[6:0], atdata_i[7:0]}`
in a FIFO of `BUFFER_DEPTH` entries (default 32). `atready_o` is low while the
FIFO is full or leaving reset, so the source stalls and no beat is dropped or
overwritten.

`telemetry_receiver_wrap` first passes each stream through an 8-entry
asynchronous crossing FIFO into `clk_i`. With the default depth of 32, the
source has 40 beats accepted (8 in the crossing FIFO and 32 in the receiver FIFO)
before `atready_o` stalls at the pins.

=== Readout

ifdef::backend-html5[]
++++
<span id="register-interface-block"></span>
<span id="message-buffer"></span>
<span id="control-path"></span>
++++
endif::backend-html5[]

`TELEMETRY_DATA` returns `{VALID[31], ATID[14:8], DATA[7:0]}` for the oldest beat.
A read of a nonempty FIFO returns the beat with `VALID` set and removes it. A read
of an empty FIFO returns zero and removes nothing. Writes are acknowledged and
ignored. `STATUS` reports `BUFFER_EMPTY` and `BUFFER_FULL`, not a numeric
occupancy count.

In the wrapper, an access in a gap inside a receiver's address slot, or beyond
the last slot, returns `DECERR` with read data `0xBADCAB1E`.

=== Interrupts

`irq_o` is the `BUFFER_THRESHOLD` source masked by `INTR_ENABLE.BUFFER_THRESHOLD`.
The source is asserted while the number of queued beats is strictly greater than
`CTRL.BUFFER_THRESHOLD`, or while `INTR_TEST.BUFFER_THRESHOLD` is set. The
comparison uses the full width of the field, and the FIFO never holds more than
`BUFFER_DEPTH` beats, so only thresholds 0 to `BUFFER_DEPTH - 1` can assert it.
Draining to at most the threshold, raising the threshold, or clearing the test
bit deasserts it. Writing the status bit does not clear this source.

=== Reset and Flush

ifdef::backend-html5[]
++++
<span id="clocking-and-reset"></span>
<span id="reset-behavior"></span>
++++
endif::backend-html5[]

Reset empties the FIFO and clears the control and interrupt registers. Supply
`rst_ni` with asynchronous assertion and deassertion synchronized to `clk_i`.

`CTRL.TELEMETRY_RX_FLUSH` is a pulse that empties the FIFO. It does not purge the
wrapper's upstream crossing FIFO, so beats in flight can make the FIFO nonempty
again. Quiesce traffic when an empty receiver must remain empty after the pulse.

`CTRL.TELEMETRY_TX_FLUSH` drives `afvalid_o` to request a flush from the upstream
transmitter. Hardware clears the bit after `afvalid_o && afready_i`. The field
is ordinary read-write storage: a `CTRL` write with bit 8 clear withdraws a
pending request, and `afvalid_o` falls without an acknowledgement. Update other
`CTRL` fields with a read-modify-write while a flush is pending. The transmitter
completes a flush only while the FIFO has space, so software reads
`TELEMETRY_DATA` while the bit is set.

=== Debug Output

`debug_o` is a 4-bit status output:

[cols="1,3",options="header"]
.Telemetry receiver debug_o bits
|===
|Bit |Meaning
|`debug_o[0]` |Stall: `atvalid_i` is high while `atready_o` is low.
|`debug_o[1]` |FIFO full.
|`debug_o[2]` |FIFO empty.
|`debug_o[3]` |Threshold interrupt request, before `INTR_ENABLE`.
|===
