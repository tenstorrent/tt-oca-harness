=== Memory Map

eFuse is not one universally placed address space. SEP, SMC, and the Key
Manager pass-through expose different subsets and placements. The generated
tables below compose those integration-specific views from their canonical
SystemRDL roots.

At the IP boundary, each region's base address and aperture size are
integration parameters; the generated tables show the selected integration
values. The MMR region exists only when the eFuse instance includes lifecycle
state (`HAS_LC_STATE=1`).

=== Detailed Register Map

==== Shadow Registers

The shadow registers provide cached read access to eFuse contents, loaded
automatically from the physical eFuse array during boot. The field layout is
defined by the SystemRDL sources of the instantiating subsystem; the generated
table below is authoritative for addresses, widths, and access rights of the
instance documented in this section.

==== SHIM Control Registers

The SHIM Control CSR provides foundry-specific configuration registers for
timing adaptation and eFuse bank initialization. Its placement is
adopter-defined within the adopter-owned SMC external aperture; it therefore
does not appear at a fixed address in the generated OCAH map.
