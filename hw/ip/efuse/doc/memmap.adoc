[[efuse-memory-map]]
== Memory Map

=== Overview

The eFuse IP address space is divided into four regions. Base addresses and
sizes are set by the instantiating subsystem through module parameters; the
values below are defaults. The MMR region is only present when the instance
is configured with a lifecycle controller (`HAS_LC_STATE=1`).

.Address Space Overview
[width="100%",cols="25%,23%,52%",options="header",]
|=================================================================================
|Default Address Range |Register Block |Description
|`0x0000-0x0FFF` |Shadow Registers |Cached eFuse contents; size parameterized by `EFUSE_MAP_REG_MAP_SIZE`
|`0x1000-0x1FFF` |MMR Registers |Security tokens; present only when `HAS_LC_STATE=1`
|`0x2000-0x2FFF` |eFuse Control CSR |Command and status registers; size parameterized by `EFUSE_CTRL_REG_MAP_SIZE`
|`0x3000-...` |SHIM Control CSR |Foundry-specific timing and initialization; outside harness
|=================================================================================

=== Shadow Registers

The shadow registers provide cached read access to eFuse contents, loaded
automatically from the physical eFuse array during boot. The field layout is
defined by the SystemRDL sources of the instantiating subsystem; the generated
table below is authoritative for addresses, widths, and access rights of the
instance documented in this section.
