[[smc-dv-efuse-programming]]
== Programming

=== Usage Examples

=== Example 1: Programming a Single Bit

[source,sourceCode,c]
----
// Enable programming
EFUSE_PROGRAM_CTRL = (1 << 28) | (1 << 16) | (bit_addr & 0xFFFF);

// Trigger program
EFUSE_PROGRAM_CTRL |= (1 << 17);

// Wait for completion
while (EFUSE_PROGRAM_CTRL & (1 << 24)); // Wait for busy to clear

// Check status
if ((EFUSE_PROGRAM_CTRL >> 26) & 0x3) {
    // Handle error
}
----

=== Example 2: Reading Multiple Words

[source,sourceCode,c]
----
// Setup read operation
EFUSE_READ_CTRL = (1 << 28) | (num_words << 16) | (bit_addr & 0xFFFF);

// Trigger read
EFUSE_READ_CTRL |= (1 << 17);

// Wait for completion
while (EFUSE_READ_CTRL & (1 << 24)); // Wait for busy to clear

// Read data
uint32_t data = EFUSE_READ_INTERFACE_READ_DATA;
----

=== Program Operation Sequence

1.  *Setup Phase*:
* Set `program_enable` = 1 in `EFUSE_PROGRAM_CTRL`
* Configure `efuse_addr` with target bit address
* Set `efuse_data` = 1 (only 1s can be programmed)
* Optionally set `efuse_program_read_back` = 1 for verification
2.  *Execute Phase*:
* Set `efuse_program_go` = 1 to trigger operation
* Monitor `program_busy` until it goes low
* Check `program_done` = 1 for completion
3.  *Status Check*:
* Read `program_status` field:
** 0: Success
** 1: Bad data (data was not 1)
** 2: Bad enables (program_enable not set or lock active)
** 3: Programming failure (verification failed)

=== Read Operation Sequence

1.  *Setup Phase*:
* Set `read_enable` = 1 in `EFUSE_READ_CTRL`
* Configure `efuse_addr` with target bit address
* Set `efuse_read_length_words` for multi-word reads
2.  *Execute Phase*:
* Set `efuse_read_go` = 1 to trigger operation
* Monitor `read_busy` until it goes low
* Check `read_done` = 1 for completion
3.  *Data Retrieval*:
* Read data from `EFUSE_READ_INTERFACE_READ_DATA`
* Check `read_status` for any errors
