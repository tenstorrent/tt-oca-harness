AXI4-Lite interface to the fuse bank control registers in the SHIM, carried on
`fuse_bank_ctrl_req_o` and `fuse_bank_ctrl_resp_i` of types `efuse_axil_req_t` and
`efuse_axil_resp_t`. The controller forwards accesses outside its own address windows on
this interface.

=== Security and Control Signals

// Retain bookmarks for replaced tables and renamed sections.
ifdef::backend-html5[]
++++
<span id="efuse-security-and-control-signals-table"></span>
++++
endif::backend-html5[]

The controller has no lifecycle-state input port. When `HAS_LC_STATE` is set, it takes the
lifecycle state from the fuses: during fuse sensing it loads the low `LC_STATE_WIDTH` bits
of shadow word `efuse_pkg::SHADOW_IDX_LC_STATE` and stores them differentially encoded in
the shadow map. The shadow word index is fixed in `efuse_pkg`. `LC_STATE_BIT_POSITION` is
used only by the guard, which derives the RMA SiP and chiplet token bit addresses from it as
`LC_STATE_BIT_POSITION + 1` and `LC_STATE_BIT_POSITION + 2`.

=== Fuse Command Protocol

Custom command interface between controller and SHIM:

*Request Structure* (`fuse_command_req_t`):

[source,sourceCode,systemverilog]
----
typedef struct packed {
    addr_t                    address;           // Target address in bits
    logic                     program_data;      // Data to program (1'b1)
    access_length_words_t     access_length_words; // Transfer size
    command_t                 command;           // Command type
    logic                     valid;             // Request valid
} fuse_command_req_t;
----

*Response Structure* (`fuse_command_resp_t`):

[source,sourceCode,systemverilog]
----
typedef struct packed {
    data_t              data;       // Read data
    logic               status;     // Operation status
    logic               valid;      // Response valid
} fuse_command_resp_t;
----

*Command Types*:

* `FUSE_COMMAND_READ (2'b00)`: Read operation
* `FUSE_COMMAND_PROGRAM (2'b01)`: Program operation
* `FUSE_COMMAND_PROGRAM_READ_BACK (2'b10)`: Program with verification
