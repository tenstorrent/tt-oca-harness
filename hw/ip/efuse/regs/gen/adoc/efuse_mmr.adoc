[NOTE]
======
*Register Arrays:* This register map contains the following register arrays:

* *RMA_SIP_TOKEN_I[8]*: 8 registers
  ** Base Address: 0x0
  ** Address Increment: 0x4 per register

* *RMA_CHIPLET_TOKEN_I[8]*: 8 registers
  ** Base Address: 0x20
  ** Address Increment: 0x4 per register

* *SEC_DISABLE_TOKEN_I[8]*: 8 registers
  ** Base Address: 0x40
  ** Address Increment: 0x4 per register

======

[cols="1,4,1,6", options="header"]
.Register Map
|===
| Address | Name | Access | Description
| 0x0 - 0x1C | RMA_SIP_TOKEN_I[8] | RW a| Software-writeable RMA token word. The assembled token is hashed and compared against the fused value to authorize lifecycle (LC) state transitions.
| 0x20 - 0x3C | RMA_CHIPLET_TOKEN_I[8] | RW a| Software-writeable RMA token word. The assembled token is hashed and compared against the fused value to authorize lifecycle (LC) state transitions.
| 0x40 - 0x5C | SEC_DISABLE_TOKEN_I[8] | RW a| Software-writeable security-disable token word. The assembled token is hashed and compared against the post-silicon injected value to authorize security_disable.
| 0x60 | TOKEN_EOP | W a| Token end-of-packet control. Writing the per-token go bit signals that all token words have been written and triggers a pulse to begin token hashing.
| 0x64 | RMA_SIP_TOKEN_MATCH | R a| Token match status. Reports the result of the token hash comparison (match, mismatch, or error).
| 0x68 | RMA_CHIPLET_TOKEN_MATCH | R a| Token match status. Reports the result of the token hash comparison (match, mismatch, or error).
| 0x6C | SEC_DISABLE_TOKEN_MATCH | R a| Token match status. Reports the result of the token hash comparison (match, mismatch, or error).
| 0x70 | TOKEN_MATCH_FAULT | R a| Token comparator redundancy fault status. The token match logic is triple redundant and is not a majority vote: all three comparators must agree and each must drive a legal differential pair. A bit sets when the comparators for that token disagree, which may indicate a fault injection or FIB attack. The corresponding token_match_status then reads the error code 6'b111111 and an interrupt is raised to the SEP CPU. Bits are sticky until reset.
|===
