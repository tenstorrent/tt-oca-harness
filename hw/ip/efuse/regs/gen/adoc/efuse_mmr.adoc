[#regmap-{regmap-instance}-efuse_mmr]
== eFuse Token Registers Address Map

Security-token input and match-status registers for RMA and secure-disable eFuse tokens.

[NOTE]
======
*Register Arrays:*

* *RMA_SIP_TOKEN_I[8]*: 8 registers, base 0x0, stride 0x4
* *RMA_CHIPLET_TOKEN_I[8]*: 8 registers, base 0x20, stride 0x4
* *SEC_DISABLE_TOKEN_I[8]*: 8 registers, base 0x40, stride 0x4
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 - 0x1C | <<reg-{regmap-instance}-efuse_mmr-RMA_SIP_TOKEN_I-0-,RMA_SIP_TOKEN_I[8]>> | RW a| Software-writeable RMA token word. The assembled token is hashed and compared against the fused value to authorize lifecycle (LC) state transitions.
| 0x20 - 0x3C | <<reg-{regmap-instance}-efuse_mmr-RMA_CHIPLET_TOKEN_I-0-,RMA_CHIPLET_TOKEN_I[8]>> | RW a| Software-writeable RMA token word. The assembled token is hashed and compared against the fused value to authorize lifecycle (LC) state transitions.
| 0x40 - 0x5C | <<reg-{regmap-instance}-efuse_mmr-SEC_DISABLE_TOKEN_I-0-,SEC_DISABLE_TOKEN_I[8]>> | RW a| Software-writeable security-disable token word. The assembled token is hashed and compared against the post-silicon injected value to authorize security_disable.
| 0x60 | <<reg-{regmap-instance}-efuse_mmr-TOKEN_EOP,TOKEN_EOP>> | W a| Token end-of-packet control. Writing the per-token go bit signals that all token words have been written and triggers a pulse to begin token hashing.
| 0x64 | <<reg-{regmap-instance}-efuse_mmr-RMA_SIP_TOKEN_MATCH,RMA_SIP_TOKEN_MATCH>> | R a| Token match status. Reports the result of the token hash comparison (match, mismatch, or error).
| 0x68 | <<reg-{regmap-instance}-efuse_mmr-RMA_CHIPLET_TOKEN_MATCH,RMA_CHIPLET_TOKEN_MATCH>> | R a| Token match status. Reports the result of the token hash comparison (match, mismatch, or error).
| 0x6C | <<reg-{regmap-instance}-efuse_mmr-SEC_DISABLE_TOKEN_MATCH,SEC_DISABLE_TOKEN_MATCH>> | R a| Token match status. Reports the result of the token hash comparison (match, mismatch, or error).
| 0x70 | <<reg-{regmap-instance}-efuse_mmr-TOKEN_MATCH_FAULT,TOKEN_MATCH_FAULT>> | R a| Token comparator redundancy fault status. The token match logic is triple redundant and is not a majority vote: all three comparators must agree and each must drive a legal differential pair. A bit sets when the comparators for that token disagree, which may indicate a fault injection or FIB attack. The corresponding token_match_status then reads the error code 6'b111111 and an interrupt is raised to the SEP CPU. Bits are sticky until reset.
|===
