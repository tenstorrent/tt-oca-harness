[#regmap-{regmap-instance}-efuse_interface_ctrl]
== Address Map: efuse_interface_ctrl

*eFuse Interface Control Address Map* — Program and read command, address, data, status, and timeout registers for the eFuse interface.

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-efuse_interface_ctrl-EFUSE_INTERFACE_CTRL_STATUS,EFUSE_INTERFACE_CTRL_STATUS>> | RW a| eFuse interface status and error-clear register. Reports the sense-done flag and request/address error conditions, and provides write-1 strobes to clear those errors.
| 0x4 | <<reg-{regmap-instance}-efuse_interface_ctrl-EFUSE_PROGRAM_CTRL,EFUSE_PROGRAM_CTRL>> | RW a| eFuse program control and status. Configures the program address and data, triggers a program (optionally with read-back), and reports program progress and completion status.
| 0x8 | <<reg-{regmap-instance}-efuse_interface_ctrl-EFUSE_READ_CTRL,EFUSE_READ_CTRL>> | RW a| eFuse read control and status. Configures the read address, triggers a read, and reports read progress and completion status.
| 0xC | <<reg-{regmap-instance}-efuse_interface_ctrl-EFUSE_PROGRAM_INTERFACE_READ_DATA,EFUSE_PROGRAM_INTERFACE_READ_DATA>> | R a| Read data captured through the program interface. Hardware debug only; valid only while the program interface state machine is in its capture-data state.
| 0x10 | <<reg-{regmap-instance}-efuse_interface_ctrl-EFUSE_READ_INTERFACE_READ_DATA,EFUSE_READ_INTERFACE_READ_DATA>> | R a| Read data returned through the eFuse read interface.
| 0x14 | <<reg-{regmap-instance}-efuse_interface_ctrl-EFUSE_READ_REQ_TIMEOUT,EFUSE_READ_REQ_TIMEOUT>> | RW a| Read interface timeout configuration. Sets the number of cycles the read interface waits for a SHIM response and enables the read timeout.
| 0x18 | <<reg-{regmap-instance}-efuse_interface_ctrl-EFUSE_PROGRAM_REQ_TIMEOUT,EFUSE_PROGRAM_REQ_TIMEOUT>> | RW a| Program interface timeout configuration. Sets the number of cycles the program interface waits for a SHIM response and enables the program timeout.
|===

[#reg-{regmap-instance}-efuse_interface_ctrl-EFUSE_INTERFACE_CTRL_STATUS]
=== EFUSE_INTERFACE_CTRL_STATUS

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:11 | `Reserved` | - | - a| Reserved
| 10 | `efuse_read_addr_error_clear` | W | 0x0 a| Clears the read out of bounds error bit (efuse_read_addr_error) in efuse_ctrl_status
| 9 | `efuse_program_addr_error_clear` | W | 0x0 a| Clears the program out of bounds error bit (efuse_program_addr_error) in efuse_ctrl_status
| 8 | `efuse_req_error_clear` | W | 0x0 a| Clears the blocked request error bit in efuse_ctrl_status
| 7 | `Reserved` | - | - a| Reserved
| 6 | `efuse_read_addr_error` | R | 0x0 a| Indicates that an invalid eFuse read address was used (address exceeds the implemented eFuse size). The error must be cleared by writing 1 to efuse_read_addr_error_clear.
| 5 | `efuse_program_addr_error` | R | 0x0 a| Indicates that an invalid eFuse program address was used (address exceeds the implemented eFuse size). The error must be cleared by writing 1 to efuse_program_addr_error_clear.
| 4 | `efuse_req_error` | R | 0x0 a| Indicates that the eFuse was blocked because of either read or a program lock.  The error must be cleared by writing 1 to efuse_req_error_clear to this register
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `efuse_sense_done` | R | - a| Indicates if the eFuse state machine has completed
|===

[#reg-{regmap-instance}-efuse_interface_ctrl-EFUSE_PROGRAM_CTRL]
=== EFUSE_PROGRAM_CTRL

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:28 | `Reserved` | - | - a| Reserved
| 27 | `program_enable` | RW | 0x0 a| When set, enables the program request
| 26 | `program_status` | R | 0x0 a| 0: No Error.  1: Error
| 25 | `program_done` | R | 0x0 a| When set, the program has completed, the status of which is in program_status
| 24 | `program_busy` | R | 0x0 a| When set, the program is in progress
| 23:19 | `Reserved` | - | - a| Reserved
| 18 | `efuse_program_read_back` | RW | 0x0 a| When set, trigger a read back after a program
| 17 | `efuse_program_go` | RW | 0x0 a| When set, triggers a program to the eFuse.  This will be ignored if the lock bit is set
| 16 | `efuse_data` | RW | 0x0 a| Data to program to eFuse.  If this bit is 0, the program request will be ignored
| 15:0 | `efuse_addr` | RW | 0x0 a| Bit address to program
|===
