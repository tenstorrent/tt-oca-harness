[[efuse_interface_ctrl_status-register]]
EFUSE_INTERFACE_CTRL_STATUS register
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x0
* Base Offset: 0x0
* Size: 0x4

eFuse interface status and error-clear register. Reports the sense-done
flag and request/address error conditions, and provides write-1 strobes
to clear those errors.

[cols=",,,,",options="header",]
|============================================
|Bits |Identifier |Access |Reset |Name
|0 |efuse_sense_done |r |— |—
|4 |efuse_req_error |r |0x0 |—
|5 |efuse_program_addr_error |r |0x0 |—
|6 |efuse_read_addr_error |r |0x0 |—
|8 |efuse_req_error_clear |w |0x0 |—
|9 |efuse_program_addr_error_clear |w |0x0 |—
|10 |efuse_read_addr_error_clear |w |0x0 |—
|============================================

[[efuse_sense_done-field]]
efuse_sense_done field
++++++++++++++++++++++

Indicates if the eFuse state machine has completed

[[efuse_req_error-field]]
efuse_req_error field
+++++++++++++++++++++

Indicates that the eFuse was blocked because of either read or a program
lock. The error must be cleared by writing 1 to efuse_req_error_clear to
this register

[[efuse_program_addr_error-field]]
efuse_program_addr_error field
++++++++++++++++++++++++++++++

Indicates that an invalid eFuse program address was used (address
exceeds the implemented eFuse size). The error must be cleared by
writing 1 to efuse_program_addr_error_clear.

[[efuse_read_addr_error-field]]
efuse_read_addr_error field
+++++++++++++++++++++++++++

Indicates that an invalid eFuse read address was used (address exceeds
the implemented eFuse size). The error must be cleared by writing 1 to
efuse_read_addr_error_clear.

[[efuse_req_error_clear-field]]
efuse_req_error_clear field
+++++++++++++++++++++++++++

Clears the blocked request error bit in efuse_ctrl_status

[[efuse_program_addr_error_clear-field]]
efuse_program_addr_error_clear field
++++++++++++++++++++++++++++++++++++

Clears the program out of bounds error bit (efuse_program_addr_error) in
efuse_ctrl_status

[[efuse_read_addr_error_clear-field]]
efuse_read_addr_error_clear field
+++++++++++++++++++++++++++++++++

Clears the read out of bounds error bit (efuse_read_addr_error) in
efuse_ctrl_status

[[efuse_program_ctrl-register]]
EFUSE_PROGRAM_CTRL register
^^^^^^^^^^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x4
* Base Offset: 0x4
* Size: 0x4

eFuse program control and status. Configures the program address and
data, triggers a program (optionally with read-back), and reports
program progress and completion status.

[cols=",,,,",options="header",]
|=======================================
|Bits |Identifier |Access |Reset |Name
|15:0 |efuse_addr |rw |0x0 |—
|16 |efuse_data |rw |0x0 |—
|17 |efuse_program_go |rw |0x0 |—
|18 |efuse_program_read_back |rw |0x0 |—
|24 |program_busy |r |0x0 |—
|25 |program_done |r |0x0 |—
|26 |program_status |r |0x0 |—
|27 |program_enable |rw |0x0 |—
|=======================================

[[efuse_addr-field]]
efuse_addr field
++++++++++++++++

Bit address to program

[[efuse_data-field]]
efuse_data field
++++++++++++++++

Data to program to eFuse. If this bit is 0, the program request will be
ignored

[[efuse_program_go-field]]
efuse_program_go field
++++++++++++++++++++++

When set, triggers a program to the eFuse. This will be ignored if the
lock bit is set

[[efuse_program_read_back-field]]
efuse_program_read_back field
+++++++++++++++++++++++++++++

When set, trigger a read back after a program

[[program_busy-field]]
program_busy field
++++++++++++++++++

When set, the program is in progress

[[program_done-field]]
program_done field
++++++++++++++++++

When set, the program has completed, the status of which is in
program_status

[[program_status-field]]
program_status field
++++++++++++++++++++

0: No Error. 1: Error

[[program_enable-field]]
program_enable field
++++++++++++++++++++

When set, enables the program request

[[efuse_read_ctrl-register]]
EFUSE_READ_CTRL register
^^^^^^^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x8
* Base Offset: 0x8
* Size: 0x4

eFuse read control and status. Configures the read address, triggers a
read, and reports read progress and completion status.

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|15:0 |efuse_addr |rw |0x0 |—
|16 |efuse_read_go |rw |0x0 |—
|24 |read_busy |r |0x0 |—
|25 |read_done |r |0x0 |—
|26 |read_status |r |0x0 |—
|28 |read_enable |rw |0x0 |—
|=====================================

[[efuse_addr-field-1]]
efuse_addr field
++++++++++++++++

Bit address to read

[[efuse_read_go-field]]
efuse_read_go field
+++++++++++++++++++

When set, triggers a read to efuse.

[[read_busy-field]]
read_busy field
+++++++++++++++

When set, the read is in progress

[[read_done-field]]
read_done field
+++++++++++++++

When set, the read has completed, the status of which is in read_status

[[read_status-field]]
read_status field
+++++++++++++++++

0: No Error. 1: Logic error, assert read_go when read is not enabled

[[read_enable-field]]
read_enable field
+++++++++++++++++

When set, enables the read request

[[efuse_program_interface_read_data-register]]
EFUSE_PROGRAM_INTERFACE_READ_DATA register
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

* Absolute Address: 0xC
* Base Offset: 0xC
* Size: 0x4

Read data captured through the program interface. Hardware debug only;
valid only while the program interface state machine is in its
capture-data state.

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|31:0 |dout |r |0x0 |—
|=====================================

[[dout-field]]
dout field
++++++++++

Read Data from eFuse through program interface. This field is only valid
when the efuse programming interface is utilized to burn the efuse IP
and only when the state machine is during ST_CAPTUER_DATA state.
Hardware debug only

[[efuse_read_req_timeout-register]]
EFUSE_READ_REQ_TIMEOUT register
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x14
* Base Offset: 0x14
* Size: 0x4

Read interface timeout configuration. Sets the number of cycles the read
interface waits for a SHIM response and enables the read timeout.

[cols=",,,,",options="header",]
|==============================================
|Bits |Identifier |Access |Reset |Name
|27:0 |read_req_timeout_cycles |rw |0x800000 |—
|28 |read_req_timout_enable |rw |0x0 |—
|==============================================

[[read_req_timeout_cycles-field]]
read_req_timeout_cycles field
+++++++++++++++++++++++++++++

Number of cycles the read interface will wait for a response from the
shim. At 100MHz this can count ~= 2.5 seconds.

[[read_req_timout_enable-field]]
read_req_timout_enable field
++++++++++++++++++++++++++++

Enable timeout on read interface
