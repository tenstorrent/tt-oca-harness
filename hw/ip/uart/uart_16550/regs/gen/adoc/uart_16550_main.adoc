[#regmap-{regmap-instance}-uart_16550_main]
== Address Map: uart_16550_main

Contains the mode-independent registers and the read-only registers accessible only
when `DLAB = 0`.

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-uart_16550_main-RBR,RBR>> | R a| Receiver Buffer Register
| 0x4 | <<reg-{regmap-instance}-uart_16550_main-IER,IER>> | RW a| Interrupt Enable Register
| 0x8 | <<reg-{regmap-instance}-uart_16550_main-IIR,IIR>> | R a| Interrupt Identification Register
| 0xC | <<reg-{regmap-instance}-uart_16550_main-LCR,LCR>> | RW a| Line Control Register
| 0x10 | <<reg-{regmap-instance}-uart_16550_main-MCR,MCR>> | RW a| Modem Control Register
| 0x14 | <<reg-{regmap-instance}-uart_16550_main-LSR,LSR>> | R a| Line Status Register
| 0x18 | <<reg-{regmap-instance}-uart_16550_main-MSR,MSR>> | R a| Modem Status Register
| 0x1C | <<reg-{regmap-instance}-uart_16550_main-SCR,SCR>> | RW a| Scratch Register
| 0x20 | <<reg-{regmap-instance}-uart_16550_main-ECR,ECR>> | RW a| Extended Control Register
| 0x24 | <<reg-{regmap-instance}-uart_16550_main-ITR,ITR>> | RW a| Interrupt Test Register
|===

[#reg-{regmap-instance}-uart_16550_main-RBR]
=== RBR

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:8 | `Reserved` | - | - a| Reserved
| 7:0 | `DATA` | R | 0x0 a| Received Data. Contains a received character. If FIFOs are enabled, this field

[#reg-{regmap-instance}-uart_16550_main-LCR]
=== LCR

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:8 | `Reserved` | - | - a| Reserved
| 7 | `DLAB` | RW | 0x0 a| Divisor Latch Access Bit. If set, allows access to the `DLL` and `DLM` registers
when accessing addresses `0x0` and `0x4`, respectively. If unset, allows access
to the `THR`, `RBR`, and `IIR` registers.
| 6 | `SET_BREAK` | RW | 0x0 a| Set Break. If set, forces the `tx_o` output to `0` to cause a break condition
on the receiving UART.
| 5 | `STICK_PARITY` | RW | 0x0 a| Stick Parity. If set, forces the transmit and received parity bits to be `0` if
even parity is selected and `1` if odd parity is selected.
| 4 | `EPS` | RW | 0x0 a| Even Parity Select:
* `1` - even parity
* `0` - odd parity
| 3 | `PEN` | RW | 0x0 a| Parity Enable.
| 2 | `STB` | RW | 0x0 a| Stop Bits:
* `0` - 1 stop bit.
* `1` - 2 stop bits (or 1.5 stop bits if word length is set to 5 bits)
| 1:0 | `WLS` | RW | 0x0 a| Word Length Select:
* `0x0` - 5 bits per character
* `0x1` - 6 bits per character
* `0x2` - 7 bits per character
* `0x3` - 8 bits per character
|===

[#reg-{regmap-instance}-uart_16550_main-LSR]
=== LSR

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:8 | `Reserved` | - | - a| Reserved
| 7 | `ERROR_IN_RCVR_FIFO` | R | 0x0 a| Error in Receiver FIFO. When set, indicates that the receiver FIFO or (RBR in
non-FIFO mode) has the parity, framing, or break error. In other words, at
least one of the PE, FE, and BI bits is set.
| 6 | `TEMT` | R | 0x1 a| Transmitter Empty. When set, indicates that the transmitter shift register and
the transmitter FIFO (or THR in non-FIFO mode) are empty.
| 5 | `THRE` | R | 0x1 a| Transmitter Holding Register Empty. When set, indicates that the TX FIFO (or
THR in non-FIFO mode) is empty. Clearing the Transmitter Holding Register Empty
Interrupt does NOT clear this bit.
| 4 | `BI` | R | 0x0 a| Break Interrupt. When set, indicates that the `rx_i` input is `0` for an entire
frame's time (start + data + parity + stop bits). In FIFO mode, this bit set
when the character reaches the top of the receiver FIFO. In non-FIFO mode, this
bit is set when the character enters the RBR. This bit triggers the Receiver
Line Status Interrupt.
| 3 | `FE` | R | 0x0 a| Framing Error. When set, indicates that the received character is missing a
stop bit. In FIFO mode, this bit is set when the character reaches the top of
the FIFO. In non-FIFO mode, this bit is set when the character enters the RBR.
This bit triggers the Receiver Line Status Interrupt.
| 2 | `PE` | R | 0x0 a| Parity Error. When set, indicates that the character at the top of the receiver
FIFO (or RBR in non-FIFO mode) has a parity error. This bit triggers the
Receiver Line Status Interrupt.
| 1 | `OE` | R | 0x0 a| Overrun Error. When set, indicates that the RX FIFO (or Receiver Buffer
Register in Non-FIFO Mode) is full when new character is received. In FIFO Mode, the new character
is dropped. In non-FIFO mode, the existing character in the RBR is overwritten.
This bit triggers the Receiver Line Status Interrupt.
| 0 | `DR` | R | 0x0 a| Data Ready. When set, indicates that the RX FIFO (or RBR in non-FIFO
mode) contains data.
|===

[#reg-{regmap-instance}-uart_16550_main-MSR]
=== MSR

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:8 | `Reserved` | - | - a| Reserved
| 7 | `DCD` | R | 0x0 a| Data Carrier Detect. This bit reflects the `dcd_ni` input in the opposite
polarity, so it reads `1` while a carrier is detected.
| 6 | `RI` | R | 0x0 a| Ring Indicator. This bit reflects the `ri_ni` input in the opposite polarity, so
it reads `1` while the remote modem signals an incoming call.
| 5 | `DSR` | R | 0x0 a| Data Set Ready. This bit reflects the `dsr_ni` input in the opposite polarity,
so it reads `1` while the remote modem is connected and ready.
| 4 | `CTS` | R | 0x0 a| Clear to Send. This bit reflects the `cts_ni` input in the opposite polarity, so
it reads `1` while the remote device is ready to receive data.
| 3 | `DDCD` | R | 0x0 a| Delta Data Carrier Detect. When set, indicates that the `DCD` bit has changed
since the last time this register was read. This bit triggers the Modem Status
Interrupt.
| 2 | `TERI` | R | 0x0 a| Trailing Edge Ring Indicator. When set, indicates that the `RI` bit has changed
from a `1` to a `0`. This bit triggers the Modem Status Interrupt.
| 1 | `DDSR` | R | 0x0 a| Delta Data Set Ready. When set, indicates that the `DSR` bit has changed since
the last time this register was read. This bit triggers the Modem Status
Interrupt.
| 0 | `DCTS` | R | 0x0 a| Delta Clear to Send. When set, indicates that the `CTS` bit has changed since
the last time this register was read. This bit triggers the Modem Status
Interrupt.
|===
