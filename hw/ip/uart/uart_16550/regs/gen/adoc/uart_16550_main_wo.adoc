[#reg-{regmap-instance}-uart_16550_main_wo-THR]
=== THR

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:8 | `Reserved` | - | - a| Reserved
| 7:0 | `DATA` | W | 0x0 a| Transmit Data. Holds a character to be transmitted. If FIFOs are enabled, this
field points to the top of the TX FIFO. Otherwise, this field points to a
single-byte Transmitter Holding Register.
|===

[#reg-{regmap-instance}-uart_16550_main_wo-FCR]
=== FCR

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:8 | `Reserved` | - | - a| Reserved
| 7:6 | `RCVR_TRIGGER` | W | 0x0 a| Receiver FIFO Trigger Level (Least Significant 2 Bits). To configure the most
significant 2 bits, use the `CTRL.RCVR_TRIGGER_MS2B` register field. The
configurations for the trigger levels are:
* `0x0` -    1 character
* `0x1` -    4 characters
* `0x2` -    8 characters
* `0x3` -   14 characters
* `0x4` -   32 characters
* `0x5` -   64 characters
* `0x6` -  128 characters
* `0x7` -  256 characters
* `0x8` -  512 characters
* `0x9` - 1024 characters
* `0xA` - 2048 characters
* `0xB` - 4096 characters
| 5:4 | `Reserved` | - | - a| Reserved
| 3 | `DMA_MODE_SELECT` | W | 0x0 a| DMA mode select:
* `0` - DMA Mode 0
* `1` - DMA Mode 1
| 2 | `XMIT_FIFO_RESET` | W | 0x0 a| Transmitter FIFO Reset. Writing `1` clears the TX FIFO.
| 1 | `RCVR_FIFO_RESET` | W | 0x0 a| Receiver FIFO Reset. Writing `1` clears the RX FIFO.
| 0 | `FIFO_ENABLE` | W | 0x0 a| FIFO Enable. When set, enables the TX and RX FIFOs (FIFO Mode). When unset,
disables the FIFOs (Non-FIFO Mode).
|===
