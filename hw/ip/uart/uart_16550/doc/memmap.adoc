[[uart-16550-memory-map]]
===== Memory Map

====== Overview

The UART 16550 register map follows the industry-standard 16550 UART
layout with additional extended registers. The register space spans 64
bytes (6-bit address) with 32-bit aligned registers. Register access
behavior depends on the DLAB (Divisor Latch Access Bit) setting in the
Line Control Register (LCR).

The register map uses a dynamic addressing scheme where certain register
addresses map to different registers based on the DLAB bit setting,
maintaining compatibility with the original 16550 UART while providing
access to baud rate configuration registers.

====== Address Map Summary

.Register Address Map

|=======================================================================
|Offset |Register Name |Access |Description
|0x00 |RBR/THR |RW |Receiver Buffer Register (Read) / Transmitter
Holding Register (Write) when DLAB=0

|0x00 |DLL |RW |Divisor Latch Low Register when DLAB=1

|0x04 |IER |RW |Interrupt Enable Register when DLAB=0

|0x04 |DLM |RW |Divisor Latch High Register when DLAB=1

|0x08 |IIR/FCR |RW |Interrupt Identification Register (Read) / FIFO
Control Register (Write)

|0x0C |LCR |RW |Line Control Register

|0x10 |MCR |RW |Modem Control Register

|0x14 |LSR |R |Line Status Register

|0x18 |MSR |R |Modem Status Register

|0x1C |SCR |RW |Scratch Register

|0x20 |ECR |RW |Extended Control Register

|0x24 |ITR |RW |Interrupt Test Register
|=======================================================================
