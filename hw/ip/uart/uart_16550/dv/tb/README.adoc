= OCA UART 16550 Unit Tests
:sectnums:

This document describes how to run the unit tests for the OCAH UART 16550 Component using Verilator.

First, make sure you have set up the environment as described in the main `README.adoc` file of the
OCAH repository:

```bash
pushd ../../../..
source bin/setup_env.sh
popd
```

Second, make sure you have built the UART 16550 Component and testbench as described in the main
`README.adoc` file of the UART 16550 Component:

```bash
make -f ocah.mk ocah-regen-regs
```

Next, run

```
make clean # If needed
make filelist
make [STRESS=1]
```

The `STRESS=1` option will run the tests with stress mode enabled, which includes additional checks
and longer test durations. If you just want to run the sanity tests, simply omit the `STRESS`
variable.
