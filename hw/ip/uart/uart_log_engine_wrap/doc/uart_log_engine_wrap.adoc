= OCAH UART & Log Engine Wrapper
:sectnums:

[#sec-description]
== Description

The OCAH UART & Log Engine Wrapper is a hardware module that integrates an UART 16550 with a Log
Engine. This wrapper is designed to facilitate communication between the UART and the log engine,
allowing for logging capabilities.

[#sec-features]
== Features

The features of this design include:

* An UART 16550
* An optional Log Engine
* Configurable APB4 or AXI4-Lite register interface

== Registers — LCR.DLAB=0, Read Direction

The UART 16550 follows the 8250 layout: single offsets map to different registers by
access direction and by `LCR.DLAB`. This table is the `LCR.DLAB=0` read view at wrapper
offset `+0x100`; write-only and divisor-latch aliases at the same offsets are in the
next section. When this wrapper is arrayed by `uart_wrap`, instance _N_ adds a further
`N * 0x400`.

[#sec-shared-thr]
== Shared Transmit Holding Register

When the Log Engine is enabled (`GEN_LOG_ENGINE=1`, the default), the UART transmit
holding register (`THR`, at wrapper offset `0x100`) is written by two initiators: the
CPU through the register interface, and the Log Engine through an internal 2:1 AXI4-Lite
arbiter. The Log Engine's write target is not fixed in hardware — it is taken from
`LOG_WRITE_ADDR` (offset `0x210`), which firmware must program to the `THR` address for
log output to reach the UART.

The arbiter serialises the two initiators, but no hardware lock protects the shared
register. The

xref:ocah-programmer-guide::index.adoc#smc-log-engine-setup[Log Engine configuration sequence]
