= OCA Log Engine Unit Tests
:sectnums:

This document describes how to run the unit tests for the OCA Log Engine Component using Verilator.

First, make sure you have set up the environment as described in the main `README.adoc` file at the
repository root:

```bash
pushd ../../../..
source bin/setup_env.sh
popd
```

Second, make sure you have built the Log Engine Component and testbench as described in the main
`README.adoc` file of the Log Engine Component:

```bash
pushd ..
python3 generate_all.py -i axi4-lite
popd
```

Next, run

```
make clean # If needed
make filelist
make [STRESS=1]
```

The `STRESS=1` option will run the tests with stress mode enabled, which includes additional checks
and longer test durations. If you just want to run the sanity tests, simply omit the `STRESS`
variable.
