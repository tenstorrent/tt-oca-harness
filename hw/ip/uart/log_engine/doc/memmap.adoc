[[log-engine-memory-map]]
== Memory Map

=== Overview

The Log Engine provides a comprehensive register interface for
configuration, control, and status monitoring. All registers are
accessible via a 32-bit AXI4-Lite interface and follow standard
read/write access patterns. The register map is organized into logical
groups for ease of use and programming.
