[[log-engine-interface]]
== Interface

The OCA Log Engine provides multiple AXI4-Lite interfaces for register
access, memory fetching, and UART communication.

The engine serves 16 independent log entries, set by `NUM_LOG_ENTRIES` in `log_engine_pkg`.

ifdef::backend-html5[]
The parameters and ports of `log_engine` are listed in xref:ocah-docs:ROOT:rtl-modules-reference/ip/log_engine/log_engine.adoc[log_engine].
endif::backend-html5[]

endif::backend-html5[]

=== DMA Interface

The DMA interface provides flow control coordination with the UART
transmitter.

=== Flow Control Operation:

* The log write FSM waits for `uart_tx_ready_i` assertion before
initiating write transfers
* This prevents overwhelming the UART transmitter and maintains data
integrity
* Ready signal typically indicates UART FIFO has space for additional
characters

=== Interrupt Interface

The interrupt interface provides error signaling to the system.

=== Interrupt Sources:

* *LOG_FETCH_ERR*: AXI4-Lite log fetch bus returned error response
* *LOG_WRITE_ERR*: AXI4-Lite log write bus returned error response

*Interrupt Control:* * Individual enable bits in INTR_ENABLE register *
Status bits in INTR_STATUS register (write-1-to-clear) * Test capability
via INTR_TEST register
