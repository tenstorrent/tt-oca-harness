[#regmap-{regmap-instance}-log_engine]
== Log Engine Address Map

Configuration and status registers for the UART log engine, including the log region and write pointers.

[NOTE]
======
*Register Arrays:*

* *LOG_CTRL[16]*: 16 registers, base 0x40, stride 0x4
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-log_engine-CTRL,CTRL>> | RW a| Control Register
| 0x4 | <<reg-{regmap-instance}-log_engine-LOG_REGION_SIZE,LOG_REGION_SIZE>> | RW a| Log Region Size Register
| 0x8 | <<reg-{regmap-instance}-log_engine-LOG_REGION_ADDR,LOG_REGION_ADDR>> | RW a| Log Region Address Register
| 0x10 | <<reg-{regmap-instance}-log_engine-LOG_WRITE_ADDR,LOG_WRITE_ADDR>> | RW a| Log Write Address Register
| 0x14 | <<reg-{regmap-instance}-log_engine-INTR_STATUS,INTR_STATUS>> | RW a| Interrupt Status Register
| 0x18 | <<reg-{regmap-instance}-log_engine-INTR_ENABLE,INTR_ENABLE>> | RW a| Interrupt Enable Register
| 0x1C | <<reg-{regmap-instance}-log_engine-INTR_TEST,INTR_TEST>> | W a| Interrupt Test Register
| 0x40 - 0x7C | <<reg-{regmap-instance}-log_engine-LOG_CTRL-0-,LOG_CTRL[16]>> | RW a| Log Control Register
|===

[#reg-{regmap-instance}-log_engine-CTRL]
=== CTRL

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:1 | `Reserved` | - | - a| Reserved
| 0 | `EN` | RW | 0x0 a| Log Engine Enable. When set, enables the Log Engine. When unset, disables the
Log Engine and resets all FSMs, flops, and FIFOs.
|===

[#reg-{regmap-instance}-log_engine-LOG_REGION_SIZE]
=== LOG_REGION_SIZE

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:20 | `Reserved` | - | - a| Reserved
| 19:0 | `LOG_REGION_SIZE` | RW | 0x0 a| Log region size in bytes. Supported values are at most 512 KiB and aligned
to 128 bytes (16 slots times the 8-byte fetch beat). If software programs a
larger value, RTL clamps the effective region to 512 KiB. For a value that is
not 128-byte aligned, RTL divides the effective region among the 16 slots and
rounds each slot's transferable capacity down to complete 8-byte fetch beats.
A requested LOG_LEN above that capacity is clamped to the capacity.
|===

[#reg-{regmap-instance}-log_engine-LOG_REGION_ADDR]
=== LOG_REGION_ADDR

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `RESERVED` | R | 0x0 a| Reserved. Reads as zero; writes are ignored.
| 55:32 | `LOG_REGION_ADDR_HI` | RW | 0x0 a| Log Region Start Address High. Contains fabric address bits [55:32].
| 31:0 | `LOG_REGION_ADDR_LO` | RW | 0x0 a| Log Region Start Address Low.
|===

[#reg-{regmap-instance}-log_engine-LOG_WRITE_ADDR]
=== LOG_WRITE_ADDR

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `LOG_WRITE_ADDR` | RW | 0x0 a| Log Write Address. This is the address where the log data is written to.
|===

[#reg-{regmap-instance}-log_engine-INTR_STATUS]
=== INTR_STATUS

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `LOG_WRITE_ERR` | RW | 0x0 a| Log Write Error Interrupt. Asserted when the bus for writing log data returns
an error.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `LOG_FETCH_ERR` | RW | 0x0 a| Log Fetch Error Interrupt. Asserted when the bus for fetching log data returns
an error.
|===

[#reg-{regmap-instance}-log_engine-INTR_ENABLE]
=== INTR_ENABLE

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `LOG_WRITE_ERR` | RW | 0x0 a| Log Write Error Interrupt Enable.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `LOG_FETCH_ERR` | RW | 0x0 a| Log Fetch Error Interrupt Enable.
|===

[#reg-{regmap-instance}-log_engine-INTR_TEST]
=== INTR_TEST

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `LOG_WRITE_ERR` | W | 0x0 a| Log Write Error Interrupt Test. Writing `1` forces the interrupt.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `LOG_FETCH_ERR` | W | 0x0 a| Log Fetch Error Interrupt Test. Writing `1` forces the interrupt.
|===

[#reg-{regmap-instance}-log_engine-LOG_CTRL-0-]
=== LOG_CTRL[16]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:16 | `Reserved` | - | - a| Reserved
| 15:0 | `LOG_LEN` | RW | 0x0 a| Log Length. Writing a nonzero value representing the log length in bytes to this field
starts the log transfer process. There are 16 copies of this register, each representing
a log entry. The log entries go through round robin arbitration.
|===
