[[status_intr-register]]
STATUS_INTR register
^^^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x2000
* Base Offset: 0x0
* Size: 0x4

Status Register with level interrupts

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|0 |busy |rw, woclr |0x0 |—
|5:4 |error |rw, woclr |0x0 |—
|8 |alert |rw, woclr |0x0 |—
|=====================================

[[busy-field]]
busy field
++++++++++

Macro is busy

[[error-field]]
error field
+++++++++++

Error occurred during operation. Bit 0 - Single bit error, Bit 1 -
Double bit error

[[alert-field]]
alert field
+++++++++++

Alert occurred, due to control signal corruption
