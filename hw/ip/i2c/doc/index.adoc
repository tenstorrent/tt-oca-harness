[[i2c-controller]]
= I2C Controller
:description: OCAH I2C wrapper. The controller core is OpenTitan I2C.

The I2C controller is based on the
https://opentitan.org/book/hw/ip/i2c/index.html[OpenTitan I2C] design.
Controller and target behavior, clock stretching, arbitration, timing setup,
and programming sequences are specified in the
https://opentitan.org/book/hw/ip/i2c/doc/theory_of_operation.html[OpenTitan theory of operation]
and the
https://opentitan.org/book/hw/ip/i2c/doc/programmers_guide.html[OpenTitan programmer's guide].

== OCAH Modifications

* AXI4-Lite register interface in place of the OpenTitan TileLink host port.
* Wrapper register blocks `i2c_ctrl` and `i2c_wrap` around the OpenTitan register bank.
