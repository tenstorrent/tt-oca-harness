[#regmap-{regmap-instance}-i2c_ctrl]
== I2C Control Address Map

Per-instance pad-function select, SMBus pad direction, and SMBus alert enable.

[NOTE]
======
*Register Arrays:*

* *I2C_CTRL[3]*: 3 registers, base 0x0, stride 0x4
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 - 0x8 | <<reg-{regmap-instance}-i2c_ctrl-I2C_CTRL-,I2C_CTRL[3]>> | RW a| Control Register
|===

[#reg-{regmap-instance}-i2c_ctrl-I2C_CTRL-]
=== I2C_CTRL[3]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:9 | `Reserved` | - | - a| Reserved
| 8 | `SMBUS_EN` | RW | 0x0 a| SMBus Enable. Gates the SMBus Alert signal.
| 7:5 | `Reserved` | - | - a| Reserved
| 4 | `I2C_CONTROLLER_MODE_EN` | RW | 0x0 a| SMBus Pad Direction. When set, the SMBus alert pad is an input and the SMBus suspend pad is an output, as for an SMBus host. When clear, the alert pad is an output and the suspend pad is an input, as for an SMBus target. SCL and SDA are unaffected. Program it to agree with the core's CTRL.ENABLEHOST and CTRL.ENABLETARGET setting.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `I2C_EN` | RW | 0x0 a| I2C Pad Function Select. When set, the integration routes this instance's SCL, SDA, SMBus alert and SMBus suspend signals to their pads. Does not enable the I2C core; CTRL.ENABLEHOST and CTRL.ENABLETARGET select the core's operating mode.
|===
