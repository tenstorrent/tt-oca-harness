[[empty-field]]
empty field
+++++++++++

0: Data is available to read, 1: Data is not available to read

[[full-field]]
full field
++++++++++

0: Space is available to write, 1: Space is not available to write

write_level_above_thresh field
++++++++++++++++++++++++++++++

If set, write fifo level is higher than threshhold set in WIRQT

[[read_level_above_thresh-field]]
read_level_above_thresh field
+++++++++++++++++++++++++++++

If set, read fifo level is higher than threshhold set in RIRQT

* Base Offset: 0x20

|=====================================

[[wirqt-field]]
wirqt field
+++++++++++

When the usage pointer of the FIFO connected to the W channel exceeds
this value, a write threshold IRQ is triggered and the corresponding
STATUS register bit is set. When a value larger than or equal to the
MailboxDepth parameter is written to this register, it gets reduced to
MailboxDepth - 1 to ensure an IRQ is triggered when the write FIFO is
full.

[[rirqt-field]]
rirqt field
+++++++++++

When the fill pointer of the FIFO connected to the R channel exceeds
this value, a read threshold IRQ is triggered and the corresponding
STATUS register bit is set. When a value larger than or equal to the
MailboxDepth parameter is written to this register, it gets reduced to
MailboxDepth - 1 to ensure an IRQ is triggered when the read FIFO is
full.

[[irqs-register]]
IRQS register
^^^^^^^^^^^^^

* Absolute Address: 0x30
* Base Offset: 0x30
* Size: 0x8

This register is used to read and clear interrupt requests, regardless
of IRQEN register and whether the interrupt is enabled or disabled.

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|0 |wtirq |rw |0x0 |—
|1 |rtirq |rw |0x0 |—
|2 |eirq |rw |0x0 |—
|=====================================

[[wtirq-field]]
wtirq field
+++++++++++

On read: link:No%20error%20IRQ%20pending[0]: No interrupt request
link:Error%20IRQ%20pending%3C/p%3E[1]: Usage level threshold in write
mailbox exceeded On write: link:No%20error%20IRQ%20pending[0]: No
acknowledge link:Error%20IRQ%20pending%3C/p%3E[1]: Acknowledge and clear
interrupt request

[[rtirq-field]]
rtirq field
+++++++++++

On read: link:No%20error%20IRQ%20pending[0]: No interrupt request
link:Error%20IRQ%20pending%3C/p%3E[1]: Usage level threshold in read
mailbox exceeded On write: link:No%20error%20IRQ%20pending[0]: No
acknowledge link:Error%20IRQ%20pending%3C/p%3E[1]: Acknowledge and clear
interrupt request

[[eirq-field]]
eirq field
++++++++++

On read: link:No%20error%20IRQ%20pending[0]: No interrupt request
link:Error%20IRQ%20pending%3C/p%3E[1]: Error on mailbox access On write:
link:No%20error%20IRQ%20pending[0]: No acknowledge
link:Error%20IRQ%20pending%3C/p%3E[1]: Acknowledge and clear interrupt
request
