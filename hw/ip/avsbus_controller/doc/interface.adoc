[[avsbus-controller-interface]]
== Interface

The AVSBus Controller provides a configurable system bus interface
(APB4 or AXI4-Lite), a two-wire AVSBus protocol interface, and
clock/reset interfaces for system integration. Dual clock domain support
enables flexible clock source selection for optimal timing and power
management.

=== Configuration Parameters

[width="100%",cols="30%,20%,50%",options="header",]
|========================================================================
|Parameter |Default |Description
|BUS_PROTOCOL |APB4 |System bus interface (APB4 or AXI4-Lite)
|CMD_FIFO_DEPTH |8 |Command FIFO depth (entries)
|RSP_FIFO_DEPTH |8 |Response FIFO depth (entries)
|CLK_DIV_WIDTH |8 |Clock divider bit width (2-255 ratios)
|DUTY_CYCLE_WIDTH |8 |Duty cycle control bit width
|========================================================================

=== AVSBus Protocol Interface

=== AVSBus Signal Definition

.AVSBus Protocol Signals
[width="100%",cols="20%,10%,10%,60%",options="header",]
|=====================================================================================
|Signal Name |Width |Direction |Description
|avs_clock_o |1 |Output |AVSBus protocol clock - Generated by controller

|avs_mdata_o |1 |Output |Master data - Serial command transmission

|avs_sdata_i |1 |Input |Slave data - Serial response from target device
|=====================================================================================

*AVSBus Clock Characteristics*: - Frequency: Programmable division of
system clock (divide by 2-255) - Duty Cycle: Configurable 8-bit control
(0-255 maps to 0-100%) - Clock Gating: Automatic gating during idle
periods if enabled - Clock Domain: Independent from register interface
clock

*Serial Data Protocol*: - avs_mdata_o: LSB-first serial transmission at
avs_clock_o rate - Frame Length: 32 bits total (29 data + 3 CRC bits) -
Bit Rate: 1 bit per avs_clock_o rising edge - Idle State: avs_mdata_o
held high between transactions

*Target Response Collection*: - avs_sdata_i: Serial collection
from target device - Response sampled on avs_clock_o edges - Target
acknowledgment extracted from response frame

=== AVSBus Frame Format

*Command Frame Structure (32 bits total)*:

.AVSBus Command Frame Format
[width="100%",cols="15%,10%,10%,65%",options="header",]
|=====================================================================================
|Field Name |Bit Range |Width |Description
|Command Type |[31:30] |2 |Operation type (0=commit write, 1=hold write,
2=read)

|Command Group |[29] |1 |Command group (0=standard, 1=manufacturer-specific)

|Command Code |[28:25] |4 |Data category (0=voltage, 1=rate, 2=current,
3=temp, etc.)

|Rail Select |[24:21] |4 |Rail selection (0-15, 0xF=broadcast)

|Data Payload |[20:5] |16 |Command-specific data (voltage values,
configuration, etc.)

|Reserved |[4:3] |2 |Reserved

|CRC-3 |[2:0] |3 |Cyclic redundancy check for error detection
|=====================================================================================

*Command Type Encoding*:

.AVSBus Command Types
[width="100%",cols="10%,20%,70%",options="header",]
|=================================================================================
|Code |Command Name |Description
|0x0 |Commit Write |Write data and immediately commit voltage changes
|0x1 |Hold Write |Write data but hold changes until commit command
|0x2 |Read |Read current values from target device
|=================================================================================

*Data Type Encoding*:

.AVSBus Data Types
[width="100%",cols="10%,25%,15%,50%",options="header",]
|=================================================================================
|Code |Data Type |Resolution |Description
|0x0 |Target Rail Voltage |1mV |16-bit voltage values for power rails
|0x1 |Vout Transition Rate |1mV/μs |Rise/fall rate configuration
|0x2 |Rail Current |10mA |Current measurement readback
|0x3 |Temperature |0.1°C |Temperature sensor readings
|0x4 |Force Voltage Reset |N/A |Emergency voltage reset command
|0x5 |Power Mode |N/A |Efficiency vs performance mode
|0xE |AVSBus Status |N/A |Target status and error reporting
|0xF |AVSBus Version |N/A |Target version readback
|=================================================================================

*Response Frame Structure (32 bits)*:

.AVSBus Response Frame Format
[width="100%",cols="15%,10%,10%,65%",options="header",]
|========================================================================
|Field Name |Bit Range |Width |Description
|Slave Acknowledgment |[31:30] |2 |ACK/NACK status (0=action performed,
1=resource unavailable, 2=bad CRC, 3=bad data)

|Status Response |[29:25] |5 |5-bit status field indicating general
condition of slave

|Response Data |[24:5] |20 |Target-specific response data

|Reserved |[4:3] |2 |Reserved

|CRC-3 |[2:0] |3 |Cyclic redundancy check for error detection
|========================================================================

=== Clock and Reset Interface

=== Multi-Clock Architecture

The controller supports flexible clocking for optimal system integration
and timing closure.

*Clock Input Signals*:

.Clock Input Signals
[width="100%",cols="20%,10%,10%,60%",options="header",]
|=====================================================================================
|Signal Name |Width |Direction |Description
|clk_reg_i |1 |Input |Register interface clock - Synchronous with bus
operations

|clk_ref_i |1 |Input |Reference clock - Independent AVS timing source

|test_en_i |1 |Input |Test enable - DFT override for clock selection

|scan_rst_ni |1 |Input |Scan reset - Test infrastructure reset control
|=====================================================================================

*Clock Output Signals*:

.Clock Output Signals
[width="100%",cols="20%,10%,10%,60%",options="header",]
|==================================================================================
|Signal Name |Width |Direction |Description
|avs_clock_o |1 |Output |AVSBus protocol clock - Drives target device
|==================================================================================

*Clock Configuration and Control*: - Clock source selection via
AVS_CFG_1.AVS_CLOCK_SELECT[1:0] - Programmable divider:
AVS_CFG_1.CLK_DIVIDER_VALUE[7:0] (range 2-255) - Duty cycle control:
AVS_CFG_1.CLK_DIVIDER_DUTY_CYCLE_NUMERATOR[7:0] (0-255) - Clock gating controls
for power management (AVS_CFG_1.STOP_AVS_CLOCK_ON_IDLE)

=== Reset Architecture

Dual-domain reset system providing staged initialization control.

*Reset Input Signals*:

.Reset Input Signals
[width="100%",cols="20%,10%,10%,60%",options="header",]
|==================================================================================
|Signal Name |Width |Direction |Description
|rst_ni |1 |Input |Primary system reset - Active low asynchronous
|rst_clk_div_ni |1 |Input |Clock divider reset - Active low asynchronous
|scan_rst_ni |1 |Input |Scan chain reset - Test infrastructure control
|==================================================================================

*Internal Reset Domains*:

.Internal Reset Domains
[width="100%",cols="25%,10%,65%",options="header",]
|=====================================================================================
|Reset Domain |Control |Description
|Clock Divider Domain |rst_clk_div_ni |Controls clock divider (must be
deasserted first)

|Clock/Register Domain |rst_ni |Controls basic clocking and register
access
|=====================================================================================

*Reset Timing Requirements*: 1. Assert rst_clk_div_ni and rst_ni to initialize all
domains 2. Configure clock sources and parameters 3. Deassert rst_clk_div_ni
to enable clock divider 4. Deassert rst_ni to enable register access 5. Configure protocol parameters and FIFO
settings 6. Begin normal AVSBus operations

=== Interrupt Interface

Comprehensive interrupt generation for system-level event handling and
status monitoring.

*Interrupt Output Signal*:

.Interrupt Output
[width="100%",cols="20%,10%,10%,60%",options="header",]
|==============================================================================
|Signal Name |Width |Direction |Description
|irq_o |1 |Output |Interrupt request - Active high level assertion
|==============================================================================

*Interrupt Sources and Control*: - Command FIFO status events (full,
empty, overflow) - Response FIFO status events (data available, full,
underflow) - Transaction completion and error conditions - Target
acknowledgment and timeout events - Protocol state changes and error
recovery - Clock domain issues and reset events - Slave resync operations

*Interrupt Configuration*: - Individual interrupt source enable/disable
control via AVS_INTERRUPT_MASK - Interrupt status register (AVS_INTERRUPT) with clear-on-write functionality (AVS_INTERRUPT_CLEAR) -
Level triggering for all interrupt sources

=== Protocol Timing Specifications

=== AVSBus Timing Parameters

*Clock Timing*: - Minimum avs_clock_o period: 2 * clk_reg_i period -
Maximum avs_clock_o frequency: clk_reg_i frequency / 2 - Duty cycle
range: 10% to 90% (configurable) - Clock jitter tolerance: ±5% of clock
period

*Data Setup and Hold Times*: - avs_mdata_o setup time: 1ns before
avs_clock_o rising edge - avs_sdata_i setup time: 2ns before avs_clock_o
rising edge - avs_sdata_i hold time: 1ns after avs_clock_o rising edge -
Propagation delay: avs_clock_o to avs_mdata_o < 10ns

*Transaction Timing*: - Frame transmission time: 32 avs_clock_o cycles -
Slave resync operation: 34 avs_clock_o cycles - Inter-frame gap: Automatic
based on protocol state - Target response timeout: Configurable per application - Maximum
transaction latency: Frame time + response time + processing overhead

=== System Integration Guidelines

=== Bus Interface Integration

*APB4 Integration*:

[source,sourceCode,verilog]
----
avsbus_controller_apb4 u_avs_ctrl (
    // APB4 interface
    .pclk_i     (apb_clk),
    .presetn_i  (apb_rst_n),
    .paddr_i    (apb_paddr[7:0]),   // 8-bit address for 256-byte space
    .psel_i     (apb_psel_avs),
    .penable_i  (apb_penable),
    .pwrite_i   (apb_pwrite),
    .pwdata_i   (apb_pwdata),
    .pstrb_i    (apb_pstrb),
    .pready_o   (apb_pready_avs),
    .prdata_o   (apb_prdata_avs),
    .pslverr_o  (apb_pslverr_avs),

    // Clock and reset
    .clk_reg_i  (apb_clk),
    .clk_ref_i  (ref_clk_100m),
    .rst_ni     (system_rst_n),
    .rst_clk_div_ni (system_rst_n),

    // AVSBus interface
    .avs_clock_o (avs_clk_out),
    .avs_mdata_o (avs_cmd_out),
    .avs_sdata_i (avs_response_in),

    // System interface
    .irq_o      (avs_irq)
);
----
