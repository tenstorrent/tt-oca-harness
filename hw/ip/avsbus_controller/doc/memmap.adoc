[[avsbus-controller-memory-map]]
===== Memory Map

====== Overview

The AVSBus Controller provides a comprehensive register interface
through a 256-byte address space (0x00-0xFF) accessible via AXI4-Lite or
APB4 protocols. The register map is organized into functional groups
including control registers for transaction management, status registers
for monitoring operations, configuration registers for system
parameters, and FIFO interfaces for command and response data handling.

All registers are 32-bit aligned and designed for efficient software
access patterns. The interface supports both polling and
interrupt-driven operation modes, with extensive status reporting and
diagnostic capabilities for robust system integration and debugging.

====== Address Alignment and Access Requirements

*Address Alignment*: - All registers aligned to 32-bit boundaries
(addresses multiples of 4) - 256-byte total address space (0x00-0xFF) -
Compatible with standard AXI4-Lite and APB4 addressing schemes

*Access Width Requirements*: - All registers must be accessed using
32-bit operations - Byte and halfword accesses not supported - may cause
unpredictable behavior - AXI4-Lite: Write strobes should be 4'b1111 for
all register writes - APB4: All pstrb_i bits should be asserted for
register writes

*Atomic Access Considerations*: - FIFO registers (AVS_CMD, AVS_READBACK)
are inherently atomic - Status registers provide consistent snapshots of
hardware state - No special atomic access patterns required for normal
operation
