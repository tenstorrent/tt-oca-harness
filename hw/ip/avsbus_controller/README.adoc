# AVSBus Controller V1.3.1

This directory contains the AVSBus (Adaptive Voltage Scaling Bus) V1.3.1 Controller IP and a basic cocotb testbench. The module provides a bridge between APB/AXI-Lite register interfaces and the AVSBus protocol, enabling dynamic voltage scaling operations for power management in single-target systems.

## Overview

The AVSBus Controller is a hardware IP that implements the AVSBus 1.3.1 specification for adaptive voltage scaling communication. It acts as a controller (master) that communicates with a single AVS target device (slave) to manage voltage rails, monitor power conditions, and perform real-time voltage adjustments for optimal performance and energy efficiency. This version supports 32-bit frame-based communication without multi-target addressing.

## Generating the IP

To generate the AVSBus Controller IP, run the following command:

```bash
python3 generate_ip.py -i <io-port-type>
```

Replace `<io-port-type>` with one of the following options:

- `apb4`
- `axi4-lite`
- `apb4-flattened`
- `axi4-lite-flattened`

### Key Features

* **Dual Bus Interface**: Supports both APB4 and AXI4-Lite register interfaces
* **Command FIFO**: 8-deep command queue for efficient transaction management
* **Readback FIFO**: 8-deep response buffer with automatic retry mechanism
* **Flexible Clock Configuration**: Programmable AVS clock generation with divider and duty cycle control
* **Interrupt Support**: Comprehensive interrupt system for status monitoring
* **Retry Mechanism**: Configurable automatic retry for failed transactions
* **Slave Resync Operation**: Automatic periodic resynchronization with configurable intervals
* **CRC Protection**: Hardware CRC-3 calculation and verification
* **Real-time Monitoring**: Live status and debug registers

## Architecture

### Module Hierarchy

```
avsbus_controller (Top-level wrapper)
├── avsbus_controller_core (Main controller logic)
│   ├── avsbus_async_fifo (Command and readback FIFOs)
│   └── avsbus_crc3 (CRC-3 calculation engine)
└── Register Interface (APB or AXI-Lite)
    └── avsbus_controller_reg (Generated register interface)
```

### AVSBus 1.3.1 Protocol Overview

The AVSBus 1.3.1 protocol operates on a two-wire interface:
- **avs_clock_o**: Controller-generated clock signal (master to slave)
- **avs_mdata_o**: Master data output (commands to slave)
- **avs_sdata_i**: Slave data input (responses from slave)

Each transaction consists of 32-bit command frames (master to slave) and 32-bit response frames (slave to master) with built-in CRC-3 protection and status reporting. The protocol supports periodic slave resynchronization operations to maintain alignment.

## Clocks and Reset

### Clock Domains

The AVSBus V1.3.1 Controller operates with the following clocks:

- Input clocks:
  - **clk_reg_i**: Register interface clock (APB4/AXI4-Lite)
  - **clk_ref_i**: Reference clock for AVS clock generation
- Internal/Output clocks:
  - **avs_clock_o**: AVS bus clock output to slave device

### AVS Clock Generation

#### Clock Source Selection (AVS_CFG_1:AVS_CLOCK_SELECT[1:0])
- **2'b00**: Use APB clock directly as AVS clock
- **2'b01**: Use divided APB clock as AVS clock
- **2'b10**: Use reference clock directly as AVS clock
- **2'b11**: Use divided reference clock as AVS clock (default)

#### Programmable Clock Divider (when using divided clock mode)
- **CLK_DIVIDER_VALUE**: Division ratio (minimum value: 2, default: 4)
- **CLK_DIVIDER_DUTY_CYCLE_NUMERATOR**: Duty cycle control (0-255, default: 128 for 50%)
  - The duty cycle percentage = (numerator / 256) × 100%
  - 50% duty cycle is only achievable with even divider values
- **Default Configuration**: Divide by 4 with 50% duty cycle

#### Clock Gating Options
- **STOP_AVS_CLOCK_ON_IDLE**: Gates AVS clock when bus is idle, restarts with 34-cycle resync
- **TURN_OFF_ALL_PREMUX_CLOCKS**: Gates all input clocks to the mux (use before changing clock config)

### Reset

The AVSBus V1.3.1 Controller has a 2 reset domains:

- **`rst_ni`**: Asynchronous active-low reset, resets everything except the clock divider
- **`rst_clk_div_ni`**: Asynchronous active-low reset for clock divider

The clock divider **MUST** be taken out of reset before the rest of the AVS logic is reset.

## Quick Setup Guide

### Prerequisites Setup
```bash
# Load required modules
module load quasar
source bin/setup_env.sh  # from OCAH repository root

# Navigate to avsbus_controller directory
cd hw/ip/avsbus_controller
```

### Generating and Testing the IP

```bash
# Generate IP first (required before testing)
python3 generate_ip.py -i apb4

# Navigate to testbench directory
cd tb

# Clean build
make clean

# Run all tests
make

# Run with specific simulator
make SIM=vcs

# Run with waveform generation
make SIM=vcs WAVES=1
```
