[#regmap-{regmap-instance}-aes_wrapper_key]
== Address Map: aes_wrapper_key

Key storage registers for the AES sideload interface.
Written by Key Manager CPU, drives keymgr_key_i on the OT AES core.

[NOTE]
======
*Register Arrays:*

* *KEY_SHARE0[8]*: 8 registers, base 0x0, stride 0x4
* *KEY_SHARE1[8]*: 8 registers, base 0x20, stride 0x4
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 - 0x1C | <<reg-{regmap-instance}-aes_wrapper_key-KEY_SHARE0-0-,KEY_SHARE0[8]>> | W a| One 32-bit word of key data. Write-only; reads return 0.
No reset; powers up with undefined value.
| 0x20 - 0x3C | <<reg-{regmap-instance}-aes_wrapper_key-KEY_SHARE1-0-,KEY_SHARE1[8]>> | W a| One 32-bit word of key data. Write-only; reads return 0.
No reset; powers up with undefined value.
| 0x40 | <<reg-{regmap-instance}-aes_wrapper_key-KEY_CTRL,KEY_CTRL>> | RW a| Key control register. Writing KEY_VALID=1 asserts the sideload
valid signal to the AES core.
|===

[#reg-{regmap-instance}-aes_wrapper_key-KEY_SHARE0-0-]
=== KEY_SHARE0[8]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `data` | W | - a| 32-bit key data word. Write-only for security.
|===

[#reg-{regmap-instance}-aes_wrapper_key-KEY_SHARE1-0-]
=== KEY_SHARE1[8]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `data` | W | - a| 32-bit key data word. Write-only for security.
|===

[#reg-{regmap-instance}-aes_wrapper_key-KEY_CTRL]
=== KEY_CTRL

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:1 | `rsvd` | R | 0x0 a| Reserved
| 0 | `key_valid` | RW | 0x0 a| When 1, asserts keymgr_key_i.valid to indicate key is loaded.
Write 0 to invalidate the current key.
|===
