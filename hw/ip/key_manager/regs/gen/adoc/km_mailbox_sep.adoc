.Register Map
|===
| Address | Name | Access | Description
| 0x0 | SEP_WRITE_DATA | W a| Write data to inbound FIFO (SEP→KM messages)
| 0x4 | SEP_WRITE_SEPARATOR | RW a| Write 1 to set message separator on next inbound (SEP→KM) write. Cleared by hardware when that write completes.
| 0x8 | SEP_READ_DATA | R a| Read data from outbound FIFO (KM→SEP messages)
| 0xC | SEP_STATUS | RW a| FIFO status information
| 0x10 | SEP_IRQ_STATUS | RW a| Interrupt status register
| 0x14 | SEP_IRQ_ENABLE | RW a| Interrupt enable register for SEP host
| 0x18 | SEP_CTRL | RW a| Control register for mailbox behavior configuration
|===

[cols="1,3,1,1,6", options="header"]
.SEP_WRITE_DATA Register
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `data` | W | 0x0 a| 32-bit data word to write to inbound FIFO
|===

|===

|===

|===

[cols="1,3,1,1,6", options="header"]
.SEP_STATUS Register
|===
| Bits | Field | Access | Reset | Description
| 31:26 | `rsvd` | R | 0x0 a| Reserved
| 25 | `outbound_separator` | R | 0x0 a| Message separator: 1 if the last word read from outbound FIFO had the separator bit set (last word of message). Read-only, not sticky.
| 24 | `inbound_separator` | R | 0x0 a| Message separator: 1 if the last word read from inbound FIFO had the separator bit set (last word of message). Read-only, not sticky.
| 23 | `outbound_underflow` | RW | 0x0 a| Outbound FIFO underflow detected (read attempted when empty). Sticky, write 1 to clear.
| 22 | `inbound_underflow` | RW | 0x0 a| Inbound FIFO underflow detected (read attempted when empty). Sticky, write 1 to clear.
| 21 | `outbound_overflow` | RW | 0x0 a| Outbound FIFO overflow detected (write attempted when full). Sticky, write 1 to clear.
| 20 | `inbound_overflow` | RW | 0x0 a| Inbound FIFO overflow detected (write attempted when full). Sticky, write 1 to clear.
| 19:12 | `outbound_depth` | R | 0x0 a| Outbound FIFO fill level (number of words in FIFO)
| 11:4 | `inbound_depth` | R | 0x0 a| Inbound FIFO fill level (number of words in FIFO)
| 3 | `outbound_full` | R | 0x0 a| Outbound FIFO is full
| 2 | `outbound_empty` | R | 0x1 a| Outbound FIFO is empty (no data available for SEP to read)
| 1 | `inbound_full` | R | 0x0 a| Inbound FIFO is full (cannot write more data)
| 0 | `inbound_empty` | R | 0x1 a| Inbound FIFO is empty (no data available for KM to read)
|===

[cols="1,3,1,1,6", options="header"]
.SEP_IRQ_STATUS Register
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `rsvd` | R | 0x0 a| Reserved
| 4 | `flushed_by_km` | RW | 0x0 a| KM performed a mailbox flush. Sticky, write 1 to clear.
| 3 | `outbound_underflow` | RW | 0x0 a| Outbound FIFO underflow detected. Sticky, write 1 to clear.
| 2 | `inbound_overflow` | RW | 0x0 a| Inbound FIFO overflow detected. Sticky, write 1 to clear.
| 1 | `inbound_write_space_avail` | R | 0x0 a| Inbound FIFO has space available for SEP to write (level-sensitive). 1 = space available, 0 = full.
| 0 | `outbound_read_data_avail` | R | 0x0 a| Outbound FIFO has data available for SEP to read (level-sensitive). 1 = data available, 0 = empty.
|===

[cols="1,3,1,1,6", options="header"]
.SEP_IRQ_ENABLE Register
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `rsvd` | R | 0x0 a| Reserved
| 4 | `flushed_by_km_en` | RW | 0x0 a| Enable interrupt to SEP when KM performs a mailbox flush
| 3 | `outbound_underflow_en` | RW | 0x0 a| Enable interrupt to SEP when outbound FIFO underflow is detected
| 2 | `inbound_overflow_en` | RW | 0x0 a| Enable interrupt to SEP when inbound FIFO overflow is detected
| 1 | `inbound_write_space_avail_en` | RW | 0x0 a| Enable interrupt to SEP when inbound FIFO has space available (SEP->KM messages)
| 0 | `outbound_read_data_avail_en` | RW | 0x0 a| Enable interrupt to SEP when outbound FIFO has data available (KM->SEP messages)
|===

[cols="1,3,1,1,6", options="header"]
.SEP_CTRL Register
|===
| Bits | Field | Access | Reset | Description
| 31:3 | `rsvd` | R | 0x0 a| Reserved
| 2 | `flush` | RW | 0x0 a| Write 1 to flush all mailbox FIFOs (inbound and outbound). Cleared by hardware when flush completes.
| 1 | `outbound_underflow_resp` | RW | 0x0 a| Response type for outbound FIFO underflow: 0=SLVERR (default), 1=OKAY
| 0 | `inbound_overflow_resp` | RW | 0x0 a| Response type for inbound FIFO overflow: 0=SLVERR (default), 1=OKAY
|===
