.Register Map
|===
| Address | Name | Access | Description
| 0x0 | VERSION | R a| Hardware version register (semantic versioning: major.minor.patch)
| 0x4 | CTRL | R a| Control register (reserved for future use)
| 0x8 | SOFT_RST_CODE | RW a| Software reset code register. Write 0x53525354 ('SRST') to trigger soft reset. Any other value has no effect.
| 0xC | IRQ_STATUS | RW a| Interrupt status register. Sticky bits cleared by writing 1.
| 0x10 | IRQ_ENABLE | RW a| Interrupt enable/mask register
| 0x14 | SCRAMBLER_KEY | RW a| 32-bit scrambler key for SRAM address/data scrambling. When locked: writes ignored, reads return 0. No reset; powers up random.
| 0x18 | SCRAMBLER_CTRL | RW a| Scrambler control register
| 0x1C | SRAM_LOCK | RW a| SRAM write-lock bits. Bit[i]=1 locks region i (1 KB each, 32 regions). Write-1-only: writing 1 sets the bit, writing 0 has no effect. Cleared by warm or cold reset (warm reset domain); ROM re-applies the lock policy on every boot before handover to mutable firmware.
| 0x20 | IRQ_SET | W a| Interrupt set register. Write 1 to trigger corresponding interrupt (for ISR testing). Write-only, reads return 0.
| 0x24 | SRAM_WRITE_LOCK_VIOLATION | RW a| Which SRAM region(s) had write attempts while locked. Bit[i]=region i. Sticky, write 1 to clear each bit.
| 0x28 | RECOVERABLE_ERR | RW a| Recoverable error status. Firmware writes 1 to set (after recovering in ISR), writes 0 to clear (e.g. when SEP requests clear). Drives recoverable error event output.
| 0x2C | BOOT_STATUS | RW a| Boot status. Firmware writes 1 to COLD_BOOT_DONE after cold-boot init completes; bit remains set until next cold reset.
| 0x30 | OTP_LIFE_CYCLE | R a| Life cycle state. 8-bit (4-bit value differentially encoded). Read-through from OTP port; no reset.
| 0x34 | OTP_DEMOTION_STATE | R a| Demotion state. 2-bit, differentially encoded. Read-through from OTP port; no reset.
| 0x38 | SRAM_EXEC_MODE | RW a| Execute-permission whitelist mode. Write-1-only (woset); cleared by warm or cold reset. 0=ROM executable; 1=write-locked SRAM regions executable, and the ROM lockout is armed. Set by ROM stack-less handover immediately before jumping to mutable firmware.
| 0xB8 | IRQ_ENTRY_ADDR | RW a| Effective IRQ entry address for subsequent interrupts. Writable while unlocked; any 32-bit value accepted.
| 0xBC | IRQ_ENTRY_LOCK | RW a| Write-one-only lock for IRQ_ENTRY_ADDR. Separate readable register; cleared only on KM reset.
| 0x100 | VUART_TX | RW a| Virtual UART transmit register. Write a byte to send to testbench. DATA_VALID is set on write and self-clears.
| 0x104 | VUART_RX | R a| Virtual UART receive register. Testbench writes bytes here for firmware to read.
| 0x108 | VUART_STATUS | R a| Virtual UART status register for flow control
| 0x110 | TB_RESULT | RW a| Test result register. Firmware writes 0=fail, 1=pass.
| 0x114 | TB_SIGNATURE | RW a| Test completion signature. Firmware writes 0x600D600D (pass) or 0xBADBADBA (fail).
| 0x118 | TB_ERRCODE | RW a| Test error code register. Firmware writes optional error code for debugging.
| 0x11C | TB_SUBTEST | RW a| Current subtest number register. Firmware increments for each subtest.
| 0x120 | TB_CMD | RW a| Testbench command register. Firmware writes command, testbench reads and clears.
| 0x124 | TB_CMD_ARG | RW a| Testbench command argument register. Firmware writes optional argument.
| 0x128 | TB_CMD_STATUS | RW a| Testbench command status register. Testbench writes status, firmware reads.
| 0x12C | TB_CMD_RESULT | R a| Testbench command result register. Testbench writes result value.
| 0x1FC | DEBUG | R a| Debug register with known constant value for verification
