[NOTE]
======
*Register Arrays:* This register map contains the following register arrays:

* *WORD[16]*: 16 registers
  ** Base Address: 0x0
  ** Address Increment: 0x4 per register

* *CTRL[64]*: 64 registers
  ** Base Address: 0x1000
  ** Address Increment: 0x4 per register

======

[cols="1,1,1,3", options="header"]
.Register Map
|===
| Address | Name | Access | Description
| 0x0 - 0x3C | WORD[16] | RW a| One 32-bit word of a key entry (512-bit key = 16 words). No reset; powers up random.
| 0x1000 - 0x10FC | CTRL[64] | RW a| Per-slot control: lock bits (W1S) and the erase trigger
| 0x1100 | KPV_SCRAMBLER_KEY | RW a| 32-bit key for KPV key entry scrambling. No reset; powers up random. Locked when KPV_SCRAMBLER_CTRL.LOCK=1.
| 0x1104 | KPV_SCRAMBLER_CTRL | RW a| KPV scrambler enable and lock. Reset to 0 on KM reset. LOCK is write-one-only.
|===

[cols="1,1,1,1,3", options="header"]
.WORD[16] Register
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `data` | RW | - a| 32-bit key data word. No reset for security; power-up value undefined.
Actual storage is in km_kpv_regfile; CSR field is a protocol placeholder.
|===

[cols="1,1,1,1,3", options="header"]
.CTRL[64] Register
|===
| Bits | Field | Access | Reset | Description
| 31:3 | `rsvd_31_3` | R | 0x0 a| Reserved
| 2 | `erase` | RW | 0x0 a| Write-1 to start hardware erase of this slot: an LFSR fills all 16 key
words (through the KPV scrambler) and the slot CTRL register is cleared.
Hardware self-clears this bit when the erase completes. Not blocked by
lock_write or lock_use.
| 1 | `lock_use` | RW | 0x0 a| Prevents KM read of this key entry data until reset. Read-any, write-1-only.
| 0 | `lock_write` | RW | 0x0 a| Prevents KM write to this key entry data and control until reset. Read-any, write-1-only.
|===

[cols="1,1,1,1,3", options="header"]
.KPV_SCRAMBLER_KEY Register
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `key` | RW | - a| Scrambler key. No reset for security. HW clears to 0 on wipe via hwclr.
|===

[cols="1,1,1,1,3", options="header"]
.KPV_SCRAMBLER_CTRL Register
|===
| Bits | Field | Access | Reset | Description
| 31:2 | `rsvd` | R | 0x0 a| Reserved
| 1 | `lock` | RW | 0x0 a| Write-one-only. When 1, key and ENABLE cannot be modified until KM reset.
| 0 | `enable` | RW | 0x0 a| 1 = scramble key entry data on write, descramble on read; 0 = passthrough.
|===
