AES Wrapper Key Registers

Key storage registers for the AES sideload interface.
Written by Key Manager CPU, drives keymgr_key_i on the OT AES core.

Register Arrays:

  • KEY_SHARE0[8]: 8 registers, base 0x0, stride 0x4
  • KEY_SHARE1[8]: 8 registers, base 0x20, stride 0x4

Register List:

AddressNameAccessDescription
0x0 - 0x1CKEY_SHARE0[8]WOne 32-bit word of key data. Write-only; reads return 0.
No reset; powers up with undefined value.
0x20 - 0x3CKEY_SHARE1[8]WOne 32-bit word of key data. Write-only; reads return 0.
No reset; powers up with undefined value.
0x40KEY_CTRLRWKey control register. Writing KEY_VALID=1 asserts the sideload
valid signal to the AES core.
