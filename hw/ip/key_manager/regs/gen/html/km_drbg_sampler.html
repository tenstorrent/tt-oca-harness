DRBG Sampler

DRBG random data interface and configuration/status registers

Register List:

AddressNameAccessDescription
0x0DATAROne word of random data. Read triggers request or returns prefetch. Writes return SLVERR. No reset.
0x4CFGRWConfiguration: PREFETCH enable, TIMEOUT cycles for active CPU read.
0x8STATUSRWStatus: DRBG_READY, PREFETCHED, TIMEOUT_ERR (W1C), STREAM_ERR (W1C), COUNT_BAD, COUNT_GOOD.
0xCPREFETCH_DATARPrefetched word (read-only, for debugging). Cleared when PREFETCH=0. No reset; power-up undefined.
