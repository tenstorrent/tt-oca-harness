The length of each variable-length JTAG2AXI register follows from the bridge's
address width, data width and pipeline depth, and for the series data registers
from the size last written to `*_AXI_SERIES_CTRL`. The
ifdef::backend-html5[]
xref:ip:jtag_ptap/doc/index.adoc#ptap-jtag2axi-support[PTAP JTAG2AXI Support]
endif::backend-html5[]
ifdef::backend-pdf[]
<<ptap-jtag2axi-support,PTAP JTAG2AXI Support>>
endif::backend-pdf[]
section defines each layout.

**NOTE:** All instruction encodings _not_ explicitly defined in this table map
to the BYPASS instruction.

=== Signal Interface

Packed control and bus types remain bundles at the `jtag_intf_unit` boundary; their
members are not separate scalar ports.

=== Dependencies

The JTAG Interface Unit depends on the following components:

* `hw/ip/jtag/jtag_ptap` - Primary TAP
* `hw/ip/jtag/jtag_stap` - Secondary TAP
* `hw/common/ocah_prim` - Primitive cells
