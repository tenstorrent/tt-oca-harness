=== Instruction Encodings

The PTAP uses 6-bit instruction encodings. During the capture phase, the least
significant bit (closest to TDO) of the instruction register always presents a 1
to the scan chain, and the next least significant bit presents a 0 as specified
by the 1149.1 standard, section 7.2.1. All other bits of the instruction
register always return 0s.

<<ptap-instruction-encodings-table>> lists the PTAP instruction encodings and associated
register lengths.

<<ptap-jtag2axi-support>> defines the layouts of the JTAG2AXI registers. An
instruction of a bridge that its enable parameter leaves out maps to the BYPASS
instruction.

**NOTE:** All instruction encodings _not_ explicitly defined in this table map
to the BYPASS instruction.

=== Signal Interface

Packed control and bus types remain bundles at the `jtag_ptap` boundary; their
members are not separate scalar ports.

=== Dependencies

The PTAP depends on the following components:

* https://github.com/tenstorrent/tt-oca-harness/tree/829b09cf54dde1969dc309733f97f8fb32cefbdd/hw/common/ocah_prim[`hw/common/ocah_prim`] — Primitive cells (synchronizers, clock gating)
* `vendor/pulp-platform/riscv-dbg` — `tdr2axi` with the Debug Module registers and the System Bus Access engine (JTAG2AXI bridges)
* `vendor/pulp-platform/axi` and `vendor/pulp-platform/common_cells` — AXI manager, demultiplexers, error slave and clock-domain crossings of the JTAG2AXI bridges
ifdef::backend-html5[]
* xref:ip:jtag_stap/doc/index.adoc[`hw/ip/jtag/jtag_stap`] — Secondary TAP (when 3DIC support enabled)
endif::backend-html5[]
ifdef::backend-pdf[]
* <<jtag-stap,`hw/ip/jtag/jtag_stap`>> — Secondary TAP (when 3DIC support enabled)
endif::backend-pdf[]
