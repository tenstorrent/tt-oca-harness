==== I3C Core Controller

===== Overview

The OCA I3C Core Controller is a comprehensive MIPI I3C/I2C communication
controller providing full HCI (Host Controller Interface) v1.2 compliant
operation with support for both controller (master) and target (slave) modes.
Based on the CHIPS Alliance i3c-core with extensive OCA enhancements, this
controller enables high-speed inter-chip communication with advanced features
including In-Band Interrupts, Common Command Codes, and device recovery.

===== Description and Features

* *MIPI Specification Compliance*: Full compliance with I3C Basic v1.0/v1.1.1,
I3C HCI v1.2, and TCRI v1.0 recovery specifications
* *Dual Operating Modes*: Configurable as active controller, secondary
controller, or I3C target with runtime mode switching
* *High-Speed Operation*: Push-Pull mode up to 12.5 MHz, Open-Drain mode for
I2C compatibility (100 kHz to 1 MHz)
* *Advanced Controller Features*: Host Controller Interface with descriptor-based
queue management, threshold-triggered interrupts, DAT/DCT device tables
* *In-Band Interrupts (IBI)*: Hardware-managed IBI detection and handling with
priority-based acceptance, reduced-latency OCA enhancement for IBI during
transactions
* *Common Command Codes (CCC)*: Full support for broadcast and direct CCCs
including dynamic address assignment (SETDASA, SETNEWDA), device
configuration (SETMWL, SETMRL), and device queries (GETPID, GETSTATUS)
* *I2C Backward Compatibility*: Standard-mode (100 kbaud), Fast-mode (400 kbaud),
and Fast-mode Plus (1 Mbaud) support for legacy I2C devices
* *Transfer Command Response Interface (TCRI)*: MIPI TCRI v1.0 recovery handler with
firmware download and peripheral reset capabilities
* *Multi-Instance Support*: Up to 6 independent I3C controller instances with
unified register interface
* *Flexible Queue Architecture*: Separate Command, Response, TX, RX, and IBI
FIFOs with configurable depths and threshold-based operation
* *AXI4-Lite Integration*: Standard 32-bit AXI4-Lite slave interface for
register access with address space multiplexing
