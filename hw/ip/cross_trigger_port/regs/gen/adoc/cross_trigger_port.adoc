[[config-register]]
CONFIG register
^^^^^^^^^^^^^^^

* Absolute Address: 0x0
* Base Offset: 0x0
* Size: 0x4

Cross Trigger Port Configuration

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|0 |MODE |rw |0x0 |—
|1 |INVERT |rw |0x0 |—
|2 |RESET |rw |0x0 |—
|=====================================

[[mode-field]]
MODE field
++++++++++

Selects the operating mode of the CTP. 0 - Wire-OR, 1 - Point-to-Point

[[invert-field]]
INVERT field
++++++++++++

Inverts the sense of the incoming and outgoing GPIO signals. 0 - No
inversion. Wire-OR mode uses active-low signaling with active or passive
pull-ups. Point-to-point mode uses active-high signaling. 1 - All inputs
and outputs of I/Os are inverted. Wire-OR mode uses active-high
signaling with active or passive pull-downs. Point-to-point mode uses
active-low signaling.

[[reset-field]]
RESET field
+++++++++++

Forcefully clears the request output signal of the point-to-point
handshake logic. Primarily for debug and recovery of handshake deadlock.

[[busy-field]]
BUSY field
++++++++++

Indicates whether a pulse assertion or handshake is currently in
progress. 0 - Pulse or handshake is not in progress, 1 - Pulse or
handshake is currently in progress

[[req_out-field]]
REQ_OUT field
+++++++++++++

Readout of the current CT_Req_out signal value.

[[ack_in-field]]
ACK_IN field
++++++++++++

Pulse Stretch Multiplier

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|15:0 |STRETCH_MULT |rw |0x0 |—
|=====================================

[[stretch_mult-field]]
STRETCH_MULT field
++++++++++++++++++

The number of clock cycles a core-side cross trigger pulse is stretched
on the GPIO pin when in wire-OR mode. Whenever a core-side pulse is
received, the generated GPIO pulse has a width of (STRETCH_MULT+1) clock
cycles.
