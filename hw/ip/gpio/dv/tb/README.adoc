= OCH GPIO Unit Tests
:sectnums:

This document describes how to run the unit tests for the OCH GPIO IP using Verilator.

First, make sure you have set up the environment as described in the main `README.adoc` file of the OCH repository:

```bash
pushd ../../../..
source bin/setup_env.sh
popd
```

Second, make sure you have built the GPIO IP and testbench as described in the main `README.adoc` file of the GPIO IP:

```bash
pushd ..
python3 generate_all_ips.py -i axi4-lite
popd
```

Next, run

```
make clean # If needed
make filelist
make [STRESS=1]
```

The `STRESS=1` option will run the tests with stress mode enabled, which includes additional checks and longer test durations. If you just want to run the sanity tests, simply omit the `STRESS` variable.
