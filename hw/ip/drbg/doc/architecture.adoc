[[drbg-deterministic-random-bit-generator]]
= DRBG Deterministic Random Bit Generator

The `drbg` wrapper combines OpenTitan CSRNG and EDN with seed packing,
endpoint queues and register-bus adapters. CSRNG implements the AES-CTR
construction described by https://csrc.nist.gov/pubs/sp/800/90/a/r1/final[NIST
SP 800-90A]. Algorithm choice alone is not a claim of system certification.
All wrapper logic uses `clk_i`; active-low reset must be released synchronously
to that clock. The wrapper adds no internal clock-domain crossing or autonomous
CSR initialization sequence.

== Parameters

[[drbg-parameters-table]]
.DRBG wrapper parameters
[cols="2,1,1,3",options="header"]
|===
|Parameter |Default |SEP |Meaning
|`SEED_FIFO_DEPTH` |1 |1 |Number of complete seeds queued for CSRNG.
|`EDN_ENDPOINT_COUNT` |1 |3 |Buffered AXI-Stream outputs.
|`EDN_NATIVE_ENDPOINT_COUNT` |0 |0 |Direct native EDN ports that bypass the
AXI-Stream queues. SEP uses external post-mux adapters instead.
|`ENDPOINT_FIFO_DEPTH` |8 |8 |32-bit words, with provenance, in each output queue.
|===

All four parameters are unsigned integers. Seed/output FIFO depths and the
AXI-Stream endpoint count must be positive. Native endpoints, when configured,
follow the AXI-Stream endpoints in the EDN index space; separate output queues
do not imply independent DRBG instances.

== Seed Assembly

`drbg_csrng_seed_adapter` packs twelve accepted 32-bit input words into one
384-bit seed and queues complete seeds. CSRNG consumes an entry through
`es_req` / `es_ack`; `es_bits` carries the seed and `es_fips` its tag.
The seed tag is provisionally fixed at 1, not derived from a health-test result.

The packer's ready output is not connected back to ESRC. While the packer
holds a complete seed awaiting queue space or handoff, incoming words are
not accepted. A full complete-seed FIFO can extend that interval; it is not
necessarily a single-cycle pause. The held seed remains intact, and packing
resumes when it can accept more words. Ingress is therefore not a lossless
stream transport, and no fixed reseed latency follows from its word rate.

== OpenTitan CSRNG and EDN

CSRNG supports instantiate, reseed, generate, update and uninstantiate commands.
EDN uses hardware application port 0 in the wrapper's hardware-port array;
additional hardware application ports are tied off. The software application
interface remains accessible through CSRNG registers. Initializing that software
instance does not initialize the hardware instance used by EDN.

EDN supplies endpoint requests after its mode and commands are configured.
Automatic mode can issue generate/reseed commands without a firmware action
for every delivered word; it does not remove initialization, command-status
checking or entropy-source recovery requirements.

`drbg_edn_axis_adapter` requests a native EDN word whenever its endpoint queue
has space, stores data and provenance together, and presents the oldest entry
until an AXI-Stream handshake consumes it. Backpressure fills that endpoint's
queue and then suppresses further requests. All SEP paths share the EDN-fed
CSRNG hardware instance; their separate interfaces are distribution paths.

For core command and mode behavior, see the OpenTitan
https://opentitan.org/book/hw/ip/csrng/[CSRNG] and
https://opentitan.org/book/hw/ip/edn/[EDN] documentation. The generated maps in
the SEP register reference describe the vendored register layout.

== Bus Protocol Adaptation

Each `drbg_axil64_lane_adapter` permits aligned 32-bit register accesses on its
64-bit AXI4-Lite port. Address bit 2 selects the lower or upper lane. Writes
must enable that entire lane: `WSTRB=0x0F` for the lower lane or `0xF0` for the
upper lane. Misaligned addresses, partial-lane writes, both-lane writes and
address/strobe mismatches return `SLVERR` without reaching the TL-UL core.
Reads use the same address alignment/lane selection; no write strobe applies.

Write address and data can arrive independently and are held until paired.
Only one downstream 32-bit transaction is active. Reads are accepted only
when neither write half was already pending; if a read and complete write
arrive together at idle, the read is forwarded first and the write waits.
The subsequent `axi_lite_to_tlul` bridge translates that access for CSRNG/EDN.
Use the generated register access rules rather than assuming a 64-bit port
permits a 64-bit register operation.
