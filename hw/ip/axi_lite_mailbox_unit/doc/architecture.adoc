=== Paired FIFOs

ifdef::backend-html5[]
++++
<span id="internal-structure"></span>
<span id="bidirectional-communication"></span>
++++
endif::backend-html5[]

An `axi_lite_demux` selects one of `2 * NUM_MAILBOXES` register apertures.
Within pair N, the outbound aperture writes FIFO A and reads FIFO B; the
inbound aperture writes FIFO B and reads FIFO A. The FIFOs are internal to
the unit. Flushing an aperture's write FIFO therefore discards data its peer
would read; flushing its read FIFO discards data the peer has already sent.

`WRITE_DATA` enqueues one word when space is available. Inactive AXI byte lanes
are written as zero; a partial write does not merge with an existing FIFO word.
`READ_DATA` returns and pops the oldest received word. Software must use status
to avoid full writes and empty reads; the interface reports errors rather than
waiting for FIFO space or data. The error responses are described below.

=== Interrupts

ifdef::backend-html5[]
++++
<span id="interrupt-architecture"></span>
<span id="interrupt-outputs"></span>
<span id="mailbox-interrupt-characteristics-table"></span>
++++
endif::backend-html5[]

Each aperture has its own `WIRQT`, `RIRQT`, `IRQS`, `IRQEN` and `IRQP`.
`inbound_interrupt_o[N]` and `outbound_interrupt_o[N]` are active-high level
outputs. Each is the OR of `IRQP = IRQS & IRQEN` for its aperture.

[[mailbox-interrupt-sources-table]]
[cols="1,1,3",options="header"]
.Mailbox interrupt sources
|===
|IRQS bit |Source |Set condition
|0 |Write threshold |Occupancy of the aperture's write FIFO is strictly greater
than `WIRQT`. This indicates queued outbound data, not successful peer receipt.
|1 |Read threshold |Occupancy of its read FIFO is strictly greater than `RIRQT`.
|2 |Access error |A full-FIFO write or empty-FIFO read. `ERROR_FLAGS` distinguishes
which access failed.
|===

These status bits latch independently of `IRQEN`. Acknowledge selected bits by
writing ones to `IRQS`; reading it does not clear them. Threshold status can
reassert if the occupancy condition remains true. `WIRQT` and `RIRQT` writes
are clamped to `MAILBOX_DEPTH - 1`, so a threshold of zero detects any queued
word and the maximum threshold detects a full FIFO.

`STATUS` exposes live FIFO-empty/full and threshold conditions. It is distinct
from the latched `IRQS`. Reading `ERROR_FLAGS` clears the detailed error flags,
but does not acknowledge the shared `IRQS` error bit.

=== Clock and Reset

ifdef::backend-html5[]
++++
<span id="mailbox-clock-and-reset-table"></span>
<span id="control-signals"></span>
<span id="mailbox-control-signal-descriptions-table"></span>
++++
endif::backend-html5[]

The unit and its FIFOs use `clk_i`; there is no internal clock-domain crossing.
`rst_ni` is asynchronous and active low. Reset empties the FIFOs and clears
thresholds, error flags, interrupt status and enables. `test_en_i` supplies the
AXI demultiplexer's test input. Follow subsystem reset and access-isolation
requirements when either endpoint is active.
