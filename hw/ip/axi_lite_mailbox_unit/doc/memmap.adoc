===== Memory Map

====== Address Space Organization

Each mailbox instance occupies a dedicated 2KB (0x800) address space.
The total address space is 0x20008 bytes supporting up to 64 mailbox
instances (32 pairs):

[source,sourceCode,text]
----
Base + 0x00000 - 0x007FF: Outbound Mailbox 0
Base + 0x00800 - 0x00FFF: Inbound Mailbox 0
Base + 0x01000 - 0x017FF: Outbound Mailbox 1
Base + 0x01800 - 0x01FFF: Inbound Mailbox 1
Base + 0x02000 - 0x027FF: Outbound Mailbox 2
Base + 0x02800 - 0x02FFF: Inbound Mailbox 2
...
Base + 0x1F000 - 0x1F7FF: Outbound Mailbox 31
Base + 0x1F800 - 0x1FFFF: Inbound Mailbox 31
Base + 0x20000 - 0x20007: MAILBOX_RSVD (Reserved space)
----

*Address Space Characteristics:*::
  * *Per-Mailbox Size*: 2KB (0x800)
  * *Total Address Space*: 0x20008 bytes
  * *Address Width*: 18 bits
  * *Maximum Mailboxes*: 32 pairs (64 instances)

====== Per-Mailbox Register Map

Within each 4KB mailbox address space, registers are organized as
follows:

.Register Address Map
[width="100%",cols="15%,20%,10%,15%,40%",options="header",]
|==============================================================
|Offset |Register Name |Width |Access |Description
|0x00 |WRITE_DATA |64-bit |W |Write data to mailbox FIFO
|0x08 |READ_DATA |64-bit |R |Read data from mailbox FIFO
|0x10 |STATUS |64-bit |R |FIFO status (empty, full, threshold)
|0x18 |ERROR_FLAGS |64-bit |R |Error flags (write/read errors)
|0x20 |WIRQT |64-bit |RW |Write interrupt threshold
|0x28 |RIRQT |64-bit |RW |Read interrupt threshold
|0x30 |IRQS |64-bit |RW |Interrupt status (write-1-to-clear)
|0x38 |IRQEN |64-bit |RW |Interrupt enable control
|0x40 |IRQP |64-bit |R |Interrupt pending status
|0x48 |CTRL |64-bit |W |Control register (FIFO flush)
|==============================================================
