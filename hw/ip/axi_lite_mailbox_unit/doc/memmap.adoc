== Memory Map

=== Address Space Organization

Each mailbox aperture occupies a dedicated 2KB (0x800) address space.
The total address space is 0x20000 bytes supporting up to 64 mailbox
apertures (32 pairs). The SMC and SEP wrapper layouts are generated from
their SystemRDL compositions:

*Address Space Characteristics:*::
  * *Per-Aperture Size*: `MAILBOX_SIZE`, 2KB (0x800)
  * *Total Address Space*: 0x20000 bytes for 32 pairs
  * *Decoded Address Span*: 17 bits for 32 pairs; the slave port itself is
    `ADDR_WIDTH` bits wide (32 in the SMC and SEP integrations)
  * *Maximum Mailboxes*: 32 pairs (64 apertures)

The two apertures of a pair are the two ends of the same pair of FIFOs:
`WRITE_DATA` in the outbound aperture pushes the FIFO that `READ_DATA` in the
paired inbound aperture pops, and vice versa. Both ends are reachable from the
same AXI4-Lite slave port.

=== Per-Mailbox Register Map

Within each 2KB mailbox aperture, registers are organized as follows.
Offsets are spaced by `DATA_WIDTH`/8, so they are 8 bytes apart in the
64-bit configurations used today. The generated detailed register map below is
authoritative for offsets, widths, access, and field descriptions. The `CTRL`
flush bits are pulses rather than stored state, so reads return zero with an
OKAY response.

=== Address Examples

For mailbox pair `N`, the outbound aperture begins at
`BASE + N * 0x1000`; the inbound aperture begins 0x800 bytes later. A
register address is the aperture base plus the generated register offset. For
example, in pair zero, `READ_DATA` is at `BASE + 0x8` outbound and
`BASE + 0x808` inbound.
