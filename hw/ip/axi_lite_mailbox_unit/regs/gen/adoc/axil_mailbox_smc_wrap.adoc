[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:8 | `Reserved` | - | - a| Reserved
| 7:0 | `wirqt` | RW | 0x0 a| When the usage pointer of the FIFO connected to the W channel exceeds this value, a write threshold IRQ is triggered and the corresponding STATUS register bit is set.
