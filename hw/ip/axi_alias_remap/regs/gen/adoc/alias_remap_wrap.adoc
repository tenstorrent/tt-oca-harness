[#regmap-{regmap-instance}-alias_remap_wrap]
== AXI Alias Remap Wrapper Address Map

Wrapper address map instantiating one alias remap register block per remap region.

[NOTE]
======
*Register Arrays:*

* *alias_remap[8].REGION.region_start*: 8 registers, base 0x0, stride 0x20
* *alias_remap[8].REGION.region_end*: 8 registers, base 0x8, stride 0x20
* *alias_remap[8].REGION.region_attrs*: 8 registers, base 0x10, stride 0x20
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 - 0xE0 | <<reg-{regmap-instance}-alias_remap_wrap-alias_remap-REGION-region_start,alias_remap[8].REGION.region_start>> | RW a| -
| 0x8 - 0xE8 | <<reg-{regmap-instance}-alias_remap_wrap-alias_remap-REGION-region_end,alias_remap[8].REGION.region_end>> | RW a| -
| 0x10 - 0xF0 | <<reg-{regmap-instance}-alias_remap_wrap-alias_remap-REGION-region_attrs,alias_remap[8].REGION.region_attrs>> | RW a| -
|===

[#reg-{regmap-instance}-alias_remap_wrap-alias_remap-REGION-region_start]
=== alias_remap[8].REGION.region_start

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `Reserved` | - | - a| Reserved
| 55:12 | `start_addr` | RW | 0x0 a| Start of remap region
| 11:0 | `Reserved` | - | - a| Reserved
|===

[#reg-{regmap-instance}-alias_remap_wrap-alias_remap-REGION-region_end]
=== alias_remap[8].REGION.region_end

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `Reserved` | - | - a| Reserved
| 55:12 | `end_addr` | RW | 0x0 a| End of remap region (non-inclusive).
| 11:0 | `Reserved` | - | - a| Reserved
|===

[#reg-{regmap-instance}-alias_remap_wrap-alias_remap-REGION-region_attrs]
=== alias_remap[8].REGION.region_attrs

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63 | `valid` | RW | 0x0 a| If set, this remap will be active
| 62:60 | `Reserved` | - | - a| Reserved
| 59:56 | `cacheable` | RW | 0x0 a| Set to change the value of the axcache field of the transaction. This field will override all existing axcache bits.
| 55:12 | `offset` | RW | 0x0 a| The value of this field is added to bits [55:12] of the input address when it falls within the remap region. The lower 12 bits of the address are preserved unchanged.
| 11:0 | `Reserved` | - | - a| Reserved
|===
