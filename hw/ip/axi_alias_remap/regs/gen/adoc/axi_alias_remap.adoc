[[offset-field]]
offset field
++++++++++++

The value of this field is added to bits [55:12] of the input address
when it falls within the remap region. The lower 12 bits of the address
are preserved unchanged.

[[cacheable-field]]
cacheable field
+++++++++++++++

If set, top two bits of a*cache will be tied high

[[valid-field]]
valid field
+++++++++++

If set, this remap will be active
