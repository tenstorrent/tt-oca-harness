[#regmap-{regmap-instance}-alias_remap]
== AXI Alias Remap Address Map

TLB Registers for address remapping and attribute tagging

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-alias_remap-REGION-region_start,region_start>> | RW a| -
| 0x8 | <<reg-{regmap-instance}-alias_remap-REGION-region_end,region_end>> | RW a| -
| 0x10 | <<reg-{regmap-instance}-alias_remap-REGION-region_attrs,region_attrs>> | RW a| -
|===

[#reg-{regmap-instance}-alias_remap-REGION-region_start]
=== region_start

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `Reserved` | - | - a| Reserved
| 55:12 | `start_addr` | RW | 0x0 a| Start of remap region
| 11:0 | `Reserved` | - | - a| Reserved
|===

[#reg-{regmap-instance}-alias_remap-REGION-region_end]
=== region_end

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `Reserved` | - | - a| Reserved
| 55:12 | `end_addr` | RW | 0x0 a| End of remap region (non-inclusive).
| 11:0 | `Reserved` | - | - a| Reserved
|===

[#reg-{regmap-instance}-alias_remap-REGION-region_attrs]
=== region_attrs

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63 | `valid` | RW | 0x0 a| If set, this remap will be active
| 62 | `cacheable` | RW | 0x0 a| If set, top two bits of a*cache will be tied high
| 61:56 | `Reserved` | - | - a| Reserved
| 55:12 | `offset` | RW | 0x0 a| The value of this field is added to bits [55:12] of the input address when it falls within the remap region. The lower 12 bits of the address are preserved unchanged.
| 11:0 | `Reserved` | - | - a| Reserved
|===
