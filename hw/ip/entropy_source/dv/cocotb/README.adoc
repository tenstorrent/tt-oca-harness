= OCA Entropy Source Unit Tests (VCS)
:sectnums:

This document describes how to run the unit tests for the Entropy Source Component using VCS.

First, make sure you have set up the environment as described in the main `README.adoc` file of the
OCA repository:

```bash
pushd ../../../..
source bin/setup_env.sh
popd
```

Next, run

```
make clean
make WAVES=1
```
