CHECKER NOTATION
----------------
  V      - Checker enabled and actively verifying
  -      - Checker disabled for this test
  Manual - Manual verification required (not automated checker)

APB REGISTER INTERFACE
----------------------
All register access via standardized APB read/write functions:
  - reg_rd(dut, address) -> returns 32-bit register value
  - reg_wr(dut, address, value) -> writes 32-bit register value
  - Proper APB handshaking with psel_i, penable_i, pready_o

ENTROPY INJECTION METHODS
--------------------------
All tests use behavioral RO (Ring Oscillator) model injection:
  - configure_entropy(dut, p_bias, p_corr, div) -> general configuration
  - configure_good_entropy(dut, div) -> balanced entropy (p_bias=0.5, p_corr=0.0)
  - configure_degraded_entropy(dut) -> stuck-at-0 for all 12 lanes
  - configure_biased_entropy(dut, p_bias, div) -> biased patterns
  - configure_correlated_entropy(dut, p_corr, div) -> correlated patterns
  - configure_mixed_entropy(dut, lane_configs) -> per-lane configuration

REPETITION COUNTER SEMANTICS
-----------------------------
The REPETITION_TEST_COUNT register counts run length (total consecutive occurrences):
  - First identical bit: counter = 1
  - Second identical bit: counter = 2
  - Third identical bit: counter = 3
  - Different bit: counter = 1 (new run starts)
  - Failure triggers when: counter >= threshold

Example: For threshold=10, failure occurs at 10th consecutive identical bit.
