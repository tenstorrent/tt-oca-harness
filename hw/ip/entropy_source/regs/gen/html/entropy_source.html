STARTUP_CTRL

BitsFieldAccessResetDescription
31:16Reserved--Reserved
15:0DELAY_CYCLESRW0x0Startup delay in system clock cycles after power-on reset before entropy collection begins. A 16-bit countdown timer is loaded with this value on reset and decrements each cycle. When counter reaches 0, entropy collection activates. GATED (blocked until delay expires): (1) FIFO writes - no entropy data pushed to collection FIFO, (2) Health test processing - counters frozen, no samples processed, (3) External entropy valid signal (entropy_stream_vld_o) - remains low, (4) Downsample counter - does not advance. NOT GATED (continues running during delay): (1) Ring oscillators - all 12 noise ROs and shared sampling RO oscillate immediately, (2) Entropy generation - raw bits produced from metastable sampling, (3) Decorrelators - LFSR processing continues internally, (4) BIW extractor - compression logic remains active, (5) Synchronizers - clock domain crossing continues. Purpose: Allow ROs to reach thermal/electrical steady-state (frequency settling, jitter stabilization, bias settling, metastability equilibrium). Early transient samples are discarded. Recommended values: 1000-10000 cycles (1-10 uss at 1 GHz) for standard startup, 10000-100000 cycles (10-100 uss at 1 GHz) for high-assurance applications. Set to 0 to disable delay (use with caution - initial entropy may have reduced quality). Default=0 (no startup delay).
