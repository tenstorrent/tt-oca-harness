== Entropy Source Address Map

Entropy-source configuration, status, and data registers.

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-entropy_source-COMPONENT_ID,COMPONENT_ID>> | R a| Identifies the entropy-source register interface.
| 0x4 | <<reg-{regmap-instance}-entropy_source-CTRL,CTRL>> | RW a| Controls entropy generation and conditioning.
| 0xC | <<reg-{regmap-instance}-entropy_source-DEBUG_CTRL,DEBUG_CTRL>> | RW a| Controls the external debug observation pin. These fields remain writable after FIPS_LOCK.LOCK; system integration controls access to exposed pre-conditioning entropy.
| 0x10 | <<reg-{regmap-instance}-entropy_source-INTR_STATUS,INTR_STATUS>> | RW a| Reports latched interrupt status; write one to clear a bit.
| 0x14 | <<reg-{regmap-instance}-entropy_source-INTR_ENABLE,INTR_ENABLE>> | RW a| Enables individual interrupt sources.
| 0x18 | <<reg-{regmap-instance}-entropy_source-INTR_TEST,INTR_TEST>> | W a| Triggers individual interrupt sources for testing.
| 0x1C | <<reg-{regmap-instance}-entropy_source-SHA256_STATUS,SHA256_STATUS>> | R a| Reports SHA-256 conditioner progress.
| 0x20 | <<reg-{regmap-instance}-entropy_source-FIFO_CTRL,FIFO_CTRL>> | RW a| Controls the 64-entry main entropy FIFO.
| 0x24 | <<reg-{regmap-instance}-entropy_source-FIFO_STATUS,FIFO_STATUS>> | R a| Reports main FIFO occupancy and pointers.
| 0x28 | <<reg-{regmap-instance}-entropy_source-FIFO_RDATA,FIFO_RDATA>> | R a| Provides the next main FIFO word.
| 0x30 | <<reg-{regmap-instance}-entropy_source-HEALTH_TEST_CTRL,HEALTH_TEST_CTRL>> | RW a| Controls continuous entropy health tests.
| 0x34 | <<reg-{regmap-instance}-entropy_source-HEALTH_TEST_WINDOW_SIZE,HEALTH_TEST_WINDOW_SIZE>> | RW a| Sets the APT and Markov window length.
| 0x38 | <<reg-{regmap-instance}-entropy_source-MARKOV_TEST_PROB_THRESHOLDS,MARKOV_TEST_PROB_THRESHOLDS>> | RW a| Sets high and low Markov alternation-count thresholds.
| 0x40 | <<reg-{regmap-instance}-entropy_source-HEALTH_TEST_STATUS,HEALTH_TEST_STATUS>> | RW a| Latches 32-bit stream health-test failures: repetition [0], APT high or low [3], Markov high [4], and Markov low [5]. Write one to clear.
| 0x44 | <<reg-{regmap-instance}-entropy_source-REPETITION_TEST_COUNT,REPETITION_TEST_COUNT>> | R a| Reports the highest current repetition count.
| 0x50 | <<reg-{regmap-instance}-entropy_source-APT_PATTERN_COUNT_1BIT,APT_PATTERN_COUNT_1BIT>> | R a| Reports the highest per-lane APT one-count in the current window.
| 0x54 | <<reg-{regmap-instance}-entropy_source-APT_PATTERN_COUNT_2BIT,APT_PATTERN_COUNT_2BIT>> | R a| Reports the lowest per-lane APT one-count in the current window.

| 0x80 | <<reg-{regmap-instance}-entropy_source-MARKOV_TEST_COUNTS_0,MARKOV_TEST_COUNTS_0>> | R a| Reports the highest and lowest per-lane alternation counts in the current Markov window.
| 0x90 | <<reg-{regmap-instance}-entropy_source-RING_OSC_ENABLE,RING_OSC_ENABLE>> | RW a| Controls noise and sample-clock ring oscillators.
| 0x94 | <<reg-{regmap-instance}-entropy_source-RING_OSC_TUNE,RING_OSC_TUNE>> | RW a| Selects detuned ring-oscillator tap points.
| 0x98 | <<reg-{regmap-instance}-entropy_source-RING_OSC_CTRL,RING_OSC_CTRL>> | RW a| Selects each generator sample-clock source.
| 0xA0 | <<reg-{regmap-instance}-entropy_source-DECORRELATOR_CTRL,DECORRELATOR_CTRL>> | RW a| Controls generator decorrelation and byte cadence.
| 0xA4 | <<reg-{regmap-instance}-entropy_source-DECORRELATOR_MASK,DECORRELATOR_MASK>> | RW a| Masks bits in every generator entropy byte.
| 0xB4 | <<reg-{regmap-instance}-entropy_source-MAIN_SM_STATUS,MAIN_SM_STATUS>> | RW a| Reports the startup health-test gate state machine.
| 0xC0 | <<reg-{regmap-instance}-entropy_source-GENERATOR_0_HEALTH_STATUS,GENERATOR_0_HEALTH_STATUS>> | RW a| Latches generator 0 health-test failures; write one to clear.
