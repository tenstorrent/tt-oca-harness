.FIFO_CTRL Register
|===
| Bits | Field | Access | Reset | Description
| 31:5 | `Reserved` | - | - a| Reserved
| 4 | `ENTROPY_CHURN_ENABLE` | RW | 0x0 a| Entropy Churning Mode Enable. When asserted high, incoming entropy data is XORed with existing FIFO data located at (write_ptr + DEPTH/2) % DEPTH before being written. This creates a circular feedback churning pattern where new entropy is combined with entropy from halfway around the FIFO buffer (16 entries earlier for DEPTH=32). Churning operation: write_data = incoming_data XOR mem[(wptr + 16) % 32]. Purpose: Enhance entropy quality through continuous churning of fresh randomness with accumulated randomness. Useful for additional conditioning and resistance to entropy source degradation. Default=0 (disabled, direct write without churning).
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `ENABLE` | RW | 0x1 a| FIFO write enable control. When enabled (1=default), entropy data flows into FIFO and write pointer updates normally. When disabled (set to 0), write operations are blocked: no entropy pushed, write pointer frozen, data collection paused. IMPORTANT: Read operations remain functional when disabled - software can still drain the FIFO by reading FIFO_RDATA. This allows capturing a snapshot of entropy and reading it out without new data being added. Use case: Stop entropy collection, drain FIFO for analysis, re-enable collection. Default=1 (enabled).

.STARTUP_CTRL Register
|===
| Bits | Field | Access | Reset | Description
| 31:16 | `Reserved` | - | - a| Reserved
| 15:0 | `DELAY_CYCLES` | RW | 0x0 a| Startup delay in system clock cycles after power-on reset before entropy collection begins. A 16-bit countdown timer is loaded with this value on reset and decrements each cycle. When counter reaches 0, entropy collection activates. GATED (blocked until delay expires): (1) FIFO writes - no entropy data pushed to collection FIFO, (2) Health test processing - counters frozen, no samples processed, (3) External entropy valid signal (entropy_stream_vld_o) - remains low, (4) Downsample counter - does not advance.
