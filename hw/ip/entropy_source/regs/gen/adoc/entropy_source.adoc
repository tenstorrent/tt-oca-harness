[[reset-field]]
RESET field
+++++++++++

Software controlled reset when asserted high. Resets all internal state
including health test counters, FIFO pointers, and decorrelator shift
registers. Ring oscillators continue running. Self-clearing after 1
clock cycle.

[[autotune_enable-field]]
AUTOTUNE_ENABLE field
+++++++++++++++++++++

Enable automatic detuning of individual ring oscillator noise generators
when corresponding per-generator health tests fail. When enabled, a
failing health test causes the generator’s noise RO to switch to its
detuned (higher frequency) tap point. The shared sampling RO also
detunes if ANY generator requests it. Automatic detuning is disabled by
default (manual tuning via RING_OSC_TUNE required).

[[bypass_entropy_compressor-field]]
BYPASS_ENTROPY_COMPRESSOR field
+++++++++++++++++++++++++++++++

Bypass Entropy Compressor (BIW extractor) when asserted high. When
bypassed, all 96 bytes from the 12 generators (8 bytes each) are pushed
directly into the FIFO without compression, increasing FIFO fill rate by
3x (96 bytes vs 32 bits per cycle). Used for raw entropy analysis and
testing. Disabled by default (32-bit compressed output).

[[downsample_rate-field]]
DOWNSAMPLE_RATE field
+++++++++++++++++++++

Downsample Rate for the decorrelator output. Specifies additional clock
cycles to wait between entropy byte outputs. Value of N means output
every (N+1) cycles. Applied after DECORRELATOR_CTRL.SAMPLE_CLK_DIV.
Example: if SAMPLE_CLK_DIV=63 (div64) and DOWNSAMPLE_RATE=3, effective
rate is div256 (64*(3+1)). Default=0 (no additional downsampling).

[[sha256_whitening_enable-field]]
SHA256_WHITENING_ENABLE field
+++++++++++++++++++++++++++++

Enable SHA-256 whitening stage after BIW compression. When enabled, 16 ×
32-bit BIW outputs (512 bits) are accumulated and hashed using SHA-256,
producing 8 × 32-bit digest words (256 bits). This provides
cryptographic conditioning per NIST SP 800-90B. When disabled, BIW
output goes directly to FIFO (passthrough mode). Default=1 (enabled).

[[select_signal-field]]
SELECT_SIGNAL field
+++++++++++++++++++

Select Signal. Selects one of 256 internal signals to route to the

[[fifo_ctrl-register]]
FIFO_CTRL register
^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x20
* Base Offset: 0x20
* Size: 0x4

FIFO Control (32-entry x 32-bit entropy collection buffer)

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|0 |ENABLE |rw |0x1 |—
|4 |ENTROPY_CHURN_ENABLE |rw |0x0 |—
|=====================================

[[enable-field]]
ENABLE field
++++++++++++

FIFO write enable control. When enabled (1=default), entropy data flows
into FIFO and write pointer updates normally. When disabled (set to 0),
write operations are blocked: no entropy pushed, write pointer frozen,
data collection paused. IMPORTANT: Read operations remain functional
when disabled - software can still drain the FIFO by reading FIFO_RDATA.
This allows capturing a snapshot of entropy and reading it out without
new data being added. Use case: Stop entropy collection, drain FIFO for
analysis, re-enable collection. Default=1 (enabled).

[[entropy_churn_enable-field]]
ENTROPY_CHURN_ENABLE field
++++++++++++++++++++++++++

Entropy Churning Mode Enable. When asserted high, incoming entropy data
is XORed with existing FIFO data located at (write_ptr + DEPTH/2) %
DEPTH before being written. This creates a circular feedback churning
pattern where new entropy is combined with entropy from halfway around
the FIFO buffer (16 entries earlier for DEPTH=32). Churning operation:
write_data = incoming_data XOR mem[(wptr + 16) % 32]. Purpose: Enhance
entropy quality through continuous churning of fresh randomness with
accumulated randomness. Useful for additional conditioning and
resistance to entropy source degradation. Default=0 (disabled, direct
write without churning).

[[enable-field-1]]
ENABLE field
++++++++++++

Enable bits for health tests [7:0]. Bit allocation: [0]=Repetition Count
Test, [1:2]=Reserved, [3]=Adaptive Proportion Test (APT), [4:7]=Markov
Test. Set bit to 1 to enable corresponding test. When a test is disabled

32-bit entropy stream. Default=0x7 (Repetition, APT, Markov enabled).

[[repetition_limit-field]]
REPETITION_LIMIT field
++++++++++++++++++++++

Repetition Count Test threshold. Maximum allowed consecutive repetitions
of the same value before test fails. NIST SP 800-90B recommends 15-30
for typical entropy sources. Lower values (5-10) increase sensitivity
but may cause false alarms. Higher values (20-40) reduce false alarms
but may miss stuck-at faults. Default=25 (covers 32 per-bit counters
with <1% false positive rate).

^^^^^^^^^^^^^^^^^^^^^

|=====================================

[[delay_cycles-field]]
DELAY_CYCLES field
++++++++++++++++++

Startup delay in system clock cycles after power-on reset before entropy
collection begins. A 16-bit countdown timer is loaded with this value on
reset and decrements each cycle. When counter reaches 0, entropy
collection activates. GATED (blocked until delay expires): (1) FIFO
writes - no entropy data pushed to collection FIFO, (2) Health test
processing - counters frozen, no samples processed, (3) External entropy
valid signal (entropy_stream_vld_o) - remains low, (4) Downsample
counter - does not advance. NOT GATED (continues running during delay):
(1) Ring oscillators - all 12 noise ROs and shared sampling RO oscillate
immediately, (2) Entropy generation - raw bits produced from metastable
sampling, (3) Decorrelators - LFSR processing continues internally, (4)
BIW extractor - compression logic remains active, (5) Synchronizers -
clock domain crossing continues. Purpose: Allow ROs to reach
thermal/electrical steady-state (frequency settling, jitter
stabilization, bias settling, metastability equilibrium). Early
transient samples are discarded. Recommended values: 1000-10000 cycles
(1-10 uss at 1 GHz) for standard startup, 10000-100000 cycles (10-100
uss at 1 GHz) for high-assurance applications. Set to 0 to disable delay
(use with caution - initial entropy may have reduced quality). Default=0
(no startup delay).
