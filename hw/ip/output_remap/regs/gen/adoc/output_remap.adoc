[#reg-{regmap-instance}-output_remap-REGION-region_attrs]
=== region_attrs

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `Reserved` | - | - a| Reserved
| 55:0 | `offset` | RW | 0x0 a| Address translation for remap region. RTL will use the number of bits appropriate for region granulaity.
e.g. SMC: 8 * 1MB regions --> 20 bits of address space per region, 36 MSBs from this register used
SEP: 16 * 512KB regions --> 19 bits of address space per region, 37 MSBs from this register used
|===
