[[offset-field]]
offset field
++++++++++++

Address translation for remap region. RTL will use the number of bits
appropriate for region granulaity. e.g. SMC: 8 * 1MB regions –> 20 bits
of address space per region, 36 MSBs from this register used SEP: 16 *
512KB regions –> 19 bits of address space per region, 37 MSBs from this
register used
