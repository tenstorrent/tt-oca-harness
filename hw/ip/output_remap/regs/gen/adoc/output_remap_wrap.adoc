[#regmap-{regmap-instance}-output_remap_wrap]
== Output Remap Wrapper Address Map

Wrapper address map instantiating one output remap register block per remap region.

[NOTE]
======
*Register Arrays:*

* *output_remap[8].REGION.region_attrs*: 8 registers, base 0x0, stride 0x8
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 - 0x38 | <<reg-{regmap-instance}-output_remap_wrap-output_remap-REGION-region_attrs,output_remap[8].REGION.region_attrs>> | RW a| -
|===

[#reg-{regmap-instance}-output_remap_wrap-output_remap-REGION-region_attrs]
=== output_remap[8].REGION.region_attrs

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63 | `valid` | RW | 0x0 a| If set, accesses to this region are remapped by offset; if clear, they pass through with their address unchanged
| 62:56 | `Reserved` | - | - a| Reserved
| 55:0 | `offset` | RW | 0x0 a| Address translation for remap region. RTL will use the number of bits appropriate for region granulaity.
e.g. SMC: 8 * 1MB regions --> 20 bits of address space per region, 36 MSBs from this register used
SEP: 16 * 512KB regions --> 19 bits of address space per region, 37 MSBs from this register used
|===
