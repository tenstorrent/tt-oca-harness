[[system-timer-octs-interface]]
== Interface

The `system_timer_octs` wrapper has no configurable module parameters.
Its package fixes AXI4-Lite addresses and data at 32 bits. The timer core
receives its step from `CTRL.STEP`; `timer_cnt_step_i` is a core input,
not an external wrapper port.

[[octs-synchronization-interface-signals-table]]
.OCTS synchronization interface
[cols="2,1,3",options="header"]
|===
|Signal |Direction |Meaning
|`timer_sync_load_i` |Input |Secondary preset-load event, detected on a rising edge.
|`timer_cnt_credit_i` |Input |Secondary credit-boundary event, detected on a rising edge.
|`timer_sync_load_o` |Output |Primary load pulse.
|`timer_cnt_credit_o` |Output |Primary credit pulse.
|===

A primary ignores both inputs. A secondary holds both outputs low.
See <<octs-pulses>> for pulse capture and spacing requirements.

[[octs-timer-counter-interface-signals-table]]
.OCTS count, GPIO and debug outputs
[cols="2,1,3",options="header"]
|===
|Signal |Width |Meaning
|`timer_count_o` |64 |Current local count, in the `clk_i` domain.
|`timer_gpio_enable_o` |1 |`TIMER_GPIO_ENABLE.GPIO_ENABLE`; selects the timer's GPIO LSIO path in SMC.
|`cur_credits_debug_o` |9 |Consumed secondary credits.
|`credits_left_debug_o` |1 |Consumed credits are less than `CREDIT_VAL`.
|===

Connect primary outputs to the corresponding secondary inputs. Where the
SMC GPIO path is used, enable it after configuration and before START.
Crossing `timer_count_o` into another clock domain requires separate coherent
capture; the synchronization pulse inputs do not provide that capture.

The wrapper exposes no APB, interrupt, `test_en_i` or `scan_rst_ni` port.
Physical setup/hold, reset and pad timing belong to the integrated implementation.
