=== Memory Map

The register bank occupies `0x00`–`0x23` and uses 32-bit AXI4-Lite accesses.
Use the enclosing subsystem's memory map for its base address.

[[octs-register-reset-values-and-power-on-behavior-table]]
.OCTS register offsets and reset values
[cols="2,1,1,3",options="header"]
|===
|Register |Offset |Reset |Meaning
|`TIMER_START` |`0x00` |0 |START is a single-cycle command.
|`CTRL` |`0x04` |`0x0001020A` |STEP=1, PULSE_WIDTH=2, CREDIT_VAL=10.
|`STATUS` |`0x08` |0 |MODE subsequently reflects the role input; RUNNING reflects enable and nonzero count.
|`TIMER_PRESET_LO/HI` |`0x0C/0x10` |0 |Two independently writable preset halves.
|`TIMER_COUNT_LO/HI` |`0x14/0x18` |0 |Live count halves; see <<octs-read-count>>.
|`CREDIT_EXPIRED` |`0x1C` |0 |Saved maximum wait for credit; any write clears it.
|`TIMER_GPIO_ENABLE` |`0x20` |0 |Timer GPIO LSIO selection starts disabled.
|===

The generated STATUS description refers to a mode parameter. In this wrapper,
mode comes from the `is_primary_i` input.
