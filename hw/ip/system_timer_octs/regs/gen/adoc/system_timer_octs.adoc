[[credit_val-field]]
CREDIT_VAL field
++++++++++++++++

Credit value factor.

[[pulse_width-field]]
PULSE_WIDTH field
+++++++++++++++++

Pulse width for sync load and credit signals.

[[step-field]]
STEP field
++++++++++

Step amount for secondary timer.

MODE field

RUNNING field
+++++++++++++
