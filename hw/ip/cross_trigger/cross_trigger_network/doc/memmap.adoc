[[ctn-memory-map]]

The Cross Trigger Network combines the Cross Trigger Matrix (CTM) and Cross
Trigger Port (CTP) registers into a unified address space. Its generated map
keeps the CTP instance count and stride with the allocated apertures:

ifdef::backend-html5[]
include::partial$cross_trigger_network/regs/gen/adoc/memory_map.adoc[]
endif::backend-html5[]

ifdef::backend-pdf[]
include::../regs/gen/adoc/memory_map.adoc[]
endif::backend-pdf[]

The CTN decodes the AXI-Lite CSR interface onto the CTM and CTP blocks it
instantiates. The composite SystemRDL top is the common source for these
addresses and for the generated RTL constants.
