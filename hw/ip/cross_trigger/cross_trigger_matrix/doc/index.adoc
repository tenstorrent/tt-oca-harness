=== Cross Trigger Matrix

==== Overview

The Cross Trigger Matrix (CTM) is a crossbar that aggregates and statically
routes cross trigger pulses between various sources and sinks. Typical
connections to the CTM include Core Logic Analyzers (CLAs) and Cross Trigger
Ports (CTPs), including other miscellaneous devices.

The CTM is compatible with CTPs operating in either of the two signaling modes,
point-to-point or wire-OR. Typically, each device or logic module connected to
the CTM will act as both a source and a sink for cross trigger pulses.

==== Configuration Parameters

[cols="<,<,<,<",options="header"]
|===
|Parameter |Range |Default |Description
|NUM_CT_SRC |26 |26 |Number of CT_Src output ports, fixed by the register map
|NUM_CT_DST |1-26 |26 |Number of CT_Dst input ports
|===

The register map provides one configuration register per CT_Src port, each with
a 26-bit destination select field, so `NUM_CT_SRC` is fixed at 26 and
`NUM_CT_DST` can only be narrowed. See <<ctm-architecture>> for how the select
fields drive the crossbar.
