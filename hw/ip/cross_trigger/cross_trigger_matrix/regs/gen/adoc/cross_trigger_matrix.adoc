*Register Arrays:* This register map contains the following register arrays:

  ** Base Address: 0x0
  ** Address Increment: 0x8 per register

======

[cols="1,1,1,3", options="header"]
.Register Map
|===
| Address | Name | Access | Description
| 0x0 - 0xC8 | CT_SRC[26].CONFIG_0 | RW a| Cross Trigger Source Configuration - Lower 32 CT_Dst ports
|===

[cols="1,1,1,1,3", options="header"]
.CT_SRC[26].CONFIG_0 Register
|===
| Bits | Field | Access | Reset | Description
| 31:26 | `RESERVED` | RW | 0x0 a| Reserved. Must be written as zero.
| 25:0 | `CT_DST_SELECT` | RW | 0x0 a| Selects the CT_Dst port(s) to forward on the CT_Src output
at this array index. Each bit is mapped to a CT_Dst port
(bits [25:0] correspond to CT_Dst[25:0]). Multiple ports
may be selected as a trigger source. All selected source
ports are then OR'd together to produce the CT_Src output.
Set this register to all-zero to disable that output. Bits
[31:26] are reserved and should be written as zero.
|===
