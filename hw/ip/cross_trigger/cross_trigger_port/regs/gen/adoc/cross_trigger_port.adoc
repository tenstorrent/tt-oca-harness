[#regmap-{regmap-instance}-cross_trigger_port]
== Address Map: cross_trigger_port

*Cross Trigger Port Address Map* — Configuration and status registers for the cross trigger port

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-cross_trigger_port-CONFIG,CONFIG>> | RW a| Cross Trigger Port Configuration
| 0x4 | <<reg-{regmap-instance}-cross_trigger_port-STATUS,STATUS>> | R a| Cross Trigger Port Status
| 0x8 | <<reg-{regmap-instance}-cross_trigger_port-STRETCH_MULT,STRETCH_MULT>> | RW a| Pulse Stretch Multiplier
|===

[#reg-{regmap-instance}-cross_trigger_port-CONFIG]
=== CONFIG

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:3 | `Reserved` | - | - a| Reserved
| 2 | `RESET` | RW | 0x0 a| Forcefully clears the request output signal of the point-to-point handshake logic. Primarily for debug and recovery of handshake deadlock.
| 1 | `INVERT` | RW | 0x0 a| Inverts the sense of the incoming and outgoing GPIO signals. 0 - No inversion. Wire-OR mode uses active-low signaling with active or passive pull-ups. Point-to-point mode uses active-high signaling. 1 - All inputs and outputs of I/Os are inverted. Wire-OR mode uses active-high signaling with active or passive pull-downs. Point-to-point mode uses active-low signaling.
| 0 | `MODE` | RW | 0x0 a| Selects the operating mode of the CTP. 0 - Wire-OR, 1 - Point-to-Point
|===

[#reg-{regmap-instance}-cross_trigger_port-STATUS]
=== STATUS

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:8 | `Reserved` | - | - a| Reserved
| 7 | `ACK_OUT` | R | 0x0 a| Readout of the current CT_Ack_out signal value.
| 6 | `REQ_IN` | R | 0x0 a| Readout of the current synchronized CT_Req_in signal value.
| 5 | `ACK_IN` | R | 0x0 a| Readout of the current synchronized CT_Ack_in signal value.
| 4 | `REQ_OUT` | R | 0x0 a| Readout of the current CT_Req_out signal value.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `BUSY` | R | 0x0 a| Indicates whether a pulse assertion or handshake is currently in progress. 0 - Pulse or handshake is not in progress, 1 - Pulse or handshake is currently in progress
|===

[#reg-{regmap-instance}-cross_trigger_port-STRETCH_MULT]
=== STRETCH_MULT

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:16 | `Reserved` | - | - a| Reserved
| 15:0 | `STRETCH_MULT` | RW | 0x0 a| The number of clock cycles a core-side cross trigger pulse is stretched on the GPIO pin when in wire-OR mode. Whenever a core-side pulse is received, the generated GPIO pulse has a width of (STRETCH_MULT+1) clock cycles.
|===
