CONFIG

BitsFieldAccessResetDescription
31:3Reserved--Reserved
2RESETRW0x0Forcefully clears the request output signal of the point-to-point handshake logic. Primarily for debug and recovery of handshake deadlock.
1INVERTRW0x0Inverts the sense of the incoming and outgoing GPIO signals. 0 - No inversion. Wire-OR mode uses active-low signaling with active or passive pull-ups. Point-to-point mode uses active-high signaling. 1 - All inputs and outputs of I/Os are inverted. Wire-OR mode uses active-high signaling with active or passive pull-downs. Point-to-point mode uses active-low signaling.
0MODERW0x0Selects the operating mode of the CTP. 0 - Wire-OR, 1 - Point-to-Point

15:0STRETCH_MULTRW0x0The number of clock cycles a core-side cross trigger pulse is stretched on the GPIO pin when in wire-OR mode. Whenever a core-side pulse is received, the generated GPIO pulse has a width of (STRETCH_MULT+1) clock cycles.
