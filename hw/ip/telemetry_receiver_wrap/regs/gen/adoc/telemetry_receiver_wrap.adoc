|=====================================

[[buffer_pop-field]]
BUFFER_POP field
++++++++++++++++

Telemetry Message Buffer Pop. Effective only if STATUS.BUFFER_EMPTY = 0.
Writing 1 pops the buffer and thus updates the data in the
TELEMETRY_PROBE_ID, TELEMETRY_COUNTER_VLDS, and TELEMETRY_COUNTER[32]
registers.

[[telemetry_rx_flush-field]]
TELEMETRY_RX_FLUSH field
++++++++++++++++++++++++

Telemetry Receiver Flush. Writing 1 flushes the Telemetry Receiver
Buffer and all other storage elements in the Telemetry Receiver.

[[telemetry_tx_flush-field]]
TELEMETRY_TX_FLUSH field
++++++++++++++++++++++++

Telemetry Transmitter Flush. Writing 1 flushes all FIFOs in the
telemetry transmitter. The flushing is done via the ATB AF interface.
This bit clears itself after the flush completes.

[[buffer_threshold-field]]
BUFFER_THRESHOLD field
++++++++++++++++++++++

Telemetry Message Buffer Threshold. The Telemetry Buffer Threshold
Interrupt is asserted when the number of entries in the buffer is
greater than this value.

[[missing_last-field]]
MISSING_LAST field
++++++++++++++++++

Last Packet Missing Interrupt. Asserted when the Telemetry Receiver has
not received a Last Packet flag when the maximum number of packets a
message can consist of has been received.

[[buffer_threshold-field-1]]
BUFFER_THRESHOLD field
++++++++++++++++++++++

Telemetry Message Buffer Threshold Interrupt. Asserted when the number
of telemetry messages in the Telemetry Message Buffer is greater than
CTRL.BUFFER_THRESHOLD.

[[buffer_pop-field-1]]
BUFFER_POP field
++++++++++++++++

Telemetry Message Buffer Pop. Effective only if STATUS.BUFFER_EMPTY = 0.
Writing 1 pops the buffer and thus updates the data in the
TELEMETRY_PROBE_ID, TELEMETRY_COUNTER_VLDS, and TELEMETRY_COUNTER[32]
registers.

[[telemetry_rx_flush-field-1]]
TELEMETRY_RX_FLUSH field
++++++++++++++++++++++++

Telemetry Receiver Flush. Writing 1 flushes the Telemetry Receiver
Buffer and all other storage elements in the Telemetry Receiver.

[[telemetry_tx_flush-field-1]]
TELEMETRY_TX_FLUSH field
++++++++++++++++++++++++

Telemetry Transmitter Flush. Writing 1 flushes all FIFOs in the
telemetry transmitter. The flushing is done via the ATB AF interface.
This bit clears itself after the flush completes.

[[buffer_threshold-field-4]]
BUFFER_THRESHOLD field
++++++++++++++++++++++

Telemetry Message Buffer Threshold. The Telemetry Buffer Threshold
Interrupt is asserted when the number of entries in the buffer is
greater than this value.

[[buffer_pop-field-2]]
BUFFER_POP field
++++++++++++++++

Telemetry Message Buffer Pop. Effective only if STATUS.BUFFER_EMPTY = 0.
Writing 1 pops the buffer and thus updates the data in the
TELEMETRY_PROBE_ID, TELEMETRY_COUNTER_VLDS, and TELEMETRY_COUNTER[32]
registers.

[[telemetry_rx_flush-field-2]]
TELEMETRY_RX_FLUSH field
++++++++++++++++++++++++

Telemetry Receiver Flush. Writing 1 flushes the Telemetry Receiver
Buffer and all other storage elements in the Telemetry Receiver.

[[telemetry_tx_flush-field-2]]
TELEMETRY_TX_FLUSH field
++++++++++++++++++++++++

Telemetry Transmitter Flush. Writing 1 flushes all FIFOs in the
telemetry transmitter. The flushing is done via the ATB AF interface.
This bit clears itself after the flush completes.

[[buffer_threshold-field-8]]
BUFFER_THRESHOLD field
++++++++++++++++++++++

Telemetry Message Buffer Threshold. The Telemetry Buffer Threshold
Interrupt is asserted when the number of entries in the buffer is
greater than this value.
