[#regmap-{regmap-instance}-zeroer_ctrl]
== Zeroer Control Address Map

Control and status registers for the AXI memory-zeroing engine.

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-zeroer_ctrl-DEST_ADDR,DEST_ADDR>> | RW a| -
| 0x8 | <<reg-{regmap-instance}-zeroer_ctrl-SIZE,SIZE>> | RW a| -
| 0x10 | <<reg-{regmap-instance}-zeroer_ctrl-CTRL_STATUS,CTRL_STATUS>> | RW a| Any write to this register triggers the start of the zeroer, irrespective of WSTRB,
including a write with no byte lanes enabled. The start is ignored while SIZE is 0.
DEST_ADDR and SIZE are captured when a clear starts; later writes to them do not
affect the clear in progress. While a clear is still issuing write bursts, a write
to this register completes on the bus but does not start a clear. Once the last
burst of a clear has been issued, a write starts a new clear even while write
responses of the previous clear are outstanding; STATUS then reads 1 across both
clears, and the completion interrupt pulses once, when STATUS returns to 0.
Wait for STATUS to read 0 before writing this register again.
|===

[#reg-{regmap-instance}-zeroer_ctrl-DEST_ADDR]
=== DEST_ADDR

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:0 | `DEST_ADDR` | RW | 0x0 a| Byte address to write zeros to
|===

[#reg-{regmap-instance}-zeroer_ctrl-SIZE]
=== SIZE

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:0 | `SIZE` | RW | 0x0 a| Size in bytes of zeros to write
|===

[#reg-{regmap-instance}-zeroer_ctrl-CTRL_STATUS]
=== CTRL_STATUS

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:33 | `Reserved` | - | - a| Reserved
| 32 | `STATUS` | R | 0x0 a| Indicates whether the zeroer is busy. 1 means the zeroer is active, has pending work, or is in an error state; 0 means it is idle with no pending or outstanding work, including after completion.
| 31:1 | `Reserved` | - | - a| Reserved
| 0 | `INT_EN` | RW | 0x0 a| If enabled, an interrupt will be outputted once zeroer completes.
|===
