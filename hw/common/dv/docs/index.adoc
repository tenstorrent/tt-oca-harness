[[shared-dv-guide-overview]]
== Overview

This guide defines the architecture, public contracts, ownership rules, and
development workflow for shared OCAH design-verification (DV) collateral under
`hw/common/dv/`.

The shared DV tree provides:

* protocol verification intellectual property (VIP) with stable OCAH APIs;
* cocotb bus-functional models (BFMs), monitors, items, and checkers;
* SystemVerilog interfaces and UVM agents where a protocol needs them;
* checker evidence and reference-model conventions;
* shared configuration, assertions, shims, and firmware support.

The intended audience includes verification engineers adding tests, VIP
maintainers, DUT owners integrating shared VIP, and reviewers deciding whether
a DUT-local helper is mature enough for promotion.

[IMPORTANT]
====
The Python package root is `hw/common/dv/vip/`. Tests import public classes from
top-level packages such as `ocah_axi_vip`, never from implementation
subdirectories or backend packages.
====
