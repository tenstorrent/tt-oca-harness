[[shared-vip-catalog]]
== VIP Package Catalog

This chapter summarizes the public package surface and qualification state.
Package READMEs remain authoritative for detailed arguments and methods.

[[shared-vip-maturity]]
=== Maturity Definitions

[cols="<2,<8",options="header"]
|===
|State |Meaning

|Promoted
|Stable OCAH API, documented dependency/limitations, example, deterministic
error behavior, and a named real DUT consumer.

|Experimental
|Useful API exists, but a dependency, integration, documentation, or gating
consumer is missing. Experimental VIP cannot be the sole P0/P1 milestone
evidence.

|Deferred
|Capability is intentionally outside the current milestone. It must not block
baseline transaction BFMs or portable checker work.
|===

[[shared-vip-axi]]
=== AXI and AXI-Lite

Package: `hw/common/dv/vip/ocah_axi_vip/`

Primary classes:

* `OcahAxiMaster`, `OcahAxiLiteMaster`;
* `OcahAxiSlave`, `OcahAxiRam`, `OcahFaultAxiRam`;
* `OcahAxiLiteSlave`, `OcahAxiLiteRam`, `OcahFaultAxiLiteRam`;
* `OcahAxiReadResult`, `OcahAxiWriteResult`;
* `OcahAxiItem` and direction/protocol-specific item subclasses;
* `OcahAxiMonitor`, `OcahAxiLiteMonitor`, `OcahAxiChecker`;
* `OcahAxiRefModel`, `OcahAxiRegionExpectation`, `OcahAxiScoreboard`
  (checker/reference-model contract adopters, issue #3295);
* `OcahAxiProtocolWatcher`, `OcahAxiLiteProtocolWatcher` (cycle-level rules).

SystemVerilog layer (compiled by explicit sim-cfg sources, never Verilator
filelists): `interface/ocah_axi_if.sv`, the clean-room
`sva/ocah_axi_protocol_checker.sv` (`OCAH_AXI_*` rules from IHI 0022 rule
descriptions), behavioral error-injectable responders under `sv/`, and the
passive `uvm/ocah_axi_uvm_pkg.sv` (monitor, reference model, scoreboard with
`CHK-*`/`CHECKER_SUMMARY` evidence, optional coverage subscriber, env).
The DTP SV-UVM flow is the first consumer.

Use compatibility `read()`/`write()` methods for positive paths. Use
`read_result()`/`write_result()` when checking responses, expected errors, or
timeouts. Event-style `init_read()`/`init_write()` is for explicit concurrent
or timeout flows.

[source,python]
----
result = await master.read_result(
    addr,
    check_response=False,
    timeout_ns=50_000,
)
checker.expect_equal(
    "CHK-RESP",
    result.resp,
    RESP_DECERR,
    context=f"addr={addr:#x}",
)
----

Raw backend fields are debug-only. DUT agents map OCAH result fields into local
sequence items and scoreboards.

[[shared-vip-apb]]
=== APB

Package: `hw/common/dv/vip/ocah_apb_vip/`

`OcahApbMaster`, `OcahApbSlave`, and `OcahApbRam` mirror the AXI-Lite register
access shape. `OcahApbReadResult` and `OcahApbWriteResult` expose `pslverr`,
`ok`, and timeout state. `OcahApbMonitor` emits `OcahApbItem` records consumed
by `OcahApbChecker`.

Promotion requires a package-local example and a real DUT regression. Until
then it is available for opt-in experiments but is not a milestone-gating VIP.

[[shared-vip-jtag]]
=== JTAG

Package: `hw/common/dv/vip/ocah_jtag_vip/`

The cocotb API provides:

* `OcahJtagTap` active TAP control and scanning;
* `OcahJtagDevice` / `OcahJtagRegister` maps;
* `OcahJtagScanItem` / `OcahJtagStateItem`;
* `OcahJtagMonitor` and `OcahJtagChecker`;
* `OcahJtagState`, `next_jtag_state()`, and `jtag_tms_path()`.

The SystemVerilog UVM layer provides a pin-level interface, item, config,
driver, monitor, sequencer, agent, and VIP environment. DTP is the first UVM
consumer.

The shared scope is IEEE 1149.1. DTP/SMC/SMU instruction maps, JTAG2AXI TDR
packing, iJTAG, STAP/3DCR, and boundary-scan fixture models remain domain- or
DUT-local.

[[shared-vip-spi]]
=== SPI Flash

Package: `hw/common/dv/vip/ocah_spi_vip/`

`OcahSpiFlash` is a deterministic NOR-flash responder with JEDEC ID, READ, FAST
READ, status, WREN/WDIS, page program, and sector erase support.
`OcahSpiMonitor` passively records command/address/data activity.
`OcahSepSpiFlash` retains compatibility with a legacy SEP xSPI pin shape.

The released personality is single-SPI Mode 0. True QSPI/OSPI lane turnaround,
DDR, vendor-accurate BUSY timing, and vendor-specific commands are deferred.

[[shared-vip-i2c]]
=== I2C

Package: `hw/common/dv/vip/ocah_i2c_vip/`

The package provides active master, target/device, EEPROM memory, passive
monitor, and split-port open-drain adapters. The supported baseline is 7-bit
Standard/Fast mode with write, read, and combined transfers.

SMC currently retains local timing/polarity integration. Reusable fixes should
be moved into this package rather than creating another shared I2C VIP.

[[shared-vip-i3c]]
=== I3C

Package: `hw/common/dv/vip/ocah_i3c_vip/`

The package exposes:

* `OcahI3cBus` for a testbench controller driving a DUT target;
* `OcahI3cTarget` for a testbench target responding to a DUT controller;
* `OcahI3cMonitor` for passive START/STOP-level observation;
* split-port controller/target adapters for open-drain OCAH testbenches.

The current scope is SDR private traffic and a CCC subset. ENTDAA arbitration,
target-initiated IBI, byte-level passive decode, HDR modes, and reproducible
backend provisioning remain limited or deferred.

[[shared-vip-uart]]
=== UART

Package: `hw/common/dv/vip/ocah_uart_vip/`

`OcahUartConsole` provides source/sink console traffic and `OcahUartMonitor`
provides passive byte observation. The optional backend is omitted from the
locked environment pending a canonical version/license decision; callers must
handle `OcahUartImportError`.

[[shared-vip-entropy]]
=== Entropy Stream

Package: `hw/common/dv/vip/ocah_entropy_vip/`

`OcahEntropySource` drives deterministic words by default, supports explicitly
seeded random mode and backpressure, and can inject IRQ/alarm sideband events.
`OcahEntropyMonitor` passively records stream activity. Randomness without an
explicit seed is forbidden.

The package remains experimental until a real subsystem gates its source and
monitor behavior.

[[shared-vip-checker]]
=== Common Checker Evidence

Package: `hw/common/dv/vip/ocah_checker/`

`OcahChecker` implements named comparisons, required-ID tracking, timeout
expectations, retained findings, and strict finalization. It does not implement
protocol legality. Each protocol checker composes this core, beginning with
`OcahJtagChecker`.

See <<shared-checker-model-contract,Checker, Model, and Scoreboard Contracts>>
for the evidence and model data flow.
