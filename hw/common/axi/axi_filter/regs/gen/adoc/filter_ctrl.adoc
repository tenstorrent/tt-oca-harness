[cols="1,1,1,1,3", options="header"]
.FILTER_CONFIG Register
|===
| Bits | Field | Access | Reset | Description
| 63 | `locked` | RW | 0x0 a| Write once register to lock filter configurations
| 62:25 | `Reserved` | - | - a| Reserved
| 24 | `allow_burst` | RW | 0x0 a| Allow burst transactions through this filter
| 23:20 | `group_id` | RW | 0x0 a| Group Id field to match
| 19:16 | `src_id` | RW | 0x0 a| Source Id field to match
| 15 | `Reserved` | - | - a| Reserved
| 14:12 | `data_bus_width` | R | 0x3 a| Data bus width in bytes, encoded as 2^value
| 11:9 | `Reserved` | - | - a| Reserved
| 8 | `allow_ns` | RW | 0x0 a| Whether non-secure or secure transactions only can pass through this field
| 7:5 | `Reserved` | - | - a| Reserved
| 4 | `addr_mode` | RW | 0x0 a| Address matching mode for the filter. A = 0 means this entry is disabled, A = 1 means this entry is enabled
| 3:2 | `Reserved` | - | - a| Reserved
| 1 | `write_en` | RW | 0x0 a| Filter range has write permissions
| 0 | `read_en` | RW | 0x0 a| Filter range has read permissions
|===
