[cols="1,1,1,1,3", options="header"]
.FILTER_CONFIG Register
|===
| Bits | Field | Access | Reset | Description
| 63 | `locked` | RW | 0x0 a| Lock filter configurations. Write once register
| 62:25 | `Reserved` | - | - a| Reserved
| 24 | `allow_burst` | RW | 0x0 a| Filter entry will match if this field is 1 or if this field is 0 and the burst len AxLEN is 0.
| 23:20 | `group_id` | RW | 0x0 a| Group ID field to match. Filter entry will match if the transactions group_id matches the value in this field.
Note the corner case is the opposite of src_id: the bypass keys off the transaction, not this field.
A transaction whose group_id is 0 matches regardless of this field, and a value of 0 here is not a wildcard.
Unused for SEP/SMC, where group_id filtering is disabled at build time and this field has no effect
| 19:16 | `src_id` | RW | 0x0 a| Source ID field to match. Filter entry will match if the transactions src_id matches the value in this field.
A value of 0 in this field is a wildcard: src_id matching is bypassed and the entry matches any src_id.
Consequently there is no way to match only transactions whose src_id is 0.
| 15 | `Reserved` | - | - a| Reserved
| 14:12 | `data_bus_width` | R | 0x3 a| Data bus width in bytes, encoded as 2^value
| 11:9 | `Reserved` | - | - a| Reserved
| 8 | `allow_ns` | RW | 0x0 a| Secure and Non-secure is categorized as AxPROT[1] in the AXI protocol, where AxPROT[1] == 0 means secure and AxPROT[1] == 1 means Non-secure.
Filter entry will match if AxPROT[1] matches the value in this field
| 7:5 | `Reserved` | - | - a| Reserved
| 4 | `entry_enabled` | RW | 0x0 a| Filter entry enabled. A = 0 means this entry is disabled, A = 1 means this entry is enabled and will be used to filter
| 3:2 | `Reserved` | - | - a| Reserved
| 1 | `write_allowed` | RW | 0x0 a| Upon match of transaction to filter fields, whether the transaction has write permissions
| 0 | `read_allowed` | RW | 0x0 a| Upon match of transaction to filter fields, whether the transaction has read permissions
|===

[cols="1,1,1,1,3", options="header"]
.START_ADDR Register
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `Reserved` | - | - a| Reserved
| 55:0 | `start_addr` | RW | 0x0 a| Start of allowable address range. Hardware will adjust this field depending on the value of the allow_burst field.
When allow_burst is 0, the start_addr will be adjusted to align with data width (2^data_bus_width == 8).
When allow_burst is 1, the start_addr will be adjusted to align with 4KB boundary.
|===

[cols="1,1,1,1,3", options="header"]
.END_ADDR Register
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `Reserved` | - | - a| Reserved
| 55:0 | `end_addr` | RW | 0x7 a| End of allowable address range. Defaults to 7 on reset to match the minimum granularity when burst is disabled.
Hardware will adjust this field depending on the value of the allow_burst field.
When allow_burst is 0, the end_addr will be adjusted to align with data width (2^data_bus_width == 8).
When allow_burst is 1, the end_addr will be adjusted to align with 4KB boundary.
|===
