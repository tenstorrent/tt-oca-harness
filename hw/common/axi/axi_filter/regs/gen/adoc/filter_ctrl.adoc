.Register Map
|===
| Address | Name | Access | Description

[cols="1,1,1,1,3", options="header"]
.FILTER_CONFIG Register
|===
| Bits | Field | Access | Reset | Description
| 63 | `locked` | RW | 0x0 a| Lock filter configurations. Write once register
| 62:25 | `Reserved` | - | - a| Reserved
| 24 | `allow_burst` | RW | 0x0 a| Allow burst transactions through this filter
| 23:20 | `group_id` | RW | 0x0 a| Group Id field to match to pass filter
| 19:16 | `src_id` | RW | 0x0 a| Source Id field to match to pass filter
| 15 | `Reserved` | - | - a| Reserved
| 14:12 | `data_bus_width` | R | 0x3 a| Data bus width in bytes, encoded as 2^value
| 11:9 | `Reserved` | - | - a| Reserved
| 8 | `allow_ns` | RW | 0x0 a| Only transactions with axprot[1] equal to this field will be allowed to pass
| 7:5 | `Reserved` | - | - a| Reserved
| 4 | `entry_enabled` | RW | 0x0 a| Filter entry enabled. A = 0 means this entry is disabled, A = 1 means this entry is enabled and will be used to filter
| 3:2 | `Reserved` | - | - a| Reserved
| 1 | `write_allowed` | RW | 0x0 a| Filter range has write permissions
| 0 | `read_allowed` | RW | 0x0 a| Filter range has read permissions
|===

[cols="1,1,1,1,3", options="header"]
.START_ADDR Register
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `Reserved` | - | - a| Reserved
| 55:0 | `start_addr` | RW | 0x0 a| Start of allowable address range
|===

[cols="1,1,1,1,3", options="header"]
.END_ADDR Register
|===
| Bits | Field | Access | Reset | Description
| 63:56 | `Reserved` | - | - a| Reserved
| 55:0 | `end_addr` | RW | 0x7 a| End of allowable address range.
Defaults to 7 on reset to match the minimum granularity when burst is disabled
|===
