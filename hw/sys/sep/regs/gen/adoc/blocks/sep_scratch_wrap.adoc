[#regmap-{regmap-instance}-sep_scratch_wrap]
== SEP Scratch Wrapper Address Map

Places the cold-reset and warm-reset scratch register banks in one 4 KiB page.

[NOTE]
======
*Register Arrays:*

* *scratch_cold.SCRATCH[8]*: 8 registers, base 0x0, stride 0x8
* *scratch_warm.SCRATCH[8]*: 8 registers, base 0x80, stride 0x8
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 - 0x38 | <<reg-{regmap-instance}-sep_scratch_wrap-scratch_cold-SCRATCH-,scratch_cold.SCRATCH[8]>> | RW a| -
| 0x80 - 0xB8 | <<reg-{regmap-instance}-sep_scratch_wrap-scratch_warm-SCRATCH-,scratch_warm.SCRATCH[8]>> | RW a| -
|===

[#reg-{regmap-instance}-sep_scratch_wrap-scratch_cold-SCRATCH-]
=== scratch_cold.SCRATCH[8]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:32 | `Reserved` | - | - a| Reserved
| 31:0 | `data` | RW | 0x0 a| Scratch register for the CPU
|===

[#reg-{regmap-instance}-sep_scratch_wrap-scratch_warm-SCRATCH-]
=== scratch_warm.SCRATCH[8]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:32 | `Reserved` | - | - a| Reserved
| 31:0 | `data` | RW | 0x0 a| Scratch register for the CPU
|===
