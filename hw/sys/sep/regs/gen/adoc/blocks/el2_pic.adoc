[#regmap-{regmap-instance}-el2_pic]
== Address Map: el2_pic

*EL2_PIC* — VeeR EL2 Programmable Interrupt Controller (PIC) memory-mapped registers.
Supports up to PIC_TOTAL_INT external interrupt sources with 15 priority levels.

[NOTE]
======
*Register Arrays:*

* *meipl[256]*: 256 registers, base 0x0, stride 0x4
* *meip[8]*: 8 registers, base 0x1000, stride 0x4
* *meie[256]*: 256 registers, base 0x2000, stride 0x4
* *meigwctrl[256]*: 256 registers, base 0x4000, stride 0x4
* *meigwclr[256]*: 256 registers, base 0x5000, stride 0x4
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 - 0x3FC | <<reg-{regmap-instance}-el2_pic-meipl-0-,meipl[256]>> | RW a| External Interrupt Priority Level Register. Sets the priority level for an interrupt source.
| 0x1000 - 0x101C | <<reg-{regmap-instance}-el2_pic-meip-0-,meip[8]>> | R a| External Interrupt Pending Register. Reports pending status of up to 32 interrupt sources.
| 0x2000 - 0x23FC | <<reg-{regmap-instance}-el2_pic-meie-0-,meie[256]>> | RW a| External Interrupt Enable Register. Controls interrupt enable for a single source.
| 0x3000 | <<reg-{regmap-instance}-el2_pic-mpiccfg,mpiccfg>> | RW a| PIC Configuration Register. Used to select the operational parameters of the PIC.
| 0x4000 - 0x43FC | <<reg-{regmap-instance}-el2_pic-meigwctrl-0-,meigwctrl[256]>> | RW a| External Interrupt Gateway Configuration Register. Controls interrupt type and polarity.
| 0x5000 - 0x53FC | <<reg-{regmap-instance}-el2_pic-meigwclr-0-,meigwclr[256]>> | W a| External Interrupt Gateway Clear Register. Writing any value clears the gateway's
interrupt pending (IP) bit for edge-triggered interrupts.
|===

[#reg-{regmap-instance}-el2_pic-meipl-0-]
=== meipl[256]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:4 | `Reserved` | - | - a| Reserved
| 3:0 | `intpriority` | RW | 0x0 a| External interrupt priority level:
RISC-V standard order: 0=Never interrupt, 1..15=Priority (1 lowest, 15 highest)
Reverse order: 15=Never interrupt, 14..0=Priority (14 lowest, 0 highest)
|===

[#reg-{regmap-instance}-el2_pic-meip-0-]
=== meip[8]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `intpend` | R | 0x0 a| External interrupt pending bits. Bit Y indicates pending status for source X*32+Y.
0: Interrupt not pending
1: Interrupt pending
|===

[#reg-{regmap-instance}-el2_pic-meie-0-]
=== meie[256]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:1 | `Reserved` | - | - a| Reserved
| 0 | `inten` | RW | 0x0 a| External interrupt enable:
0: Interrupt disabled
1: Interrupt enabled
|===

[#reg-{regmap-instance}-el2_pic-mpiccfg]
=== mpiccfg

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:1 | `Reserved` | - | - a| Reserved
| 0 | `priord` | RW | 0x0 a| Priority order:
0: RISC-V standard compliant priority order (0=lowest to 15=highest)
1: Reverse priority order (15=lowest to 0=highest)
|===

[#reg-{regmap-instance}-el2_pic-meigwctrl-0-]
=== meigwctrl[256]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:2 | `Reserved` | - | - a| Reserved
| 1 | `irq_type` | RW | 0x0 a| External interrupt type:
0: Level-triggered interrupt
1: Edge-triggered interrupt
| 0 | `polarity` | RW | 0x0 a| External interrupt polarity:
0: Active-high interrupt
1: Active-low interrupt
|===

[#reg-{regmap-instance}-el2_pic-meigwclr-0-]
=== meigwclr[256]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:1 | `Reserved` | - | - a| Reserved
| 0 | `clear` | W | 0x0 a| Write any value to clear the interrupt pending bit in the gateway.
This register is write-only; reads return 0.
|===
