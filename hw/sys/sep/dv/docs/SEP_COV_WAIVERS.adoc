[[sep-coverage-waiver-evidence]]
== SEP coverage scope and exclusion evidence

The VCS code-coverage result grades TT-owned SEP integration RTL. The
compile-time `cov/config/vcs/sep_cov_scope.hier` removes the testbench, CPU
subtree, library-class cells, DV models and complete third-party IP modules.
Those whole-module entries are ownership decisions, not claims that the logic
is unreachable.

Report-time `.el` files apply only to objects that remain in the compile-time
scope. An exclusion needs an RTL tie, parameter, unconnected port or generate
condition that makes the object unreachable. A stimulus gap stays in the
denominator.

=== PeakRDL register blocks

`cov/config/vcs/sep_regblock_exclusions.el` excludes generated register-block
signals that cannot change:

* Every listed block hardwires `cpuif_req_stall_rd` and
  `cpuif_req_stall_wr` to zero. For example,
  `hw/sys/sep/regs/gen/sv/blocks/sep_scratch_reg.sv:220-221` contains the tie.
* Register spaces with no error decode also hold `is_valid_addr` and
  `is_valid_rw` high and `decoded_err` low. The same generated block shows
  these assignments at lines 243-248.
* The five wrapper-key register blocks decode real errors. Their exclusion is
  limited to the two no-stall signals; their error responses remain graded.

=== External TRNG payload

`cov/config/vcs/sep_ext_trng_payload_exclusions.el` excludes the three
AXI-Stream request payloads while they cross `sep_ip_integration`, `sep` and
`sep_crypto`. `hw/top/sep_ip_integration.sv:773` ties the complete request
array to zero. The source-select mux remains graded because software controls
its select.

=== SEP DMA tied inputs

`cov/config/vcs/sep_unreachable_exclusions.el` contains two instance-scoped
blocks on `sep_uvm_top.u_dut.u_sep.u_sep_dma_wrap`:

* `hw/sys/sep/rtl/sep.sv:1085-1087` connects LSIO trigger bit 0 to SPI and ties
  bits 10:1 low. Bit 0 remains graded.
* `hw/sys/sep/rtl/sep_dma_wrap.sv:324-333` ties the unused CTN response fields,
  and line 347 ties the alert receiver ping request low. The live DMA host path
  and alert request/acknowledge behaviour remain graded.

The checksums in each `.el` file come from `urg -dump full_exclusions` on the
merged VCS database. A report run must complete without a checksum or missing
object warning.
