[[sep-dv-functional-coverage]]
== SEP OCAH Open-Source Functional Coverage Plan

=== Overview

This plan covers **basic legal operating modes** of every SEP IP the OSS suite
already walks. It is the functional-coverage contract for the PyUVM/Verilator
flow.

Verilator does not compile SystemVerilog `covergroup`. This revision specifies
the Phase 1 bins below. It does not instrument them: `hw/sys/sep/dv/cov/sv/`
is empty. Feature evidence is the VPLAN checkers and iconic-feature scorecard.
When cover-property modules are added they use `OCAH_FCOV_COVER`
(`hw/common/assert/ocah_fcov_macros.svh`) and land in that directory.

[cols=",",options="header"]
|===
|Field |Value
|DUT |`sep_wrapper`
|Reference specification |`hw/sys/sep/doc/`
|Reference VPLAN |`SEP_VPLAN.adoc`
|Open-source framework |PyUVM on cocotb
|Open-source simulator |Verilator
|===

=== Coverage Goals

[cols=",,",options="header"]
|===
|Metric |Contract |Collection path
|Phase 1 functional coverage |Every Phase 1 bin below |Specified only. `cov/sv/` is empty; a `--cov` run is not bin evidence
|Phase 2 functional coverage |Named future-work set at the end of this plan |Not collected this revision
|Line / expression coverage |Collected; not a functional-coverage contract |`--coverage-line`, `--coverage-expr`
|Condition / FSM / toggle / assertion |Commercial signoff |VCS / Xcelium
|===

Do not mix line coverage with the Phase 1 bins: the line population on this
DUT would mask them.

=== Two-Phase Scope

[cols="1,3",options="header"]
|===
|Phase |Scope
|**Phase 1 — this revision** |One basic-mode covergroup per SEP IP. Bins are the
legal cells a named `all`-group test already walks.
|**Phase 2 — future work** |Dense enumerations, crosses, window edges, error and
fault paths, illegal encodings. Named below. Not collected this revision.
|===

are listed at the end of this document.

=== Collection

`OCAH_COVER` compiles out under Verilator. Use `OCAH_FCOV_COVER` only, when a
module exists.

Attach to a DUT or TB port, or `bind` into the IP. Do not add a Python path to
DUT-internal nets: `sep_public_scope.vlt` keeps public marks off the fabric.

`cov/sv/` has no modules this revision. Do not treat a `--cov` run as evidence
that a Phase 1 bin fired.

=== Phase 1 coverage definitions

==== `sep_axi_decode_cg`

*Description*: The LSU splice decodes a live CSR and returns OKAY.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Reset-value decode |`SEP_LOCAL_BASE_ADDR` reads its specified non-zero reset value
|Write / readback |A masked write to a live CSR reads back the written bits
|Response |OKAY
|===

==== `sep_sram_access_cg`

*Description*: The 64-bit SRAM port accepts a write and returns the same data.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Write then read |One aligned 64-bit word at the SRAM base
|Response |OKAY
|===

==== `sep_boot_rom_cg`

*Description*: The CPU fetches from the Boot ROM, and an LSU read matches the
loaded image.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|IFU fetch |Retirement from the Boot ROM aperture
|LSU read |A word read matches the loaded image
|===

==== `sep_cpu_boot_cg`

*Description*: VeeR EL2 boots firmware and reports PASS.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Console banner |Expected banner line
|Firmware PASS |PASS magic
|PC advance |A non-zero number of distinct retired PCs
|===

==== `sep_aes_mode_cg`

*Description*: AES legal mode × key-size encrypt. The suite walks nine cells.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Mode × key size |`{ECB, CBC, CTR}` × `{128, 192, 256}` — 9 cells
|Encrypt complete |Each cell reaches `OUTPUT_VALID` and a ciphertext
|===

CTR DECRYPT is Phase 2 (VPLAN Phase 3). GCM phases are Phase 2.

==== `sep_hmac_mode_cg`

*Description*: HMAC SHA-2 variants the suite walks.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Digest size |SHA2-256, SHA2-384, SHA2-512
|Keyed hash |Each legal `(digest, key length)` pair the variant test walks
|Done |`hmac_done` after `hash_process`
|===

==== `sep_kmac_mode_cg`

*Description*: KMAC-family modes the suite walks.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|SHA3 |224, 256, 384, 512
|SHAKE |128, 256
|cSHAKE |128, 256
|KMAC |128 and 256, with the key lengths the variant test walks
|Done |Operation complete
|===

==== `sep_otbn_execute_cg`

*Description*: OTBN runs a compute program to IDLE.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Command |`EXECUTE`
|Done |`STATUS` returns to IDLE with `ERR_BITS == 0`
|===

Secure wipe commands and `LOCKED` are Phase 2.

==== `sep_abr_keygen_cg`

*Description*: Adams Bridge ML-DSA keygen completes.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Operation |ML-DSA keygen
|Done |Notification / completion status the KAT checks
|===

==== `sep_esrc_edn_flow_cg`

*Description*: Entropy leaves ESRC, passes DRBG, and a sink consumes it.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|ESRC seed ready |FIFO / seed-ready observed after bring-up
|DRBG generate |At least one generate beat
|EDN consume |At least one sink handshake (`tvalid && tready`)
|===

Health-test watermarks, FIPS lock, and alerts are Phase 2.

==== `sep_km_command_sideload_cg`

*Description*: The mailbox produces a key and a consumer uses it.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Generate |`CMD_KEY_GENERATE` success, non-null handle
|Transfer |`CMD_KEY_TRANSFER` to AES
|Consume |AES / HMAC / KMAC / OTBN each consume a sideloaded key once
|===

The full 15-command set, vault slot walk, and SRAM-exec path are Phase 2.

==== `sep_dma_copy_hash_cg`

*Description*: DMA copies memory and computes a hash.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Memory copy |DONE, destination matches source
|Hash |DONE, digest matches the firmware golden
|===

Opcode / range errors are Phase 2.

==== `sep_spi_flash_cg`

*Description*: The OpenTitan SPI host talks to a flash model.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|JEDEC |READ ID completes
|DMA RX |SRAM holds the preloaded flash pattern
|DMA TX |Transfer DONE, no SPI error
|===

==== `sep_inbound_filter_allow_cg`

*Description*: One legal inbound transaction is allowed.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Allow |An `m_axi_*` access in an allowed window returns OKAY
|===

The full rule matrix, deny path, and 48-entry winner walk are Phase 2.

==== `sep_efuse_sense_cg`

*Description*: Real fuse sense fills the shadow.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Sense done |`sep_fuse_sense_done_o`
|Shadow |Sensed words match the staged image
|===

Program × lock and set-only walks are Phase 2.

==== `sep_lc_state_cg`

*Description*: One legal lifecycle state decodes to `FEAT_CTRL`.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|LC_STATE |A named legal encoding is sensed
|FEAT_CTRL |Decode matches the independent golden for that state
|===

The six-leaf W1S matrix, demote, and token faults are Phase 2.

==== `sep_mailbox_pic_cg`

*Description*: One mailbox interrupt reaches the PIC and the CPU.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Raise |Mailbox source pending
|Claim |EL2 claims the source
|Clear |W1C / deassert, pending reads 0
|===

The 42-source exclusivity map is Phase 2.

==== `sep_wdt_bark_cg`

*Description*: Watchdog bark reaches NMI.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Bark |Bark threshold expires
|NMI |Firmware takes the NMI path
|===

Bite, wakeup cause, and REGWEN lock are Phase 2.

==== `sep_scratch_reset_cg`

*Description*: Warm scratch clears; cold scratch retains.

[cols=",",options="header"]
|===
|Coverpoint |Bins
|Warm |Warm bank reads 0 after warm reset
|Cold |Cold bank retains the written value across warm reset
|===

=== Maintenance

Add a Phase 1 bin only when an `all`-group test already walks that cell, or
when a new test is added in the same change. A cell the suite does not walk
belongs in the Phase 2 named set. Keep cover-property instance names stable
when a module is added: the coverage policy matches points by hierarchy name.
