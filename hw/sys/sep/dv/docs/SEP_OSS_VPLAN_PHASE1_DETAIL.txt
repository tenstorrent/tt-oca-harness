  CHECKERS  - what proves pass/fail (scoreboard / asserts / golden / magic).
  COVERAGE  - interconnect edges (E#) + blocks/covergroups closed.
  DV-INFRA  - TB responders/models needed.  [BUILT] = present, [TODO] = not yet.

SUMMARY   : Proves the real OpenTitan entropy stack is alive on bare `sep` and
            reaches a real KM consumer. The test uses the permitted raw ESRC-noise
            force only to make the ring-oscillator source toggle under Verilator;
            DRBG/CSRNG/EDN/KM datapath logic remains RTL and is scorechecked.
DATA-PATH : esrc_noise_ext_i -> entropy_source decorrelator -> BIW/SHA whitening
            -> CSRNG CTR_DRBG seed/genbits -> EDN -> KM entropy sampler ->
            KM PicoRV32 ROM DATA read -> KM SRAM word0.
STEPS     : 1) no_cpu bring-up with +skip_fuse_sense.
            2) Release the KM PicoRV32; load km_rom_entropy.parhex via +km_rom_hex.
            3) Configure ESRC/CSRNG/EDN in OCAH order and enable generators/EDN.
            4) Start strict CHK1..CHK5 scoreboard; drain ESRC FIFO_RDATA via AXI
               frontdoor so CHK2 observes FIFO output, not a wire tap.
            5) Wait for CTR_DRBG genbits, KM post-mux tvalid&&tready, and the KM
               ROM's consumed word landing in KM SRAM.
            6) Check CSRNG/EDN error/status alerts are zero, then report scoreboard.
CHECKERS  : +esrc_noise_force took (actual DUT noise_i tracks driven noise) ;
            seed accumulation and CTR_DRBG genbits observed ; KM consumes one
            entropy word and stores it to SRAM ; CSRNG/EDN errors and alerts zero ;
            strict CHK1_decor, CHK2_compress, CHK3_seed, CHK4_genbits, CHK5_km
            all have match>0 and mismatch==0.
COVERAGE  : Explicit E2 entropy-stack alive path (ESRC/CSRNG/EDN -> KM consumer),
            complementing the KM/OTBN sideload KAT's firmware-driven entropy use.
DV-INFRA  : ESRC raw-noise force [APPROVED] · entropy probes [BUILT] ·
            sep_entropy_golden + sep_drbg_scoreboard [BUILT] · KM ROM/SRAM
            responder [BUILT] · km_rom_entropy.parhex [BUILT].
