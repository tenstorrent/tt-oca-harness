==== 2. Fabric and remap

[[sep_address_map_test]]
===== 2.1 `sep_address_map_test`

*Phase*: 1

*Area*: Fabric and remap

*Run mode*: `no_cpu`, `+skip_fuse_sense`

*Source Module*: `sep_address_map_test`

*BFM / Model*: ocah_axi_vip

*Objective*: Prove the CPU-LSU decodes `sep_cpu_ctrl` and one safe CSR in every LSU-reachable CSR block (including Adams Bridge and the entropy pool), and that the unpopulated hole inside `sep_cpu_ctrl` reads OKAY with zero and is not a live alias.

*Test Coverage*: One safe CSR in every LSU-reachable CSR block, plus a `sep_cpu_ctrl` sweep and the interior hole.

*Test Procedure*:

[arabic]
. Bring up in `no_cpu` mode with the LSU splice owning the bus.
. Read every `sep_cpu_ctrl` reset-check register and require the exported reset value.
. Response-check hardware-driven registers; read the low half of `REFERENCE_COUNTER` twice and require it to advance (the reference clock is driven, so the counter is live and no reset value applies).
. Write/readback/restore the SEP base/size CSRs and the pure-RW storage registers (masked).
. Write the implemented `CLOCK_GATE_CTRL` bits, read them back, then restore reset after the fabric walk.
. Walk one readable CSR per LSU-reachable block (DMA, WDT, scratch, reset, OTBN, AES, HMAC, KMAC, CSRNG, EDN, ESRC, ABR NAME, entropy-pool STATUS, lifecycle, KM mailbox, eFuse shadow, AXI mailbox, inbound filter CFG, alias remap, outbound remap, SPI) and require OKAY (value-check where reset is known).
. Read three words in the hole after `SEP_FUSE_SENSE_STATUS` and before `SEP_SW_DEBUG` (including `0x10A3_0170`). Require OKAY with zero data, which `hw/sys/sep/doc/memory_map.adoc` states as the contract for an offset inside a unit's extent that owns no register. Prove `SEP_SW_DEBUG` writable, then require a hole write to leave it unchanged.

*Checkers*:

[cols="2,5",options="header"]
|===
|Checker |Contract
|CHK-REFCNT-READ
|The reference counter is LIVE and readable: the low half is read twice and must advance. It counts on `clk_ref_i`, which the testbench drives, so no pinned value can be its expectation -- and the advance is a stronger statement than a reset compare, because a neighbouring register's storage, a stuck all-ones and a zero return all hold still between the two reads. The high half is read for the pair but is not value-checked.
|CHK-RW-READBACK
|Every pure read/write register returns exactly what was written, masked to its implemented bits, and is restored afterwards.
|CHK-BASEADDR-RW
|The base and size registers accept a write, read back, and restore cleanly.
|CHK-FABRIC-WALK
|Every LSU-reachable CSR block in the walk returns OKAY on its chosen register; value-checked entries match the exported or seq-derived expectation. The logged count must be non-zero.
|CHK-EXT-DEMUX-BOUND
|The first word of the eFuse-shim window answers something other than DECERR, so the demux selected the shim port, and the word past the window answers DECERR from the extension error slave. Both addresses come from the generated header by symbol. The value behind the shim is adopter-owned and is not graded — only which port the decode selected.
|CHK-CPU-CTRL-HOLE
|Each `sep_cpu_ctrl` word in the hole after `SEP_FUSE_SENSE_STATUS` and before `SEP_SW_DEBUG` reads OKAY with zero data, and a write to `0x10A3_0170` does not change `SEP_SW_DEBUG` -- whose writability a control write proves first, since `SEP_FUSE_SENSE_STATUS` is `sw = r` and no AXI write can move it. `hw/sys/sep/doc/memory_map.adoc` states both halves: a unit accepts such an offset with zero/OKAY, and non-aliasing follows from exact-match register decode rather than from refusal.
|===

*Pass Criteria*: Every named checker PASSes. UVM_ERROR == 0.

*Evidence*: the test logs `CHK-ADDRMAP FAIL` and stops before the CHK-REFCNT-READ, CHK-BASEADDR-RW, CHK-RW-READBACK and CHK-FABRIC-WALK records if the shared scoreboard holds any response or value error. CHK-CPU-CTRL-HOLE and CHK-EXT-DEMUX-BOUND are logged after further accesses; a scoreboard error from those accesses fails the run in `check_phase`, after their PASS lines.

'''''

[[sep_cpu_ifu_lsu_alias_remap_matrix_test]]
===== 2.2 `sep_cpu_ifu_lsu_alias_remap_matrix_test`

*Phase*: 1

*Area*: Fabric and remap

*Run mode*: `cpu`, `+skip_fuse_sense`

*Source Module*: `sep_cpu_ifu_lsu_alias_remap_matrix_test`

*BFM / Model*: ocah_axi_vip, CPU FW, `tb/sep_outbound_mbx.sv` (console + verdict mailbox; OKAY / zero read data for any address). PR-CPU-IFU (`pr_cpu_ifu_*`, the raw IFU read request) is an observation tap on the SEP_TB_ARCH observation-probe list.

*Objective*: Proves the CPU-side address alias window remaps both data and instruction accesses to physical SRAM, and that every IFU read carries the AxPROT that `hw/sys/sep/doc/cpu.adoc` states (table `sep-cpu-axprot-table`).

*Test Coverage*: Alias window remaps LSU and IFU accesses to physical SRAM.

*Test Procedure*:

[arabic]
. Probe the alias base CSR with a value distinct from its reset value, restore the operating base, and read back. The region size is a fixed localparam and is not programmed.
. Write through the alias; read the physical address.
. Write the physical address; read through the alias.
. Write a small function into SRAM, fence, and call it through its alias address.

*Checkers*:

[cols="2,5",options="header"]
|===
|Checker |Contract
|CHK-CSR
|The alias base register is writable and reads back. It is probed with a value distinct from its reset value first — writing only the operating base would be unfalsifiable, since that is also the field's reset value and a read-only register would pass. `CHK-BASE-LIVE` below then proves the programmed base is actually consumed. The operating base is `0xd0000000` over a fixed 768 MiB window onto physical `0x10000000`; the probe value is `0xe0000000`.
|CHK-BASE-LIVE
|A write through the alias window with a NON-reset base programmed lands at the physical address that base selects. A remapper hardwired at the operating base (`0xD000_0000`) would map `0xE000_0318` to `0x2000_0318`, not `0x1000_0318`, and fails here. This is what makes CHK-CSR's probe more than a register readback.
|CHK-LSU-WR
|A data write through the alias lands at the physical address.
|CHK-LSU-RD
|A physical write is readable through the alias.
|CHK-IFU
|A call through the alias is fetched, remapped, executed, and returns its value.
|CHK-IFU-AXPROT
|Every IFU AR handshake on PR-CPU-IFU over the run carries ARPROT `0b101` (privileged, secure, instruction; `cpu.adoc`, `sep-cpu-axprot-table`), and the run has at least one. An X or Z on the tap fails. A core that drives the upstream VeeR `0b100`, or any other value, fails. Evidence: `CHK-IFU-AXPROT PASS: master=ifu ch=ar prot={0b101} count=<n> expect=0b101`.
|===

*Pass Criteria*: Every named checker PASSes. UVM_ERROR == 0.

*Anti-vacuity*: the instruction-fetch checker cannot pass vacuously — the fetch
demultiplexer runs on the post-remap address, so an alias address that was not
remapped routes to the error slave and never executes.

'''''

[[sep_fabric_inbound_filter_rule_matrix_test]]
===== 2.3 `sep_fabric_inbound_filter_rule_matrix_test`

*Phase*: 2

*Area*: Fabric and remap

*Run mode*: `no_cpu` (`lsu_stub_all_live`), *real PROD fuse sense* — no `+skip_fuse_sense`

*Source Module*: `sep_fabric_inbound_filter_rule_matrix_test`

*BFM / Model*: ocah_axi_vip

*Randomization*: RAND-REP — entries 0 and 7 × two windows × `{rw, r, w}` at match-all, plus entry 0 / window 0 source-ID match and mismatch, run every seed. Seed varies the window data, the entry-15 granule window, and the bound-probe registers.

*Objective*: Brings the lifecycle controller up in PROD so the inbound filter is genuinely active (`sep_debug=0`, value-checked against the lifecycle golden), then walks entries 0 and 7, two address windows, and `{rw, read-only, write-only}` at `src_id=0` (match-all), plus entry 0 / window 0 x `{rw, r, w}` at `src_id=0x5` with a matching AXI `user[3:0]` and one src-mismatch cell — 16 cells in one invocation — then the same-page `allow_burst=1` granule, page-bound, and `FILTER_CONFIG.locked` on entry 15.

*Test Coverage*: Sixteen inbound-filter cells plus burst granule, page-bound, and lock.

*Test Procedure*:

[arabic]
. Bring the lifecycle controller up in PROD so the inbound filter is active.
. Walk entries 0 and 7, two windows, `{rw, r, w}`, and the source-ID match / mismatch cells — 16 cells.
. Walk `allow_burst` deny then allow on AR and AW of the scratch window (2-beat INCR, AxLEN=1). The allow window spans two 4 KB pages. The allowed burst becomes two Lite singles; the denied burst reaches none.
. Program an 8-byte `allow_burst=1` window inside one 4 KB page on entry 15. Prove the page grant on the bus, both page edges, then freeze `allow_burst` with `FILTER_CONFIG.locked`. The lock is sticky, so this step is last.

*Checkers*:

[cols="2,5",options="header"]
|===
|Checker |Contract
|CHK-ALLOW-RULE
|An allowed external read returns OKAY *and* the exact staged value. A denied read of the same address returns DECERR *and* read data that is not the staged value, so the blocked access did not reach the target. `hw/ip/axi_filter/doc/index.adoc` (Blocked Transactions) names DECERR and no read data, so no exact deny payload is graded.
|CHK-BLOCK-DEFAULT
|A non-allowed external read in the *same CSR page* returns DECERR — so region reachability is proven by the allow case and cannot explain the deny.
|CHK-READ-ALLOWED
|The read-allowed bit gates the matched read in both directions.
|CHK-WRITE-ALLOWED
|The write-allowed bit gates the matched write in both directions, and the allowed write lands (confirmed by a CPU-side readback).
|CHK-OWNERSHIP
|The CPU-LSU reads inbound CFG, outbound CFG[0], alias/AP/STEE remap bases, `SEP_GLOBAL_BASE_ADDR`, and `SEP_REGION_SIZE`. The external master completes DECERR on read and write of each address, and the denied write does not land. Those CSRs stay outside every allow window (firmware must not allow-list them). `SEP_GLOBAL_BASE_ADDR` and `SEP_REGION_SIZE` share the window-0 (`SEP_SW_DEBUG`) 4 KB page, so they also prove the live window is START/END, not the page.
|CHK-NONVAC
|Allow and block were both observed under one lifecycle state.
|CHK-SRC-ID
|A non-zero `FILTER_CONFIG.src_id` matches only the external master's `user[3:0]`. The match cells keep r/w-allow gating; the mismatch cell DECERRs with both allow bits set.
|CHK-CELL
|One line per cell of the 16-cell walk. With every other entry disabled and only the cell's entry programmed: an allowed read returns OKAY and the staged value; a read with `read_allowed=0` returns DECERR and read data that is not the staged value; an allowed write returns OKAY and lands on a CPU-LSU readback; a write with `write_allowed=0` returns DECERR; on the source-ID mismatch cell the read and the write both return DECERR. A read of the blocked address in the same page returns DECERR in every cell.
|CHK-RAND-REP
|Entries 0 and 7, two address windows, `{rw, r, w}` at match-all, plus entry 0 / window 0 source-ID match and mismatch — 16 cells in one invocation. Entry 15 carries the granule, bound, and lock cells.
|CHK-BURST-DENY
|With `allow_burst=0`, a single-beat external read of the scratch window is OKAY (anti-vacuous) and a 2-beat INCR (AxLEN=1) to the same address is DECERR. `traffic_filter.sv` `pass_burst` is not vacuously true.
|CHK-BURST-ALLOW
|With `allow_burst=1` and a programmed window that already spans two 4 KB pages, the same 2-beat INCR is OKAY and returns the staged scratch value. START/END read back as programmed (the same-page 4 KB granule widen does not fire). The granule widen itself is `CHK-PAGE-WIDEN`.
|CHK-BURST-WRITE-DENY
|The write-side `traffic_filter` (`aw.len`) with `allow_burst=0`: a single-beat external write is OKAY and lands; a 2-beat INCR write is DECERR and does not land.
|CHK-BURST-WRITE-ALLOW
|With `allow_burst=1` and the same two-page window, a 2-beat INCR write is OKAY and the poke lands on a CPU-LSU readback. START/END stay the programmed range.
|CHK-BURST-WALK
|Summary of the `allow_burst` walk: `CHK-BURST-DENY`, `CHK-BURST-ALLOW`, `CHK-BURST-WRITE-DENY`, `CHK-BURST-WRITE-ALLOW` and the `CHK-BURST-TO-SINGLE` read and write legs all passed, so the deny and the allow side were walked on AR and on AW of the scratch window. It grades nothing of its own.
|CHK-BURST-TO-SINGLE
|A filter-allowed 2-beat INCR (AxLEN=1) becomes two AXI-Lite singles on the system-CSR bridge (`u_system_csr_a2l_1`): AR/AW at start and start+4. A denied AxLEN=1 produces zero Lite handshakes (filter before the converter). `hw/sys/sep/doc/fabric.adoc`: convert burst to single.
|CHK-WIDEN-GUARD
|Stimulus guard in `program_rule` (`seq_lib/sep_inbound_filter_rule_seq.py`). A rule programmed with `allow_burst=1` and START and END inside one 4 KB page must be requested as a page widen, or the leaf fails before the entry is written. This keeps a cell that wants a narrow window from getting the whole-page grant by accident. The DUT cannot fail this checker, and it has no PASS line.
|CHK-PAGE-WIDEN
|A same-page `allow_burst=1` window grants the whole 4 KB page (`hw/ip/axi_filter/doc/index.adoc`: `START_ADDR` rounds down, `END_ADDR` rounds up, `allow_burst` selects 4 KB). Measured on the bus rather than in a register mirror: an external access to an address inside the granted page but outside the programmed `START..END` answers OKAY for read and write and carries the staged value. The hardware-adjusted `START_ADDR`/`END_ADDR` readback is the setup step showing the rewrite took effect; a CSR mirror is not evidence of what the filter passes.
|CHK-PAGE-BOUND
|The 4 KB grant stops at both page edges. Under a scratch-page grant an access one page below is refused; with that page granted instead it answers OKAY while the scratch address turns DECERR. Both probes are proven reachable first, so neither refusal can be a decode hole rather than a filter decision. This is the security contract: 4 KB is the block pitch for the DMA CSR, watchdog and scratch-bank blocks, so a page-crossing grant would reach a neighbouring block.
|CHK-CONFIG-LOCK
|`FILTER_CONFIG.locked` freezes `allow_burst`. The lock bit is write-once, and every later write to the entry's `FILTER_CONFIG` completes DECERR (`hw/ip/axi_filter/regs/filter_ctrl.rdl` `locked`; `hw/ip/axi_filter/doc/index.adoc` "Locking a Filter Entry"). With `allow_burst` set, a write of 1 to `locked` (the high word of `FILTER_CONFIG`) reads back set. Then a low-word write that clears `allow_burst` must complete DECERR, and the low word reads back unchanged. A high-word write of 0 must complete DECERR, and `locked` reads back set. Last, an external 2-beat INCR read (AxLEN=1) inside the widened page but outside the programmed `START..END` answers OKAY, returns the staged value, and reaches the system-CSR bridge as two AXI-Lite singles. A single beat would not show this: `START`/`END` already hold the widened page, and a single beat inside that range passes with `allow_burst` 0 or 1. Only the burst depends on the bit, so the frozen bit still drives the filter and not only the CSR readback. The two write response codes are logged when they return and graded after the 2-beat read, so the read is checked whatever code the writes answered.
|===

*Pass Criteria*: Every named checker PASSes. UVM_ERROR == 0.

*Scope*: the walk is inbound-filter entries 0 and 7, two address
windows (`SEP_SW_DEBUG` and scratch-cold[0]), `{rw, read-only, write-only}` at
`src_id=0`, plus the source-ID product on entry 0 / window 0, then the
`allow_burst` deny/allow pair on AR and AW of scratch and the burst-to-single
Lite split, then the same-page 4 KB granule, page-bound, and `FILTER_CONFIG.locked`
on entry 15. `CHK-OWNERSHIP` keeps inbound CFG, outbound CFG, the remap banks, and `SEP_GLOBAL_BASE_ADDR` / `SEP_REGION_SIZE` outside every allow window. WRAP, FIXED and
`AxLEN>1` are not walked: the Lite bridges convert those bursts to singles, so the
filter only ever sees `tx_len==0`.

'''''

[[sep_fabric_remap_filter_csr_bank_test]]
===== 2.4 `sep_fabric_remap_filter_csr_bank_test`

*Phase*: 2

*Area*: Fabric and remap

*Run mode*: `no_cpu` (`lsu_stub_all_live`), `+skip_fuse_sense`, 3 seeds

*Source Module*: `sep_fabric_remap_filter_csr_bank_test`

*BFM / Model*: ocah_axi_vip

*Objective*: R/W, 64-bit, RO, valid, and write-once-set across the alias/AP/STEE remap and inbound/outbound filter CSR banks, and that every entry of the alias remap bank and of the inbound and outbound filter banks holds its own value. The AP and STEE output-remap banks are checked on one seeded region each per seed. Each filter entry and remap region is an independent rule with its own storage, so a decode that aliased two entries, or a bank that implemented fewer entries than the map declares, would be invisible to a sweep that walks one entry per group.

*Test Coverage*: Remap and filter CSR banks: R/W, 64-bit, RO, valid, write-once-set, and per-entry storage independence across all 16 alias regions, 16 inbound and 32 outbound filter entries.

*Test Procedure*:

[arabic]
. Write each bank and require the readback to differ from the observed pre-write. Each written word is read first; when the seeded pattern equals that value under the word's R/W field mask, every R/W bit of the pattern is inverted, so a pattern equal to the reset value cannot hide a register that ignores the write.
. Prove RO `data_bus_width` ignores writes on both filters.
. Write a distinct pattern into every entry of each bank, then read all of them back, and require each to hold its own pattern.
. Set and try to clear the alias `valid` bit; it clears.
. Lock one inbound and one outbound filter entry, try to clear `locked`, then write the `FILTER_CONFIG` lo word, `START_ADDR` and `END_ADDR` of the locked entry; require DECERR on each write and no change to each word.

*Checkers*:

[cols="2,5",options="header"]
|===
|Checker |Contract
|CHK-NONVAC
|A written register's readback differs from its *observed* pre-write value, and the neighbouring field is undisturbed. The pre-write sample is required: asserting only that the written pattern is non-zero is a property of the stimulus constructor, not of storage.
|CHK-ALIAS-RW
|Region start, end and attribute registers are read/write, including the 64-bit upper word: `REGION_START` hi, `REGION_END` lo and `REGION_ATTRS` lo each read back the written value, and that value differs from the word's *observed* pre-write value.
|CHK-AP-STEE-RW
|The output-remap CSRs are read/write across both banks: `REGION_ATTRS` lo and hi of the seeded AP and STEE region each read back the written value, and that value differs from the word's *observed* pre-write value.
|CHK-INFILT-CFG / CHK-OUTFILT-CFG
|Filter-configuration read/write fields (`rd`, `wr`, `ns`, `burst`, `src_id`, `group_id`) read back exactly on both the inbound and the outbound bank, and differ from the word's *observed* pre-write value.
|CHK-BANK-INDEP
|Every R/W word of every bank entry holds its own distinct pattern: 224 words across 16 alias regions (`REGION_START` lo+hi, `REGION_END`, `REGION_ATTRS` lo+hi) and 48 filter entries (`FILTER_CONFIG`, `START_ADDR`, `END_ADDR`) are each written a value carrying their bank number, entry index and word number, then all are read back and required to match through the same mask the write used. The bank term matters because the two filter banks are instances of one RDL array type and share stride and word list: without it, inbound entry *k* and outbound entry *k* would carry the same pattern and a decode that aliased one onto the other would still read back what it wrote. A bank that decodes two entries to one storage, or that implements fewer entries than the address map declares, fails here and the message names the entry and word; the walked word count is asserted against 224 so a short walk cannot pass on whatever it reached, and every entry count comes from the register export rather than a sequence literal. The per-group field sweep above picks one random entry per seed, so this is the only leg that shows the other entries exist and are distinct. Deterministic: the same words are covered on every seed, so the three `reseed` runs repeat this leg rather than sampling different slices. `FILTER_CONFIG`'s hi word is not walked -- its only field above bit 31 is `locked[63]`, which `CHK-WOSET` owns; the read-only `data_bus_width` is masked out here and graded by `CHK-RO`.
|CHK-RO
|The data-bus-width field reads its fixed value and ignores writes of the inverse pattern, on both filters.
|CHK-VALID-RW
|The region valid bit is read/write in both directions.
|CHK-WOSET
|The write-once-set `FILTER_CONFIG.locked` bit holds, and while it is set every write to that entry's `FILTER_CONFIG`, `START_ADDR` and `END_ADDR` completes DECERR, on the inbound and the outbound bank. The clear write to the `FILTER_CONFIG` hi word must complete DECERR with `locked` still 1. A write that flips every R/W field of the `FILTER_CONFIG` lo word (`read_allowed`, `write_allowed`, `entry_enabled`, `allow_ns`, `src_id`, `group_id`, `allow_burst`), and a write that flips 4 KB-aligned bits of `START_ADDR` and `END_ADDR`, must each leave the word unchanged. Each probe logs the written value and the word before and after. Source: `hw/ip/axi_filter/regs/filter_ctrl.rdl` (`locked`) and `hw/ip/axi_filter/doc/index.adoc` ("Locking a Filter Entry"). Every code is logged before it is graded.
|===

*Pass Criteria*: Every named checker PASSes. UVM_ERROR == 0.

*Scope limit*: the field sweep (`CHK-NONVAC`, `CHK-ALIAS-RW`, `CHK-AP-STEE-RW`,
`CHK-INFILT-CFG`, `CHK-OUTFILT-CFG`, `CHK-RO`, `CHK-VALID-RW`, `CHK-WOSET`)
covers one seeded region or entry per bank per seed. `CHK-BANK-INDEP` covers
every alias region and every inbound and outbound filter entry, but not the AP
and STEE output-remap banks.

'''''

[[sep_fabric_slot_csr_strobe_rand_test]]
===== 2.5 `sep_fabric_slot_csr_strobe_rand_test`

*Phase*: 2

*Area*: Fabric and remap

*Run mode*: `no_cpu` (`lsu_stub_all_live`), `+skip_fuse_sense`, 3 seeds

*Source Module*: `sep_fabric_slot_csr_strobe_rand_test`

*BFM / Model*: ocah_axi_vip; register model from the generated IP-XACT (`sep_reg_meta.register_fields`)

*Randomization*: `SepSeededRng` from the run seed: slot and register order, write order within each register's plan, access offsets and sizes of the reads, write data, the fill on inactive byte lanes, the BREADY/RREADY hold lengths and the W-ahead-of-AW gap. `reseed = 3` samples different data, fill and orderings; the plan shape (which accesses each register gets) is the same on every seed.

*Objective*: The byte-strobe, access-size, back-pressure and write-once-set rules hold at every slot of the five System-block fabric banks, not at one. Each of the 16 alias-remap regions, 16 AP and 16 STEE output-remap regions, 32 outbound and 16 inbound filter entries is its own register block behind its own AXI-Lite port, so a rule that one slot obeys says nothing about the others.

*Test Coverage*: All 224 registers of the 96 slots: reset, every byte lane written alone and in 16/32/64-bit groups, inactive lanes driven with data, read-only and reserved bits, the filter `START_ADDR`/`END_ADDR` granule write-back, `FILTER_CONFIG.locked` on all 48 filter entries, and a write and a read of every slot outstanding together on `s_axi`.

*Test Procedure*:

[arabic]
. Read every register as one 64-bit access and as one 32-bit word before any write.
. Per register, in seeded order: one 64-bit write, one write per byte lane, two 16- or 32-bit writes, each with seeded data on the active lanes and seeded fill on the inactive ones, and a seeded-size read after each write; then a 64-bit read.
. Per slot, twice: start a 32-bit write of one register's low word and a 32-bit read of its high word together on `s_axi`, once with BREADY and RREADY held and once with W presented ahead of AW and RREADY held; sample the `s_axi` pins during the pair; then read the register.
. Per filter entry, in seeded order: lock it with a write that strobes `FILTER_CONFIG.locked`; then four seeded writes to its registers, each chosen so that the entry would change if the write were taken, and a write of 0 to the lock bit; read every register of the entry.
. Read every register of every slot.

*Checkers*:

[cols="2,5",options="header"]
|===
|Checker |Contract
|CHK-SLOT-RESET
|Every register reads the reset value its RDL fields declare (`filter_ctrl.rdl`, `alias_remap.rdl`, `output_remap.rdl`, through the generated IP-XACT), as a 64-bit access and as a 32-bit word. Reserved bits read 0; `data_bus_width` reads its declared value 3.
|CHK-SLOT-STROBE
|Every write answers OKAY and changes exactly the writable field bits in its strobed byte lanes (AMBA AXI write-strobe rule); read-only and reserved bits keep their RDL value. The master drives seeded data on every inactive lane, and always a 1 on `FILTER_CONFIG.locked` and alias `REGION_ATTRS.valid` when their lane is inactive, so a block that ignored WSTRB would take the fill, lock the entry or arm the remap, and read back changed. A filter `START_ADDR`/`END_ADDR` pair that lands in one granule (4 KB with `allow_burst`, 2^`data_bus_width` bytes without) reads back widened to it, as `filter_ctrl.rdl` describes. The write count is asserted against the plan (11 per register). The W beats that carry data on an inactive lane are counted on the TB `s_axi` pins and at the AXI-Lite W port of each slot's register block (`fabric_slot_w_*` probes in `tb/tb_top.sv`, observation-only): the count must be non-zero, the slot-port count of beats and of fill beats must equal the `s_axi` counts, and every one of the 96 slot blocks must see fill, so the deny leg is exercised at the block that applies WSTRB. The log names how many writes moved the register and how many carried fill that differed from it.
|CHK-SLOT-PIPE
|On the `s_axi` pins, each pair has at least one cycle in which both the write (AW accepted) and the read (AR accepted) are unanswered; in the held pair, B and R each wait with VALID high and READY low (the hold lasts 40 to 71 cycles from the request); in the W-first pair, WVALID rises before AWVALID. Both answer OKAY, the read returns the half of the register the write does not strobe (its value does not depend on the order the DUT serves them in), and the write lands. Asserted for 2 pairs per slot. Overlap at the slot's own AXI-Lite port is not claimed: the AXI-Lite demux in front of each slot holds one transaction per direction and forwards W only after its AW, so the slot block does not see the two in flight together or W ahead of AW.

[[sep_fabric_deadspace_decode_test]]
===== 2.10 `sep_fabric_deadspace_decode_test`

*Phase*: 2

*Area*: Fabric and remap

*Run mode*: `no_cpu`, `+skip_fuse_sense`

*Source Module*: `sep_fabric_deadspace_decode_test`

*BFM / Model*: ocah_axi_vip

*Randomization*: RANDCFG — the twelve directed wrap offsets, four directed ABR probes and six directed TRNG-window probes on every seed, plus two seed-selected dead offsets per block window.

*Objective*: Negative control on intra-block dead space. Each block owns an address window and populates only part of it; an access past the allocated size owns no register and must be refused. Window ends come from `hw/sys/sep/doc/memory_map.adoc`, which states the rule: the fabric refuses an address past the extent a unit allocates, and such an access never reaches a unit. Landing on a live register instead is a hard failure. Bursts are graded in the crypto region only: `hw/sys/sep/doc/crypto.adoc` ("Single-Beat Access Only") answers every beat of a burst there DECERR, and no beat reaches an accelerator. A burst into any other register region is outside the specification (`hw/sys/sep/doc/memory_map.adoc`, "Single-Beat Register Access") and is not graded. The TRNG window, forwarded whole to an adopter endpoint and terminated in the reference integration, must refuse every access, alias no neighbouring ESRC register, and answer the code `memory_map.adoc` states for a window with no external TRNG: DECERR on a read and on a write.

*Test Coverage*: Dead-space accesses are refused and do not alias live register data or state.

*Test Procedure*:

[arabic]
. Build the seeded probe set. Require every watched window to supply its two seeded dead-offset probes (CHK-DEADSPACE-RAND). Bring up in `no_cpu`.
. Snapshot each watched window's registers twice. Require every watched register to answer OKAY and at least one register to be armed for the change compare (CHK-WINDOW-LIVE).
. Issue every directed anchor and seeded probe. A refusal that still writes the register is a failure, so every probe reads back the window's live registers as well as the response (CHK-DEADSPACE-REFUSE, CHK-DEADSPACE-NO-ALIAS).
. In the ABR window, probe every seed at the first word past the register map (read and write), at `error_intr_en_r` with offset bit 14 set, and at the last word of the window.
. In the TRNG window, read and write the first, middle and last word every seed, plus two seeded offsets. Use the neighbouring ESRC register set as this window's no-alias snapshot, which an access that drops address bit 12 reaches (CHK-TRNG-UNOWNED).
. In each crypto-region window (OTBN through ABR in the generated memory map: aes, otbn, abr, csrng, edn, entropy_src, km_mailbox, lifecycle and trng), issue a four-beat INCR read burst and, where the window takes writes, a four-beat INCR write burst. Start the burst two words before the extent where a legal burst can cross it, and at the window base otherwise. secure_dma, wdt_timer and spi_controller lie outside the crypto region and get no burst (CHK-DEADSPACE-BURST, CHK-DEADSPACE-BEAT).

*Checkers*:

[cols="2,5",options="header"]
|===
|Checker |Contract
|CHK-DEADSPACE-RAND
|Stimulus precondition. Each watched window supplies its full quota of two seed-selected, word-aligned dead-offset probes. The probe count is the random-coverage claim, so a short window fails the leaf before bring-up and is not absorbed into a smaller probe set. |CHK-WINDOW-LIVE

Armed counts the compared registers with at least one software read-write field in the generated IP-XACT (`hw/sys/sep/regs/gen/ipxact/sep.xml`): a `sw = r` field has no bus write path and a write-only field reads back nothing, so only an armed register can show a stored write. A write burst has one `BRESP`, so it is graded under CHK-DEADSPACE-BURST.
|CHK-TRNG-UNOWNED

[[sep_axi_order_sweep_test]]
===== 2.13 `sep_axi_order_sweep_test`

*Phase*: 2

*Area*: Fabric and remap

*Run mode*: `no_cpu`, `+skip_fuse_sense`

*Source Module*: `sep_axi_order_sweep_test`

*BFM / Model*: ocah_axi_vip

*Randomization*: RANDCFG — every (register x ordering) cell runs on every seed, and every (ordering x size) cell with it. The seed varies the staged data, the channel separation and the response backpressure, never which cell runs.

*Objective*: AXI write address and write data are independent channels with no ordering requirement between them (IHI 0022 A3.3), so AW-first, W-first and same-cycle are all legal stimulus and each must leave the written value in the addressed register without displacing its neighbour. The ordering is driven by holding the trailing channel until the leading one asserts VALID, and the ordering each cell actually presented is read off the bus and asserted against what was requested. The orderings are presented at the s_axi fabric ingress, and the contract is end to end: each one must land at every write-safe register of every swept block, not only at one scratch word. The crossbar in front of the block adapters can re-serialize a write (on the CSRNG path it delivers W one cycle after AW whatever the master presents, see <<sep_drbg_axil_adapter_port_arbitration_test>>), so this test does not claim that each adapter sees all three orderings; W-first and same-cycle orderings at an adapter port are covered for the DRBG lane adapter module by `sep_drbg_axil_adapter_port_arbitration_test`. The sweep configures all three orderings at every write-safe register and crosses them with the 1/2/4-byte sizes on the scratch words, where a narrow write has no side effect. The narrow cells compare the whole software-usable word against the AXI lane rule; `sep_axi_strobe_window_test` owns the same rule at default timing.

*Test Coverage*: AW/W channel ordering at every write-safe register, from the LSU splice.

*Test Procedure*:

[arabic]
. Take the register inventory and the exclusion reasons from `sep_reg_bit_bash_seq`: `write_reason() is None` for the no-side-effect blocks, plus `touch_reason() is None` restricted to `TOUCH_BLOCKS` for plain RW storage inside the other major IPs.
. Drop the blocks where the access itself would decide the result. `WDT_TIMER` is that block: `clk_wdt_i` is 5 µs and the AXI timeout is 50 µs, about ten watchdog edges, so whether a `prim_reg_cdc` round trip fits depends on the phase the access arrives on. A probe there measures CDC latency against the timeout rather than channel delivery. `sep_reg_bit_bash_rand_test` covers that block's storage, and it runs `clk_wdt` at eight core periods so the handshake retires inside the timeout.
. Prime the register with the complement under its write mask at default timing, and read it back, so a write that never lands reads as the prime rather than looking plausible.
. Apply the cell's timing profile through the VIP master (`AxiTimingProfile`, `ocah_axi_master_config`) to hold AW or W back, write the staged value, and read it back at default timing so the compare tests the write and not the read.
. Read a second register in the same block, write it back with one software-usable bit flipped at default timing, read it again, then re-read the swept register. Deriving the value from the current contents keeps a write that never arrived from reading back correct.
. A shadowed register commits on the second identical write. The profile arms a one-shot release, so it shapes the first write only and the committing second write goes out same-cycle. The ordering under test is the one the register sees first; the commit itself is not an ordered access.

*Checkers*:

[cols="2,5",options="header"]
|===
|Checker |Contract
|CHK-ORDER-LAND
|The written value is in the register after the ordering write. An adapter that latches a pending-write flag on AW accept and reads that flag in the same cycle the W arrives answers OKAY while dropping the data, so the compare is on the readback, never on the response. Every cell must produce a data compare; a cell that could not run is named with its reason, and the count then fails the test rather than reading as a full sweep.
|CHK-ORDER-DISPLACE
|The next write in the block lands on the register it addresses, and the swept register does not change when its neighbour is written. A pending flag left set by the ordering commits the following W handshake to the wrong target, which CHK-ORDER-LAND cannot see: it reads the register that was written, not the neighbour that was corrupted. The follow-on value is derived from what the neighbour currently holds and flips one software-usable bit, so a write that never arrived cannot read back correct. A refused follow-on write or readback fails this checker rather than being recorded as a skip. A cell in a single-register block offers no neighbour to write, so the required witness count is the number of cells that have one.
|CHK-ORDER-XSIZE
|All nine (ordering x size) cells produced a data compare, so the write lands at every transfer size and not only at the bus width.
|CHK-ORDER-STIM
|Each cell presented the ordering it requested, read off the AW/W valid assertions rather than taken from the configured profile. Asserted per cell. The slave's handshake is logged separately and is allowed to coincide: a slave that holds WREADY until AW answers a W-first presentation same-cycle, which is its own contract, not a stimulus failure.
|CHK-COVERAGE
|The cell count is asserted against a floor and against the cells the config presented, then the per-ordering tally, the blocks reached, the (ordering x size) grid and the witness count are logged. Every skipped register is counted under its reason on the configuration line the test logs first. A silent skip would let a shrinking sweep keep reporting PASS.
|CHK-RANDCFG
|The cell count for the seed is logged against the configured total, so a shrunken sweep is visible.
|===

*Pass Criteria*: Every named checker PASSes. UVM_ERROR == 0.

[[sep_drbg_axil_adapter_port_arbitration_test]]
===== 2.15 `sep_drbg_axil_adapter_port_arbitration_test`

*Phase*: 2

*Area*: Fabric and remap

*Run mode*: `no_cpu`, `+skip_fuse_sense`

*Source Module*: `sep_drbg_axil_adapter_port_arbitration_test`

*BFM / Model*: TB-instantiated `drbg_axil64_lane_adapter` (`u_tbadp_vehicle` in `tb/tb_top.sv`), driven pin-level from cocotb

*Randomization*: none. The three orderings are fixed and all three run on every seed; the contract is a cycle alignment, not a data pattern.

*Objective*: AW, W and AR are independent AXI channels (IHI 0022 A3.3). In idle the adapter accepts each write half independently until that half is pending, and accepts a read only when neither write half is pending. This leaf presents all three legal orderings at the port and requires both accesses to retire under each.

*Test Coverage*: All three legal AW/W/AR orderings at the TB-owned adapter port.

*Test Procedure*:

[arabic]
. Read the live CSRNG lane and require OKAY before the vehicle is touched (`CHK-PORT-ANCHOR`).
. On the vehicle, retire a lone write, a lone read, and an AW-then-W gap with no AR, each answering OKAY (`CHK-PORT-CONTROL`).
. Present each of the three legal AW/W/AR orderings at the vehicle port. Confirm the port presented the named ordering and, in the two gapped-write cells, that a cycle had AR valid with one write half handshaken and the other pending (`CHK-PORT-STIM`). Confirm both accesses retire in bound (`CHK-PORT-PROGRESS`). In every cell, require that no AR handshakes while a write half is pending, and in the two gapped-write cells that AR handshakes only after both write halves (`CHK-PORT-ARBITRATION`). Reset the vehicle between cells.

*Checkers*:

[cols="1,4",options="header"]
|===
|Checker |Contract

|CHK-PORT-ANCHOR
|A plain read of the live CSRNG lane answers OKAY before the vehicle is touched. The vehicle is a TB-owned instance, so without this the leaf could report a pass against a DUT that never left reset; it also puts a transaction through the AXI agent, which the scoreboard requires as positive evidence before it will allow a pass at all.

|CHK-PORT-CONTROL
|Three legs, all required to retire AND to answer OKAY, before any overlap cell runs. A lone write and a lone read show the vehicle and the AXI-Lite-32 responder behind the adapter are alive at all -- without them a broken driver would report every ordering as stalled and imitate the defect exactly. A third leg drives AW and then W four cycles later with no AR, the same separation the `aw-then-ar` and `w-then-ar` cells use, so the separation itself is excluded as the cause of their stall by observation rather than by reading the design under test. The response code carries the other half: an access the adapter rejects as unsupported is answered SLVERR straight out of `ST_IDLE` with nothing forwarded and retires just as promptly, so OKAY is what shows the forwarding leg is alive, and OKAY at the 64-bit port cannot be produced without the downstream handshake. The access itself is AMBA-legal by construction -- aligned, with the byte-lane strobe its address selects (IHI 0022), computed by `sep_spec_tables.axi_lane_strobe` -- so an adapter whose supported-access rule disagreed with the protocol answers this stimulus for itself rather than selecting it.

|CHK-PORT-STIM
|The ordering the port actually presented, read off `tbadp_chan_o` rather than taken from the offsets requested. In `aw-then-ar` and `w-then-ar` the cell must also reach the half-committed state the arbitration row grades: a cycle with AR valid, one write half handshaken and the other pending. That needs the two write halves to handshake in different cycles and AR to be valid by the second. A cell that misses either is a stimulus failure and is reported as one, never scored as coverage -- a cell that did not overlap says nothing about the arbitration in either direction.

|CHK-PORT-PROGRESS
|Both accesses retire: BVALID and RVALID are both seen within a bounded cycle count, and both responses are OKAY. The bound also records the longest run of held-valids-with-every-ready-low, so a hang that `ASSERT_KNOWN` would miss (a stable `1'b0` is not X) still fails the leaf.
|CHK-PORT-ARBITRATION
|In every ordering, no AR handshake falls after one write-half handshake and at or before the other, so no read is accepted while a write half is pending. In `aw-then-ar` and `w-then-ar`, where AR arrives while the leading half is pending, the AR handshake occurs strictly after both AW and W handshakes. In `all-same-cycle` all three may handshake together from idle. Logging the cycles without comparing them is not evidence.
|===

*Pass Criteria*: Every named checker PASSes. UVM_ERROR == 0.

*Scope*: the MODULE's arbitration, not the SEP integration. The DUT's own lane adapters sit behind the crossbar, which delivers W one cycle after AW and re-serializes every write to that order whatever a master presents -- `CHK-CONCURRENT-CAL` on the two fabric-driven leaves measures the gap at both ends and reports it as fabric-introduced. It is a second instance of the same RTL module with its own reset and no fabric in front of it: every legal ordering is presentable to the cycle, and a wedged cell is cleared without resetting the DUT, so the three verdicts are independent. ===== 2.19 `sep_axi_id_routing_test`

*Phase*: 2

*Area*: Fabric and remap

*Source Module*: `sep_axi_id_routing_test`

*BFM / Model*: ocah_axi_vip

*Randomization*: none. The proof is a value compare between an ID and the word
it asked for; a random ID or a random value on either side would remove it.

*Objective*: a response comes back to the request that owns it. The crossbars
prepend the master index to the incoming `AxID` and the demux keeps one
outstanding counter per ID, so the ID field is address-like state on the
response path, and a master matches its responses by it.

*Test Coverage*: the transaction-ID dimension of the SEP slave-port crossbar
path, with several reads outstanding at once on distinct IDs, including the
top ID the port's width allows.

*Test Procedure*:

[arabic]
. Prime the eight `SCRATCH_COLD` words, each with a value that names its own
word, and read each back sequentially.
. Issue eight reads, one per word, each on its own `AxID`, and hold them all
outstanding together by driving the VIP master sequence directly -- the SEP

so a shortened list cannot pass the routing compare silently.

*Checkers*:

[cols="2,5",options="header"]
|===
|Checker |Contract
|CHK-ID-PRIME
|The eight scratch words are independent storage each holding its own distinct value. Without this a block that aliased every word onto one register would let the routing compare pass for whichever value was written last.
|CHK-ID-ROUTE
|With eight reads outstanding together on eight distinct IDs, each returns the value of its own word. An ID that is mangled, truncated or dropped delivers a read's data to a different outstanding request, and every access still answers OKAY while it happens -- only the value compare sees it.
|CHK-ID-OVERLAP

|CHK-ID-TOP
|A breadth guard on the stimulus, not a second routing claim: the set of IDs the routing compare was given covered the whole width of the port's ID field. `CHK-ID-ROUTE` only compares the IDs it was handed, so an edit that shortened the list would keep passing over a subset; an ID field carried in too few bits only surfaces as a data mismatch if a read was actually issued on the top ID.

*Scope*: the SEP slave port only, whose `AxID` is three bits wide. The wider

*Anti-vacuity*: the prime leg establishes eight distinct values in eight
independent words before any routing claim is made, so a misrouted response is
distinguishable from a correct one. The concurrency is what gives the fabric

*Source Module*: `sep_crypto_csr_wide_access_test`

*BFM / Model*: ocah_axi_vip

*Objective*: Proves that a 64-bit read on each crypto host path returns the data that path's spec defines, and that concurrent 64-bit reads each return their own data. `hw/sys/sep/doc/crypto.adoc` (the `sep_crypto_axi_interconnect` paragraph) decodes one 64-bit AXI slave port to the host paths for OTBN, HMAC, AES, KMAC, ESRC, CSRNG and EDN, "with data-width conversion where required by the endpoint". [arabic]

[cols="2,5",options="header"]
|===
|Checker |Contract

*Objective*: The SEP components view of the SystemRDL memory map (`hw/sys/sep/regs/gen/py/sep_memory_map.py`, generated from `hw/sys/sep/regs/sep.rdl` by `tools/regs/rdlmap.py`, the same model that renders `hw/sys/sep/regs/gen/adoc/memory_map.adoc`) gives each unit's Decoded Extent and states how a 32-bit access that no register backs answers, as seen at the SEP inbound port: in a hole inside the extent, past the extent, and in a reserved row between apertures. Each response gives the read response, the RDL read data and the write response. `doc/trm/src/memory_map.adoc` (Decode Response Codes) defines the cells. This leaf holds the DUT to that table at the points that sit next to live registers and that `sep_fabric_deadspace_decode_test` and `sep_axi_map_refuse_test` do not probe. `env/sep_decode_resp.py` imports that view, so no expected code is typed into the test. `rdata` is a 64-bit field in `sep.rdl`: its low word answers a read with address bit 2 clear and its upper word a read with address bit 2 set. A 32-bit RDL rdata (no upper word) is the word a 32-bit read returns on either half of the bus (`ocah_resp.rdata` in `hw/common/regs/regblock_udps.rdl`; Decode Response Codes in `doc/trm/src/memory_map.adoc`). The expected codes and read data are the `ocah_resp` values `sep.rdl` states. `sep.rdl` is the specification of record for these codes, so `CHK-UNMAPPED-CODE` holds the DUT to the specification. Where the map and the RDL allocation of an array disagree, `CHK-ARRAY-TAIL` grades against the RDL allocation.

*Test Coverage*: System-CSR holes, the reserved row above SEP CPU control, the mailbox page's upper half, the space past each eFuse sibling block and past the SPI host, the end of the eFuse token MMR extent, and every remap and filter array slot tail answer the response code and read data the map states, and none of them aliases a live register.

*Test Procedure*:

[arabic]
. Program a distinct non-zero value into one live word of every array slot, the first and last AP / STEE output-remap entries, `SEP_NMI_VEC`, three mailbox thresholds, both eFuse timeouts, two eFuse token inputs and the SPI host `CSID`, and read each back. `CSID` takes effect only when a command is issued, and this leaf issues none. Each programmed word is read before its write, for the restore, except a word with a field that has no RDL reset. The two eFuse token inputs are such words: `hw/ip/efuse/regs/efuse_mmr.rdl` gives the `token` field of `RMA_TOKEN_I` and `SEC_DISABLE_TOKEN_I` no reset value, so the register has no value before its first write. The test reads this from the generated IP-XACT (`hw/sys/sep/regs/gen/ipxact/sep.xml`, no `resets` element on the field), not from the generated `_REG_DEFAULT`, which reads 0 for a field without a reset. These words are written before any read of them. Snapshot every other word of those slots, every mailbox `STATUS`, `TOKEN_MATCH_FAULT` and the SPI host `CONFIGOPTS`.
. Read `TOKEN_MATCH_FAULT` through its generated symbol.
. Read and write each probe with 32-bit singles. After each write, re-read every programmed word and the non-array snapshot words. For system-CSR and reserved-row probes, record whether the access reached the system-CSR AXI-Lite port and whether it arrived at the local crossbar's `ext` initiator. Before the probes, write and read the first address of the External row of the SEP CPU logical map (`0x0000_0000`) as the control for the `ext` initiator watcher.
. Read and write each array slot tail and the first word past each filter array, and after each write re-read the words of that slot and of the next slot. After each write to a tail inside the array extent, read that tail again.
. Re-read every live word, then restore the programmed words that were read before their write. The eFuse token inputs are not restored.

That size must equal the aperture of the array's map row. Every tail inside the extent, the last slot's tail included, must read zero and discard a write with OKAY. `sep.rdl` sets `ocah_full_stride_extent` on these arrays, so the map row's Decoded Extent is the full allocation and the map states OKAY with zero for every tail, the last one included. The first word past the outbound and inbound filter apertures (`0x10A2_0400`, `0x10A2_1200`) is in a reserved row and must be refused. The first word past the alias-remap array is `AP_OUTPUT_REMAP_CTRL[0]`, a live word, so it is not a refusal point.

* LSU is the CPU load/store splice on `s_axi`. It does not pass the inbound filter.

* approved: the probe exists in `tb/tb_top.sv` and `docs/SEP_TB_ARCH.adoc` lists it.

No test of this bucket injects a fault. The CPU-LSU splice is the one stimulus exception that the tests use. It is approved.

Bring-up modes:

* Real PROD fuse sense: the inbound filter is active.
* Real PROD fuse sense, then one DEMOTE_1 write: the inbound filter is bypassed.
* `+skip_fuse_sense`: used only for outbound and decode legs.

Every leaf reads FEAT_CTRL and logs it, so the log names the leg.

Shared rules:

* AxSIZE is the AXI size encoding: 0 is 1 byte, 1 is 2 bytes, 2 is 4 bytes and 3 is 8 bytes on the 64-bit bus. An access is aligned to its size and never crosses the end of its window.
* A read of a 32-bit register at AxSIZE 3 compares bits [31:0] only. Bits [63:32] of a `SCRATCH` word and of `SEP_SW_DEBUG` are reserved, and the specification states no read value for reserved bits, so the leaf logs them and does not grade them.
* Every graded register compare follows the shared reserved-bit rule (<<sep-vplan-reserved-bits>>): it uses the RDL field bits of the register only, and the bits that the RDL marks Reserved with no reset value are masked out of the compare and logged in the same line.
* A never check pairs with a control in the same leaf. In the control a healthy design drives the same probe or answers the same response. A leaf whose control stays silent fails.
* A deny cell pairs with an allow cell that differs in one attribute. A dead bus cannot pass the pair.
* The filter reference model is written from the `axi_filter` document (`hw/ip/axi_filter/doc/index.adoc`, "Instances", "Match, Then Permit" and "Address Range Granule") and from `hw/sys/smc/doc/assets/smc-traffic-filters.svg`. It never reads the RTL.
* The source ID that the filter compares with `src_id` is AxUSER[3:0] (`smc-traffic-filters.svg`, description of `axi_filter_wrap`: `src_id` is 0 or equals the source ID in AxUSER[3:0]). The filter document states that the decode is the same in every instance. OTHERS is source ID 0. Outside the source-ID legs every entry has `src_id` 0 and every probe carries AxUSER 0, so the source ID does not decide a verdict.
* Verdict anchor. The filter error subordinate answers DECERR to a refused request. An admitted outbound request reaches the bench responder, which answers OKAY, and the OKAY answer of the paired allow cell is the control. The response code is therefore the outbound verdict and needs no PR-OUT.
* Randomized stimulus is a pure function of the seed. `--stage sim --seed N` replays a leaf. A per-seed value is not evidence.
* A read-back of each programmed filter register sits between its write and the first dependent transaction, because the specification states no ordering between a CSR write and the next transaction.
* Every check logs `CHK-<NAME> PASS: ...` or `CHK-<NAME> FAIL: ...` with the values it compared. A leaf fails when a named check line is missing from `results.xml`.
* A `no_cpu` leaf runs on Verilator on target `lsu_stub_all_live` and on VCS on `--target default` (the shared Phase 3 testlist-entry rule), group `cpu_stub` and `testlists/system.toml`. A `cpu` leaf uses a firmware image, group `cpu` and `testlists/cpu.toml`.
* Tool "Both" means Verilator and VCS. Covergroup collection is VCS only.

===== 2.25 `sep_fabric_inbound_rebase_test`

*Phase*: 3

*Area*: Fabric and remap

*Run mode*: `no_cpu` (Verilator on `lsu_stub_all_live`, VCS on `--target default` per the shared Phase 3 testlist-entry rule, group `cpu_stub`, `testlists/system.toml`), real PROD fuse sense (no `+skip_fuse_sense`) with a pinned image: PROD, SEC_DIS 0, and fixed `SIP_DIS` and `SYS_DIS` values whose DBG_1 bit 0 is clear in both, 3 seeds. Tool: Verilator and VCS.

*Source Module*: `sep_fabric_inbound_rebase_test`

*BFM / Model*: ocah_axi_vip (LSU master on `s_axi`, SI master on `m_axi`); `tb/sep_outbound_mbx.sv` (outbound responder: OKAY and zero read data for any address), used by the unit leg only. Probes: PR-XEXT (approved: rebased request of an SRAM access), PR-CSR (approved: rebased request of a scratch access), the SI and LSU responses and read data, the LSU read-back (approved). PR-SRAM (an observation tap the test adds to the SEP_TB_ARCH observation-probe list) only supplements the LSU read-back, and no check needs it. The rebase model is written from `hw/sys/sep/doc/fabric.adoc` and never reads the RTL. No inject.

*Randomization*: `SepSeededRng` from the run seed, RAND-REP over a directed configuration. The seed samples the SRAM read offset `o` and the SRAM write offset `o2` (8-byte aligned, inside `0x0` to `0x3_FFF8`, `o2` different from `o`) and the cold scratch word offset `s` (8-byte aligned, inside the 64-byte bank). `reseed = 3` samples different offsets. The pairs, the cells and their order are the same on every seed. The test makes no claim about other base or size values, because the specification states no legal values.

*Objective*: An inbound request meets the inbound filter first on the chiplet-global address. The global-to-local remap then rebases the `SEP_REGION_SIZE`-byte window at `SEP_GLOBAL_BASE_ADDR` to address 0 and passes every other address unchanged. The peripheral crossbar forwards a local address below `0x4000_0000` to the local crossbar and answers DECERR at or above `0x4000_0000`. The inbound port has no connection to the Boot ROM, Reset Control, ICCM, DCCM, PIC and the AP and STEE regions, and answers DECERR for them at any aperture. Cites `hw/sys/sep/doc/fabric.adoc` ("Fabric Topology", input fabric; "Address Remapping"), `hw/sys/sep/doc/assets/sep-input-fabric.svg`, `hw/sys/sep/regs/gen/adoc/blocks/sep_cpu_ctrl.adoc` (`SEP_GLOBAL_BASE_ADDR`, `SEP_REGION_SIZE`), `hw/ip/axi_filter/doc/index.adoc` ("Blocked Transactions") `hw/sys/sep/doc/memory_map.adoc` ("Units Unreachable from the Inbound Port"), `hw/sys/sep/doc/assets/sep_axi_connectivity.svg` and `hw/sys/sep/doc/lifecycle_controller.adoc` ("Per-LC-state Feature Control Profile": the PROD state with no demotion keeps the inbound filter active).

Functional coverage: `sep_fabric_inbound_aperture_cg` (`cp_in_ap_class`, `cp_out_ap_class`, `cp_translation`, `cp_rebased_limit`, `cp_dest_class_verdict` for the loopback admitted cells and the unreachable-unit cells), `sep_fabric_port_silence_cp.sil_inbound_refused` (cause `rebase_ge_0x4000_0000`), existing `sep_inbound_filter_allow_cg`.

[[sep_fabric_filter_match_priority_rand_test]]
===== 2.26 `sep_fabric_filter_match_priority_rand_test`

*Phase*: 3

*Area*: Fabric and remap

*Run mode*: `no_cpu` (Verilator on `lsu_stub_all_live`, VCS on `--target default` per the shared Phase 3 testlist-entry rule, group `cpu_stub`, `testlists/system.toml`), real PROD fuse sense (no `+skip_fuse_sense`) with a pinned image: PROD, SEC_DIS 0, and fixed `SIP_DIS` and `SYS_DIS` values whose DBG_1 bit 0 is clear in both, 4 seeds. Tool: Verilator and VCS.

*Source Module*: `sep_fabric_filter_match_priority_rand_test`

*BFM / Model*: ocah_axi_vip (LSU master on `s_axi`, SI master on `m_axi`); `tb/sep_outbound_mbx.sv` (outbound responder: OKAY and zero read data for any address); the filter reference model of this bucket, written from `hw/ip/axi_filter/doc/index.adoc` and `hw/sys/smc/doc/assets/smc-traffic-filters.svg`, which reads only the programmed entry fields and the probe attributes and never the RTL. Probes. Approved: PR-XEXT and PR-CSR (an inbound refusal shows no handshake), the SI and LSU responses and read data, the LSU read-back of the SRAM and scratch words. PR-OUT, PR-EXT, PR-SRAM and PR-INFLT are observation taps the test adds to the SEP_TB_ARCH observation-probe list: PR-OUT supplements the outbound DECERR verdict, PR-EXT serves the extension-window probe of leg 3, PR-SRAM supplements the LSU read-back, and PR-INFLT shows the register-class reads of the wide-range control pass the inbound filter. No inject.

*Randomization*: `SepSeededRng` from the run seed, two classes. Legs 1, 2 and 4 are RANDCFG. Dimensions: entry count (3 to 6 per instance), entry indices (inbound 0 to 15, outbound 0 to 31), overlapping range placement, `entry_enabled`, `allow_ns`, `allow_burst`, `src_id` (0 to 15), AxUSER[3:0] of the probe (0 to 15), `read_allowed`, `write_allowed`, `group_id` (0 to 15), probe attributes, granule index, in-granule offsets of START and END, and the shape. Leg 3 is RAND-REP. Dimensions: probe address, direction, AxSIZE, probe `prot[1]` (0 or 1) and the control entry index; every destination class is probed in the directions that leg 3 lists for it, on every seed. The armed range of leg 3 is the directed value START_ADDR 0, END_ADDR 2^48-1, which covers every probed address and ends below 2^56-1. Legal range per `hw/ip/axi_filter/regs/gen/adoc/filter_ctrl.adoc` (`FILTER_CONFIG`, `START_ADDR`, `END_ADDR`). Rejection list: an inverted range; a range that touches 2^56-1; a range where START is in a higher granule than END; any outbound burst; any inbound entry that covers the filter-bank page or `SEP_CPU_CTRL` in legs 1, 2 and 4; the `locked` bit; any draw of the `SEP_DBG` bit; probe addresses of units that the inbound port does not reach (their DECERR comes from decode); in a leg 1 (entry state, attribute) cell, any other stack entry that matches the probe in the deny cell or in the allow cell (each other entry does not cover the probe address or fails a match term, so the covering entry alone decides both verdicts). In the granule leg a range is whole granules inside SRAM (inbound) or inside the SMU window above `0x8000_1000` (outbound, `src_id` 0). `reseed = 4` samples different stacks, values and probe attributes. The cell classes of each leg are the same on every seed. Leg 1 draws the destination class of each (entry state, attribute) cell from the classes of its instance, and every class gets at least one cell per instance on every seed. The cross of attribute and destination class is seed-dependent and has no bin. Leg 2 runs the source-ID values 1, 2, 4, 8 and 15 (each bit alone and all four bits) and the wildcard probes with AxUSER[3:0] 0 and 15 on every seed. It draws one more non-zero source ID from the other ten values and two more wildcard AxUSER[3:0] values from 1 to 14. No bin records a value (`cp_src_id_class` bins the classes), and no regression claims the full value sets. The other values come only over a merge of regressions.

*Objective*: A filter entry matches only when it is enabled, the address is in the widened range, `prot[1]` equals `allow_ns`, the source ID equals `src_id` or `src_id` is 0, and `allow_burst` is 1 or AxLEN is 0. The source ID is AxUSER[3:0]. The lowest-numbered match wins and only its permission bit counts. A failed match falls through. A clear permission bit on the lowest match blocks. A transaction that no entry matches is blocked with DECERR. AW and AR decode independently. `group_id` is programmed with a random value and is not graded. After reset every entry is disabled, so unmatched traffic is blocked. Default deny rests on `entry_enabled`: an entry that holds a range, permission bits and an `allow_ns` equal to the probe `prot[1]` does not match while it is disabled. The granule is 4 KB with `allow_burst` 1 and 8 bytes with `allow_burst` 0. START_ADDR widens down and END_ADDR widens up, and a range that straddles a boundary admits both granules. The specification states no write-back timing, so the test grades the admitted set through the verdicts and logs the START_ADDR and END_ADDR read-back without grading it. Cites `hw/ip/axi_filter/doc/index.adoc` ("Instances"; "Match, Then Permit"; "Address Range Granule"; "Blocked Transactions"), `hw/ip/axi_filter/regs/gen/adoc/filter_ctrl.adoc` (`FILTER_CONFIG`, `START_ADDR`, `END_ADDR`), `hw/sys/smc/doc/assets/smc-traffic-filters.svg` (the five match conditions of `axi_filter_wrap`, including `src_id` against AxUSER[3:0]) `hw/sys/sep/doc/fabric.adoc` ("Top Level AXI4"; "Filtering and Protection"; "Transaction Routing") and `hw/sys/sep/doc/lifecycle_controller.adoc` ("Per-LC-state Feature Control Profile": the PROD state with no demotion keeps the inbound filter active).

*Test Coverage*: Four legs that share one stimulus family (programmed entries and one probe per cell), one run mode and one tool.

* Leg 1, match and priority: entry state (enabled, disabled) by attribute (range, `prot[1]`, burst, read permission, write permission) on each instance; the corner cells fall-through (a), permission block (b), burst fall-through (c, inbound only), disabled lowest entry (d), read and write that choose different entries (e) and no match (g); the destination classes SRAM and scratch inbound and the SMU window and the AP region outbound, each as a read and as a write.
* Leg 2, source ID: the non-zero values 1, 2, 4, 8 and 15 and one drawn non-zero value, the wildcard against AxUSER[3:0] 0 and 15 and two drawn values, the fall-through on a source-ID mismatch, an upper AxUSER bit, and the outbound exact and mismatch cells.
* Leg 3, default deny: the reset state, the armed-but-disabled state of all 48 entries and the enabled control entry per instance.
* Leg 4, granule: seven cells. Outbound 4 KB granule by the one, equal and straddle shapes. Inbound 4 KB granule by the equal and straddle shapes. 8-byte granule by the straddle shape on both instances.

Extends `sep_fabric_inbound_filter_rule_matrix_test`, which grades the per-entry inbound cells (enabled, range, burst, read and write permission), one `src_id` match value and one mismatch on entry 0, the 4 KB widening of one entry and the reset-state block. It also extends `sep_fabric_inbound_filter_window_walk_test` and `sep_fabric_outbound_remap_filter_walk_test`, which grade the one 8-byte granule that holds the probe address on both instances, `sep_lcc_uvm_inbound_filter_gating_test`, which grades the inbound block with the debug bit clear, `sep_fabric_output_remap_datapath_proxy_test`, which grades one outbound entry whose enable is cleared after it admitted an access, and `sep_fabric_slot_csr_strobe_rand_test`, which reads the reset values of all 48 entries. Only the new cells are graded here:

* leg 1: the outbound instance, the fall-through, permission-block and no-match corner cells, the read and write divergence, the permission block that hides an allow, and the inbound `prot[1]` mismatch cell (`allow_ns` different from the probe `prot[1]`) with its paired allow cell;
* leg 2: every source-ID cell beyond the single inbound match value, namely the non-zero values 1, 2, 4, 8 and 15 and one drawn non-zero value, the wildcard against AxUSER[3:0] 0 and 15 and two drawn values, the fall-through on a source-ID mismatch and the outbound exact and mismatch cells;
* leg 3: the armed-but-disabled sweep over all 48 entries, the outbound reset state and the enabled control entry per instance;
* leg 4: the outbound 4 KB granule, the equal shape on the 4 KB granule and the straddle shape on both granules and both instances.

The open tests keep the rest. Functional coverage: `sep_filter_match_cg` (`cp_fail_cond_fallthrough`, `cp_src_id_class`, `cp_ar_aw_independent`, `cp_winner_class`), `sep_filter_range_granule_cg` (`cp_granule_shape_inst`, `cp_probe_point_verdict`, `cp_subgranule_off`), `sep_filter_default_policy_cg` (`cp_deny_basis`, `cp_filter_active_block`), `sep_fabric_inbound_aperture_cg.cp_dest_class_verdict`, `sep_fabric_port_silence_cp.sil_inbound_refused` (cause `filter_deny`), existing `sep_inbound_filter_allow_cg`.

*Test Procedure*:

[arabic]
. Bring up with real PROD fuse sense of the pinned image, so the inbound filter is active. The LSU reads `FEAT_CTRL` (64 bits) and compares it with the golden decode that the model computes from the profile table of `lifecycle_controller.adoc` for that image. The golden holds the SEP_DBG state that keeps the filter active. A mismatch prints `CTL-FILTER-ACTIVE FAIL` and stops the leaf.
. The LSU stages a non-zero marker at two consecutive SRAM words (16-byte aligned, so a 2-beat probe at the first word stays inside one 4 KB page and reads both) and at one cold scratch word, and reads all three back. The scratch register holds 32 data bits, so every compare of a scratch read uses bits [31:0], and bits [63:32] are reserved and logged only. These markers differ from every value that a probe writes. Each inbound write probe to a staged word drives a seeded value that differs from the value that the model holds for that word (the staged marker or the last write that landed), so a landed write changes the LSU read-back and a refused write leaves it unchanged.
. The LSU programs AP output remap region 0 with `valid` 1 and offset `0x20_0000_0000`, and STEE output remap region 0 with `valid` 1 and offset `0x28_0000_0000`. The model predicts the outbound address of an AP or STEE probe as the offset bits [55:19] joined with the region address bits [18:0] (`hw/ip/output_remap/regs/gen/adoc/output_remap.adoc`, `region_attrs`). The LSU reads the registers back. No filter entry is programmed at this step.
. Leg 3, reset state. SI reads and writes SRAM, scratch, a mailbox word and a crypto-region word, and SI reads the filter bank page and `SEP_CPU_CTRL`, each with `prot[1]` 0 and with `prot[1]` 1 (AxLEN 0, AxUSER 0). Error injection at `smn_inbound_axi_req_i`: every entry is disabled. The expected response is DECERR on RRESP or BRESP.
. The LSU reads back the staged SRAM and scratch words. Both hold their staged value.
. Error injection at the LSU outbound path: the LSU reads one SMU-window word (above `0x8000_1000`) and one AP region word (offset below `0x8_0000` in region 0), each with `prot[1]` 0 and with `prot[1]` 1. Every outbound entry is disabled. The expected response is DECERR.
. SI reads one word of the extension window (`0x2000_0000` to `0x3FFF_FFFF`, outside the eFuse shim window) and the word `0x4000_0100`, each with `prot[1]` 0 and with `prot[1]` 1. The responses are logged and are not graded. PR-EXT shows no handshake for the extension-window read.
. Leg 3, armed but disabled. The LSU programs all 16 inbound and all 32 outbound entries with the range START_ADDR 0, END_ADDR 2^48-1, which covers every probed address (SRAM, scratch, mailbox, crypto word, filter bank page, `SEP_CPU_CTRL`, the SMU window and the translated AP and STEE words), and with read and write permission, `src_id` 0, `allow_burst` 1 and `entry_enabled` 0. `allow_ns` is 0 on half of the entries of each instance and 1 on the other half, so for each probe `prot[1]` at least one entry would match if it were enabled. The LSU reads every entry back.
. Repeat steps 4 to 7 with the armed entries.
. Leg 3, wide-range control. For each probe `prot[1]` value and each instance, the LSU enables one armed entry whose `allow_ns` equals that `prot[1]` value, keeps its range START_ADDR 0, END_ADDR 2^48-1, and reads it back. SI reads the staged SRAM word, the staged scratch word and the mailbox, crypto, filter-page and `SEP_CPU_CTRL` words of the deny probes, and the LSU reads one SMU-window word and one translated AP word. Every read answers OKAY. The SRAM and scratch reads show their handshake on PR-XEXT or PR-CSR and return the staged data. The mailbox, crypto, filter-page and `SEP_CPU_CTRL` reads show their request on PR-INFLT, after the inbound filter. So each inbound class that the armed run counts is shown to reach its unit when the filter admits it. With the inbound entry enabled, SI also reads the extension-window word of step 7 with the same `prot[1]`. The filter admits it, so PR-EXT shows one request at that address (the PR-EXT control of CHK-RESET-DENY). Its response is logged and is not graded. The LSU disables the entry again. This shows that the armed range matches a probe when the entry is enabled.
. Leg 3, control. The LSU selects the seeded control entry index `k` on each instance, programs it over the control probe range only (SRAM or scratch inbound, the SMU window or the AP region word outbound) with `allow_ns` equal to the probe `prot[1]`, and enables it. The other entries stay armed and disabled. The LSU reads the entry back.
. Leg 3, control probes. SI reads the control-eligible inbound probe and the LSU reads the control-eligible outbound probe. Both answer OKAY. The inbound probe shows its handshake on PR-XEXT or PR-CSR.
. The LSU disables every entry of both instances. Legs 1, 2 and 4 follow. Before each cell of those legs the LSU programs every entry that the cell uses, disables all others and reads each programmed register back.
. Leg 1, cell list. Per instance, the test builds one cell for each (entry state, attribute) pair (the burst attribute applies to inbound SRAM only), the corner cells a, b, d, e and g on both instances and the corner cell c inbound only. Each cell is a read probe and a write probe, each with its own `prot[1]`. Each (entry state, attribute) cell runs on one destination class of its instance that the seed draws: SRAM or scratch inbound, the SMU window or the AP region outbound. The draw gives each destination class at least one cell per instance, so every class runs as a read and as a write on every seed. The burst attribute applies to the inbound SRAM class only.
. For each cell the LSU programs a seeded stack of 3 to 6 entries at seeded indices. The entries overlap on a seeded window set. For the AP class the entries cover the translated AP address. Every entry gets a random `group_id`, and `src_id` is 0 on every entry of leg 1.
. For each (state, attribute) cell, one attribute of the covering entry is changed so that the probe fails exactly one match term or permission bit (range, `prot[1]`, burst, read permission, write permission, or `entry_enabled`). Run the probe. Error injection: the expected response is DECERR. Then run the paired allow cell, which is the same cell with that one attribute restored. The expected response is OKAY. The burst-attribute cell is inbound SRAM only: its probe is a 2-beat INCR (AxLEN 1) whose 16 bytes lie inside the covering range, the covering entry has `allow_burst` 0 in the deny cell and 1 in the allow cell, and the probe of every other cell has AxLEN 0, because a single beat always satisfies the burst term. The scratch class and the outbound instance do not draw the burst attribute.
. Corner cell a. The lowest entry rejects the probe on `prot[1]`, and a higher entry allows it. The probe is admitted by the higher entry.
. Corner cell b. The lowest entry matches with the permission bit clear, and a higher entry allows it. Error injection: the expected response is DECERR, the higher entry never counts.
. Corner cell c, inbound only. The lowest entry has `allow_burst` 0, the probe is a 2-beat INCR burst (AxLEN 1) to SRAM, and a higher entry has `allow_burst` 1. The probe is admitted by the higher entry. Its paired allow cell is an AxLEN 0 probe to the same address.
. Corner cell d. The lowest entry is disabled and covers the probe, and a higher entry allows it. The probe is admitted.
. Corner cell e. The read and the write of one address carry different `prot[1]` and select different entries, so one is admitted and the other is refused.
. Corner cell g. No enabled entry covers the probe. Error injection: the expected response is DECERR.
. Each corner cell runs once as a read and once as a write on each instance it applies to. Inbound probes come from SI with AxLEN 0, and AxLEN 1 INCR to SRAM runs only for the burst-attribute cell, corner cell c and their allow cells. Outbound probes come from the LSU with AxLEN 0.
. The model computes the expected verdict of every cell from the programmed fields and the probe attributes. Each probe response is compared with it.
. Leg 2 entries have read and write permission, `allow_ns` equal to the probe `prot[1]` and `allow_burst` 0, unless a cell names another value.
. Leg 2, inbound exact and mismatch. For each `src_id` value s of the set 1, 2, 4, 8, 15 and one non-zero value drawn from the other ten (seeded order), the LSU programs an entry over SRAM with `src_id` s. SI probes with AxUSER[3:0] = s (match) and with AxUSER[3:0] different from s, AxUSER[3:0] 0 included (mismatch), as read and as write.
. Leg 2, inbound wildcard. The LSU programs an entry over SRAM with `src_id` 0. SI probes with AxUSER[3:0] 0, 15 and two values drawn from 1 to 14, in a seeded order, as read and as write. Every probe is admitted.
. Leg 2, inbound fall-through. The lowest entry mismatches on the source ID, and a higher entry (wildcard or exact) admits. SI probes the covered address as a read and as a write, on every seed.
. Leg 2, inbound upper bits. When the inbound port carries more than 4 AxUSER bits, SI probes with an upper AxUSER bit set and AxUSER[3:0] equal to s against the entry of s. The probe matches.
. Leg 2, outbound mismatch. The LSU programs an outbound entry over the translated AP range with a non-zero `src_id` and enables it alone. The LSU reads and writes an AP word (source ID OTHERS). Error injection at the outbound filter input: the expected response is DECERR, because OTHERS does not equal the non-zero `src_id`. The LSU disables that entry, programs an entry over the same range with `src_id` 0 and enables it alone. The same probes are admitted: OKAY. The LSU repeats both runs for the STEE range.
. Leg 2, outbound exact. The LSU programs an outbound entry over an SMU-window word with `src_id` u (1 to 15) and enables it alone. The LSU probes the word with AxUSER[3:0] u (match, OKAY), then reprograms `src_id` to a non-zero value other than u and probes again (mismatch). Error injection at the outbound filter input: the expected response of the mismatch run is DECERR. The LSU bench master stands in for a CPU master. The source ID value of a real CPU master is not used. Reads and writes both run.
. Every deny cell of leg 2 runs next to a paired allow cell that differs in AxUSER[3:0] or in `src_id` only.
. Leg 4, granule. For each of the seven cells, draw a granule index `g` so that the granules `g` - 1 to `g` + 2 lie inside SRAM (inbound) or inside the SMU window above `0x8000_1000` (outbound). The first page of the SMU window is not used, because the bench responder decodes stores to `0x8000_0000` as console output.
. Program one entry over the cell range: `allow_burst` 1 for the 4 KB granule and 0 for the 8-byte granule, `src_id` 0, `allow_ns` equal to the probe `prot[1]`, read and write allowed. The shape sets START and END. One: both inside granule `g`, not aligned, START different from END (outbound 4 KB only). Equal: START equal to END, unaligned (4 KB granule, both instances). Straddle: START inside granule `g` and END inside granule `g` + 1 (both granules, both instances). Read START_ADDR and END_ADDR back and log them. The read-back is not graded.
. Probe each shape at the widened base minus 4, the widened base, the widened base plus 4, the last 4 bytes of the last admitted granule and the first 4 bytes after it. AxSIZE 2, AxLEN 0, read and write. Before each inbound cell the LSU stages a non-zero marker at every SRAM word that the cell probes and reads it back. Each write probe drives a seeded value that differs from that marker, and the LSU reads each probed word back after the probes. The model computes the admitted set from the widening rule. The probes outside the admitted set expect DECERR, and the probes inside expect OKAY.
. The LSU disables every entry and restores AP and STEE output remap region 0 to the reset value.

[[sep_fabric_outbound_route_attr_test]]
===== 2.27 `sep_fabric_outbound_route_attr_test`

*Phase*: 3

*Area*: Fabric and remap

*Run mode*: `no_cpu` (Verilator on `lsu_stub_all_live`, VCS on `--target default` per the shared Phase 3 testlist-entry rule, group `cpu_stub`, `testlists/system.toml`), real PROD fuse sense (no `+skip_fuse_sense`) with a pinned image: PROD, SEC_DIS 0, and fixed `SIP_DIS` and `SYS_DIS` values whose DBG_1 bit 0 is clear in both, then one DEMOTE_1 write for the no-bypass leg, 4 seeds. Tool: Verilator and VCS. VCS is required for the X check on the PR-OUT capture.

*Source Module*: `sep_fabric_outbound_route_attr_test`

*BFM / Model*: ocah_axi_vip (LSU master on `s_axi`, SI master on `m_axi`); `tb/sep_outbound_mbx.sv` (outbound responder: OKAY and zero read data for any address); the filter reference model of this bucket (written from `hw/ip/axi_filter/doc/index.adoc`, never from the RTL). Probes. Approved: the LSU and SI responses and read data, the LSU read-back of local words, the LSU and SI reads of `FEAT_CTRL`. PR-OUT (an observation tap the test adds to the SEP_TB_ARCH observation-probe list), for CHK-OUT-CAPTURE, CHK-OUT-NOEXTRA and the disabled-pair silence of CHK-OUT-ROUTE. No inject.

*Randomization*: `SepSeededRng` from the run seed, RANDCFG. Dimensions: region index (0 to 15 per remap), offset bits 55:19 (non-identity), direction order, AxPROT value, LSU AxUSER[3:0] u (1 to 15, upper AxUSER bits 0). The SMU aperture stays at the reset pair (`0x8000_0000`, size `0x4000_0000`). Legal range per `hw/ip/output_remap/regs/gen/adoc/output_remap.adoc` (`region_attrs`). Rejection list: an offset equal to the region identity; an offset sum at or above 2^56; a translated AP or STEE address, or the untranslated word of the step 9 pair, that lies inside the SMU aperture, inside the local pair range, or inside the range of any other pair or stack entry that is enabled in the same step. `reseed = 4` samples different region indices, offsets, AxPROT values and u. Every route class runs in both directions on every seed.

*Objective*: The route demux sends the SMU aperture (reset `SMU_GLOBAL_BASE_ADDR` and `SMU_REGION_SIZE`) and the AP and STEE regions through their output remaps to `smn_outbound_axi_req_o`. A scratch or system-CSR request does not leave on that port. The AP and STEE remaps set the source ID in AxUSER to OTHERS (zero). Other traffic keeps the AxUSER of its initiator. AxPROT passes unchanged. The outbound filter checks address, NS and source ID after remapping and has no bypass. The test grades the forcing of OTHERS through the outbound filter: while the LSU drives a non-zero AxUSER[3:0] `u`, an AP or STEE request carries OTHERS, so it does not match an entry whose `src_id` is `u` and it matches an entry whose `src_id` is 0. The route of an address at or above `0x1_0000_0000` is graded by the hit cells of `sep_fabric_alias_remap_attr_rand_test`, and the NS mismatch response and the exact source-ID match of an SMU word by `sep_fabric_filter_match_priority_rand_test`. The specification states two conflicting rules for an address below `0x1_0000_0000` outside every window, so the test does not write the SMU aperture registers and does not grade a route outside every window. Cites `hw/sys/sep/doc/fabric.adoc` ("Fabric Topology", output fabric; "Transaction Routing"), `hw/sys/sep/doc/assets/sep-output-fabric.svg`, `hw/sys/sep/regs/gen/adoc/blocks/sep_cpu_ctrl.adoc` (`SMU_GLOBAL_BASE_ADDR`, `SMU_REGION_SIZE`), `hw/ip/output_remap/regs/gen/adoc/output_remap.adoc` (`region_attrs`), `hw/ip/axi_filter/doc/index.adoc` ("Match, Then Permit"; "Blocked Transactions") `hw/sys/smc/doc/assets/smc-traffic-filters.svg` (`src_id` against AxUSER[3:0]) and `hw/sys/sep/doc/lifecycle_controller.adoc` ("Per-LC-state Feature Control Profile": PROD with SEC_DIS 0 and the demotion of DBG_1).

*Test Coverage*: The SMU reset aperture (first, middle and last word) and the AP and STEE regions with a non-identity offset, each on read and write and each with `prot[1]` 0 and 1; the source-ID stack over the AP and STEE words with the LSU AxUSER[3:0] non-zero; the outbound pair after DEMOTE_1; and local scratch and `SEP_SW_DEBUG` accesses behind an outbound pair that would admit them. Extends `sep_fabric_outbound_remap_filter_walk_test` and `sep_fabric_output_remap_datapath_proxy_test`, which grade the offset translation and the low-bit pass-through of the AP and STEE regions through read requests and the valid-clear pass-through, `sep_lcc_uvm_inbound_filter_gating_test` and `sep_lcc_demote_feat_ctrl_matrix_test`, which grade the `FEAT_CTRL` value and the inbound filter bypass after DEMOTE_1, and `sep_address_map_test`, which grades the local scratch and `SEP_SW_DEBUG` accesses with no outbound entry. Only the new cells are graded here: the SMU aperture on read and write, the AP and STEE writes, the forcing of OTHERS on AP and STEE traffic and the outbound pair with the inbound filter bypassed. The absence of scratch and `SEP_SW_DEBUG` requests on the port and the PR-OUT capture of AxPROT, AxUSER and write data are new cells, and this test grades them. The AP and STEE read cells run as controls, and the open tests grade them. The open tests keep the rest. Functional coverage: `sep_fabric_outbound_route_cg` (`cp_route_class_dir` for the SMU, AP and STEE cells, `cp_smu_aperture_cfg`, `cp_out_attr`), `sep_remap_output_offset_cg.cp_instance_dir`, `sep_filter_match_cg.cp_fail_cond_fallthrough` (the outbound source-ID mismatch cells), `sep_filter_default_policy_cg.cp_dbg_bypass`, `sep_fabric_port_silence_cp` (`sil_out_local_target`, `sil_out_filter_deny`).

. Key Manager mailbox, from SI, with KM held in reset. Read `SEP_STATUS`, `SEP_IRQ_STATUS`, `SEP_CTRL` and `SEP_IRQ_ENABLE` as the baseline. Read `SEP_WRITE_SEPARATOR`. Do not access `SEP_WRITE_DATA` or `SEP_READ_DATA`. Then, per direction, access the pairs at offsets `0x1C` and `0x20`, `0xFF8` and `0xFFC`, drawn pairs in `0x1C` to `0xFFC`, and drawn pairs in `0x1092_1000` to `0x1092_FFFC`. Read the baseline again after each access. Error injection at the decode of the row. Expected response: DECERR on every access, with read data `0xBADCAB1E` on a read. Baseline control: after the last access, SI writes `SEP_IRQ_ENABLE` = `0x1C` (the three sticky-event enables; reset value 0), reads it back, writes 0 and reads it back.
. Burst leg, from SI, for each cell: each of the OTBN, HMAC, KMAC, entropy source and ABR windows, each start kind (a stable RW register at an 8-byte-aligned address, and a hole) and each direction. Draw the start address and AxLEN. From the LSU, read the snapshot of every stable register of the touched window that has no read side effect.
. Error injection at `smn_inbound_axi_req_i`, for the same cell: issue the INCR burst with AxSIZE 3 and the drawn AxLEN. Each write beat drives the bitwise complement of the snapshot words at its address, and seeded data where no snapshot word exists. Expected response: DECERR on the single B or on every R beat.

. Control, for the same cell: issue a single-beat SI access with AxSIZE 2 at the start address. For a register, write the complement of its snapshot value, read it back, and restore the snapshot value. For a hole, read it and write it.

*Test Procedure*:

[arabic]
. The host patches the seeded values and the leg enables into the firmware parameter block, stages the image and releases the CPU. The SMC leg runs on every seed.
. Firmware programs the DMA once: `ENABLED_MEMORY_RANGE_BASE` 0, `ENABLED_MEMORY_RANGE_LIMIT` `0xFFFF_FFFF`, `RANGE_VALID` 1, `TRANSFER_WIDTH` 4 bytes and the done and error interrupt enables. A DMA run means: program the source and destination address, `TOTAL_DATA_SIZE`, `CHUNK_DATA_SIZE` equal to `TOTAL_DATA_SIZE` (one chunk; `secure_dma.adoc`, CHUNK_DATA_SIZE: for a single memory transfer the two registers hold the same value), `SRC_CONFIG` and `DST_CONFIG`; clear `STATUS` DONE, ERROR and CHUNK_DONE (write one to clear) and the DMA bus-error latch (`DMA_BUS_ERR_CLEAR`); read `STATUS` and check that all three bits read 0; set `CONTROL.GO`; wait for `STATUS.DONE` or `STATUS.ERROR`. A wait that ends in neither within a bounded wait fails the leg. A recovery copy means: clear the DMA error state, then run an SRAM to SRAM copy of seeded words and compare the destination with the source.
. Random copies. For each pair of the list SRAM to scratch, scratch to SRAM, WDT status word to SRAM and AES `CTRL_AUX_REGWEN` word to SRAM, in the seeded order (every pair runs on every seed), stage the source with seeded words and the destination with a different pattern, run the DMA and compare. For a register source, set the increment of the register side to 0 (fixed address) and compare each destination word with the LSU read of the register before and after the run. A scratch word holds its `data` field in bits [31:0] at its 8-byte-aligned address, and the 4-byte beat at that address + 4 lands on bits [63:32], which are Reserved with no stated read value. The scratch pairs therefore compare only the 4-byte words at a scratch word address (address bit 2 clear) with their twins on the SRAM side, and log the other words. The WDT word is `WDOG_REGWEN` (`regwen` reads 1 from reset until a write of 0, `aon_timer.adoc`; the leaf never writes it) and the AES word is `CTRL_AUX_REGWEN` (RW0C, reset value 1, reads 1 until a write of 0, `vendor/lowRISC/opentitan/overlay/regs/aes/regs/gen/adoc/aes.adoc`; the leaf never writes it), so bit 0 of both reads 1 before and after the run. Bits [31:1] of both words are Reserved with no stated read value, so the compare uses bit 0 and logs bits [31:1]. The staged destination pattern has bit 0 = 0. A bit 0 that reads 0 or changes fails the pair, because a DMA read that lands on another zero word gives the same destination. Then run the directed SRAM to SRAM copy at direct addresses. It is the direct-form cell of CHK-DMA-ALIAS and is not graded as a pair.
. Extension port. Run one DMA read from `0x2000_0100` into SRAM and one DMA write from SRAM to `0x2000_0100`, each one 4-byte beat (`TOTAL_DATA_SIZE` 4). The port answers DECERR (`hw/sys/sep/doc/port_table.adoc`, `axi_extension_axi_resp_i`: tie to DECERR if unused), so each run ends with `STATUS.ERROR` and `ERROR_CODE.BUS_ERROR`. PR-EXT records the AR and the AW address and the number of beats, and its reply channel the response. Run a recovery copy after each.
. Alias legs. Run an SRAM to SRAM copy with the source at `0xD000_0000` + `o_s` and the destination at `0xD000_0000` + `o_d`, with seeded offsets whose ranges do not overlap. Stage the source at the direct address `0x1000_0000` + `o_s` with seeded words and the destination with a pattern that differs from them, and read the destination at the direct address `0x1000_0000` + `o_d`. Run an 8-byte DMA write (`TOTAL_DATA_SIZE` 8) from SRAM to the destination `0xFFFF_FFF8`, so the write ends at `0xFFFF_FFFF`, and run a recovery copy afterwards. PR-EXT records the address of that write.
. Outbound legs. Program AP region 0 with a non-identity offset and `valid` 1. Program an outbound entry pair (`allow_ns` 0 and 1, read and write allowed, `src_id` 0) over the remapped AP word and a second pair over the SMU window word. Read the entries back. Run a DMA write from SRAM to an AP region word and a DMA write from SRAM to the SMU window word. Store one word from the CPU to the SMU window as the control. PR-OUT records every beat.
. Source-ID stack over the SMU window. Program all 32 outbound entries over the SMU window word: entries 0 to 14 with `src_id` 1 to 15 and `allow_ns` 0, entries 15 to 29 with `src_id` 1 to 15 and `allow_ns` 1, all enabled and with write permission set; entries 30 and 31 with `src_id` 0, one for each `allow_ns` value, with write permission clear. Read the entries back. Error injection at the outbound filter input: run a DMA write (AxUSER 0) to the SMU window word. Expected response: DECERR, shown as `STATUS.ERROR` with `ERROR_CODE.BUS_ERROR`. Check `STATUS` and `ERROR_CODE`, then clear the DMA error state and run a recovery copy. Then set write permission on entries 30 and 31, read them back and run the same write as the control write. It completes with `STATUS.DONE` and no error.
. Register endpoints. Read each register once from the LSU. For each of SCRATCH[0], SPI `CSID` and `SEP_SW_DEBUG`, run SRAM to register first and register to SRAM next, with the register side at a fixed address (increment 0). The last source word of the SRAM to register run is seeded and differs from the register value read before it. Firmware writes the inbound entry 0 `FILTER_CONFIG` with seeded non-zero `src_id` (bits [19:16]) and `group_id` (bits [23:20]) and every other field at its reset value, so the entry stays disabled, and reads it back. Run a DMA read of `SW_RESET_N` to SRAM and a DMA read of the inbound entry 0 `FILTER_CONFIG` to SRAM. After each destination register, read it from the LSU. Restore each written register, `FILTER_CONFIG` included.
. SMC port. Poll `SMC_FUSE_SENSE_STATUS` until `smc_fuse_sense_done` reads 1, within a bounded wait, and log the poll count. Run a DMA copy from SRAM to an SMC window address inside configuration A (16 to 1024 bytes), then a DMA copy from that address back to a different SRAM region. Read one word from the CPU at the same SMC address as the control.
. Not-connected legs. Read the boot ROM base word and a DMA CSR word (`ENABLED_MEMORY_RANGE_LIMIT`, non-zero) from the LSU. PR-ROM records the handshake of the boot ROM read. Stage a destination SRAM value that differs from both. Error injection at the DMA master request, one run each for these three targets: source at the boot ROM base, destination at the boot ROM base, source at the DMA CSR word. From the `CONTROL.GO` write until the done or error interrupt the CPU waits in a bounded loop that reads only a DTCM flag, so no CPU access reaches the DMA CSR in that window. A wait that ends with no interrupt fails the firmware with a line that names the leg. The host bounds the wait; a timeout fails CHK-DMA-NOTCONN. No DMA path reaches the boot ROM or the DMA CSR port (`hw/sys/sep/doc/assets/sep_axi_connectivity.svg`; `fabric.adoc`, "Fabric Topology"), so each run ends in error with `STATUS.ERROR` and `ERROR_CODE.BUS_ERROR` and no other defined `ERROR_CODE` bit (`vendor/lowRISC/opentitan/overlay/regs/secure_dma/regs/gen/adoc/secure_dma.adoc`, `STATUS.ERROR`: error occurred; `ERROR_CODE.BUS_ERROR`: the bus transfer returned an error). The bus response code of the refused request is not stated and is logged. After each interrupt, read the destination, the DMA `STATUS` and `ERROR_CODE`, clear the DMA error state and run a recovery copy. Read the boot ROM word and the DMA CSR word from the LSU again as the control.
