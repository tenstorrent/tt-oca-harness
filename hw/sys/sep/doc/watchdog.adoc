= Watchdog Timer (WDT)
:description: SEP watchdog timer integration, clocking, bark interrupts, and bite reset requests.

[[watchdog-timer-wdt-watchdog-timer-wdt,Watchdog Timer (WDT)]]

The Watchdog timer is a component used to enhance reliability and ensure
that the system is notified if the SEP subsystem is ``hanging''. The SEP
CPU must periodically visit the WDT and reset its counter, proving that
the CPU is still alive and well i.e. not hanging. If the WDT timer
counts up to its bark threshold it fires an external interrupt, and if it
counts up to its bite threshold it requests a reset, both indicating a
timeout has expired and there is a problem within the SEP.

== Bus Interface

The `sep_wdt_wrap` module integrates the OpenTitan `aon_timer` IP as the watchdog timer. The 64-bit AXI slave port from the system crossbar is narrowed to 32-bit AXI through an `axi_dw_converter`. The address path subtracts the WDT base address so that the internal TL-UL decoder sees zero-based offsets. After `axi_to_axi_lite` and `axi_lite_to_tlul` conversion, the TL-UL bus drives the standard `aon_timer` register block.

== Clock, Reset, and Debug Behavior

The register path described above is reset by cold reset (`rst_ni`), like the crossbar that drives it. The `aon_timer`, including its registers, and its alert receivers are reset by the SEP watchdog reset (`rst_wdt_ni`, driven by `sep_wdt_reset_no` of the SEP Reset Controller), which asserts on cold reset and on every watchdog reset. A `prim_sync_reset` synchronizes it to the dedicated watchdog clock (`clk_wdt_i`) to produce the `rst_aon_ni` reset for the timer domain. The `wdt_debug_sleep_mode_i` input controls whether the timer continues to count during debug halt. Life-cycle escalation is tied to its inactive state. Alert receivers are initialized to the idle encoding to avoid spurious integrity errors; alert outputs are left unconnected since the SEP aggregates watchdog events through the interrupt path.

== Bark Interrupt and Bite Reset

The wrapper exports two signals: `intr_wdog_timer_bark_o`, the watchdog bark interrupt that fires when the first timeout stage expires, and `wdt_timer_rst_req_o`, the bite reset request that fires when the second timeout stage expires and the system failed to respond to the bark.

The SMC reset unit turns the bite into the shared watchdog reset, which returns to the SEP on `wdt_rst_ni`. It restarts the SEP CPU and resets the watchdog, which clears the bite. The
