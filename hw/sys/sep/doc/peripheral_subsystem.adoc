= Peripheral Subsystem
:description: SEP access to SMC peripherals and the local SPI boot interface.

[[peripheral-subsystem,Peripheral Subsystem]]

SEP accesses serial-I/O peripherals in SMC through its AXI4 extension port.
It also has a local SPI host for boot-flash access. The SPI chapter describes
that controller; SMC documents the shared peripherals.

SEP boot uses configuration straps supplied from the SMC GPIO interface.
For their role in selecting boot options, see
ifdef::backend-html5[]
xref:cpu.adoc#configuration-straps[Configuration Straps] and
xref:rom.adoc#bl0-secure-boot-and-bl1-execution-unlock[BL0 Boot Flow].
endif::backend-html5[]

endif::backend-pdf[]
