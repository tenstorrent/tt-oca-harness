= Security Processor (SEP)
:description: SEP architecture, security model, processing subsystems, peripherals, and register reference.

[[security-processor-sep]]

The Security Processor (SEP) is the chiplet Root of Trust. Its documentation is
organized into focused topic pages so architecture, security policy, software
interfaces, and generated register details can be read independently.
