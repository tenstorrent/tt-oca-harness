[NOTE]
======
*Register Arrays:* This register map contains the following register arrays:

* *I2C_I3C_ID[9]*: 9 registers
  ** Base Address: 0x8AC
  ** Address Increment: 0x8 per register

* *RESERVED[65]*: 65 registers
  ** Base Address: 0xAFC
  ** Address Increment: 0x4 per register

======

[cols="1,1,1,3", options="header"]
.Register Map
|===
| Address | Name | Access | Description
| 0x0 | LOCKS | RW a| Lock controls for each fuse field. When write locked, the corresponding field is not
programmable. When read locked, the shadow register is not readable.
| 0x8 | CHIPLET_ID | RW a| Chiplet ID register
| 0x28 | PACKAGE_ID | RW a| Package ID register
| 0x48 | BIRA | RW a| Built-In Repair Analysis data
| 0x848 | CLUSTER | RW a| CPU cluster configuration
| 0x888 | FABRIC | RW a| Fabric configuration
| 0x8A8 | SOP_TOPOLOGY | RW a| System on Package topology
| 0x8AC - 0x8EC | I2C_I3C_ID[9] | RW a| I2C/I3C interface ID
| 0x8F4 | I2C_CLOCK_GATING | RW a| I2C clock gating control
| 0x8F8 | I3C_DISABLE | RW a| I3C interface disable control
| 0x8FC | PLL_AND_SENSOR | RW a| PLL and sensor configuration
| 0xAFC - 0xBFC | RESERVED[65] | RW a| Reserved register
|===

.CHIPLET_ID Register
|===
| Bits | Field | Access | Reset | Description
| 255:0 | `chiplet_id_value` | RW | 0x0 a| Chiplet ID stored in fuse, divided into 8 words and defined as follows:
[1:0]: Serial number of the chiplet. The format is flexible and could include time info of manufacture, (x, y) coordinates on the wafer, and a counter for example;
[3]: Chiplet Design Version. The format is flexible and the word bits could be defined as reserved[31:16], major[15:8], minor[7:0] for example;[127:96]: Chiplet Design ID;
[4]: Chiplet User ID. When TT assembles the package, we assign TT’s ID (32’b0);
[5]: Chiplet User Group ID;
[7:6]: Reserved for extension.
|===

[cols="1,1,1,1,3", options="header"]
.PACKAGE_ID Register
|===
| Bits | Field | Access | Reset | Description
| 255:0 | `package_id_value` | RW | 0x0 a| Package ID stored in fuse, divided into 8 words. The same value gets provisioned into SMCs in all chiplets of the same package. Words are defined as follows:
[1:0]: Serial number of the package;
[2]: Package Design Version, e.g. A1Q1/…​;
[3]: Package Design ID;
[4]: Package User ID, e.g. if it’s TT who assembles the system, use TT’s GROUP_ID (32’b0);
[5]: Package User Group ID;
[7:6]: Reserved for extension
|===
