[#regmap-{regmap-instance}-smc_efuse_map]
== Efuse address map of physical efuse macro

Address map for efuse shadow registers providing access to various chip configuration and ID fields

[NOTE]
======
*Register Arrays:*

* *I2C_I3C_ID[9]*: 9 registers, base 0x30, stride 0x8
* *SPARE[3]*: 3 registers, base 0x88, stride 0x20
* *SPARE_TAIL[3]*: 3 registers, base 0xE8, stride 0x8
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-smc_efuse_map-HARNESS_LOCKS,HARNESS_LOCKS>> | RW a| Lock controls for each fuse field. When write locked, the corresponding field is not
programmable. When read locked, the shadow register is not readable.
| 0x8 | <<reg-{regmap-instance}-smc_efuse_map-SUPPLEMENTARY_LOCKS,SUPPLEMENTARY_LOCKS>> | RW a| Lock controls for the supplementary fuse region. When write locked, the corresponding
supplementary lock region is not programmable. When read locked, its shadow register is
not readable.
| 0x10 | <<reg-{regmap-instance}-smc_efuse_map-JTAG_PUBLIC_IDENTITY,JTAG_PUBLIC_IDENTITY>> | RW a| JTAG-public exception window. In PROD and RMA_SiP, JTAG reads of this range
are admitted while JTAG access to every other fuse field is blocked. Encoding
is adopter-defined; the harness does not interpret or consume the value. The
slot-0 read lock still hides the bits when set.
| 0x30 - 0x70 | <<reg-{regmap-instance}-smc_efuse_map-I2C_I3C_ID-,I2C_I3C_ID[9]>> | RW a| I2C/I3C interface ID
| 0x78 | <<reg-{regmap-instance}-smc_efuse_map-SMC_CONFIG,SMC_CONFIG>> | RW a| SMC boot and configuration controls sourced from fuse. Only the low word carries
assigned bits, so firmware reads it as a single 32-bit access.
| 0x80 | <<reg-{regmap-instance}-smc_efuse_map-OCCP_TRANSPORT_TIMEOUT,OCCP_TRANSPORT_TIMEOUT>> | RW a| OCCP transport timeout in the low word; upper word reserved.
| 0x88 - 0xC8 | <<reg-{regmap-instance}-smc_efuse_map-SPARE-,SPARE[3]>> | RW a| Individually lockable 256-bit spare region, reserved for fields assigned after the
RTL is frozen. Each element has its own write/read lock pair in HARNESS_LOCKS.
| 0xE8 - 0xF8 | <<reg-{regmap-instance}-smc_efuse_map-SPARE_TAIL-,SPARE_TAIL[3]>> | RW a| 64-bit spare region at the end of the map, reserved for fields assigned after the
RTL is frozen. All elements share the slot-7 write/read lock pair in
HARNESS_LOCKS.
|===
