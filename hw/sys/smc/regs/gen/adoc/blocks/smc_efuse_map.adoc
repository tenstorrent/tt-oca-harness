[#regmap-{regmap-instance}-smc_efuse_map]
== Efuse address map of physical efuse macro

Address map for efuse shadow registers providing access to various chip configuration and ID fields

[NOTE]
======
*Register Arrays:*

* *I2C_I3C_ID[9]*: 9 registers, base 0x28, stride 0x8
* *SPARE[28]*: 28 registers, base 0x80, stride 0x20
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-smc_efuse_map-LOCKS,LOCKS>> | RW a| Lock controls for each fuse field. When write locked, the corresponding field is not
programmable. When read locked, the shadow register is not readable.
| 0x8 | <<reg-{regmap-instance}-smc_efuse_map-JTAG_PUBLIC_IDENTITY,JTAG_PUBLIC_IDENTITY>> | RW a| JTAG-public exception window. In PROD and RMA_SiP, JTAG reads of this range
are admitted while JTAG access to every other fuse field is blocked. Encoding
is adopter-defined; the harness does not interpret or consume the value. The
slot-0 read lock still hides the bits when set.
| 0x28 - 0x68 | <<reg-{regmap-instance}-smc_efuse_map-I2C_I3C_ID-0-,I2C_I3C_ID[9]>> | RW a| I2C/I3C interface ID
| 0x70 | <<reg-{regmap-instance}-smc_efuse_map-SMC_CONFIG,SMC_CONFIG>> | RW a| SMC boot and configuration controls sourced from fuse. Only the low word carries
assigned bits, so firmware reads it as a single 32-bit access.
| 0x78 | <<reg-{regmap-instance}-smc_efuse_map-OCCP_TRANSPORT_TIMEOUT,OCCP_TRANSPORT_TIMEOUT>> | RW a| OCCP transport timeout in the low word; upper word reserved.
| 0x80 - 0x3E0 | <<reg-{regmap-instance}-smc_efuse_map-SPARE-0-,SPARE[28]>> | RW a| Individually lockable 256-bit spare region, reserved for fields assigned after the
RTL is frozen. Each element has its own write/read lock pair in LOCKS.
|===

[#reg-{regmap-instance}-smc_efuse_map-I2C_I3C_ID-0-]
=== I2C_I3C_ID[9]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:0 | `interface_id` | RW | 0x0 a| I2C or I3C ID configuration:
* Static ID mode: [6:0] contains ID, [63:7] reserved
* Provisional ID mode: [63:0] full ID
|===

[#reg-{regmap-instance}-smc_efuse_map-SMC_CONFIG]
=== SMC_CONFIG

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:16 | `config_rsvd_high` | RW | 0x0 a| Reserved for future configuration bits.
| 15 | `dft_ignore_error` | RW | 0x0 a| When set, boot continues despite a reported memory repair or MBIST failure.
| 14:8 | `config_rsvd_mid` | RW | 0x0 a| Reserved for future configuration bits.
| 7 | `sram_auto_zero_disable` | RW | 0x0 a| When set, boot skips the SRAM auto-zero initialisation pass.
| 6:1 | `config_rsvd_low` | RW | 0x0 a| Reserved for future configuration bits.
| 0 | `rom_flip_endianness` | RW | 0x0 a| When set, the ROM interface swaps byte order on instruction fetch.
|===
