[#regmap-{regmap-instance}-wdt]
== Watchdog Timer Address Map

Watchdog timer configuration, counter, compare, and feed and key registers.

A write takes effect only if its byte enables cover all four bytes of COUNT, COUNT_HI, FEED or KEY, or bytes 0 and 1 of SCALED_COUNT or CMP; each CTRL byte is written on its own. Any other write returns OKAY and changes nothing, not even the lock.

Each effective write to a register other than KEY locks the watchdog, and changes no field if it was already locked. A 64-bit write at 0x18 writes FEED and KEY together and leaves the watchdog locked.

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-wdt-CTRL,CTRL>> | RW a| KEY reg must be written to before any other register in this addrmap can be written to, unlocking the WDT. After writing to another register, the WDT will be locked again, and KEY must be written to again to unlock it.
| 0x8 | <<reg-{regmap-instance}-wdt-COUNT,COUNT>> | RW a| -
| 0xC | <<reg-{regmap-instance}-wdt-COUNT_HI,COUNT_HI>> | W a| -
| 0x10 | <<reg-{regmap-instance}-wdt-SCALED_COUNT,SCALED_COUNT>> | RW a| -
| 0x18 | <<reg-{regmap-instance}-wdt-FEED,FEED>> | RW a| -
| 0x1C | <<reg-{regmap-instance}-wdt-KEY,KEY>> | RW a| -
| 0x20 | <<reg-{regmap-instance}-wdt-CMP,CMP>> | RW a| -
|===

[#reg-{regmap-instance}-wdt-CTRL]
=== CTRL

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:29 | `rsvd3` | R | 0x0 a| Reserved
| 28 | `wdogip0` | RW | 0x0 a| Pending interrupt. Hardware sets this bit on every cycle the scaled count has reached the compare value.
To clear it, write KEY and then write 0 to this bit while the scaled count is below the compare value. Writing FEED does not clear it.
| 27:14 | `rsvd2` | R | 0x0 a| Reserved
| 13 | `wdogcoreawake` | RW | 0x0 a| Enable WDT to only count when the core is not in reset
| 12 | `wdogenalways` | RW | 0x0 a| Enable WDT to always count. This has priority over wdogcoreawake
| 11:10 | `rsvd1` | R | 0x0 a| Reserved
| 9 | `wdogzerocmp` | RW | 0x0 a| Enable cycle counter to be reset to 0 when compare value has been reached
| 8 | `wdogrsten` | RW | 0x0 a| Enables a sticky reset signal to outputted to top level, can be used for a second stage wdt
| 7:4 | `rsvd0` | R | 0x0 a| Reserved
| 3:0 | `wdogscale` | RW | 0x0 a| WDT counter scale value. Scales the current cycle count (time) by count / 2 ^ wdogscale value
|===

[#reg-{regmap-instance}-wdt-COUNT]
=== COUNT

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31 | `Reserved` | - | - a| Reserved
| 30:0 | `wdogcount` | RW | 0x0 a| 31 bit wdt counter registers. On write, the counter will be set to the written value, then continue counting up.
KEY reg must be written to before any other register in this addrmap can be written to, unlocking the WDT. After writing to another register, the WDT will be locked again, and KEY must be written to again to unlock it.
|===

[#reg-{regmap-instance}-wdt-COUNT_HI]
=== COUNT_HI

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `wdogcounthi` | W | 0x0 a| Upper word of the counter. The counter is 31 bits wide and lies entirely in COUNT, so this register has no storage and reads 0. A write covering all four bytes leaves the counter unchanged but locks the WDT, so KEY must be written again before the next write.
|===

[#reg-{regmap-instance}-wdt-SCALED_COUNT]
=== SCALED_COUNT

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:16 | `Reserved` | - | - a| Reserved
| 15:0 | `wdogs` | RW | 0x0 a| Scaled value of wdt counter. (i.e. count >> wdogscale). Writing to this reg has no effect, but will lock the WDT (meaning KEY must be written to KEY reg to unlock it again).
KEY reg must be written to before any other register in this addrmap can be written to, unlocking the WDT. After writing to another register, the WDT will be locked again, and KEY must be written to again to unlock it.
|===

[#reg-{regmap-instance}-wdt-FEED]
=== FEED

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `wdogfeed` | RW | 0x0 a| Feed register. Writing 0xD09F00D will reset the counter value back to 0. Feeding does not clear CTRL.wdogip0.
KEY reg must be written to before any other register in this addrmap can be written to, unlocking the WDT. After writing to another register, the WDT will be locked again, and KEY must be written to again to unlock it.
|===

[#reg-{regmap-instance}-wdt-KEY]
=== KEY

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `wdogkey` | RW | 0x0 a| Key register. Magic key (0x51F15E) must be written to this register before a write to any other register in this addrmap. Must be written every time. Reading this reg returns 1 if key has been written to it and it
is unlocked, 0 otherwise.
|===

[#reg-{regmap-instance}-wdt-CMP]
=== CMP

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:16 | `Reserved` | - | - a| Reserved
| 15:0 | `wdogcmp0` | RW | 0x1000 a| Compare register. Value that gets compared to wdogs.
KEY reg must be written to before any other register in this addrmap can be written to, unlocking the WDT. After writing to another register, the WDT will be locked again, and KEY must be written to again to unlock it.
|===
