[[ctrl-register]]
CTRL register
^^^^^^^^^^^^^

* Absolute Address: 0x0
* Base Offset: 0x0
* Size: 0x4

KEY reg must be written to before any other register in this addrmap can
be written to, unlocking the WDT. After writing to another register, the
WDT will be locked again, and KEY must be written to again to unlock it.

[[wdogscale-field]]
wdogscale field
+++++++++++++++

WDT counter scale value. Scales the current cycle count (time) by count
/ 2 ^ wdogscale value

[[rsvd0-field]]
rsvd0 field
+++++++++++

Reserved

[[wdogrsten-field]]
wdogrsten field
+++++++++++++++

Enables a sticky reset signal to outputted to top level, can be used for
a second stage wdt

[[wdogzerocmp-field]]
wdogzerocmp field
+++++++++++++++++

Enable cycle counter to be reset to 0 when compare value has been
reached

[[rsvd1-field]]
rsvd1 field
+++++++++++

Reserved

[[wdogenalways-field]]
wdogenalways field
++++++++++++++++++

Enable WDT to always count. This has priority over wdogcoreawake

[[wdogcoreawake-field]]
wdogcoreawake field
+++++++++++++++++++

Enable WDT to only count when the core is not in reset

[[rsvd2-field]]
rsvd2 field
+++++++++++

Reserved

[[wdogip0-field]]
wdogip0 field
+++++++++++++

Pending interrupt

[[rsvd3-field]]
rsvd3 field
+++++++++++

Reserved

[[wdogcount-field]]
wdogcount field
+++++++++++++++

31 bit wdt counter registers. On write, the counter will be set to the
written value, then continue counting up. KEY reg must be written to
before any other register in this addrmap can be written to, unlocking
the WDT. After writing to another register, the WDT will be locked
again, and KEY must be written to again to unlock it.

[[scaled_count-register]]
SCALED_COUNT register
^^^^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x10
* Base Offset: 0x10
* Size: 0x4

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|15:0 |wdogs |rw |0x0 |—
|=====================================

[[wdogs-field]]
wdogs field
+++++++++++

Scaled value of wdt counter. (i.e. count >> wdogscale). Writing to this
reg has no effect, but will lock the WDT (meaning KEY must be written to
KEY reg to unlock it again). KEY reg must be written to before any other
register in this addrmap can be written to, unlocking the WDT. After
writing to another register, the WDT will be locked again, and KEY must
be written to again to unlock it.

[[wdogfeed-field]]
wdogfeed field
++++++++++++++

Feed register. Writing 0xD09F00D will reset the counter value back to 0.
KEY reg must be written to before any other register in this addrmap can
be written to, unlocking the WDT. After writing to another register, the
WDT will be locked again, and KEY must be written to again to unlock it.

[[key-register]]
KEY register
^^^^^^^^^^^^

* Absolute Address: 0x1C
* Base Offset: 0x1C
* Size: 0x4

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|31:0 |wdogkey |rw |0x0 |—
|=====================================

[[wdogkey-field]]
wdogkey field
+++++++++++++

Key register. Magic key (0x51F15E) must be written to this register
before a write to any other register in this addrmap. Must be written
every time. Reading this reg returns 1 if key has been written to it and
it is unlocked, 0 otherwise.

[[wdogcmp0-field]]
wdogcmp0 field
++++++++++++++

Compare register. Value that gets compared to wdogs. KEY reg must be
written to before any other register in this addrmap can be written to,
unlocking the WDT. After writing to another register, the WDT will be
locked again, and KEY must be written to again to unlock it.
