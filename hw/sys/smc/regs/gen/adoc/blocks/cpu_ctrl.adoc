core0_reset_pulse_start_n0_scan field
+++++++++++++++++++++++++++++++++++++

of which is set by CORE_RESET_PULSE_COUNT. This pulse is ANDed with
core_reset_n[0] so a 0 in core_reset_n[0] will override the pulse.

[[reset_timeout-register]]
RESET_TIMEOUT register
^^^^^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x38
* Base Offset: 0x38
* Size: 0x8

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|15:0 |timeout_value |rw |0x0 |—
|16 |timeout_mode |rw |0x0 |—
|32 |reset_applied |r |0x0 |—
|36 |reset_timeout |r |0x0 |—
|=====================================

[[timeout_value-field]]
timeout_value field
+++++++++++++++++++

Cycles (clk_smc) a software reset may stay pending (withheld, waiting
for drain) before timeout. 0 = disabled, wait indefinitely.

[[timeout_mode-field]]
timeout_mode field
++++++++++++++++++

Timeout mode: 0 = give up and report error (stay withheld, do not
apply); 1 = force the reset on timeout.

[[reset_applied-field]]
reset_applied field
+++++++++++++++++++

Live status: high while a requested software reset is actually applied
at the cluster (drain complete and reset asserted).

[[reset_timeout-field]]
reset_timeout field
+++++++++++++++++++

Live status: high while a pending software reset has exceeded
timeout_value (timeout/error flag; set in both modes).

AXI hang detector control.

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name

|4 |irq_en |rw |0x0 |—
|8 |irq_test |rw |0x0 |—
|=====================================

[[enable-field]]
enable field
++++++++++++

When 1, the timeout counter runs. When 0, it is held at 0 and irq_o is
forced low.

[[irq_en-field]]
irq_en field
++++++++++++

Interrupt enable. When 1, a timeout event propagates to irq_o.

[[irq_test-field]]
irq_test field
++++++++++++++

Interrupt test. When 1, forces irq_o high for verification / firmware
bring-up.
