[NOTE]
======
*Register Arrays:* This register map contains the following register arrays:

* *RESET_VECTOR[4]*: 4 registers
  ** Base Address: 0x0
  ** Address Increment: 0x8 per register

* *SCRATCH[16]*: 16 registers
  ** Base Address: 0x80
  ** Address Increment: 0x8 per register

* *WB_PC_CORE0[8]*: 8 registers
  ** Base Address: 0x100
  ** Address Increment: 0x8 per register

* *WB_PC_CORE1[8]*: 8 registers
  ** Base Address: 0x140
  ** Address Increment: 0x8 per register

* *WB_PC_CORE2[8]*: 8 registers
  ** Base Address: 0x180
  ** Address Increment: 0x8 per register

* *WB_PC_CORE3[8]*: 8 registers
  ** Base Address: 0x1C0
  ** Address Increment: 0x8 per register

* *MUTEX[4]*: 4 registers
  ** Base Address: 0x240
  ** Address Increment: 0x8 per register

* *SEMA[4]*: 4 registers
  ** Base Address: 0x260
  ** Address Increment: 0x8 per register

* *DUMMY_ROM_NULL[4]*: 4 registers
  ** Base Address: 0x2A0
  ** Address Increment: 0x8 per register

.RESET_CTRL Register
|===
| Bits | Field | Access | Reset | Description
| 63:25 | `Reserved` | - | - a| Reserved
| 24 | `debug_reset_n_n0_scan` | RW | 0x0 a| Debug Module Reset, active low
| 23:9 | `Reserved` | - | - a| Reserved
| 8 | `uncore_reset_n_n0_scan` | RW | 0x1 a| Cluster Uncore Reset, active low. Writing this register will only reset the uncore portion in the chipyard cluster.
WARNING: using this can cause any outstanding axi requests to and from the cluster to cause timeouts/exceptions.
| 7 | `core3_reset_pulse_start_n0_scan` | RW | 0x0 a| Writing a 1 to this register triggers a core reset pulse, the duration of which is set by CORE_RESET_PULSE_COUNT.
This pulse is ANDed with core_reset_n[3] so a 0 in core_reset_n[3] will override the pulse.
| 6 | `core2_reset_pulse_start_n0_scan` | RW | 0x0 a| Writing a 1 to this register triggers a core reset pulse, the duration of which is set by CORE_RESET_PULSE_COUNT.
This pulse is ANDed with core_reset_n[2] so a 0 in core_reset_n[2] will override the pulse.
| 5 | `core1_reset_pulse_start_n0_scan` | RW | 0x0 a| Writing a 1 to this register triggers a core reset pulse, the duration of which is set by CORE_RESET_PULSE_COUNT.
This pulse is ANDed with core_reset_n[1] so a 0 in core_reset_n[1] will override the pulse.
| 4 | `core0_reset_pulse_start_n0_scan` | RW | 0x0 a| Writing a 1 to this register triggers a core reset pulse, the duration of which is set by CORE_RESET_PULSE_COUNT.
This pulse is ANDed with core_reset_n[0] so a 0 in core_reset_n[0] will override the pulse.
| 3 | `core3_reset_n_n0_scan` | RW | 0x1 a| Reset control for the CPU, active low.
| 2 | `core2_reset_n_n0_scan` | RW | 0x1 a| Reset control for the CPU, active low.
| 1 | `core1_reset_n_n0_scan` | RW | 0x1 a| Reset control for the CPU, active low.
| 0 | `core0_reset_n_n0_scan` | RW | 0x1 a| Reset control for the CPU, active low.
|===

.RESET_TIMEOUT Register
|===
| Bits | Field | Access | Reset | Description
| 63:37 | `Reserved` | - | - a| Reserved
| 36 | `reset_timeout` | R | 0x0 a| Live status: high while a pending software reset has exceeded
timeout_value (timeout/error flag; set in both modes).
| 35:33 | `Reserved` | - | - a| Reserved
| 32 | `reset_applied` | R | 0x0 a| Live status: high while a requested software reset is actually applied
at the cluster (drain complete and reset asserted).
| 31:17 | `Reserved` | - | - a| Reserved
| 16 | `timeout_mode` | RW | 0x0 a| Timeout mode: 0 = give up and report error (stay withheld, do not apply);
1 = force the reset on timeout.
| 15:0 | `timeout_value` | RW | 0x0 a| Cycles (clk_smc) a software reset may stay pending (withheld, waiting
for drain) before timeout. 0 = disabled, wait indefinitely.
|===
