[#reg-{regmap-instance}-plic-PRIORITY-0-]
=== PRIORITY[337]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:3 | `Reserved` | - | - a| Reserved
| 2:0 | `value` | RW | - a| Priority of interrupt. The higher the set value, the higher the priority.
For interrupts with the same priority, the tie is broken by interrupt ID; interrupts with the lowest ID has highest effective priority.
Interrupts start counting at 1.
|===

[#reg-{regmap-instance}-plic-PENDING-0-]
=== PENDING[11]

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `value` | R | 0x0 a| Set to 1 if interrupt source 1 is pending, regardless of its enable or priority setting.
Interrupts start counting at 1.
|===

[#reg-{regmap-instance}-plic-CORE0_MEIP_CLAIM_COMPLETE]
=== CORE0_MEIP_CLAIM_COMPLETE

[cols="1,3,1,1,6", options="header"]
|===

| 31:0 | `value` | RW | - a| Claim/Complete register.
Reading this register returns the claimed interrupt number and makes it no longer pending.
Writing the interrupt number back completes the interrupt.
|===
