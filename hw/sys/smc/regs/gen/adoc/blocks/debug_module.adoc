[[dmcontrol-register]]
dmcontrol register
^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x40
* Base Offset: 0x40
* Size: 0x4

Controls the overall Debug Module and selected harts. Writes to action
bits (haltreq, resumereq, etc.) apply to the new value of hartsel and
hasel.

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|0 |dmactive |rw |0x0 |—
|1 |ndmreset |rw |0x0 |—
|2 |clrresethaltreq |rw, woset |0x0 |—
|3 |setresethaltreq |rw, woset |0x0 |—
|5:4 |_reserved_5_4 |r |0x0 |—
|15:6 |hartselhi |rw |0x0 |—
|25:16 |hartsello |rw |0x0 |—
|26 |hasel |rw |0x0 |—
|27 |_reserved_27 |r |0x0 |—
|28 |ackhavereset |rw, woset |0x0 |—
|29 |hartreset |rw |0x0 |—
|30 |resumereq |rw, woset |0x0 |—
|31 |haltreq |rw |0x0 |—
|=====================================

[[dmactive-field]]
dmactive field
++++++++++++++

Debug Module active and reset. 0: DM takes reset values (except this
bit). 1: DM functions normally.

[[ndmreset-field]]
ndmreset field
++++++++++++++

Controls reset signal from DM to system (ndmreset). Write 1, then 0 to
deassert.

[[clrresethaltreq-field]]
clrresethaltreq field
+++++++++++++++++++++

Optional (if dmstatus.hasresethaltreq=1). Writing 1 clears halt-on-reset
request bit for selected harts.

[[setresethaltreq-field]]
setresethaltreq field
+++++++++++++++++++++

Optional (if dmstatus.hasresethaltreq=1). Writing 1 sets halt-on-reset
request bit for selected harts (unless clrresethaltreq is also 1).

[[reserved_5_4-field]]
_reserved_5_4 field
+++++++++++++++++++

Reserved.

[[hartselhi-field]]
hartselhi field
+++++++++++++++

High 10 bits of hartsel: DM-specific index of the hart to select.

[[hartsello-field]]
hartsello field
+++++++++++++++

Low 10 bits of hartsel: DM-specific index of the hart to select.

[[hasel-field]]
hasel field
+++++++++++

Selects definition of currently selected harts. 0: single hart by
hartsel. 1: hart by hartsel plus those by hart array mask. Tied to 0 if
hart array mask not implemented.

[[reserved_27-field]]
_reserved_27 field
++++++++++++++++++

Reserved.

[[ackhavereset-field]]
ackhavereset field
++++++++++++++++++

Writing 1 clears havereset for any selected harts.

[[hartreset-field]]
hartreset field
+++++++++++++++

Optional. Hart reset for currently selected harts. Write 1, then 0 to
deassert. Debugger must not change selection while this is 1. If not
implemented, reads as 0.

[[resumereq-field]]
resumereq field
+++++++++++++++

Resume request for currently selected harts. Writing 1 causes halted
harts to resume and clears their resume ack bit. Ignored if haltreq is
set.

[[haltreq-field]]
haltreq field
+++++++++++++

Halt request for currently selected harts. Write 0 to clear, 1 to set.

\{hartsel[19:10],10’h0}-\{hartsel[19:10],10’h1f}, MSB for harts
\{hartsel[19:10],10’h3e0}-\{hartsel[19:10],10’h3ff}.

[[sbasize-field]]
sbasize field
+++++++++++++

Width of system bus addresses in bits (e.g., 32 for 32-bit addresses). 0
indicates no bus access support. NOTE: This field is 4 bits wide
([8:5]), which is insufficient to directly store typical bus widths like
32 or 64. This implies the value is an encoding or there is a spec
issue. The text implies it stores values like 32, 64, etc (e.g. `if
sbasize < 33').

+++++++++++++

System bus master error flags. No new access if non-zero. 0=none,
1=timeout, 2=bad_address, 3=alignment, 4=unsupported_size, 7=other.

++++++++++++++++++

[[sbautoincrement-field]]
sbautoincrement field
+++++++++++++++++++++

system bus access.

[[sbaccess-field]]
sbaccess field
++++++++++++++

3=64-bit, 4=128-bit. If unsupported, access fails, sberror=4.

sbreadonaddr field
