[#regmap-{regmap-instance}-debug_module]
== Debug Module Hart Interface

Memory region through which a hart in Debug Mode exchanges state with the Debug Module: handshake mailboxes, generated instructions, program buffer, data registers, per-hart flags and the debug ROM. The debugger-facing Debug Module registers (dmcontrol, dmstatus, abstractcs, sbcs, ...) are reached over the Debug Module Interface and do not appear in this map.

[NOTE]
======
*Register Arrays:*

* *ABSTRACT[5]*: 5 registers, base 0x328, stride 0x4
* *PROGBUF[16]*: 16 registers, base 0x33C, stride 0x4
* *DATA[4]*: 4 registers, base 0x380, stride 0x4
* *ROM[26]*: 26 registers, base 0x800, stride 0x4
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x100 | <<reg-{regmap-instance}-debug_module-HALTED,HALTED>> | W a| -
| 0x104 | <<reg-{regmap-instance}-debug_module-GOING,GOING>> | W a| -
| 0x108 | <<reg-{regmap-instance}-debug_module-RESUMING,RESUMING>> | W a| -
| 0x10C | <<reg-{regmap-instance}-debug_module-EXCEPTION,EXCEPTION>> | W a| -
| 0x300 | <<reg-{regmap-instance}-debug_module-WHERETO,WHERETO>> | R a| -
| 0x328 - 0x338 | <<reg-{regmap-instance}-debug_module-ABSTRACT-,ABSTRACT[5]>> | R a| -
| 0x33C - 0x378 | <<reg-{regmap-instance}-debug_module-PROGBUF-,PROGBUF[16]>> | RW a| -
| 0x37C | <<reg-{regmap-instance}-debug_module-IMPEBREAK,IMPEBREAK>> | R a| -
| 0x380 - 0x38C | <<reg-{regmap-instance}-debug_module-DATA-,DATA[4]>> | RW a| -
| 0x400 | <<reg-{regmap-instance}-debug_module-FLAGS,FLAGS>> | R a| One flag byte per hart, at byte offset equal to the hart ID. Bit 0 is go (execute the command at WHERETO); bit 1 is resume (leave Debug Mode). Bits 7:2 read as 0.
| 0x800 - 0x864 | <<reg-{regmap-instance}-debug_module-ROM-,ROM[26]>> | R a| -
|===

[#reg-{regmap-instance}-debug_module-HALTED]
=== HALTED

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:10 | `Reserved` | - | - a| Reserved
| 9:0 | `hartid` | W | - a| Debug ROM causes the hart to write its hart ID here when it is in Debug Mode.
|===

[#reg-{regmap-instance}-debug_module-GOING]

| 9:0 | `hartid` | W | - a| Debug ROM causes the hart to write 0 here when it begins executing Debug Mode instructions.
|===
