[#regmap-{regmap-instance}-misc_wrap]
== SMC Miscellaneous Wrapper Address Map

Aggregates the SMC scratch, chip-configuration, and NDM-reset register blocks.

[NOTE]
======
*Register Arrays:*

* *scratch_cold.SCRATCH[8]*: 8 registers, base 0x0, stride 0x4
* *scratch_cold_warm.SCRATCH[8]*: 8 registers, base 0x80, stride 0x4
======

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 - 0x1C | <<reg-{regmap-instance}-misc_wrap-scratch_cold-SCRATCH-0-,scratch_cold.SCRATCH[8]>> | RW a| -
| 0x80 - 0x9C | <<reg-{regmap-instance}-misc_wrap-scratch_cold_warm-SCRATCH-0-,scratch_cold_warm.SCRATCH[8]>> | RW a| -
| 0x100 | <<reg-{regmap-instance}-misc_wrap-chip_config-VERSION_LO,VERSION_LO>> | R a| -
| 0x104 | <<reg-{regmap-instance}-misc_wrap-chip_config-VERSION_HI,VERSION_HI>> | R a| -
| 0x108 | <<reg-{regmap-instance}-misc_wrap-chip_config-CHIP_ID,CHIP_ID>> | R a| -
| 0x10C | <<reg-{regmap-instance}-misc_wrap-chip_config-LC_STATE,LC_STATE>> | R a| -
| 0x200 | <<reg-{regmap-instance}-misc_wrap-ndm_reset-NDMRESET_REQUEST,NDMRESET_REQUEST>> | R a| -
| 0x204 | <<reg-{regmap-instance}-misc_wrap-ndm_reset-NDMRESET_PROCESS,NDMRESET_PROCESS>> | RW a| -
| 0x208 | <<reg-{regmap-instance}-misc_wrap-ndm_reset-NDMRESET_CLUSTER_COUNT,NDMRESET_CLUSTER_COUNT>> | R a| -
|===

[#reg-{regmap-instance}-misc_wrap-ndm_reset-NDMRESET_REQUEST]
=== NDMRESET_REQUEST

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `ndmreset_request` | R | 0x0 a| Bit i is the NDM reset request from external CPU cluster i.
Bits below ndmreset_cluster_count follow the request input.
Bits at and above that count read as 0. The field holds up to 32 clusters.
|===

[#reg-{regmap-instance}-misc_wrap-ndm_reset-NDMRESET_PROCESS]
=== NDMRESET_PROCESS

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `ndmreset_process` | RW | 0x0 a| Bit i is the firmware response to the NDM reset request from external CPU cluster i.
Bits below ndmreset_cluster_count are driven on the process output.
Bits at and above that count are stored and are not driven. The field holds up to 32 clusters.
|===

[#reg-{regmap-instance}-misc_wrap-ndm_reset-NDMRESET_CLUSTER_COUNT]
=== NDMRESET_CLUSTER_COUNT

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:8 | `Reserved` | - | - a| Reserved
| 7:0 | `ndmreset_cluster_count` | R | 0x0 a| Number of external CPU clusters connected on the low bits of NDMRESET_REQUEST and NDMRESET_PROCESS.
Software masks those registers with this value. The maximum is 32.
|===
