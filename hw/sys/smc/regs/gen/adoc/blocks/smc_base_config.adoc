.REGION_SIZE Register
|===
| Bits | Field | Access | Reset | Description
| 63:32 | `Reserved` | - | - a| Reserved
| 31:0 | `size` | RW | 0x1000000 a| Region size for SMC resources, sizing both the local alias window and the global aperture. Must be a non-zero power of two: the fabric derives its local-alias address mask as (size - 1), so any other value produces a discontiguous mask and misroutes accesses. Zero leaves no reachable local aperture. GLOBAL_BASE and LOCAL_BASE must be aligned to this size. Defaults to 16MB (0x100_0000); FW reprograms per chiplet spec.
|===

.HANG_DET_SYS_AXI_CTRL Register
|===
| Bits | Field | Access | Reset | Description
| 31:9 | `Reserved` | - | - a| Reserved
| 8 | `irq_test` | RW | 0x0 a| Interrupt test. When 1, asserts irq_o without a bus stall, so firmware can exercise the interrupt path. Gated by enable and irq_en: it substitutes for the timeout, it does not override the interrupt enable.
| 7:5 | `Reserved` | - | - a| Reserved
| 4 | `irq_en` | RW | 0x0 a| Interrupt enable. When irq_en and enable are high, irq_o follows the detector; when 0, irq_o is held low. Gates a real timeout and irq_test alike.
| 3:1 | `Reserved` | - | - a| Reserved
| 0 | `enable` | RW | 0x0 a| When 1, the timeout counter runs. When 0, it is held at 0 and irq_o is forced low.
|===

[cols="1,3,1,1,6", options="header"]
.HANG_DET_SYS_AXI_TIMEOUT_THRESHOLD Register
|===
| Bits | Field | Access | Reset | Description
| 31:20 | `Reserved` | - | - a| Reserved
| 19:0 | `value` | RW | 0x1000 a| Threshold in clock cycles. Default 0x1000. 20 bits => up to ~1M cycles (~1ms at 1GHz). 0 disables timeout detection: a stalled bus never asserts irq_o, though irq_test still asserts it. A threshold write takes effect when the stall count next restarts (on a completion, an idle bus, or enable cleared). So it does not change a stall already being timed.
|===
