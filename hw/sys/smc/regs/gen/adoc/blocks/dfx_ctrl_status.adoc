[#regmap-{regmap-instance}-dfx_ctrl_status]
== DFX Control and Status Address Map

Memory-repair and MBIST status, chiplet enable, clock and debug controls, and debug-mux selects.

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-dfx_ctrl_status-STATUS_SMU,STATUS_SMU>> | R a| -
| 0x8 | <<reg-{regmap-instance}-dfx_ctrl_status-DEBUG_CTRL,DEBUG_CTRL>> | RW a| -
| 0x10 | <<reg-{regmap-instance}-dfx_ctrl_status-DEBUG_BUS_MUX,DEBUG_BUS_MUX>> | RW a| Mode, ID and lane selects for the twelve debug-bus muxes that reduce the SMC debug
bus to the 16 CLA input lanes. Each mux takes its mode while Dbmid equals its ID,
and its lane selects while Dbmid equals its ID and its mode is 1, so program one mux
at a time.
|===

[#reg-{regmap-instance}-dfx_ctrl_status-STATUS_SMU]
=== STATUS_SMU

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 63:13 | `Reserved` | - | - a| Reserved
| 12 | `mbist_abort` | R | 0x0 a| One bit indicator from DFT logic to say that MBIST has hit timeout and aborted
This register is sticky 1 and will hold the value until reset
| 11:9 | `Reserved` | - | - a| Reserved
| 8 | `mbist_pass` | R | 0x0 a| One bit indicator from DFT logic to say when MBIST is successful
This register is sticky 1 and will hold the value until reset
| 7:5 | `Reserved` | - | - a| Reserved
| 4 | `mbist_done` | R | 0x0 a| One bit indicator from DFT logic to say when MBIST is completed
This register is sticky 1 and will hold the value until reset
| 3 | `Reserved` | - | - a| Reserved
| 2 | `mem_repair_abort` | R | 0x0 a| One bit indicator from DFT logic to say that mem repair has hit timeout and aborted
This register is sticky 1 and will hold the value until reset
| 1 | `mem_repair_success` | R | 0x0 a| One bit indicator from DFT logic to say if mem repair was successful
This register is sticky 1 and will hold the value until reset
| 0 | `mem_repair_done` | R | 0x0 a| One bit indicator from DFT logic to say when mem repair is completed.
This register is sticky 1 and will hold the value until reset
|===
