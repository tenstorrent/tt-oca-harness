[[mem_repair_done-field]]
mem_repair_done field
+++++++++++++++++++++

One bit indicator from DFT logic to say when mem repair is completed.
This register is sticky 1 and will hold the value until reset

[[mem_repair_success-field]]
mem_repair_success field
++++++++++++++++++++++++

One bit indicator from DFT logic to say if mem repair was successful
This register is sticky 1 and will hold the value until reset

[[mem_repair_abort-field]]
mem_repair_abort field
++++++++++++++++++++++

One bit indicator from DFT logic to say that mem repair has hit timeout
and aborted This register is sticky 1 and will hold the value until
reset

[[mbist_done-field]]
mbist_done field
++++++++++++++++

One bit indicator from DFT logic to say when MBIST is completed This
register is sticky 1 and will hold the value until reset

[[mbist_pass-field]]
mbist_pass field
++++++++++++++++

One bit indicator from DFT logic to say when MBIST is successful This
register is sticky 1 and will hold the value until reset

[[mbist_abort-field]]
mbist_abort field
+++++++++++++++++

One bit indicator from DFT logic to say that MBIST has hit timeout and
aborted This register is sticky 1 and will hold the value until reset
