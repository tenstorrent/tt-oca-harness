[[ndm_reset-address-map]]
ndm_reset address map
~~~~~~~~~~~~~~~~~~~~~

* Absolute Address: 0x0
* Base Offset: 0x0
* Size: 0xC

NDM Reset Control Register for communicating with debug module in each
Ascalon cluster

|==============================
|Offset |Identifier |Name
|0x0 |NDMRESET_REQUEST |—
|0x4 |NDMRESET_PROCESS |—
|0x8 |NDMRESET_CLUSTER_COUNT |—
|==============================

[[ndmreset_request-field]]
ndmreset_request field
++++++++++++++++++++++

NDM Request from Cluster [0:NDMRESET_CLUSTER_COUNT]. Read-only field
that reflects incoming NDM reset requests. Connected from
ndmreset_request_i input port. Also connected to SMC interrupts.
Supports up to 32 CPU Clusters

[[ndmreset_process-field]]
ndmreset_process field
++++++++++++++++++++++

NDM Response Firmware writes to this field to respond to NDM reset
requests. Connected to ndmreset_process_o output port. Supports up to 32
CPU Clusters

ndmreset_cluster_count field
++++++++++++++++++++++++++++

Number of NDM Clusters supported. Can be read to mask the
ndmreset_request register
