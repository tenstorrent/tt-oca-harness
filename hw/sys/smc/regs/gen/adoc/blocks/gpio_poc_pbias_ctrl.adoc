[[gpio_poc_pbias_ctrl-address-map]]
gpio_poc_pbias_ctrl address map
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* Absolute Address: 0x0
* Base Offset: 0x0
* Size: 0xC

GPIO POC and PBIAS Control Register Interface

[cols=",,",options="header",]
|========================
|Offset |Identifier |Name
|0x0 |CONTROL |—
|0x8 |ACCESS_FILTER |—
|========================

[[control-register]]
CONTROL register
^^^^^^^^^^^^^^^^

* Absolute Address: 0x0
* Base Offset: 0x0
* Size: 0x4

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|0 |pwr_supply_sel |rw |0x0 |—
|1 |retention_en |rw |0x0 |—
|=====================================

[[pwr_supply_sel-field]]
pwr_supply_sel field
++++++++++++++++++++

Power supply voltage level selection. PSW=0 at 1.8V I/O supply PSW=1 at
1.2V I/O supply

[[retention_en-field]]
retention_en field
++++++++++++++++++

Retention enable control. Set to 0 by default which disables retention.

[[access_filter-register]]
ACCESS_FILTER register
^^^^^^^^^^^^^^^^^^^^^^

* Absolute Address: 0x8
* Base Offset: 0x8
* Size: 0x4

[cols=",,,,",options="header",]
|=====================================
|Bits |Identifier |Access |Reset |Name
|0 |write_filter_enable |rw |0x0 |—
|1 |read_filter_enable |rw |0x0 |—
|10:8 |awprot_requirement |rw |0x1 |—
|18:16 |arprot_requirement |rw |0x1 |—
|=====================================

[[write_filter_enable-field]]
write_filter_enable field
+++++++++++++++++++++++++

Filter Enable - when set, only SEP may access the GPIO register
interface. This effectivley makes the GPIO a SEP-only interface.

[[read_filter_enable-field]]
read_filter_enable field
++++++++++++++++++++++++

Filter Value - the value that must be written to the filter register to
allow access to the GPIO register interface.

[[awprot_requirement-field]]
awprot_requirement field
++++++++++++++++++++++++

When write_filter_enable is set, only allow write accesses with this
prot value

[[arprot_requirement-field]]
arprot_requirement field
++++++++++++++++++++++++

When read_filter_enable is set, only allow read accesses with this prot
value
