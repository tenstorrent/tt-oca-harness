[#reg-{regmap-instance}-gpio_poc_pbias_ctrl-CONTROL]
=== CONTROL

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:2 | `Reserved` | - | - a| Reserved
| 1 | `retention_en` | RW | 0x0 a| Retention enable control. Set to 0 by default which disables retention.
| 0 | `pwr_supply_sel` | RW | 0x0 a| Power supply voltage level selection.
PSW=0 at 1.8V I/O supply
PSW=1 at 1.2V I/O supply
|===

[#reg-{regmap-instance}-gpio_poc_pbias_ctrl-ACCESS_FILTER]
=== ACCESS_FILTER

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:19 | `Reserved` | - | - a| Reserved
| 18:16 | `arprot_requirement` | RW | 0x1 a| When read_filter_enable is set, only allow read accesses with this prot value
| 15:11 | `Reserved` | - | - a| Reserved
| 10:8 | `awprot_requirement` | RW | 0x1 a| When write_filter_enable is set, only allow write accesses with this prot value
| 7:2 | `Reserved` | - | - a| Reserved
| 1 | `read_filter_enable` | RW | 0x0 a| Filter Value - the value that must be written to the filter register to allow access to the GPIO register interface.
| 0 | `write_filter_enable` | RW | 0x0 a| Filter Enable - when set, only SEP may access the GPIO register interface. This effectivley makes the GPIO a SEP-only interface.
|===
