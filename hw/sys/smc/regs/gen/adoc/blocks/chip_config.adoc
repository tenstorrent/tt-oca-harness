== Chip Configuration Address Map

Chip version, chiplet type, and lifecycle-state registers.

[cols="1,4,1,6", options="header"]
|===
| Address | Name | Access | Description
| 0x0 | <<reg-{regmap-instance}-chip_config-VERSION_LO,VERSION_LO>> | R a| -
| 0x4 | <<reg-{regmap-instance}-chip_config-VERSION_HI,VERSION_HI>> | R a| -
| 0x8 | <<reg-{regmap-instance}-chip_config-CHIPLET_TYPE,CHIPLET_TYPE>> | R a| -
| 0xC | <<reg-{regmap-instance}-chip_config-LC_STATE,LC_STATE>> | R a| -
|===

[#reg-{regmap-instance}-chip_config-VERSION_LO]
=== VERSION_LO

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `version_lo` | R | 0x100A0 a| SMC version identifier, lower 32 bits, set by eight metal-programmable revision cells, one byte per cell, so a metal-only respin can change it. The register has no storage: a read returns the cell values, and the reset value is the version the cells are tied to.
|===

[#reg-{regmap-instance}-chip_config-VERSION_HI]
=== VERSION_HI

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `version_hi` | R | 0x0 a| SMC version identifier, upper 32 bits, set by eight metal-programmable revision cells, one byte per cell, so a metal-only respin can change it. The register has no storage: a read returns the cell values, and the reset value is the version the cells are tied to.
|===

[#reg-{regmap-instance}-chip_config-CHIPLET_TYPE]
=== CHIPLET_TYPE

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:0 | `chiplet_type` | R | 0x0 a| Kind of chiplet the SMC is integrated in, a constant fixed when the SMC is integrated, not read from fuses: 0 = MEMORY, 1 = CPU, 2 = AI_COMPUTE, 3 = ETHERNET; values 4 and above are reserved. Bits 1:0 are the upper two bits of the boot ROM's fallback I2C and I3C address, so two chiplet types that share a bus must report different values. The register has no storage: a read returns that constant, and the reset value is the default constant.
|===

[#reg-{regmap-instance}-chip_config-LC_STATE]
=== LC_STATE

[cols="1,3,1,1,6", options="header"]
|===
| Bits | Field | Access | Reset | Description
| 31:8 | `Reserved` | - | - a| Reserved
| 7:0 | `lc_state` | R | 0xF a| Lifecycle state from SEP, differentially encoded: {~raw[3:0], raw[3:0]}. The register has no storage: each read returns the value SEP drives at that moment, neither latched nor decoded. The reset value 0x0F is the INVALID encoding 4'b1111, the fail-safe state, and is what SEP itself drives until fuse sensing completes. An SMU built without SEP drives 0xF0 (TEST_DEV).
|===
