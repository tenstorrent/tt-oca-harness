Address Map: smc_efuse_map

Address map for efuse shadow registers providing access to various chip configuration and ID fields

Register Arrays:

  • I2C_I3C_ID[9]: 9 registers, base 0x28, stride 0x8
  • SPARE[28]: 28 registers, base 0x80, stride 0x20

Register List:

AddressNameAccessDescription
0x0LOCKSRWLock controls for each fuse field. When write locked, the corresponding field is not
programmable. When read locked, the shadow register is not readable.
0x8JTAG_PUBLIC_IDENTITYRWJTAG-public exception window. In PROD and RMA_SiP, JTAG reads of this range
are admitted while JTAG access to every other fuse field is blocked. Encoding
is adopter-defined; the harness does not interpret or consume the value. The
slot-0 read lock still hides the bits when set.
0x28 - 0x68I2C_I3C_ID[9]RWI2C/I3C interface ID
0x70SMC_CONFIGRWSMC boot and configuration controls sourced from fuse. Only the low word carries
assigned bits, so firmware reads it as a single 32-bit access.
0x78OCCP_TRANSPORT_TIMEOUTRWOCCP transport timeout in the low word; upper word reserved.
0x80 - 0x3E0SPARE[28]RWIndividually lockable 256-bit spare region, reserved for fields assigned after the
RTL is frozen. Each element has its own write/read lock pair in LOCKS.
