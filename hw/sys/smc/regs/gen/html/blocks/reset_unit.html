Register Details:

SS_CONFIG

BitsFieldAccessResetDescription
31:0ss_configRW0x0Configuration registers to setup system configuration.
Usage is integration-specific; see the adopter chiplet specification.

SS_CONFIG_LOCK

BitsFieldAccessResetDescription
31:0config_lockRW1S0x0SS_CONFIG write lock. Writing 1 to bit i sets it, and SS_CONFIG bit i then ignores
writes until the primary reset clears the lock. A write to SS_CONFIG that touches
locked bits completes with OKAY: the locked bits keep their value and the unlocked
bits of the same write apply.

SS_RESET_COMPLETE

BitsFieldAccessResetDescription
31:0reset_completeR0x0Response signal from subsystem to indicate reset (or some other critical step) has completed.
Each bit reads the synchronized live value of its subsystem's signal; it is not latched.

SS_COLD_RESET_LOCK

BitsFieldAccessResetDescription
31:0cold_reset_lockRW1S0x0SS_COLD_RESET_N write lock. Writing 1 to bit i sets it, and SS_COLD_RESET_N bit i then
ignores writes until the primary reset clears the lock. A write to SS_COLD_RESET_N
that touches locked bits completes with OKAY: the locked bits keep their value and
the unlocked bits of the same write apply.

ISOLATE_REQ_REG

BitsFieldAccessResetDescription
31:0isolate_req_regRW0x0Isolate request. Bit i raises isolate_req_o[i]. The reset unit does not gate any
reset with it; a subsystem that must survive a reset gates its own reset with
its isolate_req_o bit. Cleared only by the cold reset; survives the cool reset.

ISOLATE_REQ_PINEN_REG

BitsFieldAccessResetDescription
31:0isolate_req_pinen_regRW0x0Isolate request pin enable. Bit i lets the isolate request pin raise isolate_req_o[i].
The cold reset clears it only while the pin is low; it keeps its value through a
cold reset with the pin high, and survives the cool reset.

ISOLATE_REQ_SMC_REG

BitsFieldAccessResetDescription
31:1Reserved--Reserved
0isolate_req_smc_regRW1C0x0Isolate request smc. Set by a rising edge of isolate_sequence_trigger_i; software writes 1
to clear. A write of 0, or a write whose byte strobes do not select this field,
leaves it unchanged; a rising edge in the same cycle as a clearing write wins.
Cleared only by the cold reset; survives the cool reset.

ISOLATE_REQ_SMCEN_REG

BitsFieldAccessResetDescription
31:0isolate_req_smcen_regRW0x0Isolate request smc enable. Bit i raises isolate_req_o[i] while ISOLATE_REQ_SMC_REG
is set, and makes the isolation sequence wait for isolate_req_ack_i[i] before it
asserts the cool reset. Cleared only by the cold reset; survives the cool reset.

ISOLATE_REQ_FLR_COUNTER_VALUE

BitsFieldAccessResetDescription
31:0isolate_req_flr_counter_valueRW0x0Isolation sequence timeout N, in reference clock cycles. cool_reset_n asserts N+1
cycles after the synchronized isolate_sequence_trigger_i rising edge, or earlier
once every subsystem enabled in ISOLATE_REQ_SMCEN_REG acknowledges on
isolate_req_ack_i. A trigger edge that arrives before the cool reset hold ends is
ignored. Cleared only by the cold reset; survives the cool reset.

ISOLATE_REQ_FLR_RESET_COUNTER_VALUE

BitsFieldAccessResetDescription
31:0isolate_req_flr_reset_counter_valueRW0x0Isolation sequence hold M: the number of reference clock cycles cool_reset_n stays
asserted. A value of 0 prevents the sequence from starting, whatever
ISOLATE_REQ_FLR_COUNTER_VALUE holds. Cleared only by the cold reset; survives the
cool reset.
