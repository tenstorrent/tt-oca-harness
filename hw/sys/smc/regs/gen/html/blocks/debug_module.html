Address Map: debug_module

RISC-V External Debug Support Version 0.13.2 - Section 3.12. Field reset values updated as per specification and user rules (Preset/- -> 0x0). HW access permissions are derived based on SW access. SW 'w' access changed to 'rw'. Fields previously rw1c now use 'woclr'.

Register Arrays:

  • abstractdata[12]: 12 registers, base 0x10, stride 0x4
  • confstrptr[3]: 3 registers, base 0x64, stride 0x4
  • progbuf[16]: 16 registers, base 0x80, stride 0x4
