SMC eFuse Wrapper Address Map

Places the SMC eFuse controller and its shadow registers in one 4 KiB page.

Register Arrays:

  • I2C_I3C_ID[9]: 9 registers, base 0x830, stride 0x8
  • SPARE[3]: 3 registers, base 0x888, stride 0x20
  • SPARE_TAIL[3]: 3 registers, base 0x8E8, stride 0x8

Register List:

0x4EFUSE_PROGRAM_CTRLRWeFuse program control and status. Configures the program data, triggers a program of the bit at EFUSE_PROGRAM_ADDR, and reports program progress and completion status.
0x8EFUSE_READ_CTRLRWeFuse read control and status. Triggers a read of the word at EFUSE_READ_ADDR and reports read progress and completion status.
0xCEFUSE_PROGRAM_INTERFACE_READ_DATARData the adopter SHIM returned with the last successful program, for example a read-back word. Held until the next successful program and not valid after an error. Hardware debug only.
0x10EFUSE_READ_INTERFACE_READ_DATARRead data returned through the eFuse read interface.
0x14EFUSE_READ_REQ_TIMEOUTRWRead interface timeout configuration. Sets the number of cycles the read interface waits for a SHIM response and enables the read timeout.
0x18EFUSE_PROGRAM_REQ_TIMEOUTRWProgram interface timeout configuration. Sets the number of cycles the program interface waits for a SHIM response and enables the program timeout.
0x1CEFUSE_PROGRAM_ADDRRWBit address for the next program. Set it before EFUSE_PROGRAM_CTRL.efuse_program_go.
0x20EFUSE_READ_ADDRRWBit address for the next read. Set it before EFUSE_READ_CTRL.efuse_read_go.
0x800HARNESS_LOCKSRWLock controls for each fuse field. When write locked, the corresponding field is not
programmable. When read locked, the shadow register is not readable.

A write to the shadow register of a write-locked field, or a read of the shadow
register of a read-locked field, completes with SLVERR and read data 0xBADCAB1E,
leaves the shadow register unchanged and raises the locked-field access interrupt
for the duration of the access. An attempted fuse program of a write-locked field,
or an attempted fuse read of a read-locked field, started through the eFuse
interface control registers is refused and sets
EFUSE_INTERFACE_CTRL_STATUS.efuse_req_error until it is cleared.
0x808SUPPLEMENTARY_LOCKSRWLock controls for the supplementary fuse region. When write locked, the corresponding
supplementary lock region is not programmable. When read locked, its shadow register is
not readable.
0x810JTAG_PUBLIC_IDENTITYRWJTAG-public exception window. In PROD and RMA_SiP, JTAG reads of this range
are admitted while every JTAG write and every other JTAG read is blocked. When
the lifecycle state fails its integrity check, JTAG reads of this range are
blocked as well. Encoding
is adopter-defined; the harness does not interpret or consume the value. The
slot-0 read lock still hides the bits when set.
0x830 - 0x870I2C_I3C_ID[9]RWI2C/I3C interface ID
0x878SMC_CONFIGRWSMC boot and configuration controls sourced from fuse. Only the low word carries
assigned bits, so firmware reads it as a single 32-bit access.
0x880OCCP_TRANSPORT_TIMEOUTRWOCCP transport timeout in the low word; upper word reserved.
0x888 - 0x8C8SPARE[3]RWIndividually lockable 256-bit spare region, reserved for fields assigned after the
RTL is frozen. Each element has its own write/read lock pair in HARNESS_LOCKS.
0x8E8 - 0x8F8SPARE_TAIL[3]RW64-bit spare region at the end of the map, reserved for fields assigned after the
RTL is frozen. All elements share the slot-7 write/read lock pair in
HARNESS_LOCKS.
