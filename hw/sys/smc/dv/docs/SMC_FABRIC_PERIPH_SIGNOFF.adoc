[[smc-fabric-periph-signoff]]
== SMC fabric and peripheral honesty signoff

This chapter records the v0.5.0 decision for #500. Feature credit is the
SCOPE matrix in `SMC_SCOPE_TRACEABILITY.adoc`. A green fabric or I3C
name is not protocol proof. `testlists/deferred.toml` is gone; OUT rows
live in `SMC_DEFERRED_DISPOSITION.adoc` and the README "Present but not
enrolled" table.

Evidence: scheduled nightly `--dut smc --items smoke` on `a273033a0`
completed successfully
(https://github.com/tenstorrent/tt-oca-harness/actions/runs/34051136716).
Every credited fabric / peripheral name below is in that `smoke` group.
