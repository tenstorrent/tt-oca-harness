[[smc-reset-clock-irq-signoff]]
== SMC reset, clock, and interrupt signoff

This chapter records the v0.5.0 decision for #499. Feature credit is
the SCOPE matrix in `SMC_SCOPE_TRACEABILITY.adoc`, not every name in
`reset.toml` / `clock.toml` / `irq.toml`. SAMPLE-only observe tests
stay in `smoke` and are not requirement rows.

Evidence: scheduled nightly and weekly `--dut smc --items smoke` on
`a273033a0` both completed successfully
(https://github.com/tenstorrent/tt-oca-harness/actions/runs/34051136716
nightly; weekly run 33982997638). `smoke` includes the credited
reset / mailbox-IRQ / FLR names and the SAMPLE observe cluster.

[[smc-rci-credit]]
=== Credited vs observe-only

[cols="2,3,2,1",options="header",]
|===
|Requirement |Test |Group |Credit
|Reset / power-good bring-up |`smc_canonical_smoke_test` |`smoke`, `canonical_top6` |YES
|Mailbox STATUS / IRQ |`smc_mailbox_irq_test` |`smoke`, `canonical_top6` |YES
|Function-level reset |`smc_flr_sanity_test` |`smoke`, `canonical_top10` |YES
|GPIO IRQ active |`smc_gpio_irq_active_test` |`smoke`, `canonical_top20` |YES
|Multi-reset CSR persist |`smc_multi_reset_csr_persistence_test` |`canonical_top20` (not `smoke`) |YES
|Cold reset / clk running / IRQ observe |`smc_cold_reset_test`, `smc_clk_running_test`, `smc_irq_observe_test` |`smoke` / `project_p0` |NO (SAMPLE-only)
|PLL/PVT clock config |`smc_pll_*` |unenrolled `rtl_placeholder` |NO
|===

`allow_timeout=True` stays a reviewed exception: helpers in
`smc_csr_seq_utils.py` that set it score the timeout, and each live
call site keeps a rationale comment (README gate). Force / placeholder
paths receive no credit.

Depth groups `reset` / `clock` / `irq` remain debug breadth. They are
not an extra feature-credit set.
