[[smc-credit-rules]]
=== Credit rules

* Feature credit requires active CSR/fabric/pin stimulus and a
  non-vacuous `SmcScoreboard` count. SAMPLE-only bring-up stays in
  `smoke` and is not a requirement row.
* `smc_i3c_to_fabric_test` is HCI_VERSION decode (`proxy=True`). It
  remains runnable via `i3c_depth` / `batch_c` / by name. It is not
  stub-signature SLVERR, and it is not I3C protocol credit (#504).
* Deferred.toml names, adopter PLL/PVT OKAY+0 wraps, and TB-glue DFD
  tokens are OUT (#505 / #506).
* UART loopback / ROM firmware stay on Bruce's existing intake issues.
  They are not re-scoped here.
* `--dut smc` already instantiates `smc_wrapper`. There is no separate
  `wrapper.toml` and no test named `main_wrapper` or `main_wrapper_por`.
  Bring-up / POR successors are `smc_canonical_smoke_test` and the reset
  cluster (`smc_cold_reset_test`, `smc_powergood_glitch_test`,
  `smc_multi_reset_csr_persistence_test`). See #260.
