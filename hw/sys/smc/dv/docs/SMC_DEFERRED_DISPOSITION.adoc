[[smc-deferred-disposition]]
== SMC deferred and OUT disposition

This table is the v0.5.0 source of truth for every named `[[tests]]` entry in
`testlists/deferred.toml`. The file is not included by `testlists/all.toml`.
Nothing here is enrolled PASS. `rg -c '^name = "'` on that file is 66 because
it also counts the three inventory groups (`deferred_tb_policy`,
`deferred_nightly_tier_a`, `deferred_nightly_remainder`); those groups are not
tests.

Buckets:

* `restore-for-v0.5.0` — implement and enroll before OSS signoff. None today.
* `adopter-pending OUT` — waits on adopter IP, a product pin, firmware/ROM, or a TB terminator.
* `child-TB-owned` — protocol completeness belongs to a block-level TB (I3C, DTP).
* `waived` — fake BFM, TB-glue, or a commercial alias already covered by a live name.

=== Idle smc_wrapper boundaries (v0.5.0 OUT)

These ports have no TB terminator on `--dut smc` / `smc_wrapper` today
(`models/README.md`). v0.5.0 records them as OUT rather than adding a
placeholder responder. Block-level I3C and DTP signoff stay on those TBs;
do not count a wrapper terminator as that proof.
