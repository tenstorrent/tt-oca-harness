== SMC canonical bring-up and CSR signoff

This chapter records the v0.5.0 decision for #498. Feature credit is the
SCOPE matrix in `SMC_SCOPE_TRACEABILITY.adoc`, not the historical
six-/ten-/twenty-wide prose in `SMC_VPLAN.adoc`. Live membership is
`testlists/all.toml`. Launch is `--dut smc` (the TB instantiates
`smc_wrapper`); there is no `--dut smc_wrapper`.
