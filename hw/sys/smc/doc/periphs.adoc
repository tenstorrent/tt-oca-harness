= Peripherals
:description: Communication, telemetry, timer, fuse, and GPIO peripherals in the SMC.

[[peripherals]]

This section documents the main peripherals integrated within the System
Management Controller (SMC). These peripherals provide essential I/O and
communication capabilities for the OCAH system, supporting various
protocols and interfaces required for system operation and external
connectivity.

== PWM Registers

The pulse-width modulator has one output per channel; the count is `smc_config_pkg::NumPwmOutputs`.
The PWM wrapper map places the OpenTitan PWM registers at offset 0x000 and the
pad-control register `CTRL` at offset 0x800. `CTRL.PAD_EN` holds one bit per
channel: while bit _i_ is set, channel _i_ drives GPIO pad 59+_i_ (pads 59 to 62
for four channels), with the pad output enabled and its input disabled; while it is
clear the pad is ordinary software GPIO. `PAD_EN` resets to 0. It does not start the
channel; `PWM_EN` does. A claimed pad whose channel is off (`PWM_EN[_i_]` 0) drives the
idle level selected by `INVERT`. The pad's own `DATA_CTRL.lsio_disable` vetoes the
claim, so the pad stays under register control. Setting the pad's
`DATA_CTRL.lsio_select` also routes channel _i_ to the pad, as it does for the other
LSIO pads. Other offsets in the wrapper answer DECERR. Offsets are relative to the PWM
base address.

== Peripheral Parameter Settings

The SMC sets peripheral parameters at instantiation from `smc_config_pkg`,
`smc_pkg`, and the padring package; these are the authoritative sources.
Most values match the IP defaults, but the following differ from the default
documented in the IP's own section.

<<smc-peripheral-parameter-overrides-table>> compares the SMC parameter overrides with
each peripheral's default values.

[[smc-peripheral-parameter-overrides-table]]
.SMC Peripheral Parameter Overrides
[width="100%",cols="16%,38%,18%,28%",options="header",]
|=======================================================================
|Peripheral |Parameter |IP default |SMC value

|Mailbox |`smc_pkg::NumMailboxes` |2 |32

|Mailbox |`smc_pkg::MailboxDepth` |8 |2

|I2C |`smc_config_pkg::I2cTargetRxFifoDepth` |268 |64

|I3C |`smc_config_pkg::NumI3c` |2 |6

|GPIO |`MAX_TRANS` (threaded from the `smc` module parameter) |32 |2

|GPIO |`INPUT_BY_DEFAULT` (per instance, from
`smc_padring_pkg::DefaultDirectionMap`) |input on all |input on 60 of 67
GPIOs, output on the remaining 7

|GPIO |`LSIO_PAD2CORE_IDLE` (per instance, from
`smc_padring_pkg::LsioIdleLevelMap`) |0 on all |1 on the UART RX and CTS,
I2C SCL, SDA, SMBALERT# and SMBSUS#, and I3C SCL and SDA pads; 0 on the rest

|UART 16550 |`smc_config_pkg::UartTxFifoDepth` |16 |32

|UART 16550 |`smc_config_pkg::UartRxFifoDepth` |16 |32

|PWM |`smc_config_pkg::NumPwmOutputs` (channels) |6 |4
|=======================================================================

The SMC I2C instances keep the IP default of 64 entries for the controller TX
(FMT), controller RX and target TX FIFOs, so with the target RX override all
four FIFOs of each instance hold 64 entries, and `FMTLVL`, `RXLVL`, `TXLVL`
and `ACQLVL` read 64 when their FIFO is full.

The System Timer OCTS takes no parameters. The eFuse overrides only bus
widths and interface types. The Log Engine, AVSBus Controller, and Telemetry
Receiver are configured explicitly through `smc_config_pkg`, but at values
equal to their IP defaults.
