= Watchdog Timers

[[smc-watchdog]]

== Operation

Each CPU core includes a dedicated watchdog timer (at 0xC000_0000 + N *
0x400), providing per-core timeout monitoring. Reset effects are described in
Clocks and Resets. Base addresses and interrupt-related context for the WDT are
summarized in
ifdef::backend-html5[]
xref:smc:interrupts.adoc#interrupts[Interrupts].
endif::backend-html5[]
ifdef::backend-pdf[]
<<interrupts,Interrupts>>.
endif::backend-pdf[]

Timeouts are configurable to suit different workloads, and staged
warnings (followed by reset) allow software intervention before hardware
reset is triggered.

Watchdog monitoring can be disabled during debugging to prevent false
triggers, supporting uninterrupted development and troubleshooting.
