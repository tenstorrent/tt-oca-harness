[[smc-release-matrix]]
== SMC release regression matrix

This chapter defines the mandatory qualification set: the *live* CI matrix on
Verilator — `smoke` per PR, `hosted` nightly and weekly. It is not narrowed
to a smaller tier.

`--dut smc` already instantiates `smc_wrapper`. There is no separate
`--dut smc_wrapper` job.

[[smc-release-combinations]]
=== Mandatory combinations

[cols="2,2,1,3",options="header",]
|===
|Tier |Command |Seeds |Blocks
|PR |`--dut smc --tool verilator --items smoke` |1 |PR merge (`sim.yml`)
|Nightly |`--dut smc --tool verilator --items hosted` |3 |Release qualification (`regress.yml`)
|Weekly |`--dut smc --tool verilator --items hosted` |3 |Coverage / dashboard; same group
|===

Group sizes are the `expected_count` guards in
`hw/sys/smc/dv/testlists/all.toml`.

[[smc-release-credit]]
=== Credit versus the CI group

`smoke` and `hosted` are debug breadth. Feature credit is the SCOPE YES rows,
not every SAMPLE observe name in the group. `smc_i3c_to_fabric_test` is
HCI_VERSION decode (`proxy=True`) and is not in `smoke` / `functional`.

The coverage gate is defined in `SMC_COVERAGE_POLICY.adoc`; this chapter does
not absorb it.
