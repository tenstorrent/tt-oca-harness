[[smc-canonical-bringup-signoff]]
== SMC canonical bring-up and CSR signoff

This chapter defines the canonical bring-up and CSR signoff. Feature credit is
the SCOPE matrix in `SMC_SCOPE_TRACEABILITY.adoc`. Live membership is
`hw/sys/smc/dv/testlists/all.toml`. Launch is `--dut smc` (the TB instantiates
`smc_wrapper`); there is no `--dut smc_wrapper`.

[[smc-canonical-groups]]
=== Live groups

The table lists the groups `hw/sys/smc/dv/testlists/` defines; their sizes are
the `expected_count` guards in `hw/sys/smc/dv/testlists/all.toml`.

[cols="2,3",options="header",]
|===
|Group |Role
|`smoke` |PR gate: canonical bring-up, cold reset, and a CSR frontdoor read
|`hosted` |Nightly and weekly: `all` minus the seventeen leaves that need the RISC-V toolchain (fourteen `fw` leaves, three dual-target leaves that run a ROM or firmware image)
|`rtl_issue` |Weekly on its own `regress.yml` row: defect reproducers graded under `expect_fail`; no bring-up credit
|`per_ip` |One pass across every IP the bench drives
|`all` |The package regression; `all.toml` names the leaves outside it and why, and `SMC_DEFERRED_DISPOSITION.adoc` records the leaves no scheduled tier runs
|===

[[smc-canonical-credit]]
=== Credited bring-up / CSR

[cols="2,3,3,1",options="header",]
|===
|Requirement |Test |Evidence |Credit
|Reset / power-good bring-up |`smc_canonical_smoke_test` |`CHK-CANONICAL-SMOKE`, `CHK-RESET-WAIT-COLD_PRIMARY_ASSERTED` / `COOL_PRIMARY_ASSERTED` |YES
|Scratch / chip-config CSR |`smc_register_sanity_test` |15 SEP_IN AXI scratch RW/restore accesses; scoreboard value checks; `proxy=False` |YES
|Default / RO register read |`smc_default_reg_rd_test` |`CHK-DEFAULT-REG-SWEEP`, `CHK-DEFAULT-REG-VALUE` |YES
|Mailbox STATUS / IRQ |`smc_mailbox_irq_test` |`CHK-MAILBOX-IRQ-ASSERT` / `CLEAR` / `SOURCE` |YES
|Function-level reset |`smc_flr_sanity_test` |8 scoreboard item-count checks and 5 value-checked CSR reads across `rst_cool_ni`; warm scratch recovers to mapped reset |YES
|Multi-reset CSR persist |`smc_multi_reset_csr_persistence_test` |`CHK-MULTI-RESET-CSR-SWEEP`, `CHK-COOL-RESET-CLEARS-WARM-SCRATCH` |YES
|I3C window decode |`smc_i3c_to_fabric_test` |Not in `smoke`. HCI_VERSION decode, `proxy=True` |NO
|SAMPLE observe |`smc_cold_reset_test` and other `functional` observe leaves |`functional`; SAMPLE-only |NO
|===

`functional` carries no I3C leaf. `smc_i3c_to_fabric_test` is decode only, not SLVERR-to-stub, and is not
I3C protocol credit.
