= System Management Controller (SMC)
:description: SMC architecture, management functions, processing, peripherals, debug, and register reference.

[[system-management-controller]]

The System Management Controller (SMC) performs firmware-driven platform
management for each chiplet. Its documentation is organized into focused topic
pages covering the subsystem architecture, hardware services, and programming
interfaces.
