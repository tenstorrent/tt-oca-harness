[[smu-release-matrix]]
== SMU release regression matrix

This chapter defines the mandatory qualification set: the CI matrix in
`.github/workflows/sim.yml` and `regress.yml`. `--dut smu` is the wrapper
bench and its `sep0_all` is the mandatory job; `--dut smu_block` is not.

[[smu-release-combinations]]
=== Mandatory combinations

[cols="2,2,1,3",options="header",]
|===
|Tier |Command |Seeds |Blocks
|PR |`--dut smu --tool verilator --items smoke_sep0` |1 |PR merge (`sim.yml`)
|Nightly |`--dut smu --tool verilator --items sep0_all` |1 |release qualification (`regress.yml`)
|Weekly |`--dut smu --tool verilator --items sep0_all` |3 |Coverage / dashboard; same group as nightly
|===

Nightly is one seed; weekly is three. A red nightly is not a PR merge gate
(`regress.yml` says so) but it blocks release qualification.

`smu` `smoke` members: `smu_wrapper_elaboration_no_sep_test`,
`smu_smc_smoke_test`, `smu_wrapper_elaboration_sep_rtl_test`,
`smu_sep_smoke_test`. The hosted-runner PR tier is `smoke_sep0`.

[[smu-release-decisions]]
=== Decisions

* `smu_ext_boot_seq_gate_test` is in `sep0_all` and `smoke_sep0`.
  It is not a member of `smoke`.
* `--dut smu_block` is **not** a release CI job beyond its own `smoke`. Its
  PASSes are labelled `DUT_TAG=BARE` and are not `sep0_all` density.
* Feature credit is the enrolled `sep0_all` set on `--dut smu`. The SEP=1
  firmware groups and the names in `SMU_DEFERRED_DISPOSITION.adoc` are OUT.
