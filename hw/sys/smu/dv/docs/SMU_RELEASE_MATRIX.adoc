This chapter records the #485 decision. The mandatory qualification set
is the *live* CI matrix in `.github/workflows/sim.yml` and
`regress.yml`. It is not revised. `--dut smu_wrapper` is not a
mandatory job.

[[smu-release-decisions]]
=== Decisions

* Keep `smu_ext_boot_seq_gate_test` PR-only. Do not add it to
  `sep0_all` / nightly. It stays in `smoke` / `phase1` / `smc`.
  Re-enrollment is a later #493 choice, not this matrix.
* `--dut smu_wrapper` is **not** a v0.5.0 CI job. Wrapper `smoke` /
  elaboration PASSes stay labelled `DUT_TAG=WRAPPER` and are not
  `sep0_all` density (#489).
* Feature credit stays the enrolled `sep0_all` set. Wrapper and
  `tests_deferred/` names are OUT.
