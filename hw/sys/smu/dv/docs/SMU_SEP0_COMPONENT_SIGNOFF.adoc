=== ATOP reject and filter-allow (#491)

Filter-allow positive control is enrolled and PASSed:
`smu_axi_filter_allow_ns_test` emits `CHK-SMU-ALLOW-NS-S1/S2/S3`;
the SYS_IN program / window / shrink leaves emit `AXI_FILTER_OKAY`
via `CHK-FILTER-PROG-*`.

(`AXI_NON_ATOP_OK`, RID==ARID). The TB ties
`smu_axi_in_req.aw.atop = 0`; there is no legal ATOP driver on this
DUT. ATOP reject / err_slv poison is **OUT** for v0.5.0 SEP=0
(NEGATIVE-NEEDS-POSITIVE-CONTROL). A green atomic test is not ATOP
non-support credit. Revisit when a public ATOP stimulus exists.
