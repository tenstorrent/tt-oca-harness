== SMU v0.5.0 feature list (candidate)

This chapter freezes the *candidate* SEP=0 feature subset for designer
confirmation (#487). It is not an approval. Do not treat a merged copy of
this file as designer sign-off.

The executable contract remains `testlists/all.toml`. Feature credit is
only the enrolled `sep0_all` set (52) plus the two pull-request-only names
called out below. Deferred raise stubs, wrapper PASSes, and SEP=1 work are
OUT.

(F1) are enrolled in `smoke` / `phase1` / `smc` but not in `sep0_all`.

[[smu-out-and-wrapper]]
=== OUT, wrapper, and missing commercial names

* Every name in `docs/SMU_DEFERRED_DISPOSITION.adoc` is OUT for this subset. #488 is the
  per-row disposition; do not imply those features are done because a
  `TEST_EVIDENCE` row still exists for catalog continuity.
* `--dut smu_wrapper` (`smu_wrapper_elaboration_no_sep_test`,
  `smu_smc_smoke_test` on the wrapper) is a production-pin surface. Its
  PASSes are `DUT_TAG=WRAPPER` and are not `sep0_all` density credit
  (`SMU_VPLAN.adoc`).
* The commercial names `main_wrapper` and `main_wrapper_por` are not in
  this tree. The wrapper successors are
  `smu_wrapper_elaboration_no_sep_test` (elaboration / reset) and
  `smu_wrapper_elaboration_sep_rtl_test` (SEP=1 elab, wrapper `smoke`).
  See #261. Do not invent a bare-`smu` test under those names.
