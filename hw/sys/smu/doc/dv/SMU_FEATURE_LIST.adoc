[[smu-feature-list]]
== SMU hosted feature list

This chapter defines the hosted feature subset F1–F7 and maps every enrolled
test to one feature and one `TEST_EVIDENCE` token. The F1–F7 numbering is
defined by the table below and nowhere else; there is no separate SMU feature
specification in this tree. The hardware facts the features describe are in
`doc/integrator/src/smu.adoc`.

The executable contract is `testlists/all.toml`. Feature credit is
the enrolled `hosted` group. Names in `SMU_DEFERRED_DISPOSITION.adoc`
and SEP=1 work are OUT.

[cols=",",options="header",]
|===
|Field |Value
|Feature numbering |F1–7, defined by the table in this chapter
|Feature-credit group |`hosted` (`--dut smu`)
|PR smoke |`smoke` (`smu_dtp_jtag_smoke_test`, `smu_ext_boot_seq_gate_test`)
|Evidence map |`cocotb/env/smu_evidence_map.py` `TEST_EVIDENCE`
|OUT catalog |`SMU_DEFERRED_DISPOSITION.adoc`
|===

[[smu-feature-subset]]
=== Hosted subset

Features 1–7, scoped to `--dut smu` on its compile profile `compile_smu_chiplet`
(the wrapper with the real SEP). The SEP=0 composition proofs run on
`--dut smu_block` (`nosep`) and are listed with that group below.

[cols="1,2,2,3,3",options="header",]
|===
|ID |SPEC feature |Scope |What is in |What stays OUT
|F1 |SMC boot and firmware execution |IN (observe) |Bring-up, reset release, mailbox CSR, WDT, GPIO strap, OCTS free-run |SMC CPU firmware boot, ROM regression
|F2 |Real SEP RTL under the SMU |OUT |— |SEP=1 instantiate / fetch / retire
|F3 |DTP debug and test access |IN |PTAP IDCODE/BYPASS, JTAG2AXI, OTP MAP, STAP, BSR select, boot-stall, IC_RESET |Closed JTAG2AXI security gate (the default SEP eFuse preload leaves debug enabled), lifecycle policy, iJTAG model depth
|F4 |AXI crossbar fabric |IN |External-port ID conversion through the crossbar, filters, ATOP reject, alias remap, fabric BAR |The crossbar routing matrix beyond the SMC aperture; the SEP=0 shape (direct ID converters, `smu_axi_xbar` absent) is `--dut smu_block` `nosep`
|F5 |SMC↔SEP interoperability |OUT |— |Mailbox challenge-response with a live SEP
|F6 |Cross-trigger and clock-stop |IN (pin-level) |Clock-stop coordination, product-pin CTM remap, illegal-phase corners |Four-phase CTM handshake / CLA loop (no product pin or frontdoor for CLA feedback or the CTM handshake)
|F7 |Lifecycle and security |OUT for `hosted` |— (the SEP=0 demote / `lc_state` observe, `smu_smc_security_demote_pm_test`, is `--dut smu_block` `nosep`) |`feat_ctrl` matrices, lifecycle policy (need a real SEP under SMU)
|===

[[smu-out-and-wrapper]]
=== OUT, wrapper, and missing commercial names

* Every name in `SMU_DEFERRED_DISPOSITION.adoc` is OUT for this subset,
  and none of them has a `TEST_EVIDENCE` row: the map holds rows only for
  names with a test body in this tree.
* `--dut smu` is the wrapper bench and carries `hosted` itself; PASSes are
  labelled `DUT_TAG=WRAPPER`. The bare block bench is `--dut smu_block`
  (`SMU_VPLAN.adoc`).
* Wrapper elaboration / reset is `smu_wrapper_elaboration_test`
  (wrapper `fw_smoke` and `build_smoke`).
