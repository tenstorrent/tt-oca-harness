[[smu-scope-traceability]]
== SMU scope and traceability

This chapter is the requirement-to-test-to-coverage matrix for
`SMU_SPEC.md` Features 1–7. `SMU_FEATURE_LIST.adoc` defines the SEP=0
subset and the per-leaf `TEST_EVIDENCE` tokens;
`SMU_DEFERRED_DISPOSITION.adoc` classifies the OUT names. Live group
membership for `--dut smu` is `testlists/wrapper.toml`.

[cols=",",options="header",]
|===
|Field |Value
|DUT |`--dut smu` → `hw/top/smu_wrapper.sv` under `smu_wrapper_uvm_top`, on its `SEP=0` compile profile (alias `smu_wrapper`)
|Spec / plan |`SMU_FEATURE_LIST.adoc` Features 1–7
|Coverage intent |`smu_fcov.py` scenario bins + `TEST_EVIDENCE` tokens. Verilator toggle / FCOV is scoped to `--dut smu_block` (`SMU_COVERAGE_POLICY.adoc`)
|Checker |`SmuScoreboard` named `evidence=` / `expect_*` tokens + `results.xml`
|CI |`.github/workflows/sim.yml` (PR gate) runs `smoke_sep0`; `.github/workflows/regress.yml` runs `sep0_all`
|===

[[smu-live-groups]]
=== Live groups versus credit

Executable membership, `--dut smu` only:

[cols="2,3",options="header",]
|===
|Group |Role
|`smoke_sep0` |PR gate (`sim.yml`). Toolchain-free; `smoke` reaches the SEP=1 firmware and cannot run on a hosted runner.
|`sep0_all` |`regress.yml` regression. Feature-credit set.
|`all` |Adds the SEP=1 firmware set. Not the `regress.yml` denominator.
|===

`sep0_all` and the SEP=1 groups are two evidence surfaces on one DUT:
`--dut smu` is the wrapper (`testlists/wrapper.toml`), and `regress.yml`
runs its `sep0_all`. PASSes carry `DUT_TAG=WRAPPER`. The residual block
bench is `--dut smu_block` (`testlists/all.toml`), whose PASSes carry
`DUT_TAG=BARE` and are not feature credit.

[[smu-credit-rules]]
=== Credit rules

* Feature credit requires a named `TEST_EVIDENCE` token the sequence
  already emits and a non-vacuous `SmuScoreboard` count. The map must not
  invent a checkbox the body cannot prove.
* Credit is the enrolled `sep0_all` set.
* Every name in `SMU_DEFERRED_DISPOSITION.adoc` is OUT and reports no PASS.
* `--dut smu_block` PASSes (`DUT_TAG=BARE`) are OUT of this matrix.
* SEP=1 instantiate / fetch / retire (F2) and live SMC↔SEP mailbox
  challenge-response (F5) are OUT.
* Wrapper elaboration / reset is `smu_wrapper_elaboration_no_sep_test`;
  SEP=1 elaboration is `smu_wrapper_elaboration_sep_rtl_test`.
