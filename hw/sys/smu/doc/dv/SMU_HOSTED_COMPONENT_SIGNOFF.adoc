[[smu-hosted-component-signoff]]
== SMU hosted component scope

This chapter defines the hosted component scope. Feature credit is the
enrolled `hosted` set, which runs on `--dut smu` — the wrapper, whose
PASSes carry `DUT_TAG=WRAPPER`. `--dut smu_block` PASSes (`DUT_TAG=BARE`)
and the names in `SMU_DEFERRED_DISPOSITION.adoc` are OUT.

[[smu-signoff-490]]

[[smu-signoff-491]]
=== ATOP reject and filter-allow

Filter-allow positive control is enrolled:
`smu_axi_filter_allow_ns_test` emits `CHK-SMU-ALLOW-NS-S1/S2/S3`;
the SYS_IN program / window / shrink leaves emit `AXI_FILTER_OKAY`
via `CHK-AXI-FILTER-OKAY`.

`smu_axi_atomic_operation_test` proves the supported class only
(`AXI_NON_ATOP_OK`, RID==ARID). The TB ties
`smu_axi_in_req.aw.atop = 0`; there is no legal ATOP driver on this
DUT. ATOP reject / err_slv poison is **OUT** for the hosted set: a negative check
needs a positive control, and no legal ATOP stimulus exists on this DUT.
A green atomic test is not ATOP non-support credit.

[[smu-signoff-481]]
=== SMC-under-SMU

Release-group (`hosted`) SMC-under-SMU names:

`smu_no_sep_configuration_test`,
`smu_smc_reset_ctrl_test`, `smu_smc_security_demote_pm_test`,
`smu_system_timer_octs_test`, `smu_i3c_mem_port_connectivity_test`,
`smu_smc_wdt_sanity_test`, `smu_smc_wdt_timeout_irq_test`,
`smu_smc_mailbox_sanity_test`.

`smu_smc_smoke_test` -- the SMC ROM boot to PASS on the wrapper -- is not in
`hosted`. It is enrolled in `fw_smoke` and `all`, which need the SMC
firmware compile; neither `sim.yml` nor `regress.yml` runs either group, so it
carries no release credit until one of them is scheduled.

`smu_ext_boot_seq_gate_test` and `smu_smc_mailbox_int_test` are in
`hosted` (the former also in `smoke`).

eFuse / burn under SMU is OUT (SEP=1 / child-TB).
`smu_smc_gpio_strap_sanity_test` is named in `SMU_FEATURE_LIST.adoc`
but is enrolled in no group of `testlists/all.toml`; it is not release credit.

[[smu-signoff-482]]
=== DTP-under-SMU

JTAG smoke, boot-stall, IC_RESET, clock-stop, STAP, BSR, illegal-phase CTM
and product-pin CTM remap (`smu_xtrig_ctm_remap_test`) are the enrolled
DTP-under-SMU set in `hosted`. Block-level DTP signoff is the DTP package.

`feat_ctrl` scenarios that need the SEP=1 lifecycle controller are OUT in
`SMU_DEFERRED_DISPOSITION.adoc`.

[[smu-signoff-483]]
=== Hosted fabric

ID-width, crossbar error, prot decode, alias remap, and fabric BAR are
checked through `ocah_axi_vip`
(`common/seq_lib/smu_axi_helpers.py`). Filter-allow and ATOP reject are
covered above. SEP=1 3×3 xbar receives no release credit.
