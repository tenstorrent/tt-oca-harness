DTP instantiation parameters are defined on their owning IP pages:

* *JTAG Interface Unit* parameters (STAP count, I/O/SMC/SEP/extra STAP enables) —
  see the
ifdef::backend-html5[]
  xref:ip:jtag_intf_unit/doc/index.adoc[JTAG Interface Unit]
endif::backend-html5[]
ifdef::backend-pdf[]
  <<jtag-interface-unit,JTAG Interface Unit>>
endif::backend-pdf[]
  page.
* *PTAP* parameters (IC_RESET struct types, IDCODE fields, JTAG2AXI pipeline
  depths, feature-enable enables) — see the
ifdef::backend-html5[]
  xref:ip:jtag_ptap/doc/index.adoc[JTAG PTAP]
endif::backend-html5[]
ifdef::backend-pdf[]
  <<jtag-ptap,JTAG PTAP>>
endif::backend-pdf[]
  page.
* *Cross Trigger Network* parameters (CTP count, internal CT count, clock-stop
  request count, per-CTP operating mode) — see the
ifdef::backend-html5[]
  xref:ip:cross_trigger_network/doc/index.adoc[Cross-Trigger Network]
endif::backend-html5[]
ifdef::backend-pdf[]
  <<cross-trigger-network,Cross-Trigger Network>>
