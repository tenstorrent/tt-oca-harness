= Cross-Trigger Operation

[[dtp-cross-trigger-operation]]

The Cross-Trigger Network (CTN) routes debug events between internal sources
and external cross-trigger ports. Matrices select event destinations; ports
provide wire-OR or point-to-point signaling at the chiplet boundary.

== Event Routing

The CTN combines Cross-Trigger Matrices (CTMs) and Cross-Trigger Ports (CTPs).
Configure the port modes, then the matrix routes, for the required event path before
enabling the participating debug sources.

== Clock Stop

JTAG and CLA clock-stop requests feed the chiplet halt path. Clocks and Resets
owns its aggregation, clock-domain crossing and reset behavior.
