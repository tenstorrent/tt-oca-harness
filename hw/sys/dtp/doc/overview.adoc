= Architecture and Access Paths
:description: DTP internal structure and how debug access reaches the JIU and CTN.

[[dtp-overview]]

The DTP contains two major functional blocks — the JTAG Interface Unit (JIU) and
the Cross Trigger Network (CTN) — plus the DTP top-level wiring that connects
them to each other, to the SMU AXI crossbar, and to the external JTAG and
cross-trigger pads.

== JTAG Interface Unit

The JTAG Interface Unit (JIU) is the top-level JTAG control module. It contains:

* A Primary TAP (PTAP) — the main chiplet JTAG entry point, connected to the
  five external JTAG pins (TCK, TDI, TDO, TMS, TRST_n).
* A configurable set of Secondary TAPs (STAPs) — for I/O chiplet-to-chiplet
  JTAG, SMC CPU debug, SEP CPU debug, and optional extra TAPs.
* An iJTAG network selected by `SELECT_IJTAG`, with a serial cascade of
  secure DFT, non-secure DFT, and DFD SIBs. Each SIB inserts or bypasses its
  associated external scan segment.
* Independent instruction-selected PTAP TDRs for SMC fabric debug
  (JTAG2AXI), SMC OTP (JTAG2AXIL), and SEP OTP (JTAG2AXIL). These bridges
  are outside the iJTAG SIB cascade.

== Cross Trigger Network

The Cross Trigger Network (CTN) routes cross-trigger pulses between on-chip
sources and sinks and the external CTP pads. It consists of:

* *Cross Trigger Ports (CTPs)* — pad-facing modules, each connecting to four
  I/O pads (CT_Req_out, CT_Ack_in, CT_Req_in, CT_Ack_out) and supporting both
  wire-OR and point-to-point signalling.
* *Cross Trigger Matrix (CTM)* — a 26×26 AND-OR crossbar that statically routes
  trigger pulses under AXI-Lite CSR control.
* *Clock stop aggregation* — the CTN OR-reduces all `xtrig_clk_stop_req_i`
  inputs (CLA sources) and OR-combines the result with the JTAG `jtag_clock_stop`
  bit to produce the registered `stop_clks_o` output.

Per-path debug-disable inputs gate STAPs, iJTAG SIBs, and JTAG2AXI bridges.

== Debug Access Paths

External debug access reaches the DTP subsystem through two routes:

*JTAG path*: An external debugger drives the five JTAG pins directly. The PTAP
decodes the JTAG instruction, selects the appropriate TDR, and routes data
through the scan chain. JTAG2AXI instructions allow the debugger to generate
AXI transactions on the SMC fabric via the PTAP's built-in bridges, without
involving the SMC CPU.

*AXI path*: The DTP cross-trigger configuration registers (CTM and CTP CSRs)
are memory-mapped inside the SMC address space. The SMC exposes them on its
`axil_dtp_csr_req_o` / `axil_dtp_csr_resp_i` interface, which the SMU wires
directly to the DTP `axil_xtrig_req_i` / `axil_xtrig_resp_o` ports. Software
running on the SMC reaches the CTN CSRs through its own register map
(`dtp_ctrl_reg` in `smc.rdl`). An external debugger using the PTAP JTAG2AXI
bridge reaches the same window through the SMC fabric AXI port.
