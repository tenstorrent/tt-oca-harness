System Management Controller (SMC)

The System Management Controller (SMC) performs firmware-driven platform management for each chiplet. Its documentation is organized into focused topic pages covering the subsystem architecture, hardware services, and programming interfaces.

Architecture and Processing

  • Overview — responsibilities, structure, and the top-level block diagram.

  • Clock and Reset Management — clock domains, reset sequencing, and power-management integration.

  • CPU and Memory System — processor cluster, caches, local memory, isolation, and debug.

  • Fabric — internal networks, remapping, filtering, protection, and routing.

Services and Peripherals

  • Peripherals — communication, telemetry, timer, fuse, and GPIO blocks.

  • Interrupts — interrupt routing, PLIC, CLINT, and error delivery.

  • Boot ROM — ROM architecture, firmware, and operation.

  • Direct Memory Access Engine — data-movement architecture, control, and integration.

  • Zeroer — hardware-assisted memory clearing.

Debug, Protection, and Reference

  • Design-for-Debug and Core Logic Analyzer — event observation, triggering, and trace capture.

  • eFuse Shadow Register Scan Protection — scan policy for access-control assets.

  • Memory Map — address-space organization, access controls, and register documentation.
