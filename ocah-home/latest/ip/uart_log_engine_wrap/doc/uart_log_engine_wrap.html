OCAH UART & Log Engine Wrapper

1. Description

The OCAH UART & Log Engine Wrapper is a hardware module that integrates an UART 16550 with a Log Engine. This wrapper is designed to facilitate communication between the UART and the log engine, allowing for logging capabilities.

2. Features

The features of this design include:

  • An UART 16550

  • An optional Log Engine

  • Configurable APB4 or AXI4-Lite register interface

Receiver Line Status Interrupt.

is dropped. In non-FIFO mode, the existing character in the RBR is overwritten.
This bit triggers the Receiver Line Status Interrupt.
0DRR0x0Data Ready. When set, indicates that the RX FIFO (or RBR in non-FIFO
mode) contains data.

19:0LOG_REGION_SIZERW0x0Log region size in bytes. Supported values are at most 512 KiB and aligned
