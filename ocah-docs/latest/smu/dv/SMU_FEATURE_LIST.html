1. SMU hosted feature list

This chapter defines the hosted feature subset F1–F7 and maps every enrolled test to one feature and one TEST_EVIDENCE token. The F1–F7 numbering is defined by the table below and nowhere else; there is no separate SMU feature specification in this tree. The hardware facts the features describe are in doc/integrator/src/smu.adoc.

The executable contract is testlists/wrapper.toml. Feature credit is the enrolled hosted group. Names in SMU_DEFERRED_DISPOSITION.adoc and SEP=1 work are OUT.

1.3. OUT, wrapper, and missing commercial names

  • Every name in SMU_DEFERRED_DISPOSITION.adoc is OUT for this subset, and none of them has a TEST_EVIDENCE row: the map holds rows only for names with a test body in this tree.

  • --dut smu is the wrapper bench and carries hosted itself; PASSes are labelled DUT_TAG=WRAPPER. The bare block bench is --dut smu_block (SMU_VPLAN.adoc).

  • Wrapper elaboration / reset is smu_wrapper_elaboration_sep_rtl_test (wrapper smoke).
