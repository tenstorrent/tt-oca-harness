Table 1. Hardware Safety Requirements
Requirement ID Category Requirement Description

OCAH-HWSR-GENERAL-000

GENERAL

OCAH shall always generate level sensitive, active-high, wired interrupts upon detection of an error

OCAH-HWSR-GENERAL-001

GENERAL

OCAH shall be capable of performing HW-driven error injection to test against latent faults in diagnostic mechanisms

OCAH-HWSR-GENERAL-002

GENERAL

OCAH shall integrate a Safety Bus ingress port to all of its subsystems to control/access error injection interface and error logging registers

OCAH-HWSR-GENERAL-003

GENERAL

OCAH safety bus shall be isolated from the subsystem’s local fabric to achieve freedom from interference (FFI)

OCAH-HWSR-SMC-000

COMPUTE_CPU

The OCAH SMC shall implement a Dual-Core Lockstep architecture for the CPU pipeline to detect random transient faults in the execution path, including Cache Controller Logic.

OCAH-HWSR-SMC-001

FAULT_DETECTED_STATE

When the OCAH SMC Dual-Core Lockstep comparator detects a mismatch between master and checker CPU outputs, the OCAH SMC shall activate a manager isolation mechanism to prevent the faulty CPU from injecting corrupted data into the subsystem.

OCAH-HWSR-SMC-002

ERROR_REPORTING

When the OCAH SMC Dual-Core Lockstep comparator detects a mismatch between master and checker CPU outputs, the OCAH SMC shall signal an uncorrectable error interrupt to an external safety entity in the chiplet.

OCAH-HWSR-SMC-003

FAULT_REACTION

When the OCAH SMC Dual-Core Lockstep comparator detects a mismatch between master and checker CPU outputs, the OCAH SMC shall trigger a reset of the specific CPU core to restore safe operation.

OCAH-HWSR-SMC-004

ERROR_LOGGING

When the OCAH SMC Dual-Core Lockstep comparator detects a mismatch between master and checker CPU outputs, the OCAH SMC shall record the program counter and data values from both master and checker CPUs for diagnostic purposes.

OCAH-HWSR-SMC-005

COMPUTE_CPU

The OCAH SMC shall implement a Windowed Watchdog Timer for each CPU core to detect execution hangs and runaway conditions.

OCAH-HWSR-SMC-006

FAULT_DETECTED_STATE

When the OCAH SMC CPU Windowed Watchdog Timer detects a timeout or early feed violation, the OCAH SMC shall activate a manager isolation mechanism to prevent the faulty CPU from injecting corrupted data into the subsystem.

OCAH-HWSR-SMC-007

ERROR_REPORTING

When the OCAH SMC CPU Windowed Watchdog Timer detects a timeout or early feed violation, the OCAH SMC shall signal an interrupt to an external safety entity in the chiplet.

OCAH-HWSR-SMC-008

FAULT_REACTION

When the OCAH SMC CPU Windowed Watchdog Timer detects a timeout or early feed violation, the OCAH SMC shall trigger a reset of the specific CPU core.

OCAH-HWSR-SMC-009

COMPUTE_CPU

The OCAH SMC shall implement ECC SECDED protection on all CPU Instruction Cache SRAM macros to detect and correct memory faults.

OCAH-HWSR-SMC-010
