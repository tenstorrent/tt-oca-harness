This page provides the DTP top-level port table. Configuration parameters are defined on their owning IP pages; see the links in the section below. The generated CTM and CTP register maps appear in the CTN Memory Map section of the Cross-Trigger Network page.

2. Configuration Parameters

DTP instantiation parameters are defined on their owning IP pages:

  • JTAG Interface Unit parameters (STAP count, I/O/SMC/SEP/extra STAP enables) — see the JTAG Interface Unit page.

  • PTAP parameters (IC_RESET struct types, IDCODE fields, JTAG2AXI pipeline depths, feature-enable enables) — see the JTAG PTAP page.

  • Cross Trigger Network parameters (CTP count, internal CT count, clock-stop request count, per-CTP operating mode) — see the Cross-Trigger Network page.
