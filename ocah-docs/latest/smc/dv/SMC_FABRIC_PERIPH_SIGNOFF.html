1. SMC fabric and peripheral honesty signoff

This chapter defines the fabric and peripheral honesty signoff. Feature credit is the SCOPE matrix in SMC_SCOPE_TRACEABILITY.adoc. A green fabric or I3C name is not protocol proof. OUT rows live in SMC_DEFERRED_DISPOSITION.adoc.
