Fuse Command Protocol

Custom command interface between controller and SHIM:

Request Structure (fuse_command_req_t):

typedef struct packed {
    addr_t                    address;           // Target address in bits
    logic                     program_data;      // Data to program (1'b1)
    access_length_words_t     access_length_words; // Transfer size
    command_t                 command;           // Command type
    logic                     valid;             // Request valid
} fuse_command_req_t;

Response Structure (fuse_command_resp_t):

typedef struct packed {
    data_t              data;       // Read data
    logic               status;     // Operation status
    logic               valid;      // Response valid
} fuse_command_resp_t;

Command Types:

  • FUSE_COMMAND_READ (2’b00): Read operation

  • FUSE_COMMAND_PROGRAM (2’b01): Program operation

  • FUSE_COMMAND_PROGRAM_READ_BACK (2’b10): Program with verification
