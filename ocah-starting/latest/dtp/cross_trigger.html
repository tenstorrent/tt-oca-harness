Cross-Trigger Operation

The Cross-Trigger Network (CTN) routes debug events between internal sources and external cross-trigger ports. Matrices select event destinations; ports provide wire-OR or point-to-point signaling at the chiplet boundary.

1. Event Routing

The CTN combines Cross-Trigger Matrices (CTMs) and Cross-Trigger Ports (CTPs). The port modes are configured before the matrix routes for an event path, and both before the participating debug sources are enabled.

2. Clock Stop

JTAG and CLA clock-stop requests feed the chiplet halt path. Clocks and Resets owns its aggregation, clock-domain crossing and reset behavior.

Clock-stop integration

3. Programming Reference

IP Reference groups the network, port and matrix descriptions. The CTN owns the unified register map; its component chapters describe routing and handshakes.

CTN Register Map

The Programmer’s Guide gives the cross-trigger programming sequence for the port modes and matrix routes referenced above.
