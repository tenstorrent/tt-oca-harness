Environment Setup

This document is currently under development.

  • Can we add an installation script to the repo?

  • Need to add requirements for tt-oca-manifest and tt-oca-harness-model

1. Python

We recommend the use of pyenv to ensure the correct version of python is in use. To install pyenv, visit their GitHub page, or run curl https://pyenv.run | bash.

The piping of a script from the internet as above, without checking it, is never safe. You should always check the contents of the script first to guarantee safety. This may be done using curl https://pyenv.run, which will print the script, instead of running it.

To install Python 3.11 with pyenv, first install the python build dependencies, and then Python 3.11 itself:

# Check Pyenv GitHub for up-to-date build environment
sudo apt update
sudo apt install make build-essential libssl-dev zlib1g-dev \
libbz2-dev libreadline-dev libsqlite3-dev curl git \
libncursesw5-dev xz-utils tk-dev libxml2-dev \
libxmlsec1-dev libffi-dev liblzma-dev libzstd-dev

pyenv install 3.11

From here, enter a pyenv shell, and install uv using the following commands:

pyenv shell 3.11

# In the shell
pip install uv

2. Repository

To clone the repository, ensure that you have git installed (sudo apt install git), and then run the following commands:

git clone https://github.com/tenstorrent/tt-oca-harness.git

cd tt-oca-harness

The repository’s open RTL, documentation, register generation, lint, and containerized firmware flows do not require submodules. The production SEP boot manifest tooling is an optional submodule that requires separate access; do not use --recursive for the public setup path.

3. Package Dependencies

Once the repository is cloned, install the required open source tools:

sudo apt install asciidoctor asciidoctor-pdf verilator gcc \
ccache picolibc-riscv64-unknown-elf cmake

Follow the instructions on the following pages for tools not packaged within Ubuntu:

  • Antora

  • Bender

  • Verible

  • Slang

  • Surfer (optional, alternatives available, used for wave trace debugging)

  • Drawio (optional, used for creating new diagrams for documentation)

  • Wavedrom (optional, used for creating new diagrams for documentation)

Enter the repository and use the following command to set up the Python environment:

uv sync # or `make uv-sync`

4. Containers

Certain workflows within the repository currently use a container, so a docker-compatible containerisation system is also required. We support docker and podman at this time, follow the installation guides to install either docker or podman below:

  • Podman (recommended)

  • Docker

If you installed podman, you’ll need to add the docker hub as a container registry to be able to pull the container, and have fuse-overlayfs installed:

sudo apt install -y fuse-overlayfs

sudo mkdir -p /etc/containers/registries.conf.d
cat <<'EOF' | sudo tee /etc/containers/registries.conf.d/docker.conf
unqualified-search-registries = ["docker.io"]
EOF
