Open Chiplet Atlas Harness (OCAH): Starting with OCAH

This document is currently under development.

  • The material on contribution may not be required at this point.

1. About this Guide

The Open Chiplet Atlas Harness (OCAH) is a chiplet design IP where the non-application-specific functions are integrated to form a chiplet design framework.

These non-application-specific functions include common chiplet subsystems like Security Processor (SEP), System Management Controller (SMC), System Management Network (SMN), AXI-over-UCIe bridge (AoU), Debug & Test Ports (DTP), etc.

This guide outlines how to get started with OCA Harness, including the use of the repository, licensing and guidelines for effective contribution.

2. Repository structure

The OCAH repository is organised as below

Path Contents

hw/common/

Shared RTL: primitives (ocah_prim, ocah_prim_generic), TL-UL, AXI network/monitor elements, register-flow makefiles.

hw/ip/

Reusable IP blocks, grouped by family where applicable (e.g. jtag/, uart/, cross_trigger/).

hw/sys/

Subsystems (smc, sep, smu, dtp) that integrate the IP blocks.

hw/top/

Top-level integration.

doc/

Documentation products (TRM, Integrator Guide, …)

vendor/

Third-party IP vendored via Bender

tools/, scripts/, nix/

Register-flow, documentation, and container helpers.
