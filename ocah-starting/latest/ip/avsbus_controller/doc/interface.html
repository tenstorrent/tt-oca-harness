Interface

The AVSBus Controller provides a configurable system bus interface (APB4 or AXI4-Lite), a two-wire AVSBus protocol interface, and clock/reset interfaces for system integration. Dual clock domain support enables flexible clock source selection for optimal timing and power management.

AVSBus Protocol Interface
AVSBus Signal Definition
Table 1. AVSBus Protocol Signals
Signal Name Width Direction Description

avs_clock_o

1

Output

avs_mdata_o

1

Output

Master data - Serial command transmission

avs_sdata_i

1

Input

Slave data - Serial response from target device

AVSBus Clock Characteristics: - Frequency: Programmable division of system clock (divide by 2-255) - Duty Cycle: Configurable 8-bit control (0-255 maps to 0-100%) - Clock Gating: Automatic gating during idle periods if enabled - Clock Domain: Independent from register interface clock

Serial Data Protocol: - avs_mdata_o: LSB-first serial transmission at avs_clock_o rate - Frame Length: 32 bits total (29 data + 3 CRC bits) - Bit Rate: 1 bit per avs_clock_o rising edge - Idle State: avs_mdata_o held high between transactions

Target Response Collection: - avs_sdata_i: Serial collection from target device - Response sampled on avs_clock_o edges - Target acknowledgment extracted from response frame

Interrupt Interface

Comprehensive interrupt generation for system-level event handling and status monitoring.

Table 10. Interrupt Output

Interrupt Sources and Control: - Command FIFO status events (full, empty, overflow) - Response FIFO status events (data available, full, underflow) - Transaction completion and error conditions - Target acknowledgment and timeout events - Protocol state changes and error recovery - Clock domain issues and reset events - Slave resync operations

Interrupt Configuration: - Individual interrupt source enable/disable control via AVS_INTERRUPT_MASK - Interrupt status register (AVS_INTERRUPT) with clear-on-write functionality (AVS_INTERRUPT_CLEAR) - Level triggering for all interrupt sources

Protocol Timing Specifications
AVSBus Timing Parameters

Clock Timing: - Minimum avs_clock_o period: 2 * clk_reg_i period - Maximum avs_clock_o frequency: clk_reg_i frequency / 2 - Duty cycle range: 10% to 90% (configurable) - Clock jitter tolerance: ±5% of clock period

Data Setup and Hold Times: - avs_mdata_o setup time: 1ns before avs_clock_o rising edge - avs_sdata_i setup time: 2ns before avs_clock_o rising edge - avs_sdata_i hold time: 1ns after avs_clock_o rising edge - Propagation delay: avs_clock_o to avs_mdata_o < 10ns

Transaction Timing: - Frame transmission time: 32 avs_clock_o cycles - Slave resync operation: 34 avs_clock_o cycles - Inter-frame gap: Automatic based on protocol state - Target response timeout: Configurable per application - Maximum transaction latency: Frame time + response time + processing overhead

System Integration Guidelines
Bus Interface Integration

APB4 Integration:

avsbus_controller_apb4 u_avs_ctrl (
    // APB4 interface
    .pclk_i     (apb_clk),
    .presetn_i  (apb_rst_n),
    .paddr_i    (apb_paddr[7:0]),   // 8-bit address for 256-byte space
    .psel_i     (apb_psel_avs),
    .penable_i  (apb_penable),
    .pwrite_i   (apb_pwrite),
    .pwdata_i   (apb_pwdata),
    .pstrb_i    (apb_pstrb),
    .pready_o   (apb_pready_avs),
    .prdata_o   (apb_prdata_avs),
    .pslverr_o  (apb_pslverr_avs),

    // Clock and reset
    .clk_reg_i  (apb_clk),
    .clk_ref_i  (ref_clk_100m),
    .rst_ni     (system_rst_n),
    .rst_clk_div_ni (system_rst_n),

    // AVSBus interface
    .avs_clock_o (avs_clk_out),
    .avs_mdata_o (avs_cmd_out),
    .avs_sdata_i (avs_response_in),

    // System interface
    .irq_o      (avs_irq)
);

    .bvalid_o   (axi_bvalid),
    .bready_i   (axi_bready),
    .bresp_o    (axi_bresp),

    // AXI4-Lite Read Channels
    .arvalid_i  (axi_arvalid),
    .arready_o  (axi_arready),
    .araddr_i   (axi_araddr[7:0]),
    .rvalid_o   (axi_rvalid),
    .rready_i   (axi_rready),
    .rdata_o    (axi_rdata),
    .rresp_o    (axi_rresp),

    // Clock and reset
    .clk_reg_i  (axi_clk),
    .clk_ref_i  (ref_clk_100m),
    .rst_ni     (system_rst_n),
    .rst_clk_div_ni (system_rst_n),

    // AVSBus interface
    .avs_clock_o (avs_clk_out),
    .avs_mdata_o (avs_cmd_out),
    .avs_sdata_i (avs_response_in),

    // System interface
    .irq_o      (avs_irq)
);
