1. SMC canonical bring-up and CSR signoff

This chapter defines the canonical bring-up and CSR signoff. Feature credit is the SCOPE matrix in SMC_SCOPE_TRACEABILITY.adoc. Live membership is hw/sys/smc/dv/testlists/all.toml. Launch is --dut smc (the TB instantiates smc_wrapper); there is no --dut smc_wrapper.

1.1. Live groups

The table lists the groups hw/sys/smc/dv/testlists/ defines; their sizes are the expected_count guards in hw/sys/smc/dv/testlists/all.toml.

Group Role

smoke

PR gate: canonical bring-up, cold reset, and a CSR frontdoor read

hosted

Nightly and weekly: all minus the seventeen leaves that need the RISC-V toolchain (fourteen fw leaves, three dual-target leaves that run a ROM or firmware image)

rtl_issue

Weekly on its own regress.yml row: defect reproducers graded under expect_fail; no bring-up credit

per_ip

One pass across every IP the bench drives

all

The package regression; all.toml names the leaves outside it and why, and SMC_DEFERRED_DISPOSITION.adoc records the leaves no scheduled tier runs
