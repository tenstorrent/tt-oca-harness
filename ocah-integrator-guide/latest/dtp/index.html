Debug & Test Ports (DTP)

The Debug & Test Ports (DTP) module provides debug and test infrastructure. It integrates the JTAG Interface Unit (JIU) and the Cross Trigger Network (CTN) into a single instantiable subsystem that exposes a standard external JTAG port, internal debug bridges, and a configurable cross-trigger fabric.

1. Capabilities

  • JTAG access — IEEE 1149.1-2013 Primary TAP with configurable Secondary TAPs for hierarchical multi-chiplet debug connectivity per IEEE 1838-2019 (3DIC).

  • iJTAG chains — IEEE 1687-2014 SIB-based chains for DFT secure, DFT non-secure, and DFD instrumentation, plus SMC and SEP OTP debug bridges.

  • JTAG2AXI bridges — SMC fabric, SMC OTP and SEP OTP debug access without system software.

  • Cross-trigger fabric — Configurable network (1–32 external CTPs, 0–32 internal cross triggers) supporting both wire-OR and point-to-point signalling per the Open Chiplet Cross Triggering (OCCT) specification.

  • Clock stop — Unified halt path combining JTAG DEBUG_CONTROL and CLA clock-stop requests, with separate CLA-only readback for software observation.

  • Lifecycle feature control — SEP-driven enable polarity gates eleven debug and test paths (five STAP/scan paths, three iJTAG chains and three JTAG2AXI bridges) independently.

2. Reading Route

Follow this order to understand the DTP:

  1. Architecture and Access Paths — how the JIU and CTN connect internally and how debug access reaches them through the SMU.

  2. JTAG Operation — DTP-level topology, scan chain ordering, clock domains, reset hierarchy and lifecycle feature control, before the per-component reference pages below.

  3. JTAG reference — JTAG Interface Unit, JTAG PTAP, JTAG STAP.

  4. Cross-trigger reference — Cross-Trigger Network (includes unified register map), Cross-Trigger Port, Cross-Trigger Matrix.

  5. Clock Stop / Reset — architecture of the combined JTAG and CLA halt path.

  6. Configuration and Reference — port table and parameter summary.

JTAG

JTAG Interface Unit ( architecture, interface)

IEEE 1149.1 primary and secondary TAP controller.

JTAG PTAP ( architecture, interface)

Primary TAP implementation and instruction decoder.

JTAG STAP ( architecture, interface)

Secondary TAP for hierarchical multi-chiplet connectivity.

Cross-trigger

Cross-Trigger Network ( architecture, interface, register map)

CTN hub integrating CTMs and CTPs; owns the unified register map.

Cross-Trigger Port ( architecture, interface)

External pad-ring interface for OCCT cross-chiplet triggering.

Cross-Trigger Matrix ( architecture, interface)

Configurable N×M routing matrix for internal cross triggers.
