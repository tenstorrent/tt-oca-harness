Project Defines

Compile-time defines that apply across OCAH rather than to a single block. Set the OCAH names in this chapter. Do not set vendor preprocessor names; hw/common/defs/ocah_vendor_defines.svh derives the aliases those names imply. OCAH lint and Yosys force-include that header. Native DV expands the same aliases onto the command line. An adopter compile must do one of those two.

A define in a header is visible only in compilation units that include it. Command-line `define / -D is global. Force-include (or the flow’s alias expansion) is what makes the mapping apply to vendored files that never include an OCAH header.

1. SIMULATION

SIMULATION selects the verification view of OCAH RTL. Set it on every simulation compile and on no other kind of build:

+define+SIMULATION   # VCS, Xcelium
-DSIMULATION         # Verilator, Icarus

OCAH’s own DV flows set it; a compile driven by an adopter’s testbench does not.

Do not let SIMULATION reach synthesis, formal, or a gate-level flow. It enables initial blocks, $readmemh, $random and DPI exports; a tool that skips those rather than rejecting them yields a netlist that does not correspond to the RTL you verified.

Without the define, these testbench hooks are not compiled in and the plusargs are silently ignored:

Plusarg Effect

+skip_fuse_sense

efuse_shadow_regs reports fuse sense complete immediately rather than sensing the bank through the adopter’s SHIM.

+smc_shadow_reg_preload=<file>, +sep_shadow_reg_preload=<file>

Loads the shadow registers from a hex image. Takes effect only alongside +skip_fuse_sense.

+rom_bin64=<file>, +rom_hex=<file>

Preloads OCAH4CORECluster_rom_ext, the SMC CPU ROM simulation model. Applies only to integrations that use the reference memory swaps.

The define also zeroes the RMA and security-disable token and digest bits in efuse_token_processing at time 0, which have no reset and otherwise power up X, and routes OpenTitan assertion failures in the SEP prim_assert shim to $error on non-UVM runs.

Two model families it enables make simulation deliberately non-deterministic: prim_flop_2sync and its Caliptra and Adams Bridge equivalents insert prim_cdc_rand_delay ahead of the synchronizer, and prim_lfsr and prim_double_lfsr randomize their default seed on simulators other than Verilator (+prim_lfsr_use_default_seed=1 pins it). Two runs of one test are therefore not identical unless the simulator seed is fixed; record the seed with any failure you intend to reproduce.

2. SYNTHESIS

SYNTHESIS selects the implementation view: simulation-only SVA, $readmemh preload, procedural delays, and similar non-synthesizable paths are omitted. Slang lint, Verilator lint, and Yosys set it (OCAH_FLOW_COMMON_DEFINES, or +define+SYNTHESIS=1 for Verilator lint). A Synopsys (Design Compiler, Fusion Compiler) or Cadence Genus synthesis compile must set it too; those tools may also predefine the name. Native DV does not, except the SMC dual target, which lists it next to SMC_DUAL. The open formal path (sby / read_slang) keeps it defined. Licensed formal backends leave it unset.

3. EMULATION

EMULATION is the reserved OCAH name for a synthesizable emulator view (Palladium, Zebu, and similar): assertions, cover, assume, and $display / $error / $fatal stay compiled, while procedural delays, random-init initial blocks, force/release, dump/$fopen tasks, and non-synthesizable real-time constructs do not.

The tree has no EMULATION gating. Setting the name does not select that view. Do not set SYNTHESIS in order to keep emulator debug hooks; SYNTHESIS strips assertions as well. Do not set PULP_FPGA_EMUL as a substitute: that name is an FPGA clock-mux path.

4. Tool predefined names

Simulators and frontends define these themselves. Restate them only on that tool’s compile line. Do not put them in a Bender filelist shared with other tools, and do not add a Bender target named verilator (flist-plus would emit +define+TARGET_VERILATOR into that shared .f).

Define Role

VERILATOR

Verilator’s predefine. First-party and OpenTitan SVA leave their include-assert macros undefined.

VCS

VCS predefine. Some PULP AXI files branch on it.

XCELIUM

Xcelium’s predefine. Native DV uses this tool.

XSIM

Vivado simulator. PULP assertion macros also treat it as off.

QUESTA

QuestaSim’s predefine. Some PULP AXI files branch on it.

YOSYS

Auto-defined by yosys-slang. The Yosys prim_assert.sv shim undefines it around the vendored header when SYNTHESIS is also set.

5. Native DV extras

An adopter that copies the native profile sees these in addition to SIMULATION. They are not required to elaborate OCAH RTL for silicon.

Define Role

RANDOM=0, RANDOMIZE_MEM_INIT, RANDOMIZE_REG_INIT, RANDOMIZE_DELAY=0.02

Chisel/FIRRTL random-init hooks on the generated SMC cluster. Native DV zero-fills rather than randomizing.

UVM

SV-UVM framework overlay. Assertion headers report through uvm_report_error. Adds the UVM harness block to shared testbench tops. Do not set it on a cocotb compile.

COMMON_CELLS_ASSERTS_OFF

Strips inline assertion blocks inside PULP common_cells modules. Native DV sets it on every tool (Verilator, VCS, Xcelium) from hw/common/dv/configs/profiles/native.toml. This spelling is the OCAH name.

ASSERTS_OFF

Turns off PULP OCAH_PULP_INC_ASSERT macros. Verilator DUT flags and Verilator lint set it; VCS and Xcelium native compiles do not.

6. Derived assertion gates

Do not set these. Headers define them from the view and tool names above.

Define Defined when

OCAH_INC_ASSERT

First-party concurrent SVA. ocah_assert.svh defines it only when SYNTHESIS, VERILATOR, and NO_OCAH_ASSERT are all absent.

OCAH_OT_INC_ASSERT

OpenTitan-derived SVA, from SYNTHESIS and VERILATOR (YOSYS forces it on).

OCAH_PULP_INC_ASSERT

PULP OCAH_PULP_ASSERT* macros, unless ASSERTS_OFF, SYNTHESIS, or XSIM is set.

NO_OCAH_ASSERT

Optional escape: drops first-party SVA only. No OCAH flow sets it.

7. Vendor aliases

ocah_vendor_defines.svh defines these from the OCAH names. Do not set the vendor column.

OCAH name Vendor alias

SYNTHESIS

SIMULATION

VERILATOR

XSIM

TARGET_XSIM

8. Adopter overlay hooks

No checked-in config sets these. An adopter overlay (run_dv.py --overlay) may append them.

Define Role

OCAH_JTAG_VENDOR_IF

Nests a commercial JTAG verification interface.

OCAH_AXI_VENDOR_IF

Nests a commercial AXI verification interface.
