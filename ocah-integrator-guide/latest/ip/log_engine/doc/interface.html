Interface

The OCA Log Engine provides multiple AXI4-Lite interfaces for register access, memory fetching, and UART communication.

Configuration Parameters
Parameter Default Description

NUM_LOG_ENTRIES

16

Number of independent log entries

MAX_LOG_SIZE

Configurable

Maximum log region size (must be multiple of 16)

ADDR_WIDTH

64

Address bus width for log region

DATA_WIDTH

32

Data bus width
Signal Interfaces
Global Interface
Table 1. Global Interface Signals
Signal Name Width Direction Active Description

clk_i

1

Input

Rising

System clock. All interfaces operate synchronously to this clock.

rst_ni

1

Input

Low

System reset. Asynchronous assertion and synchronous deassertion. Resets all state machines, counters, and FIFO to initial state.
DMA Interface

The DMA interface provides flow control coordination with the UART transmitter.

Table 2. DMA Interface Signals
Signal Name Width Direction Active Description

uart_tx_ready_i

1

Input

High

UART ready to accept character(s) for transmission. Used as flow control to prevent UART FIFO overflow.
Flow Control Operation:

  • The log write FSM waits for uart_tx_ready_i assertion before initiating write transfers

  • This prevents overwhelming the UART transmitter and maintains data integrity

  • Ready signal typically indicates UART FIFO has space for additional characters

Interrupt Interface

The interrupt interface provides error signaling to the system.

Table 3. Interrupt Interface Signals
Signal Name Width Direction Active Description

irq_o

1

Output

High

Interrupt request. Asserted when any enabled interrupt condition occurs.
Interrupt Sources:

  • LOG_FETCH_ERR: AXI4-Lite log fetch bus returned error response

  • LOG_WRITE_ERR: AXI4-Lite log write bus returned error response

Interrupt Control: * Individual enable bits in INTR_ENABLE register * Status bits in INTR_STATUS register (write-1-to-clear) * Test capability via INTR_TEST register
