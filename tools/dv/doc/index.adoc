= OCAH DV Tooling Guide
:doctype: book
:sectanchors:
:sectlinks:
:sectnums:
:source-highlighter: highlight.js
:imagesdir: assets

This guide describes the command-line tools used to launch OCAH design
verification (DV) and formal verification (FV) flows and to turn their results
into static reports:

* `tools/dv/run_dv.py` discovers and executes configured DUT flows.
* `tools/dv/run_dashboard.py` collects completed run results, renders reports,
  aggregates history, and publishes static output.

The guide documents the behavior of the tools in this source tree.

ifdef::backend-html5[]
== Building This Guide

`tools/dv/doc` is a standalone documentation source and is not staged by the
TRM/Antora build or documentation CI. Render all three HTML pages together so
the landing-page links resolve:

[source,bash]
----
out=$(mktemp -d "${TMPDIR:-/tmp}/ocah-dv-doc.XXXXXX")

asciidoctor -a data-uri -D "$out" \
  tools/dv/doc/index.adoc \
  tools/dv/doc/run-dv.adoc \
  tools/dv/doc/run-dashboard.adoc

asciidoctor-pdf \
  -o "$out/ocah-dv-tooling-guide.pdf" \
  tools/dv/doc/index.adoc
----
endif::backend-html5[]
