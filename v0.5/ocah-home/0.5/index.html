Open Chiplet Atlas (OCA) Harness

The Open Chiplet Atlas (OCA) Harness is an OCA architecture compliant, open-source chiplet framework: a reusable implementation vehicle for the Open Chiplet Atlas (OCA) standard. It packages the common, non-differentiating infrastructure every chiplet needs — security, boot, system management, debug, test, and die-to-die integration — so adopters can focus their effort on their own value-differentiating application logic.

OCA Harness is the Harness pillar of the wider Open Chiplet Atlas (OCA) ecosystem, alongside the OCA Architecture specification and the OCA Compliance program.

Ecosystem repositories

The OCA Harness ecosystem itself spans a small family of Tenstorrent-owned repositories, each covering a distinct part of building and using OCA Harness:

OCA Harness also reuses third-party open-source IP rather than reimplementing it. Tenstorrent generally maintains a fork of each such dependency to support coordinated development, keeps it synchronized with the upstream project, and contributes suitable changes back upstream where possible. The exact revisions and subsets imported into this repository are defined in Bender.yml; the Getting Started Guide explains how Bender materializes and updates them.
