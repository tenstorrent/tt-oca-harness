Peripherals

SEP peripherals provide data movement, mailboxes, external I/O and watchdog services. Reset control is described in Clocks and Resets; OTP and lifecycle controls are described in Security and Lifecycle.

  • Direct Memory Access (DMA)

  • Mailboxes

  • Peripheral Subsystem

  • Serial Peripheral Interface (SPI)

  • Watchdog Timer (WDT)

For related controls, see Security and Lifecycle and Clocks and Resets.
