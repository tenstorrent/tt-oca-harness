sep_system_peripherals_xbar_pkg

Define types and configuration for the SEP system-peripherals AXI crossbar.

Address decode rules live in sep_system_peripherals_xbar rather than this package; the named address-range constants here mirror its smn_inbound_from_xbar and mailbox rules and are not referenced by the crossbar. Its system_csr rules take each register block's bounds from sep_top_addrmap_pkg. Both initiators connect to all three targets.
