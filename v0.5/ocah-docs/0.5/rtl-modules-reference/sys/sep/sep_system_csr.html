sep_system_csr

Publish SEP system CSRs for remap, filters, straps, and bridge-fault status.

Exposes alias and output remap register hwifs, inbound and outbound filter ctrl/status, aperture address/size outputs, NMI vector, external TRNG source select, Key Manager wipe, and DMA/peripheral bus-error status/clear.

An AXI-Lite demux decodes the local-master alias remap, AP and STEE output remap, outbound and inbound filter, sep_cpu_ctrl, and cold and warm scratch windows; any other address reaches a DECERR slave. The cold scratch registers reset on rst_ni and the warm ones on rst_warm_ni; everything else resets on rst_ni. REFERENCE_COUNTER counts clk_ref_i and is read through a CDC into clk_i; a software write loads it.
