OCAH UART & Log Engine Wrapper

1. Description

The OCAH UART & Log Engine Wrapper is a hardware module that integrates an UART 16550 with a Log Engine. This wrapper is designed to facilitate communication between the UART and the log engine, allowing for logging capabilities.

2. Features

The features of this design include:

  • An UART 16550

  • An optional Log Engine

  • Configurable APB4 or AXI4-Lite register interface
