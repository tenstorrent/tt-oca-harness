Haohao Liao

Added Key Manager key-management architecture: per-UID software/hardware root keys, deterministic UID-derived key hierarchy, requester-selected chip configuration, configuration-tied key revocation, ECC key metadata in signatures, and user input keys.

0.5.6

2026-06-06

Haohao Liao

Refined the SEP Lifecycle Controller feature-control section per review: reordered it to define the disable vector (SIP_DIS / SYS_DIS) before the per-LC-state feature-control result, added an Overrides and Final Gates description (SEC_DIS override and the SECURE_TM final gate on the test group), and removed the obsolete screening/diagnostic test definitions.

0.5.7

2026-06-07

Haohao Liao

Key Manager: moved UID and hardware-root-key read-locks to the warm reset domain (re-applied by ROM on every boot), matching the warm-reset KM CPU.

0.5.8

2026-06-09

Haohao Liao

Updated Key Manager spec per review feedback: clarified OTP inputs (UIDs and life-cycle hardwired; demotion from LCC), the eFuse access path, KDF concatenation notation, 512-bit user_input, and mailbox-only user-input-key injection.

0.5.9

2026-06-10

Haohao Liao

0.5.10

2026-06-11

Alessandro Ottaviano

Documented PLIC and mie CSR software initialization requirements before enabling external interrupts.

0.5.11

Fixed contradictory descriptions across the SEP spec following the Lifecycle Controller update.

0.5.12

2026-06-17
