1. Dependencies

This section is currently under development. Content has been taken verbatim from existing documentation. More content will be added as the project matures.

This section outlines the system requirements and dependencies for the OCAH project.

1.1. System Requirements

  • Linux Distribution: Ubuntu 20.04+ or CentOS 8+

  • Python: Version 3.9.18 or later

  • Memory: Minimum 16GB RAM recommended for full builds

  • Storage: Minimum 50GB available disk space

1.2. Python Dependencies

The project uses a Python virtual environment for SystemRDL and documentation tools:

  • PeakRDL: SystemRDL processing and RTL generation

  • Asciidoctor: AsciiDoc documentation processing and PDF generation

  • Antora: Multi-repository documentation site generator for AsciiDoc

  • Python packages: Managed by the repo-level pyproject.toml and uv.lock; run make uv-sync or uv sync from the repository root.

1.3. Hardware Requirements

For simulation and synthesis:

  • CPU: Multi-core processor (8+ cores recommended)

  • RAM: 16GB minimum, 32GB recommended for large designs

  • Storage: SSD recommended for build performance

1.4. License Requirements

  • Open Source Tools: No additional licenses required

  • Commercial Tools: Valid licenses required for VCS, Design Compiler, etc.

  • Dependencies: Some external IPs may have specific license requirements

1.5. Environment Setup

Refer to the project setup documentation for detailed installation instructions of these dependencies.
